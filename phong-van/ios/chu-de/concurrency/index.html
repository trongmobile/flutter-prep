Junior iOS Junior

Mọi chủ đề Junior →
  • Gọi API bằng URLSession rồi gán dữ liệu và tableView.reloadData() ngay trong completion; đôi khi UI không cập nhật, Xcode hiện cảnh báo tím của Main Thread Checker. Vì sao và sửa thế nào?
  • Phân biệt serial queue với concurrent queue, sync với async trong GCD. Cần một logger được gọi từ nhiều thread trong app thì bạn thiết kế thế nào?
  • Một bạn viết DispatchQueue.main.sync { ... } trong viewDidLoad để "chắc chắn chạy trên main" và app crash ngay khi mở màn hình. Giải thích vì sao.
  • Màn hình Home cần gọi song song 3 API (banner, danh mục, sản phẩm) và chỉ tắt loading khi cả 3 xong. Bạn làm bằng GCD thế nào, cần tránh lỗi gì?
  • Luồng tải ảnh gồm các bước tải về, áp filter rồi lưu cache, và phải huỷ được cả chuỗi khi người dùng rời màn hình. Khi nào bạn chọn OperationQueue thay vì GCD, và gọi cancel() lên một Operation có dừng ngay việc đang chạy không?
  • Bạn viết let user = try await api.fetchUser() trong viewDidLoad và compiler báo 'async' call in a function that does not support concurrency. Vì sao, xử lý thế nào, và sau await cập nhật label có cần DispatchQueue.main.async không?
  • Trong viewDidLoad (main thread), code trộn main.async và global().sync. Thứ tự in ra là gì? Quiz
  • Hai lệnh async và một lệnh sync được đưa vào cùng một queue tạo bằng DispatchQueue(label:). Thứ tự in ra là gì? Quiz
  • Nhiều thread cùng append vào một biến var results: [Int] dùng chung, ví dụ bên trong DispatchQueue.concurrentPerform. Điều gì có thể xảy ra? Quiz
  • Người dùng bấm mở một tài liệu lớn và đang chờ nó hiện ra; việc đọc và parse file chạy trên DispatchQueue.global(qos:). QoS nào phù hợp nhất? Quiz
  • Bạn debounce ô tìm kiếm bằng DispatchWorkItem: mỗi lần gõ thì cancel() item cũ và asyncAfter một item mới sau 0,3 giây. Phát biểu nào đúng về cancel()? Quiz

Middle iOS Middle

Mọi chủ đề Middle →
  • Màn Home cần gọi 3 API độc lập (profile, banner, khuyến mãi), còn màn danh sách phải tải thumbnail cho N sản phẩm. Bạn dùng async let hay TaskGroup cho từng trường hợp? Nếu một request throw thì các request còn lại ra sao?
  • Bạn đưa logic refresh token vào một actor để tránh race condition, nhưng log vẫn cho thấy API refresh bị gọi 2–3 lần khi nhiều request cùng gặp 401. Vì sao actor không chặn được, và sửa thế nào?
  • ViewModel gán @Published từ completion handler của URLSession và Xcode báo tím "Publishing changes from background threads is not allowed". Với Swift Concurrency, bạn sửa thế nào cho triệt để thay vì rải DispatchQueue.main.async khắp nơi?
  • Ô search gọi API mỗi khi user gõ, và kết quả của từ khoá cũ đôi khi về sau, đè lên kết quả mới. Bạn huỷ request cũ thế nào? Gọi task.cancel() thì code trong task có dừng ngay không?
  • Team còn dùng một SDK cũ chỉ có API dạng callback. Bạn bọc nó thành hàm async thế nào, và bẫy nào có thể khiến app crash hoặc treo?

  • Codebase đang dùng Combine cho màn search (debounce, removeDuplicates, flatMap). Team muốn chuyển sang async/await. Combine và AsyncSequence khác nhau ở điểm nào, phần nào nên giữ Combine?
  • Giả sử fetchA() và fetchB() độc lập, mỗi hàm mất khoảng 1 giây. Hai cách viết dưới đây mất bao lâu? Quiz
  • Task group dưới đây thêm task theo thứ tự 3, 1, 2 với thời gian ngủ tỉ lệ theo n. Mảng result in ra là gì? Quiz
  • Điều gì xảy ra với task sau khi gọi task.cancel()? Quiz
