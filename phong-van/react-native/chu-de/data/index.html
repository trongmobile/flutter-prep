Junior React Native Junior

Mọi chủ đề Junior →
  • Màn hình chi tiết sản phẩm gọi API theo id trong useEffect. Bạn tổ chức trạng thái loading/error thế nào, và cần xử lý gì khi người dùng thoát màn hình hoặc đổi id trước khi request xong?
  • Team định dùng AsyncStorage để lưu danh sách vài nghìn sản phẩm cho chế độ offline cùng với cài đặt người dùng. Bạn góp ý gì?
  • Người dùng vào thang máy mất mạng, app cứ quay spinner rồi báo lỗi chung chung, và khi có mạng lại thì phải tự kéo để làm mới. Bạn phát hiện trạng thái mạng bằng gì, hiện banner offline thế nào, và cần để ý gì giữa isConnected với isInternetReachable?
  • API trả 401 khi access token hết hạn. Bạn viết interceptor Axios để tự gắn token và tự làm mới token, nhưng khi màn Home bắn 4 request cùng lúc thì app gọi /refresh tới 4 lần, và có lần người dùng bị đăng xuất oan. Nguyên nhân và cách xử lý?
  • API gateway trả HTTP 502 kèm một trang lỗi HTML. Đoạn code sau in ra gì? Quiz
  • Người dùng đã xem onboarding, nhưng mỗi lần mở app màn Onboarding vẫn hiện chớp một nhịp rồi mới sang Home. Nguyên nhân là gì? Quiz
  • Mạng yếu khiến request treo rất lâu. Bạn muốn fetch tự huỷ nếu sau 10 giây chưa xong. Cách nào đúng? Quiz
  • Server trả về HTTP 401. Với cấu hình mặc định, fetch và axios khác nhau thế nào? Quiz
