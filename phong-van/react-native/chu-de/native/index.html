Junior React Native Junior

Mọi chủ đề Junior →
  • Dự án vừa nâng lên bản React Native chạy New Architecture mặc định. Giải thích ngắn gọn New Architecture khác kiến trúc cũ (bridge) ở đâu, và khi thêm một thư viện native mới bạn cần kiểm tra gì?
  • README cũ của một thư viện native (ví dụ react-native-keychain) vẫn hướng dẫn chạy react-native link và sửa tay MainApplication, Podfile. Với React Native hiện tại, autolinking làm thay bạn những gì, và bạn vẫn phải tự làm bước nào?
  • Điểm khác biệt cốt lõi giữa JSI (New Architecture) và bridge của kiến trúc cũ là gì? Quiz
  • Trên Android, người dùng đã từ chối quyền camera tới mức hệ thống không hỏi lại nữa. Gọi PermissionsAndroid.request(PermissionsAndroid.PERMISSIONS.CAMERA) lúc này thì sao? Quiz
  • Code xin quyền camera trên iOS nhưng quên khai báo NSCameraUsageDescription trong Info.plist. Điều gì xảy ra khi app truy cập camera? Quiz

Middle React Native Middle

Mọi chủ đề Middle →
  • Bạn cần viết một Turbo Native Module đọc mức pin cho cả Android và iOS. Các bước với Codegen là gì, và được lợi gì so với native module kiểu cũ?
  • Native module cần đẩy sự kiện liên tục lên JS (vị trí GPS, tiến độ tải file). Bạn làm thế nào ở cả hai phía, và cần chú ý gì để không rò rỉ?
  • Khi nào cần viết Fabric Native Component thay vì Turbo Native Module? Props và event của component được khai báo thế nào?
  • Trong file spec của Turbo Native Module, TurboModuleRegistry.getEnforcing khác TurboModuleRegistry.get ở điểm nào? Quiz
  • Đã cấu hình codegenConfig với jsSrcsDir đúng thư mục, nhưng Codegen không sinh gì cho module có spec tên BatterySpec.ts. Nguyên nhân hợp lý nhất? Quiz
  • Module iOS kế thừa RCTEventEmitter liên tục gửi sự kiện ngay cả khi JS chưa có listener, Xcode log cảnh báo. Cách xử lý đúng là gì? Quiz
  • Cần nhúng một map view viết bằng native, có prop zoomLevel và event onRegionChange. Nên viết gì? Quiz

Senior React Native Senior

Mọi chủ đề Senior →
  • Ở kiến trúc cũ, mọi lời gọi giữa JS và native đi qua bridge. Bridge có những giới hạn gì, JSI khắc phục chúng ra sao, và dùng JSI có bẫy gì?
  • Fabric thay renderer cũ như thế nào? Những lợi ích nào của Fabric mà user và dev thực sự cảm nhận được?
  • Team bạn duy trì một TurboModule nội bộ (thanh toán, sinh trắc học) dùng chung cho 3 app, các app đều phát hành JS qua OTA. Khi cần thêm method hoặc đổi kiểu trong spec, bạn đặt quy trình gì để không làm vỡ app đang chạy?
  • App của bạn vẫn chạy kiến trúc cũ với khoảng 60 thư viện native bên thứ ba. Bạn lên kế hoạch chuyển sang New Architecture thế nào để không làm vỡ production?
  • Công ty muốn nhúng vài màn React Native vào app native Android/iOS đang chạy (brownfield). Những vấn đề kỹ thuật chính bạn phải thiết kế là gì?
  • Native module Android giữ một listener cảm biến và gọi callback sang JS. Sau khi reload JS từ dev menu (process vẫn sống), app thỉnh thoảng crash vì listener cũ vẫn bắn sự kiện vào React instance đã bị huỷ. Cách xử lý đúng là gì? Quiz
  • Một TurboModule có method đồng bộ đọc và giải mã file mất khoảng 300ms, được gọi trong onPress. Khi user bấm nút, điều gì xảy ra? Quiz
  • Trong một C++ TurboModule, việc tải file chạy trên thread nền và khi xong cần gọi callback JS mà module đã lưu lại. Cách làm đúng là gì? Quiz
  • Mô tả nào đúng về cách Fabric xử lý một cập nhật UI sau khi React render xong? Quiz
  • Sau khi bật New Architecture, một native component cũ viết theo kiểu requireNativeComponent (chưa có Codegen) vẫn hiển thị bình thường. Cơ chế nào giúp điều này? Quiz
  • Native module đọc cảm biến gửi khoảng 200 event mỗi giây sang JS để vẽ một chỉ số trên màn hình. JS thread nghẽn, các thao tác khác đều trễ. Hướng xử lý hợp lý nhất? Quiz
  • App native nhúng 5 màn React Native (brownfield); code hiện tại tạo mới một React host/instance mỗi lần mở một màn RN. Hậu quả chính là gì? Quiz
  • Sau khi migrate 40 native module cũ sang TurboModule mà không đổi logic, thời gian khởi động giảm rõ rệt. Lý do chính là gì? Quiz
