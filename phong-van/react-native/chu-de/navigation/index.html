Fresher React Native Fresher

Mọi chủ đề Fresher →
  • Trong stack navigator của React Navigation, navigate, push, goBack và popToTop khác nhau thế nào?
  • Truyền dữ liệu sang màn hình khác bằng params thế nào? Nên truyền cả object sản phẩm hay chỉ truyền id?
  • Trong stack navigator, đang ở màn Product với params { id: 1 }, gọi navigation.navigate('Product', { id: 2 }). Kết quả là gì? Quiz
  • Màn OrderDetail được mở bằng navigation.navigate('OrderDetail', { orderId: 7 }). Bên trong màn hình, đọc orderId thế nào? Quiz
  • Luồng màn hình là Home → Cart → Checkout → Success. Ở Success, nút "Về trang chủ" cần quay về Home và bỏ các màn ở giữa. Dùng gì? Quiz

Junior React Native Junior

Mọi chủ đề Junior →
  • App có bottom tab (Home, Đơn hàng, Tài khoản). Khi mở màn hình Chi tiết sản phẩm từ tab Home thì tab bar vẫn hiện bên dưới, trong khi thiết kế yêu cầu ẩn. Bạn tổ chức navigator thế nào?
  • Marketing muốn gửi link myshop://product/42 để mở thẳng màn hình chi tiết sản phẩm. Bạn cấu hình deep link với React Navigation thế nào, và có bẫy gì khi người dùng bấm back từ màn hình đó?
  • Người dùng rời tab Giỏ hàng sang tab khác thêm sản phẩm rồi quay lại, nhưng Giỏ hàng vẫn hiện dữ liệu cũ dù đã gọi API trong useEffect. Vì sao, và dùng useFocusEffect thế nào cho đúng?
  • Đoạn code sau nằm trong một màn hình đang được focus. Nó có vấn đề gì? Quiz
  • Trong Bottom Tab, người dùng chuyển từ tab Home sang Profile rồi quay lại Home. useEffect(() => { ... }, []) của màn hình Home có chạy lại không? Quiz
  • Stack gốc có màn hình Main chứa Bottom Tab (Home, Settings). Từ một màn hình khác của Stack gốc, lời gọi nào mở đúng tab Settings? Quiz
  • Màn soạn bài viết cần hỏi xác nhận trước khi rời màn nếu còn nội dung chưa lưu, dù người dùng bấm back trên header hay nút back cứng của Android. Với React Navigation, cách nào phù hợp? Quiz
  • Để link myshop://product/42 mở màn hình Product với id là '42' trong React Navigation, ngoài phần đăng ký scheme ở native, bạn cần làm gì? Quiz
