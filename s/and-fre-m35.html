Muốn truyền cả object Product qua Intent sang màn khác, cách được khuyến nghị trên Android là gì?

  1. ALưu vào biến static toàn cục rồi màn kia đọc ra
  2. BImplement Serializable vì nó nhanh hơn Parcelable
  3. CImplement Parcelable, trong Kotlin dùng @Parcelize
  4. DGọi putExtra("product", product) không cần implement gì
Xem đáp án
Đáp án đúng: C
Parcelable là cơ chế serialize được tối ưu cho Android, và plugin kotlin-parcelize sinh code tự động qua @Parcelize. Serializable cũng chạy được nhưng chậm hơn do dùng reflection; biến static mất khi process bị huỷ, còn putExtra không nhận object tuỳ ý nếu class không implement một trong hai interface đó.
