User đã có property id, nhưng List(users) vẫn báo lỗi compile. Cách sửa gọn nhất là gì?

struct User {
  let id: Int
  let name: String
}

struct UserList: View {
  let users: [User]
  var body: some View {
    List(users) { user in Text(user.name) }
  }
}
  1. ACho User conform Identifiable
  2. BĐổi User từ struct sang class
  3. CĐổi kiểu của id thành UUID
  4. DThêm @State cho property users
Xem đáp án
Đáp án đúng: A
List khi không truyền tham số id yêu cầu phần tử conform Identifiable; chỉ có property tên id là chưa đủ, phải khai báo conform và property id sẵn có sẽ thoả requirement. Cách khác là viết List(users, id: \.id); kiểu của id chỉ cần Hashable, không bắt buộc là UUID.
