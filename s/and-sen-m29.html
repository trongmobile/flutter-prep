Luồng bình thường không lỗi, nhưng Crashlytics báo UninitializedPropertyAccessException ở CheckoutActivity khi user quay lại app sau thời gian dài ở background. Nguyên nhân là gì?

object Session {
  lateinit var user: User // gán ở LoginActivity sau khi đăng nhập
}

class CheckoutActivity : AppCompatActivity() {
  override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    title = Session.user.name
  }
}
  1. AProcess mới tạo lại thẳng CheckoutActivity, chỗ gán user chưa chạy
  2. BGC thu hồi object Session khi app nằm lâu ở background
  3. Clateinit không thread-safe nên giá trị mất khi đổi Activity
  4. DHệ thống khôi phục Session từ Bundle nhưng bỏ qua field lateinit

Đáp án đúng: A
Sau process death, hệ thống khôi phục back stack và tạo CheckoutActivity trong process mới; LoginActivity không chạy lại nên Session.user chưa bao giờ được gán. Singleton không bị GC khi process còn sống và cũng không được hệ thống lưu lại, nên hãy lưu session bền (DataStore, DB) hoặc load lại khi màn hình khởi tạo.
