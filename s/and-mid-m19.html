Lambda truyền vào hàm inline có lệnh return trần. Gọi main() in ra gì?

inline fun repeatTwice(block: () -> Unit) {
  block()
  block()
}

fun main() {
  repeatTwice {
    println("x")
    return
  }
  println("end")
}

Đáp án đúng: A
Lambda của hàm inline được chép vào chỗ gọi nên return là non-local return, thoát luôn khỏi main() ngay lần gọi block() đầu tiên. Muốn chỉ thoát lambda thì dùng return@repeatTwice; nếu hàm không inline thì return trần mới là lỗi compile.
