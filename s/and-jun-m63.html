Mỗi lần người dùng gõ vào ô tìm kiếm, query đổi và ProductScreen recompose. Đoạn code sau có vấn đề hiệu năng gì và nên sửa thế nào?

@Composable
fun ProductScreen(
  products: List<Product>, // vài nghìn phần tử
  query: String,
  onQueryChange: (String) -> Unit,
) {
  val sorted = products.sortedBy { it.price }
  Column {
    SearchField(query, onQueryChange)
    LazyColumn { items(sorted, key = { it.id }) { ProductRow(it) } }
  }
}
  1. AsortedBy chạy lại ở mỗi lần recompose dù products không đổi; bọc trong remember(products)
  2. BsortedBy sửa thẳng products gốc nên làm hỏng state; phải đổi sang sortBy để sửa tại chỗ
  3. CCompose cấm gọi sortedBy trong composable; phải sắp xếp trong LaunchedEffect rồi gán vào biến cục bộ
  4. DLazyColumn sắp xếp lại danh sách mỗi khi cuộn; chỉ cần bỏ tham số key là hết sắp xếp lặp
Xem đáp án
Đáp án đúng: A
Thân composable có thể chạy lại bất cứ lúc nào, ở đây là mỗi ký tự gõ vào ô tìm kiếm, nên phép sắp xếp vài nghìn phần tử bị làm đi làm lại. remember(products) { products.sortedBy { it.price } } giữ kết quả và chỉ tính lại khi products đổi; tốt hơn nữa là sắp xếp sẵn ở ViewModel hay tầng data. sortedBy trả về list mới chứ không đụng list gốc, gán biến cục bộ trong LaunchedEffect không kích hoạt recompose, còn key chỉ định danh item chứ không liên quan tới sắp xếp.
