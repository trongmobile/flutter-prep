Vòng lặp dùng var kết hợp setTimeout dưới đây in ra gì?

for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 0);
}
  1. A0 1 2
  2. B3 3 3
  3. C0 0 0
  4. D2 2 2
Xem đáp án
Đáp án đúng: B
var có phạm vi theo function nên cả vòng lặp chỉ có một biến i dùng chung; các callback chạy sau khi vòng lặp kết thúc, lúc đó i đã là 3. Đổi sang let thì mỗi vòng lặp có một binding riêng và kết quả là 0 1 2.
