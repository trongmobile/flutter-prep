Sau khi app lên iPad, user báo layout vỡ khi dùng Split View, kéo cửa sổ Stage Manager hoặc xoay máy, còn màn danh sách chỉ là một cột kéo giãn kín màn hình. Bạn thiết kế UI thích ứng cho iPad và đa nhiệm thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đừng đoán theo thiết bị. UIScreen.main.bounds, UIDevice.current.orientation hay userInterfaceIdiom == .pad đều sai khi cửa sổ không còn là toàn màn hình: Split View, Slide Over và Stage Manager làm kích thước cửa sổ đổi liên tục. Layout phải phản ứng với kích thước của chính container và với size class: iPad toàn màn hình là regular width, nhưng ở Split View 1/3 hay Slide Over lại là compact width. Với SwiftUI: @Environment(\.horizontalSizeClass); ViewThatFits chọn bố cục đầu tiên vừa chỗ; LazyVGrid với GridItem(.adaptive(minimum:)) tự đổi số cột; NavigationSplitView (hai hoặc ba cột) tự thu thành stack ở compact width và giữ selection khi đổi. Với UIKit: UISplitViewController (style .doubleColumn hay .tripleColumn) tự collapse, còn UICollectionViewCompositionalLayout đọc layoutEnvironment.container.effectiveContentSize để đổi số cột khi cửa sổ đổi. Khai UIRequiresFullScreen hoặc khoá orientation sẽ loại app khỏi đa nhiệm, nên tránh. Cũng nên tính tới những thứ người dùng iPad kỳ vọng: bàn phím phần cứng (phím tắt, focus), pointer hover, kéo thả và nhiều cửa sổ qua scene. Kiểm thử bằng iPad simulator ở nhiều kích thước cửa sổ và Xcode Previews trên nhiều thiết bị, không chỉ xoay dọc ngang. Bẫy hay gặp: hard-code chiều rộng, popover và sheet neo sai vị trí khi cửa sổ nhỏ, và state điều hướng bị mất khi cửa sổ chuyển giữa compact và regular.
struct ShopRoot: View {
  @State private var category: Category.ID?
  @State private var product: Product.ID?

  var body: some View {
    // Compact width tự thu thành stack, regular width hiện đủ ba cột
    NavigationSplitView {
      CategoryList(selection: $category)
    } content: {
      ProductList(category: category, selection: $product)
    } detail: {
      if let product {
        ProductDetail(id: product)
      } else {
        ContentUnavailableView("Chọn một sản phẩm", systemImage: "bag")
      }
    }
  }
}

struct ActionBar: View {
  var body: some View {
    // Chọn bố cục đầu tiên vừa chỗ, thay cho việc đoán theo loại thiết bị
    ViewThatFits(in: .horizontal) {
      HStack { Button("Mua ngay") {}; Button("Thêm vào giỏ") {}; Button("Chia sẻ") {} }
      VStack { Button("Mua ngay") {}; Button("Thêm vào giỏ") {} }
    }
  }
}
