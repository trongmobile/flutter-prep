Khi người dùng bật dark mode, nền một số màn vẫn trắng nhưng chữ của TextInput và thư viện bên thứ ba lại chuyển sang trắng nên không đọc được; đổi chế độ lúc app đang chạy thì màn đổi, màn không. Bạn hỗ trợ dark mode trong React Native thế nào: useColorScheme, theme provider, StatusBar, và những bẫy nào hay gặp?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
useColorScheme() của react-native trả về 'light', 'dark' (hoặc null) và làm component render lại khi người dùng đổi chế độ hệ thống. Gọi nó ở một nơi duy nhất, thường là ThemeProvider, để chọn bộ màu rồi phát qua Context; component lấy màu theo tên ngữ nghĩa (background, text, border) qua hook useTheme() thay vì hardcode #fff/#000. Bẫy hay gặp: StyleSheet.create ở cấp module chỉ chạy một lần nên màu trong đó không đổi theo theme, hãy tạo style theo theme (hàm makeStyles(theme) kèm useMemo) hoặc đặt màu inline; Appearance.getColorScheme() gọi một lần ở đầu file chỉ là ảnh chụp tại thời điểm đó. Đổi StatusBar theo theme, truyền theme (DefaultTheme/DarkTheme hoặc theme tuỳ chỉnh) cho NavigationContainer để header và tab bar đổi theo, kiểm tra icon và ảnh có nền trong suốt. Với Expo cần đặt userInterfaceStyle là automatic trong app config, nếu không app có thể bị khoá ở giao diện sáng. Muốn cho người dùng chọn Sáng/Tối/Theo hệ thống thì lưu lựa chọn rồi tự quản lý trong Context.
const palettes = {
  light: { background: '#FFFFFF', text: '#111111', border: '#E5E5E5' },
  dark: { background: '#121212', text: '#F2F2F2', border: '#2C2C2C' },
};

const ThemeContext = createContext(palettes.light);
export const useTheme = () => useContext(ThemeContext);

export function ThemeProvider({ children }: { children: ReactNode }) {
  const scheme = useColorScheme(); // render lại khi người dùng đổi chế độ hệ thống
  const isDark = scheme === 'dark';

  return (
    <ThemeContext.Provider value={isDark ? palettes.dark : palettes.light}>
      <StatusBar barStyle={isDark ? 'light-content' : 'dark-content'} />
      {children}
    </ThemeContext.Provider>
  );
}

function Card({ title }: { title: string }) {
  const theme = useTheme();
  return (
    <View style={{ backgroundColor: theme.background, borderColor: theme.border }}>
      <Text style={{ color: theme.text }}>{title}</Text>
    </View>
  );
}
