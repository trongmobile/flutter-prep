Màn chat log toàn bộ payload của mỗi message WebSocket như dưới. Ở bản release, phát biểu nào đúng?

socket.onmessage = (e) => {
  console.log('WS message', JSON.parse(e.data)); // payload vài chục KB
  handleMessage(JSON.parse(e.data));
};
  1. Aconsole.log vẫn chạy ở release, tốn JS thread; nên gỡ bằng plugin Babel
  2. BMetro tự xoá mọi console.log khi build release nên không ảnh hưởng gì
  3. Cconsole.log chỉ tốn thời gian khi đang mở React Native DevTools để debug
  4. DHermes bỏ qua console.log ở release, chỉ còn chi phí JSON.parse hai lần
Xem đáp án
Đáp án đúng: A
Bundle release không tự loại bỏ console.*; các lời gọi vẫn chạy (định dạng object, ghi ra log hệ thống) và với payload lớn trong đường nóng có thể chiếm đáng kể JS thread. Tài liệu performance của RN khuyên dùng babel-plugin-transform-remove-console cho production; đoạn code còn JSON.parse hai lần không cần thiết.
