Header parallax cần dịch theo scrollState.value. Cách viết nào vừa cho header di chuyển đúng vừa không làm recompose mỗi frame khi cuộn?

  1. AModifier.offset(y = (scrollState.value / 2).dp)
  2. BModifier.offset { IntOffset(0, scrollState.value / 2) }
  3. Cval y = remember { scrollState.value / 2 } rồi Modifier.offset(y = y.dp)
  4. Dval y by remember { derivedStateOf { scrollState.value / 2 } } rồi Modifier.offset(y = y.dp)
Xem đáp án
Đáp án đúng: B
Lambda của Modifier.offset { } chạy ở phase layout nên đọc scrollState.value ở đó chỉ làm layout lại, bỏ qua composition. derivedStateOf không giúp gì vì giá trị dẫn xuất vẫn đổi liên tục khi cuộn, còn remember không key chỉ tính một lần nên header đứng yên.
