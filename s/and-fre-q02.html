Kotlin chống NullPointerException bằng cách nào? Giải thích ?., ?: và !! qua ví dụ.

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Kotlin tách kiểu non-null (String) và nullable (String?); compiler không cho gọi thẳng method trên kiểu nullable, nên phần lớn lỗi null bị chặn ngay lúc compile thay vì crash lúc chạy. ?. (safe call) chỉ gọi khi giá trị khác null, ngược lại cả biểu thức trả về null. ?: (Elvis) đưa ra giá trị thay thế khi vế trái là null, hay dùng kèm return để thoát sớm khỏi hàm. !! ép về non-null và ném NullPointerException nếu giá trị đang là null, nên chỉ dùng khi thật sự chắc chắn; thấy !! rải rác khắp code thường là dấu hiệu xử lý null chưa tốt.
fun greet(name: String?) {
  val length = name?.length ?: 0   // null thì lấy 0
  println("Độ dài: $length")

  val upper = name?.uppercase()     // kiểu String?
  println(upper)                    // có thể in ra null

  println(name!!.length)            // name null -> NullPointerException
}
