Team dùng Expo cần ba loại build: development (có dev client), preview (cho QA cài thử nội bộ) và production (lên store), mỗi loại trỏ tới API khác nhau. Bạn cấu hình eas.json, biến môi trường và OTA channel thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
eas.json định nghĩa các build profile. Profile development đặt developmentClient: true và distribution: "internal" (build dev client để chạy Metro và dùng native code tuỳ biến mà không cần Expo Go). Profile preview đặt distribution: "internal" để QA cài qua link (Android cài APK; iOS cần đăng ký UDID thiết bị hoặc đi qua TestFlight) và trỏ tới channel preview. Profile production dùng distribution: "store", autoIncrement cho version code và build number, rồi đưa lên store bằng eas submit. Mỗi profile có env riêng (như EXPO_PUBLIC_API_URL); biến có tiền tố EXPO_PUBLIC_ được nhúng vào bundle JS nên không dành cho secret, còn giá trị nhạy cảm dùng EAS Environment Variables hoặc secrets, chỉ có mặt lúc build. app.config.ts đọc biến môi trường (ví dụ APP_VARIANT) để đổi tên app, bundle identifier và scheme theo môi trường (com.shop.app.dev), nhờ đó cài song song được các bản trên một máy. channel của mỗi profile gắn bản build với một luồng EAS Update: bản preview chỉ nhận update đẩy lên channel preview, production chỉ nhận production, nên update thử nghiệm không lọt sang user thật; runtimeVersion (policy fingerprint) bảo đảm update chỉ tới đúng binary tương thích. Credentials (keystore, certificate, provisioning profile) do EAS lưu và quản lý, và hãy nhớ sao lưu keystore. Trên CI chạy eas build --non-interactive --profile ... với EXPO_TOKEN, thêm --auto-submit nếu muốn build xong tự nộp lên store.
{
  "cli": { "appVersionSource": "remote" },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal",
      "channel": "development",
      "env": { "APP_VARIANT": "dev", "EXPO_PUBLIC_API_URL": "https://dev.api.shop.vn" }
    },
    "preview": {
      "distribution": "internal",
      "channel": "preview",
      "env": { "APP_VARIANT": "staging", "EXPO_PUBLIC_API_URL": "https://staging.api.shop.vn" }
    },
    "production": {
      "distribution": "store",
      "channel": "production",
      "autoIncrement": true,
      "env": { "APP_VARIANT": "production", "EXPO_PUBLIC_API_URL": "https://api.shop.vn" }
    }
  }
}
