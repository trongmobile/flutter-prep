Hai lời gọi withdraw(80) chạy đồng thời trên actor sau, số dư ban đầu là 100. Điều nào đúng?

actor Wallet {
  var balance = 100

  func withdraw(_ amount: Int) async -> Bool {
    guard balance >= amount else { return false }
    await logToServer(amount) // điểm suspend
    balance -= amount
    return true
  }
}
  1. AKhông thể sai: actor chạy trọn từng lời gọi một
  2. BCó thể cả hai trả true và balance thành -60
  3. CLỗi compile vì không được await bên trong actor
  4. DCrash runtime vì hai task cùng ghi vào balance
Xem đáp án
Đáp án đúng: B
Actor là reentrant: tại await logToServer, actor cho lời gọi khác chạy, nên cả hai có thể cùng qua guard khi balance vẫn là 100. Actor không crash mà chỉ sai logic; cách sửa là trừ tiền trước await hoặc kiểm tra lại điều kiện sau khi await.
