Bạn tích hợp push bằng Firebase Cloud Messaging trong Flutter: hiện thông báo khi app đang mở, xử lý khi người dùng bấm thông báo lúc app đang chạy nền hoặc đã bị tắt, và xử lý tin nhắn khi app ở background. Những chỗ nào Android và iOS khác nhau?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
firebase_messaging cung cấp: onMessage (stream, khi app ở foreground), onMessageOpenedApp (người dùng bấm thông báo khi app ở background), getInitialMessage() (người dùng bấm thông báo khi app đã bị tắt, gọi một lần lúc khởi động) và FirebaseMessaging.onBackgroundMessage(handler) cho tin nhắn data khi app ở background hoặc terminated; handler phải là hàm top-level (hoặc static) có @pragma('vm:entry-point') vì chạy trong isolate riêng và có thể chưa có gì được khởi tạo (cần Firebase.initializeApp() trong đó). Tin nhắn có khối notification: khi ở background hệ thống tự hiện; khi foreground trên Android không tự hiện (cần flutter_local_notifications kèm AndroidNotificationChannel để hiện), còn trên iOS bật setForegroundNotificationPresentationOptions(alert: true, sound: true) thì hiện. Tin nhắn chỉ có data luôn đi vào handler nên app tự quyết định hiển thị. Điều hướng khi bấm: lấy message.data rồi chuyển cho router hay deep link; với app bị tắt phải chờ app khởi tạo xong (đăng nhập, router) rồi mới điều hướng. Android 13 trở lên cần xin quyền POST_NOTIFICATIONS (requestPermission()); iOS cần xin quyền và cấu hình APNs (tải key APNs lên Firebase, bật capability Push Notifications và Background Modes). Token lấy bằng getToken() và lắng nghe onTokenRefresh để gửi lại lên server. Silent push trên iOS bị throttle và không đảm bảo tới nên đừng dùng cho việc bắt buộc.
@pragma('vm:entry-point') // handler chạy trong isolate riêng: phải là hàm top-level
Future<void> _onBackgroundMessage(RemoteMessage message) async {
  await Firebase.initializeApp();
  // xử lý tin nhắn data, ví dụ lưu vào DB cục bộ
}

Future<void> setupPush(GoRouter router) async {
  final fcm = FirebaseMessaging.instance;
  await fcm.requestPermission(); // Android 13+ và iOS cần xin quyền
  FirebaseMessaging.onBackgroundMessage(_onBackgroundMessage);

  await fcm.setForegroundNotificationPresentationOptions(alert: true, sound: true); // iOS: hiện khi foreground

  FirebaseMessaging.onMessage.listen(showLocalNotification); // Android foreground: tự hiện bằng flutter_local_notifications
  FirebaseMessaging.onMessageOpenedApp.listen((m) => _open(router, m)); // bấm khi app ở background

  final initial = await fcm.getInitialMessage(); // bấm khi app đã bị tắt
  if (initial != null) _open(router, initial);

  fcm.onTokenRefresh.listen(tokenRepo.upload); // token đổi: gửi lại lên server
}

void _open(GoRouter router, RemoteMessage m) {
  final orderId = m.data['orderId'];
  if (orderId != null) router.go('/orders/$orderId');
}
