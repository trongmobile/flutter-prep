Bản 2.4.0 (cấu hình dưới) thêm react-native-maps và đã lên store. Sau đó team đẩy một bản EAS Update có dùng thư viện này. User còn ở bản 2.3.0 sẽ thế nào?

// app.config.ts
export default {
  name: 'Shop',
  version: '2.4.0',
  runtimeVersion: { policy: 'appVersion' },
  updates: { url: 'https://u.expo.dev/<project-id>' },
};
  1. AKhông nhận update đó, vì runtime version của họ là 2.3.0
  2. BNhận update và crash khi màn bản đồ gọi native module chưa có
  3. CNhận update, EAS tự tải thêm phần native của react-native-maps
  4. DNhận update nhưng màn bản đồ tự ẩn vì thiếu native module
Xem đáp án
Đáp án đúng: A
Với policy appVersion, runtime version chính là version của app; update build từ 2.4.0 chỉ đến máy có binary cùng runtime 2.4.0. Kịch bản crash chỉ xảy ra khi đổi native mà không đổi runtime version — vì vậy policy fingerprint an toàn hơn khi team hay quên; OTA không bao giờ tải được code native.
