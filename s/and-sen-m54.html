CircleView tự vẽ hình tròn đường kính 48dp trong onDraw và không override onMeasure. Khai báo layout_width="wrap_content" trong một LinearLayout ngang thì view lại chiếm hết chiều rộng còn lại. Nguyên nhân là gì?

class CircleView @JvmOverloads constructor(
  context: Context,
  attrs: AttributeSet? = null,
) : View(context, attrs) {
  private val paint = Paint(Paint.ANTI_ALIAS_FLAG).apply { color = Color.RED }
  private val radiusPx = 24f * resources.displayMetrics.density

  override fun onDraw(canvas: Canvas) {
    canvas.drawCircle(width / 2f, height / 2f, radiusPx, paint)
  }
}
  1. AThiếu requestLayout() sau khi tạo Paint, nên kích thước view chưa được tính lại
  2. BLinearLayout ngang tự gán layout_weight cho view không có con nên view bị kéo giãn
  3. CView.onMeasure mặc định trả về kích thước tối đa parent cho phép khi gặp wrap_content
  4. DonDraw chạy trước onMeasure nên width còn bằng 0 và hệ thống bù bằng cỡ tối đa
Xem đáp án
Đáp án đúng: C
View.onMeasure mặc định gọi getDefaultSize(): với EXACTLY và cả AT_MOST (chế độ ứng với wrap_content) nó trả luôn kích thước mà parent cho phép; chỉ UNSPECIFIED mới dùng suggestedMinimumWidth. Vì vậy view tự vẽ phải override onMeasure, tính cỡ mong muốn (48dp) rồi dùng resolveSize(desired, widthMeasureSpec) và setMeasuredDimension(...) để tôn trọng cả AT_MOST lẫn EXACTLY. Thứ tự luôn là measure, layout rồi draw nên width đã có giá trị khi onDraw chạy, LinearLayout không tự thêm weight cho view nào, và requestLayout() không liên quan tới lần đo đầu tiên.
