Gradle làm gì trong một dự án Android? build.gradle.kts cấp project và cấp module khác nhau thế nào, implementation nghĩa là gì, và khi "Gradle sync failed" hoặc lỗi dependency thì bạn xem gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Gradle là công cụ build: tải dependency, biên dịch, rồi đóng gói APK/AAB thông qua Android Gradle Plugin (AGP). settings.gradle.kts khai báo các module (include(":app")) và repository tải plugin/thư viện (google(), mavenCentral()). build.gradle.kts cấp project chủ yếu khai báo plugin dùng chung (thường kèm apply false); app/build.gradle.kts cấp module chứa khối android { } (namespace, compileSdk, buildTypes) và dependencies { }. implementation("group:artifact:version") thêm thư viện cho module hiện tại mà không lộ ra module khác phụ thuộc vào nó; testImplementation và androidTestImplementation chỉ dùng cho test. Version nên gom vào Version Catalog (libs.versions.toml). Gradle sync đọc các file cấu hình để IDE hiểu dự án nên phải sync lại sau mỗi lần sửa. Khi lỗi, đọc thông báo lỗi đầu tiên trong tab Build chứ không phải dòng cuối: Could not resolve ... thường do sai tên hoặc version, thiếu repository, mất mạng hay proxy; Duplicate class là hai thư viện kéo cùng một class; lỗi Unsupported/requires Gradle ... là Gradle, AGP và JDK không khớp. Thêm --stacktrace hoặc chạy ./gradlew app:dependencies để xem cây phụ thuộc; xoá cache là biện pháp cuối cùng.
// build.gradle.kts (cấp project): chỉ khai báo plugin, chưa áp dụng
plugins {
  id("com.android.application") version "8.7.3" apply false
  id("org.jetbrains.kotlin.android") version "2.1.0" apply false
}

// settings.gradle.kts
dependencyResolutionManagement {
  repositories { google(); mavenCentral() }   // thiếu repository -> "Could not resolve"
}
include(":app")

// app/build.gradle.kts (cấp module)
plugins {
  id("com.android.application")
  id("org.jetbrains.kotlin.android")
}

dependencies {
  implementation("androidx.core:core-ktx:1.15.0")  // dùng trong module này, không lộ ra module khác
  testImplementation("junit:junit:4.13.2")         // chỉ cho src/test
}
