TanStack Query v5, userId chưa có nên query đang bị tắt. Với đoạn code dưới đây, isPending và isLoading lúc này có giá trị gì?

const { isPending, isLoading } = useQuery({
  queryKey: ['profile', userId],
  queryFn: () => fetchProfile(userId!),
  enabled: userId != null,
});

// userId đang là undefined
  1. ACả hai đều true, vì query chưa có dữ liệu nào để hiển thị lên màn hình
  2. BCả hai đều false, vì query bị tắt nên không có trạng thái nào được tính
  3. CisPending là false, isLoading là true, vì query đang chờ userId
  4. DisPending là true, isLoading là false: chưa có data, chưa fetch
Xem đáp án
Đáp án đúng: D
Ở v5, isPending nghĩa là chưa có dữ liệu (status === 'pending'), còn isLoading bằng isFetching && isPending, tức là đang tải lần đầu thật sự. Query bị tắt và chưa có data thì isPending là true nhưng không có fetch nào nên isLoading là false (fetchStatus là 'idle'). Vì vậy nếu hiện spinner theo isPending, spinner sẽ quay mãi cho tới khi enabled thành true; dùng isLoading (hoặc kiểm tra fetchStatus) để chỉ hiện spinner khi request thật sự đang chạy.
