Pool dưới đây có corePoolSize = 2, maximumPoolSize = 8 và hàng đợi không giới hạn. Gửi 20 task chạy lâu cùng lúc. Pool tạo tối đa bao nhiêu thread worker?

ThreadPoolExecutor pool = new ThreadPoolExecutor(
    2, 8, 60, TimeUnit.SECONDS,
    new LinkedBlockingQueue<>() // hàng đợi không giới hạn
);
for (int i = 0; i < 20; i++) {
  pool.execute(() -> heavyWork());
}
  1. A8 thread: 2 thread core cộng thêm 6 thread khi các thread core đều đang bận
  2. B20 thread vì mọi task chạy lâu nên pool tạo thread riêng cho từng task
  3. CNém RejectedExecutionException từ task thứ 9 vì vượt maximumPoolSize
  4. DTối đa 2 thread, 18 task còn lại nằm chờ trong queue
Xem đáp án
Đáp án đúng: D
ThreadPoolExecutor xử lý task mới theo thứ tự: nếu số thread ít hơn corePoolSize thì tạo thread mới; còn lại thử xếp vào queue; chỉ khi queue từ chối (đầy) mới tạo thêm thread tới maximumPoolSize. LinkedBlockingQueue không giới hạn không bao giờ đầy nên pool dừng ở 2 thread và maximumPoolSize trở nên vô nghĩa. Executors.newFixedThreadPool cũng dùng queue kiểu này, nên nếu task đến nhanh hơn tốc độ xử lý thì queue phình dần tới OutOfMemoryError. Muốn pool co giãn thì dùng queue có giới hạn như ArrayBlockingQueue hoặc SynchronousQueue kèm chính sách từ chối rõ ràng.
