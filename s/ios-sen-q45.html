Đội chống gian lận phát hiện người dùng chạy bản app bị hook bằng Frida để sửa giá và giả vị trí; CTO yêu cầu "chặn máy jailbreak là xong". Bạn tư vấn thế nào về chống can thiệp trên iOS và nên đặt niềm tin ở đâu?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Nguyên tắc nền: client nằm trong tay kẻ tấn công nên mọi kiểm tra phía client đều có thể bị vượt; mục tiêu thực tế là tăng chi phí tấn công và có tín hiệu để phát hiện, còn quyết định quan trọng phải nằm ở server. Bắt đầu bằng mô hình đe doạ: ai tấn công, nhằm gì (sửa giá, lạm dụng khuyến mãi, cào dữ liệu, crack subscription) và thiệt hại bao nhiêu, từ đó mới biết đáng đầu tư tới mức nào. Phát hiện jailbreak (file như Cydia, ghi được ngoài sandbox, dylib lạ qua _dyld_image_count), debugger (sysctl kiểm cờ P_TRACED) hay Frida (port, dylib bị tiêm) đều có thể bị chính các công cụ đó hook và qua mặt, lại có thể báo nhầm với user bình thường. Vì vậy nên coi chúng là tín hiệu rủi ro gửi lên server để chấm điểm, thay vì tự exit(0) làm lộ chỗ kiểm tra. Obfuscation hay mã hoá chuỗi chỉ làm reverse chậm hơn, đổi lại khó debug và khó symbolicate crash. Thứ có giá trị thật nằm ở server: giá, vị trí hợp lệ, điểm thưởng đều tính và kiểm lại ở server, kèm rate limit và phát hiện bất thường. App Attest (DCAppAttestService) cho server bằng chứng được Apple xác nhận rằng một khoá trong Secure Enclave do đúng app của bạn tạo trên thiết bị Apple thật; sau đó mỗi request nhạy cảm kèm assertion có chữ ký và bộ đếm chống replay. DeviceCheck (DCDevice) lưu hai bit cho mỗi thiết bị ở phía Apple, hợp để đánh dấu máy đã nhận ưu đãi. Giới hạn cần nói rõ: App Attest không chứng minh máy không jailbreak hay không bị hook, nó chỉ chứng minh khoá và bản app là hợp lệ.
import CryptoKit
import DeviceCheck

// Chạy một lần: tạo khoá trong Secure Enclave rồi nhờ Apple chứng thực
func attestKey() async throws -> (keyID: String, attestation: Data) {
  let service = DCAppAttestService.shared
  guard service.isSupported else { throw AttestError.unsupported } // simulator, máy không hỗ trợ

  let keyID = try await service.generateKey()
  let challenge = try await api.fetchAttestChallenge() // server cấp, dùng một lần
  let hash = Data(SHA256.hash(data: challenge))
  let attestation = try await service.attestKey(keyID, clientDataHash: hash)
  return (keyID, attestation) // gửi lên server để xác minh với Apple
}

// Mỗi request nhạy cảm: ký lại nội dung, server kiểm tra chữ ký và bộ đếm
func assertion(for body: Data, keyID: String) async throws -> Data {
  let hash = Data(SHA256.hash(data: body))
  return try await DCAppAttestService.shared.generateAssertion(keyID, clientDataHash: hash)
}
