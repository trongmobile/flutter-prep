Một dev bọc try { viewModelScope.launch { api.load() } } catch (e: Exception) { ... } nhưng khi API lỗi app vẫn crash. Vì sao try/catch bên ngoài launch không bắt được lỗi, nên đặt nó ở đâu, và launch, async, CoroutineExceptionHandler xử lý exception khác nhau thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
launch chỉ khởi động coroutine rồi trả về Job ngay, nên khi khối try kết thúc thì coroutine còn chưa chạy tới api.load(); lỗi ném sau đó nằm ngoài try. Exception trong launch không được ném lại cho nơi gọi mà lan lên Job cha, rồi tới CoroutineExceptionHandler hoặc handler mặc định của thread, nên app crash. Cách đúng là đặt try/catch bên trong coroutine, quanh lời gọi suspend, và bắt đúng loại lỗi (IOException, HttpException); nếu bắt Exception rộng thì phải ném lại CancellationException, không thì tín hiệu huỷ bị nuốt. async khác launch: lỗi được giữ trong Deferred và ném ra ở await(). Nhưng async là con của scope nên lỗi vẫn huỷ scope cha ngay, chỉ bọc await() bằng try/catch thì chưa đủ; hãy bọc cả coroutineScope { } chứa async, vì coroutineScope ném lại lỗi cho nơi gọi. CoroutineExceptionHandler chỉ là lưới an toàn cuối cùng để log hoặc báo lỗi, không làm coroutine chạy tiếp, và chỉ có tác dụng khi gắn vào coroutine gốc (như viewModelScope.launch(handler)); gắn vào launch con hoặc vào async thì bị bỏ qua.
// Sai: launch trả về ngay, lỗi ném sau đó nằm ngoài try nên không bị bắt
try {
    viewModelScope.launch { api.load() }
} catch (e: IOException) { /* không bao giờ chạy */ }

// Đúng: try/catch nằm bên trong coroutine
viewModelScope.launch {
    try {
        _state.value = UiState.Success(api.load())
    } catch (e: IOException) {
        _state.value = UiState.Error("Không có mạng")
    }
}

// async: bọc cả coroutineScope để lỗi được ném lại cho try/catch bên ngoài
viewModelScope.launch {
    try {
        val (user, orders) = coroutineScope {
            val u = async { api.getUser() }
            val o = async { api.getOrders() }
            u.await() to o.await()
        }
        showContent(user, orders)
    } catch (e: IOException) {
        _state.value = UiState.Error("Không có mạng")
    }
}
