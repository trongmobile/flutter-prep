Đồng hồ đếm ngược tạo bằng Timer.scheduledTimer(withTimeInterval:repeats:block:) đứng yên mỗi khi user kéo UIScrollView, thả tay mới chạy tiếp. Cách sửa đúng là gì?

  1. ATạo timer trên một background DispatchQueue
  2. BThêm timer vào RunLoop.main với mode .common
  3. CGiảm timeInterval để timer bắn dày hơn
  4. DGọi RunLoop.main.run() ngay sau khi tạo timer
Xem đáp án
Đáp án đúng: B
scheduledTimer gắn timer vào mode .default; khi đang scroll, main run loop chuyển sang mode .tracking nên timer không được bắn. Mode .common gồm cả .default và .tracking; còn tạo timer trên background queue thì không chạy vì thread đó không có run loop đang chạy.
