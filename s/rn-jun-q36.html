Kéo code mới về và chạy yarn install xong thì iOS không build được (The sandbox is not in sync with the Podfile.lock), còn Android báo lỗi liên quan tới phiên bản Java/Gradle. Bạn xử lý theo thứ tự nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Lỗi sandbox nghĩa là thư mục Pods không khớp Podfile.lock: package.json vừa đổi (thêm hoặc nâng thư viện có code native) mà chưa cài lại pod. Vào thư mục ios chạy bundle exec pod install (Bundler dùng đúng CocoaPods của Gemfile), thêm --repo-update nếu báo không tìm thấy phiên bản pod, rồi mở .xcworkspace chứ không mở .xcodeproj. Android: kiểm tra JDK đúng phiên bản React Native của bạn yêu cầu (hiện là JDK 17), sdk.dir trong android/local.properties hoặc ANDROID_HOME, rồi chạy ./gradlew clean trong android. Lỗi JS lạ sau khi đổi dependency thì khởi động Metro với --reset-cache. Trước khi xoá cache hàng loạt, đọc dòng lỗi gốc (mục What went wrong của Gradle hoặc lỗi đầu tiên trong Xcode), và dùng npx react-native doctor để kiểm tra môi trường; với Expo, npx expo install --check báo thư viện lệch phiên bản SDK.
