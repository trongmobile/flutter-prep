Đoạn code khai báo biến bằng var dưới đây cho kết quả gì?

void main() {
  var count = 10;
  count = 'mười';
  print(count);
}
  1. AIn ra mười
  2. BLỗi compile vì count có kiểu int
  3. CIn ra 10
  4. DLỗi runtime TypeError khi chạy tới dòng gán
Xem đáp án
Đáp án đúng: B
var suy ra kiểu từ giá trị khởi tạo (int) và kiểu này cố định, nên gán String bị compiler báo lỗi ngay. Nhầm lẫn thường gặp là nghĩ var giống dynamic hoặc var trong JavaScript nên chỉ lỗi lúc chạy.
