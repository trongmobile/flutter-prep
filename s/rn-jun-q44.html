Interceptor Axios nhận 401 thì cần đưa người dùng về màn Login, nhưng nó nằm ngoài cây component nên không gọi được useNavigation(). Bạn điều hướng từ ngoài component thế nào, và vì sao đôi khi lệnh điều hướng bị bỏ qua hoặc báo lỗi?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Dùng createNavigationContainerRef của React Navigation: tạo ref ở một module riêng, truyền vào <NavigationContainer ref={navigationRef}>, rồi gọi ở bất kỳ đâu như navigationRef.navigate(...) hay navigationRef.dispatch(...). Bẫy lớn nhất là ref chỉ dùng được sau khi NavigationContainer đã mount và navigator đã render: gọi quá sớm (request chạy lúc khởi động, hoặc 401 về khi app đang load) thì lệnh không có tác dụng và console báo lỗi hasn't been initialized yet. Hãy kiểm tra navigationRef.isReady() trước khi gọi. Khi hết phiên nên reset cả stack bằng CommonActions.reset thay vì navigate('Login') để nút back không đưa người dùng về màn cũ chứa dữ liệu của họ. Nhiều request 401 về cùng lúc chỉ nên kích hoạt đăng xuất một lần (dùng cờ). Cách sạch hơn nữa: interceptor chỉ xoá token và cập nhật state đăng nhập, còn cây navigation render có điều kiện (isSignedIn ? <AppStack /> : <AuthStack />), nên app tự về Login mà không cần ai gọi navigate.
// navigationRef.ts
import { createNavigationContainerRef, CommonActions } from '@react-navigation/native';

export const navigationRef = createNavigationContainerRef<RootStackParamList>();

export function resetToLogin() {
  if (navigationRef.isReady()) {
    navigationRef.dispatch(CommonActions.reset({ index: 0, routes: [{ name: 'Login' }] }));
  }
}

// App.tsx
<NavigationContainer ref={navigationRef}>{/* ... */}</NavigationContainer>

// api.ts
let loggingOut = false;

api.interceptors.response.use(undefined, async (error) => {
  if (error.response?.status === 401 && !loggingOut) {
    loggingOut = true; // nhiều request 401 cùng lúc chỉ đăng xuất một lần
    await clearTokens();
    resetToLogin();
    loggingOut = false;
  }
  return Promise.reject(error);
});
