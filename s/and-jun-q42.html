Màn danh sách sản phẩm mở màn chi tiết bằng Navigation Compose, và một dev định truyền cả object Product (kèm danh sách ảnh, mô tả dài) qua route. Bạn truyền argument thế nào cho đúng, vì sao chỉ nên truyền ID, và ViewModel của màn chi tiết đọc argument ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Chỉ nên truyền định danh nhỏ (ID, từ khoá ngắn) rồi để màn đích tự lấy dữ liệu từ repository hoặc Room. Argument nằm trong back stack và được lưu cùng saved state, nên object lớn làm phình Bundle (giới hạn giao dịch khoảng 1MB, vượt thì TransactionTooLargeException), dễ lệch với dữ liệu thật khi nơi khác sửa sản phẩm, và nhét object vào route string còn phải encode ký tự đặc biệt. Navigation 2.8+ hỗ trợ type-safe route: khai báo @Serializable data class ProductDetail(val id: Long) (cần plugin kotlinx.serialization), gọi navController.navigate(ProductDetail(42)) và composable<ProductDetail> { }. Kiểu cũ dùng route string "detail/{id}" với navArgument("id") { type = NavType.LongType }, dễ sai chính tả và sai kiểu (quên NavType thì nhận về String). ViewModel không cần ai truyền tay: argument tự có trong SavedStateHandle, đọc bằng savedStateHandle.toRoute<ProductDetail>() (hoặc savedStateHandle.get<Long>("id") với route string), và vẫn còn sau process death.
@Serializable object ProductList
@Serializable data class ProductDetail(val id: Long) // chỉ truyền ID

NavHost(navController, startDestination = ProductList) {
    composable<ProductList> {
        ProductListScreen(onProductClick = { id -> navController.navigate(ProductDetail(id)) })
    }
    composable<ProductDetail> { ProductDetailScreen() }
}

@HiltViewModel
class ProductDetailViewModel @Inject constructor(
    savedStateHandle: SavedStateHandle,
    repository: ProductRepository,
) : ViewModel() {
    private val route = savedStateHandle.toRoute<ProductDetail>()

    // Màn đích tự tải dữ liệu theo ID, luôn là bản mới nhất
    val product: StateFlow<Product?> = repository.observeProduct(route.id)
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), null)
}
