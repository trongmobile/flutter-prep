Reviewer yêu cầu thêm [weak self] vào Task dưới đây để tránh retain cycle. Nhận định nào đúng?

final class ProfileViewController: UIViewController {
  override func viewDidLoad() {
    super.viewDidLoad()
    Task {
      let profile = try? await api.fetchProfile() // mất khoảng 1 giây
      render(profile)
    }
  }
}
  1. AKhông có cycle: Task giữ self tới khi xong rồi thả ra
  2. BCó cycle vì closure của Task giữ self và self giữ Task
  3. CCó cycle, deinit sẽ không chạy cho tới khi app bị kill
  4. DKhông cần, vì Task luôn tự capture self dưới dạng weak
Xem đáp án
Đáp án đúng: A
Retain cycle cần tham chiếu hai chiều, mà view controller không lưu task nên không có chiều ngược lại; task xong thì reference tới self được thả, chỉ khiến màn hình sống thêm một chút. Task capture self mạnh chứ không phải weak; [weak self] thực sự cần khi task chạy rất lâu hoặc vô hạn như vòng for await, và khi đó nên lưu task để cancel().
