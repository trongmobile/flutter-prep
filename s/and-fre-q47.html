Trong Navigation Compose, NavHost, NavController và nav graph là gì? navigate và popBackStack làm việc với back stack thế nào, và làm sao để bấm Back sau khi đăng nhập không quay lại màn login?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Navigation Component quản lý việc chuyển màn trong app. Nav graph là tập các destination (màn hình) cùng đường đi giữa chúng: với Fragment là file XML, với Compose là các khối composable("route") { ... } khai báo trong NavHost. NavHost là vùng chứa hiển thị destination hiện tại và cần một startDestination; NavController (tạo bằng rememberNavController()) là bộ điều khiển. navigate("detail/42") đẩy một destination mới lên back stack; bấm Back hoặc gọi popBackStack() bỏ destination trên cùng để quay về màn trước (hàm trả về false nếu không còn gì để bỏ). Muốn bỏ luôn các màn phía sau khi đi tiếp, dùng popUpTo(...) trong navigate, với inclusive = true thì xoá cả điểm mốc: đây là cách chuẩn khi chuyển từ login sang home. Bẫy: truyền NavController xuống từng composable con làm khó test và dễ gọi sai chỗ, nên truyền callback như onItemClick và để chỉ NavHost biết tới controller; route chỉ nên mang id, rồi màn đích tự tải dữ liệu thay vì nhét cả object lớn vào route.
@Composable
fun AppNavHost() {
  val navController = rememberNavController()

  NavHost(navController = navController, startDestination = "login") {
    composable("login") {
      LoginScreen(onLoggedIn = {
        navController.navigate("home") {
          popUpTo("login") { inclusive = true }   // xoá login khỏi back stack: Back không quay lại
        }
      })
    }
    composable("home") {
      HomeScreen(onOpenDetail = { id -> navController.navigate("detail/$id") })
    }
    composable(
      route = "detail/{id}",
      arguments = listOf(navArgument("id") { type = NavType.IntType }),
    ) { entry ->
      val id = entry.arguments?.getInt("id") ?: return@composable
      DetailScreen(id = id, onBack = { navController.popBackStack() })
    }
  }
}
