Bốn tính chất của lập trình hướng đối tượng (OOP) là gì? Cho ví dụ gắn với Android.

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đóng gói (encapsulation) là giấu dữ liệu bên trong và chỉ cho truy cập qua method được kiểm soát, ví dụ field private kèm getter/setter, hay ViewModel giữ private val _state rồi chỉ expose bản read-only. Kế thừa (inheritance) cho lớp con dùng lại code của lớp cha, ví dụ MainActivity kế thừa AppCompatActivity; lạm dụng kế thừa làm code cứng nhắc nên nhiều khi nên chọn composition. Đa hình (polymorphism) là cùng một lời gọi nhưng hành vi tuỳ theo object thật lúc chạy: một danh sách View chứa cả TextView lẫn Button, gọi onDraw thì mỗi loại tự vẽ theo cách của nó (override được chọn lúc runtime). Trừu tượng (abstraction) là chỉ lộ "làm gì" qua abstract class hoặc interface và giấu "làm thế nào", ví dụ ViewModel chỉ biết interface UserRepository mà không cần biết dữ liệu đến từ Retrofit hay Room. Khi trả lời nên kèm ví dụ như vậy thay vì chỉ đọc lại định nghĩa.
abstract class Shape {                       // trừu tượng: chỉ nói "có diện tích"
  private final String name;                 // đóng gói: field không public
  Shape(String name) { this.name = name; }
  abstract double area();
  String describe() { return name + ": " + area(); }
}

class Circle extends Shape {                 // kế thừa Shape
  private final double r;
  Circle(double r) { super("Tròn"); this.r = r; }
  @Override double area() { return Math.PI * r * r; }
}

class Square extends Shape {
  private final double side;
  Square(double side) { super("Vuông"); this.side = side; }
  @Override double area() { return side * side; }
}

// Đa hình: cùng gọi describe(), kết quả tuỳ object thật
List<Shape> shapes = List.of(new Circle(1), new Square(2));
for (Shape s : shapes) System.out.println(s.describe());
