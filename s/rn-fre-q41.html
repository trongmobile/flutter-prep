Bạn cần làm bốn thứ: hộp thoại xác nhận xoá, vòng xoay chờ khi đang tải, công tắc bật thông báo và một popup chọn bộ lọc. Alert, Modal, ActivityIndicator và Switch dùng cho trường hợp nào, và Modal có những bẫy gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Alert.alert(title, message, buttons) gọi hộp thoại native của hệ điều hành, hợp cho xác nhận ngắn. Nút có style: 'cancel' hoặc 'destructive' (hai kiểu này chủ yếu có tác dụng trên iOS), Android tối đa 3 nút và bấm ra ngoài mặc định không đóng trừ khi đặt cancelable: true; giao diện gần như không tuỳ biến được. Modal thì bạn tự vẽ nội dung và nó hiện chồng lên toàn màn hình, hợp cho popup chọn bộ lọc hay form nhỏ; điều khiển bằng prop visible, thêm transparent nếu muốn thấy nền phía sau mờ. Bẫy lớn nhất: trên Android bắt buộc có onRequestClose để xử lý nút Back; thiếu thì không đóng được và React Native cảnh báo. Ngoài ra Modal nằm trên cùng nên toast hay overlay vẽ ở component khác thường bị che. ActivityIndicator là vòng xoay báo đang tải (size, color, animating), thường hiển thị có điều kiện {loading && <ActivityIndicator />}. Switch là công tắc dạng controlled: phải truyền value và cập nhật state trong onValueChange, nếu không công tắc sẽ bật rồi tự nhảy lại trạng thái cũ.
const confirmDelete = (id: number) =>
  Alert.alert('Xoá đơn hàng?', 'Hành động này không thể hoàn tác.', [
    { text: 'Huỷ', style: 'cancel' },
    { text: 'Xoá', style: 'destructive', onPress: () => deleteOrder(id) },
  ]);

function FilterModal() {
  const [open, setOpen] = useState(false);
  const [notify, setNotify] = useState(true);

  return (
    <>
      <Button title="Bộ lọc" onPress={() => setOpen(true)} />
      <Modal visible={open} animationType="slide" transparent onRequestClose={() => setOpen(false)}>
        <View style={styles.backdrop}>
          <View style={styles.sheet}>
            <Switch value={notify} onValueChange={setNotify} />
            <Button title="Đóng" onPress={() => setOpen(false)} />
          </View>
        </View>
      </Modal>
    </>
  );
}
