Dự án vừa nâng lên bản React Native chạy New Architecture mặc định. Giải thích ngắn gọn New Architecture khác kiến trúc cũ (bridge) ở đâu, và khi thêm một thư viện native mới bạn cần kiểm tra gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Với bridge, JS và native là hai thế giới tách biệt: mỗi lời gọi được serialize thành JSON, gom theo batch và gửi bất đồng bộ qua lại, nên tốn chi phí chuyển đổi, không gọi đồng bộ được và dễ nghẽn khi dữ liệu dồn dập như sự kiện cuộn hay animation. JSI (JavaScript Interface) là lớp C++ cho phép JS giữ tham chiếu tới object C++/native và gọi method trực tiếp, kể cả đồng bộ, không cần serialize JSON. Trên nền JSI có TurboModules (native module khởi tạo khi cần, gọi trực tiếp) và Fabric (renderer mới). New Architecture được bật mặc định từ React Native 0.76, nên khi chọn thư viện native cần xem README hoặc React Native Directory để biết nó đã hỗ trợ New Architecture chưa, thư viện còn được bảo trì không, rồi test kỹ trên cả hai nền tảng; nhiều thư viện cũ vẫn chạy nhờ lớp tương thích (interop layer) nhưng không phải trường hợp nào cũng ổn.
