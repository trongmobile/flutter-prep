Bạn present một màn hình chọn bộ lọc dạng bottom sheet từ UIKit: cần dừng ở nửa màn hình, kéo lên được toàn màn hình, chặn user vuốt đóng khi form còn dữ liệu chưa lưu, và biết khi nào sheet đóng để làm mới danh sách. Bạn dùng UISheetPresentationController, isModalInPresentation và UIAdaptivePresentationControllerDelegate thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Từ iOS 15, view controller present kiểu .pageSheet có sheetPresentationController để cấu hình bottom sheet: detents khai báo các điểm dừng (.medium(), .large(), và .custom từ iOS 16 để chiều cao theo nội dung), prefersGrabberVisible hiện thanh kéo, selectedDetentIdentifier chọn điểm dừng ban đầu, largestUndimmedDetentIdentifier cho phép tương tác với nội dung phía sau khi sheet ở điểm dừng nhỏ. Muốn chặn vuốt đóng khi form chưa lưu thì đặt isModalInPresentation = true (cập nhật động theo trạng thái form); khi đó vuốt xuống không đóng mà chỉ gọi presentationControllerDidAttemptToDismiss(_:), nơi hiện hộp thoại xác nhận bỏ thay đổi. Để biết khi nào sheet đóng: presentationControllerDidDismiss(_:) của UIAdaptivePresentationControllerDelegate chỉ được gọi khi user đóng bằng thao tác vuốt, còn đóng bằng code (dismiss(animated:), nút Xong) thì không, nên cần gom mọi đường đóng về một closure onFinish để không bỏ sót; viewWillDisappear không đáng tin vì cũng chạy khi có màn khác present chồng lên. Trên iPad hoặc cửa sổ lớn sheet có thể hiển thị dạng popover hay form sheet nên đừng giả định toàn màn hình. Trong SwiftUI, ý tưởng tương ứng là .sheet kèm .presentationDetents([.medium, .large]) và .interactiveDismissDisabled(isDirty).
final class FilterViewController: UIViewController, UIAdaptivePresentationControllerDelegate {
  var onFinish: (() -> Void)? // gom mọi đường đóng sheet về một chỗ

  private var hasUnsavedChanges = false {
    didSet { isModalInPresentation = hasUnsavedChanges } // chặn vuốt đóng khi form chưa lưu
  }

  override func viewDidLoad() {
    super.viewDidLoad()
    if let sheet = sheetPresentationController {
      sheet.detents = [.medium(), .large()]
      sheet.prefersGrabberVisible = true
      sheet.largestUndimmedDetentIdentifier = .medium // vẫn thao tác được nội dung phía sau ở nửa màn hình
    }
    presentationController?.delegate = self
  }

  // Bị chặn bởi isModalInPresentation: vuốt xuống chỉ báo 'đã cố đóng'
  func presentationControllerDidAttemptToDismiss(_ presentationController: UIPresentationController) {
    showDiscardAlert { [weak self] in
      self?.dismiss(animated: true)
      self?.onFinish?()
    }
  }

  // Chỉ được gọi khi user đóng bằng vuốt, không gọi khi đóng bằng code
  func presentationControllerDidDismiss(_ presentationController: UIPresentationController) {
    onFinish?()
  }

  @objc private func doneTapped() {
    dismiss(animated: true) { [weak self] in self?.onFinish?() }
  }
}
