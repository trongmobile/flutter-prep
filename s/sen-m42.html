Extension dưới đây được khai báo trong cùng file. Chạy main cho kết quả nào (Dart 3.x)?

extension Shout on String {
  String shout() => '${toUpperCase()}!';
}

void main() {
  String s = 'hi';
  dynamic d = 'hi';
  print(s.shout());
  print(d.shout());
}
  1. AIn HI!, sau đó dòng d.shout() ném NoSuchMethodError
  2. BIn HI! hai lần, vì runtime biết d đang giữ một String
  3. CLỗi compile ở dòng d.shout() vì dynamic không có method shout
  4. Ds.shout() cũng ném NoSuchMethodError, vì extension không sửa class String
Xem đáp án
Đáp án đúng: A
Extension method được resolve lúc compile theo static type: s là String nên tìm thấy shout, còn d là dynamic nên analyzer không kiểm tra gì và lời gọi trở thành dynamic invocation, tìm shout trên chính object String và không thấy. Đây là lý do extension không áp dụng cho dữ liệu dynamic lấy từ jsonDecode cho tới khi ép kiểu (as String).
