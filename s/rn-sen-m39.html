CI build lại app native cho mọi PR mất 25 phút, dù đa số PR chỉ sửa JS. Cách rút ngắn mà vẫn an toàn nhất là gì?

  1. AChỉ build native ban đêm, PR ban ngày chạy E2E trên build của hôm trước
  2. BBỏ E2E khỏi CI của PR, chỉ chạy unit test và để QA kiểm tra thủ công
  3. CBăm fingerprint phần native; không đổi thì dùng lại binary cache, chỉ thay JS
  4. DChạy E2E trên debug build vì build debug nhanh hơn build release nhiều
Xem đáp án
Đáp án đúng: C
Fingerprint (ví dụ bằng @expo/fingerprint) băm mọi input native: dependency native, cấu hình, code trong ios//android/; không đổi nghĩa là binary cũ vẫn đúng và chỉ cần bundle JS mới. Build đêm có thể lệch native so với PR, còn E2E trên debug build không phản ánh đúng hành vi bản release.
