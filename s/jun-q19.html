ChangeNotifierProvider(create: ...) và ChangeNotifierProvider.value(...) khác nhau thế nào? Dùng sai gây hậu quả gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
create để Provider tự tạo object một lần và tự gọi dispose() khi provider bị gỡ khỏi cây, dùng khi khởi tạo một notifier mới. .value chỉ đưa một object đã tồn tại xuống cây và không dispose nó, hợp khi truyền một item có sẵn trong list hoặc chuyển notifier sang route mới. Viết .value(value: CartModel()) trong build sẽ tạo instance mới mỗi lần rebuild, làm mất state và không ai dispose; ngược lại dùng create cho object đang do nơi khác quản lý thì nó bị dispose sớm.
// Provider tự tạo và tự dispose
ChangeNotifierProvider(
  create: (_) => CartModel(),
  child: const CartPage(),
)

// Đưa object có sẵn xuống, Provider KHÔNG dispose
ChangeNotifierProvider.value(
  value: products[index],
  child: const ProductTile(),
)
