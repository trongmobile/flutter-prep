App có hai flavor free và paid (cùng một dimension), hai build type debug và release. Resource app_name được khai báo ở src/main là "Shop", ở src/paid là "Shop Pro" và ở src/debug là "Shop Debug" (không có src/paidDebug). Variant paidDebug hiển thị tên nào?

  1. AShop Debug, vì source set của build type debug đè lên flavor paid
  2. BShop Pro, vì source set của flavor paid đè lên build type debug
  3. CShop, vì src/main luôn là nguồn resource có độ ưu tiên cao nhất
  4. DBuild lỗi Duplicate resources vì app_name khai báo ở ba source set
Xem đáp án
Đáp án đúng: A
Khi gộp resource, AGP áp dụng độ ưu tiên: source set của variant (paidDebug) > build type (debug) > product flavor (paid) > main > dependency. app_name ở src/debug ghi đè bản của flavor paid, nên ra Shop Debug. Khai báo cùng tên ở các source set khác cấp là cách override có chủ đích nên không báo trùng; lỗi duplicate resources chỉ xảy ra khi cùng một tên bị khai báo hai lần trong cùng một source set.
