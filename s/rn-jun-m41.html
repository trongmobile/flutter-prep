Người dùng bấm Counter 3 lần khi mode là 'a', sau đó Screen render lại với mode là 'b'. Text hiển thị gì?

function Counter({ label }: { label: string }) {
  const [n, setN] = useState(0);
  return (
    <Pressable onPress={() => setN(n + 1)}>
      <Text>{label}: {n}</Text>
    </Pressable>
  );
}

function Screen({ mode }: { mode: 'a' | 'b' }) {
  return mode === 'a' ? <Counter label="A" /> : <Counter label="B" />;
}
  1. AB: 0, vì nhánh 'b' mount một Counter hoàn toàn mới
  2. BA: 3, vì label chỉ được đọc ở lần render đầu tiên
  3. CB: 3, vì cùng loại và cùng vị trí nên giữ state
  4. DB: 0, vì mỗi nhánh ba ngôi có một state riêng

Đáp án đúng: C
React nhận diện component theo kiểu và vị trí trong cây: hai nhánh đều là Counter ở cùng một vị trí nên React tái sử dụng instance, chỉ cập nhật prop label và giữ nguyên state n là 3. Muốn reset state khi đổi nhánh, gán key khác nhau cho hai Counter (ví dụ key="b") để React mount lại.
