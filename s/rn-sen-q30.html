App RN dùng React Navigation, link shop://order/123 (hoặc universal link) cần mở màn chi tiết đơn khi app đang tắt, và nếu user chưa đăng nhập thì phải đăng nhập xong mới vào đúng màn đó. Bạn cấu hình deep link, luồng đăng nhập và back stack thế nào, và các bẫy chính là gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Khai báo linking cho NavigationContainer với prefixes và config ánh xạ đường dẫn sang route (OrderDetail: 'order/:id', kèm parse để ép kiểu tham số); React Navigation xử lý cả cold start (getInitialURL) lẫn khi app đang chạy (subscribe). Với luồng đăng nhập, cách tự nhiên là điều kiện hoá màn hình theo trạng thái: chưa đăng nhập chỉ render nhóm màn Auth, đăng nhập xong thì render nhóm màn chính (từ React Navigation 7.1 có Stack.Protected với prop guard, Expo Router cũng có Stack.Protected). Nhưng link tới màn chưa tồn tại trong navigator thì bị bỏ qua, nên tôi chủ động giữ link đích: nếu chưa đăng nhập, getInitialURL (và subscribe cho lúc app đang chạy) lưu URL vào store rồi trả về null, sau khi đăng nhập thì điều hướng bằng chính linking.config qua useLinkTo(). Back stack: deep link chỉ dựng đúng màn đích; muốn nút back về danh sách đơn thay vì thoát app thì cấu hình initialRouteName cho navigator lồng nhau hoặc tuỳ biến getStateFromPath để dựng stack đầy đủ. Các bẫy: universal link và app link chỉ mở app khi xác minh domain đúng (apple-app-site-association, assetlinks.json), còn custom scheme thì app khác có thể đăng ký trùng; mọi tham số trong link là input không đáng tin nên phải validate và server phải kiểm tra quyền; link tới ID không tồn tại phải ra một màn lỗi hợp lý thay vì crash. Với Expo Router, mỗi file là một route nên deep link tự khớp với cấu trúc thư mục.
const linking: LinkingOptions<RootParamList> = {
  prefixes: ['shop://', 'https://shop.vn'],
  config: {
    screens: {
      Orders: { screens: { OrderDetail: { path: 'order/:id', parse: { id: String } } } },
    },
  },
  async getInitialURL() {
    const url = await Linking.getInitialURL();
    if (url && !authStore.getState().isLoggedIn) {
      authStore.getState().setPendingUrl(url); // chưa đăng nhập: giữ lại link đích
      return null; // vào màn hình đầu như bình thường
    }
    return url;
  },
  // subscribe() cho lúc app đang chạy xử lý tương tự
};

function useResumePendingLink() {
  const linkTo = useLinkTo();
  const { isLoggedIn, pendingUrl, setPendingUrl } = useAuth();
  useEffect(() => {
    if (isLoggedIn && pendingUrl) {
      linkTo(toPath(pendingUrl)); // toPath: bỏ prefix, còn '/order/123', rồi dùng chính linking.config ở trên
      setPendingUrl(null);
    }
  }, [isLoggedIn, pendingUrl, linkTo, setPendingUrl]);
}
