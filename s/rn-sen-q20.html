Bạn cần ship cùng một app cho 8 thương hiệu khác nhau (logo, màu, bundle id, vài tính năng riêng). Thiết kế codebase RN thế nào để không thành 8 nhánh git?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Một codebase duy nhất, khác biệt giữa các brand được mô tả bằng cấu hình chứ không bằng nhánh. Ở build time, mỗi brand có một file config (tên app, bundle id/applicationId, icon, splash, màu, URL backend, key SDK) được chọn qua biến môi trường; với Expo thì app.config.ts đọc biến BRAND để sinh project native tương ứng, với project bare thì dùng product flavors trên Android và scheme/target trên iOS. Ở runtime, theme token và asset được nạp theo brand qua một provider; tính năng khác nhau bật bằng feature flag hoặc danh sách capability của brand, thay vì if (brand === 'x') rải khắp code. CI build theo ma trận brand × môi trường; mỗi brand có tài khoản store, signing và channel OTA riêng để update không đi nhầm brand. Thêm screenshot test cho từng brand để bắt vỡ giao diện, và quy tắc review: mọi tuỳ biến brand mới phải đi qua config hoặc flag.
// app.config.ts
import type { ExpoConfig } from 'expo/config';
import { brands } from './brands';

const brand = brands[process.env.BRAND ?? 'default'];

export default (): ExpoConfig => ({
  name: brand.displayName,
  slug: brand.slug,
  icon: brand.icon,
  ios: { bundleIdentifier: brand.iosBundleId },
  android: { package: brand.androidPackage },
  extra: { brandId: brand.id, apiUrl: brand.apiUrl },
});
