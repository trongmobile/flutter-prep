Config được viết như một singleton, nhưng đoạn code sau lại in ra light dark. Vì sao và cần sửa gì?

final class Config {
    static let shared = Config()
    var theme = "light"
}

let other = Config()
other.theme = "dark"
print(Config.shared.theme, other.theme)
  1. Astatic let bị copy mỗi lần truy cập shared; cần đổi thành static var để dùng chung một instance
  2. Bfinal class khiến Config hoạt động như value type; bỏ final thì mọi biến sẽ dùng chung instance
  3. Ctheme là property của từng instance; phải khai báo static var theme thì mới dùng chung được
  4. Dinit() mặc định là internal nên vẫn tạo được instance thứ hai; khai báo private init() để chặn
Xem đáp án
Đáp án đúng: D
Class không khai báo initializer sẽ có init() mặc định với mức internal, nên Config() ở bất kỳ đâu trong module vẫn tạo ra object riêng, độc lập với shared. Thêm private init() thì compiler báo lỗi khi ai đó gọi Config(), buộc mọi nơi phải dùng Config.shared. static let chỉ khởi tạo một lần (lười, an toàn thread) và class là reference type nên không bị copy; final chỉ cấm kế thừa.
