Điểm khác biệt thực sự giữa @unknown default và default thường trong switch trên UNAuthorizationStatus (enum của Apple SDK) là gì?

func message(for status: UNAuthorizationStatus) -> String {
  switch status {
  case .notDetermined: return "Chưa hỏi quyền"
  case .denied: return "Đã từ chối"
  case .authorized, .provisional, .ephemeral: return "Đã được phép"
  @unknown default: return "Không xác định"
  }
}
  1. AChỉ dùng được với enum khai báo @frozen, còn enum thường của Apple bắt buộc phải dùng default
  2. BLàm compiler bỏ kiểm tra exhaustiveness, nên bạn không còn phải liệt kê hết các case đã biết
  3. CGiúp switch chạy nhanh hơn vì compiler biết nhánh cuối cùng hiếm khi bị chạm tới
  4. DVẫn đón case lạ lúc chạy như default, nhưng khi SDK thêm case mới thì compiler cảnh báo
Xem đáp án
Đáp án đúng: D
Enum không frozen của Apple (như UNAuthorizationStatus) có thể được thêm case ở bản iOS sau. @unknown default vừa đón các giá trị chưa biết lúc chạy giống default, vừa giữ việc kiểm tra: khi SDK mới thêm case, compiler cảnh báo rằng switch chưa xử lý case mới; còn default thường thì im lặng nuốt luôn case mới. Nó cũng không liên quan tới tốc độ chạy.
