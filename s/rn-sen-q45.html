Công ty có 4 team RN, mỗi team tự viết Button, Input, typography riêng nên UI lệch nhau và đổi màu thương hiệu phải sửa hàng trăm file. Bạn dựng design system cho RN thế nào, và cân bằng giữa nhất quán với tốc độ của các team ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Tôi tách thành ba việc: token, component và quy trình. Token chia hai tầng: nguyên thuỷ (blue600, space16) và ngữ nghĩa (actionPrimary, textDefault); component chỉ dùng token ngữ nghĩa nên dark mode hay đổi thương hiệu chỉ là đổi ánh xạ, theme lấy qua hook useTheme và có kiểu TypeScript chung để thiếu token là lỗi compile. Component có API nhỏ, có kiểu: variant, size là union chứ không nhận màu tuỳ ý; style chỉ cho phép thuộc tính bố cục (margin, alignSelf) để team không ghi đè ngoại hình; accessibility dựng sẵn (role, state, vùng chạm tối thiểu, testID). Công cụ: Storybook (on-device để thử thao tác thật, bản web để review và chụp ảnh so sánh), mỗi component có story cho từng variant và trạng thái; thư viện style (StyleSheet + theme, Unistyles, NativeWind, Tamagui...) chọn theo chi phí runtime, hỗ trợ dark mode, DX TypeScript và tương thích New Architecture hơn là theo mốt. Quy trình: phát hành như package riêng có semver và changelog (vd. Changesets), đánh dấu @deprecated kèm codemod khi đổi API, khai báo peer dependency (RN, Reanimated) và bảng tương thích. Để DS không thành nút cổ chai: cho component sinh ra trong app của team rồi "thăng hạng" vào DS khi có từ hai team dùng; cung cấp primitive (Box, Text, Stack) để team tự ghép thứ chưa có; lint cảnh báo (không chặn) khi dùng màu hex hay Text thô; đo mức dùng DS (tỷ lệ màn hình dùng component DS) và thời gian từ yêu cầu tới phát hành.
// Hai tầng token: nguyên thuỷ -> ngữ nghĩa. Component chỉ biết token ngữ nghĩa.
export interface Theme {
  color: { actionPrimary: string; onActionPrimary: string; textDefault: string };
  space: { sm: number; md: number };
}
const palette = { blue600: '#1D4ED8', blue300: '#93C5FD', white: '#FFFFFF', gray900: '#111827' };
export const lightTheme: Theme = {
  color: { actionPrimary: palette.blue600, onActionPrimary: palette.white, textDefault: palette.gray900 },
  space: { sm: 8, md: 16 },
};
export const darkTheme: Theme = {
  color: { actionPrimary: palette.blue300, onActionPrimary: palette.gray900, textDefault: palette.white },
  space: { sm: 8, md: 16 },
};

type ButtonProps = {
  label: string;
  onPress: () => void;
  variant?: 'primary' | 'ghost'; // union, không nhận màu tuỳ ý
  disabled?: boolean;
  testID?: string;
  style?: Pick<ViewStyle, 'margin' | 'marginTop' | 'marginBottom' | 'alignSelf'>; // chỉ cho chỉnh bố cục
};

export function Button({ label, onPress, variant = 'primary', disabled, testID, style }: ButtonProps) {
  const theme = useTheme();
  const primary = variant === 'primary';
  return (
    <Pressable
      accessibilityRole="button"
      accessibilityState={{ disabled: !!disabled }}
      disabled={disabled}
      onPress={onPress}
      testID={testID}
      style={[
        {
          minHeight: 44, // vùng chạm tối thiểu
          paddingHorizontal: theme.space.md,
          justifyContent: 'center',
          borderRadius: 8,
          backgroundColor: primary ? theme.color.actionPrimary : 'transparent',
          opacity: disabled ? 0.5 : 1,
        },
        style,
      ]}
    >
      <Text style={{ color: primary ? theme.color.onActionPrimary : theme.color.actionPrimary }}>{label}</Text>
    </Pressable>
  );
}
