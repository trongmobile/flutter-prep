Bạn cần (1) tự dừng và chạy lại listener vị trí theo vòng đời màn hình mà không rải code vào onStart/onStop của từng Activity, và (2) biết cả app vừa vào nền hay vừa trở lại foreground để khoá app hoặc gửi analytics. Dùng DefaultLifecycleObserver, LifecycleEventObserver và ProcessLifecycleOwner thế nào, bẫy gì cần tránh?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Với (1), đóng gói thành một class tự quản vòng đời: implement DefaultLifecycleObserver (ghi đè các callback cần như onStart(owner), onStop(owner); cách này thay thế @OnLifecycleEvent đã deprecated) rồi đăng ký bằng lifecycle.addObserver(...). Activity chỉ việc tạo object. LifecycleEventObserver nhận một hàm onStateChanged(source, event), tiện khi muốn xử lý bằng when(event); trong Compose có LifecycleEventEffect và LifecycleResumeEffect. Chọn đúng cặp sự kiện: STARTED/STOPPED cho thứ cần khi màn hiển thị (location, listener UI), RESUMED/PAUSED cho thứ cần khi người dùng đang tương tác (camera). Observer được gỡ khi owner bị huỷ nên không leak owner, nhưng nếu observer giữ Context của Activity mà sống lâu hơn thì vẫn leak, nên dùng applicationContext. Với (2), ProcessLifecycleOwner.get().lifecycle là lifecycle của cả process: ON_START khi Activity đầu tiên started, còn ON_STOP chỉ phát sau khi Activity cuối cùng đã stop, kèm độ trễ khoảng 700ms để không nhấp nháy khi xoay màn hình hay chuyển Activity. ON_CREATE chỉ phát một lần và ON_DESTROY không bao giờ được phát. Đăng ký trong Application.onCreate(). Bẫy: ON_STOP không bảo đảm app còn sống để ghi dữ liệu, việc cần chắc chắn hãy lưu sớm hoặc giao cho WorkManager; và đừng dùng nó thay cho service để chạy nền.
class LocationTracker(
  private val client: FusedLocationProviderClient,
  private val request: LocationRequest,
  private val callback: LocationCallback,
) : DefaultLifecycleObserver {
  // Đã kiểm tra quyền vị trí ở nơi khởi tạo
  @SuppressLint("MissingPermission")
  override fun onStart(owner: LifecycleOwner) {
    client.requestLocationUpdates(request, callback, Looper.getMainLooper())
  }
  override fun onStop(owner: LifecycleOwner) {
    client.removeLocationUpdates(callback)
  }
}
// Activity: lifecycle.addObserver(LocationTracker(client, request, callback))

class App : Application() {
  override fun onCreate() {
    super.onCreate()
    ProcessLifecycleOwner.get().lifecycle.addObserver(object : DefaultLifecycleObserver {
      override fun onStart(owner: LifecycleOwner) = sessionLock.onForeground()
      override fun onStop(owner: LifecycleOwner) = sessionLock.onBackground() // sau Activity cuối + ~700ms
    })
  }
}
