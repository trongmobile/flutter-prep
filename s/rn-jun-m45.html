Row đã bọc React.memo, nhưng mỗi khi Products re-render vì query đổi, mọi Row đang hiển thị vẫn render lại dù item không đổi. Nguyên nhân chính là gì?

const Row = React.memo(function Row({ item, onPress }: RowProps) {
  return <Text onPress={() => onPress(item.id)}>{item.title}</Text>;
});

function Products({ products }: { products: Product[] }) {
  const navigation = useNavigation();
  const [query, setQuery] = useState(''); // ô tìm kiếm gọi setQuery
  const openDetail = (id: string) => navigation.navigate('Detail', { id });

  return (
    <FlatList
      data={products}
      keyExtractor={(p) => p.id}
      renderItem={({ item }) => <Row item={item} onPress={openDetail} />}
    />
  );
}
  1. AFlatList mount lại mọi ô mỗi khi renderItem đổi tham chiếu
  2. BopenDetail là hàm mới mỗi lần render, memo thấy prop onPress đổi
  3. Citem là object nên React.memo không thể so sánh prop đó với lần trước
  4. DkeyExtractor là hàm inline nên React gán lại key cho từng ô mỗi lần
Xem đáp án
Đáp án đúng: B
React.memo so sánh nông từng prop bằng Object.is; openDetail được tạo lại ở mỗi lần render Products nên onPress luôn là tham chiếu mới và memo không bao giờ bỏ qua được. Bọc openDetail bằng useCallback (deps phù hợp) để giữ nguyên tham chiếu. item giữ nguyên tham chiếu nên so sánh bình thường, còn đổi renderItem hay keyExtractor không làm mount lại ô vì key tạo ra vẫn như cũ.
