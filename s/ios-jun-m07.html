Person giữ strong Phone, còn Phone giữ weak tới Person. Sau khi lần lượt gán hai biến về nil, các dòng nào được in ra theo thứ tự?

class Person {
  var phone: Phone?
  deinit { print("Person deinit") }
}
class Phone {
  weak var owner: Person?
  deinit { print("Phone deinit") }
}
var person: Person? = Person()
var phone: Phone? = Phone()
person?.phone = phone
phone?.owner = person
person = nil
print("giữa")
phone = nil
  1. AChỉ in giữa, không object nào được giải phóng
  2. BPerson deinit, Phone deinit, giữa
  3. Cgiữa, Person deinit, Phone deinit
  4. DPerson deinit, giữa, Phone deinit
Xem đáp án
Đáp án đúng: D
Phone chỉ giữ Person bằng weak, nên khi person = nil thì Person hết strong reference và bị huỷ ngay; nó thả strong reference tới Phone, nhưng biến phone vẫn giữ Phone nên Phone chưa bị huỷ. Chỉ khi phone = nil thì Phone deinit mới chạy; nếu cả hai chiều đều strong thì không object nào được giải phóng.
