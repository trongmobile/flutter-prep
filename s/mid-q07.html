vsync/TickerProvider trong AnimationController để làm gì? Khi nào dùng SingleTickerProviderStateMixin, khi nào dùng TickerProviderStateMixin?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Ticker gọi callback mỗi frame để controller cập nhật giá trị; vsync cung cấp Ticker chịu sự điều khiển của TickerMode, nên khi route bị route khác che hoàn toàn (offstage) animation tạm ngưng thay vì tiêu tốn CPU/pin. SingleTickerProviderStateMixin nhẹ hơn nhưng chỉ tạo được đúng một Ticker; State có từ hai controller trở lên (hoặc tạo lại controller nhiều lần) phải dùng TickerProviderStateMixin, nếu không sẽ gặp assertion 'multiple tickers were created'. Luôn dispose() controller trong dispose() của State, nếu không sẽ báo lỗi State bị dispose khi Ticker còn active.
class _PulseState extends State<Pulse> with SingleTickerProviderStateMixin {
  late final _c = AnimationController(
    vsync: this,
    duration: const Duration(milliseconds: 800),
  )..repeat(reverse: true);
  @override
  void dispose() {
    _c.dispose(); // bắt buộc, nếu không Ticker vẫn active
    super.dispose();
  }
  @override
  Widget build(BuildContext context) =>
      FadeTransition(opacity: _c, child: widget.child);
}
