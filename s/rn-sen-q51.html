Codebase có hơn 15 tính năng tách thành các feature package riêng, nhưng file navigator gốc đang import trực tiếp mọi màn hình nên vòng phụ thuộc ngày càng rối và sửa một màn hình kéo theo ảnh hưởng nhiều nơi. Bạn tổ chức kiến trúc điều hướng thế nào để các feature độc lập mà vẫn giữ TypeScript type-safe?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Nguyên tắc cốt lõi là đảo ngược phụ thuộc: feature module không được import navigator gốc hay import chéo feature khác, chỉ có tầng app shell đóng vai trò composition root để lắp ghép các navigator lại. Mỗi feature tự xuất ra một sub-navigator khép kín kèm kiểu param list của riêng nó, và có thể dùng getComponent trên Screen kết hợp inlineRequires để trì hoãn việc nạp code màn hình cho tới khi người dùng thật sự điều hướng tới. Để giữ type-safe khi điều hướng xuyên feature mà không tạo vòng phụ thuộc, mình tách một package nhẹ tên kiểu navigation-contracts chỉ chứa tên route, interface param list (ghép bằng declaration merging qua declare global cho ReactNavigation.RootParamList) và các hàm điều phối trừu tượng, tuyệt đối không import UI hay thư viện nặng. Tránh việc rải lệnh navigation.navigate lồng 3-4 tầng tab và stack khắp các feature vì chỉ cần đổi một màn từ tab ra modal là phải sửa hàng loạt file; thay vào đó các feature nên gọi qua các semantic intent hoặc typed route path để mọi thay đổi cấu trúc cây điều hướng chỉ nằm gói gọn ở app shell. Cuối cùng dùng ESLint (eslint-plugin-boundaries hoặc no-restricted-imports) để chặn cứng việc feature A import trực tiếp màn hình của feature B ngay từ lúc viết code.
// packages/navigation-contracts/src/index.ts (chỉ chứa types, không import UI)
export type CheckoutParams = { CheckoutConfirm: { orderId: string } };
export type OrdersParams = { OrderList: undefined; OrderDetail: { id: string } };

declare global {
  namespace ReactNavigation {
    interface RootParamList extends CheckoutParams, OrdersParams {}
  }
}

// apps/mobile/src/RootNavigator.tsx (composition root lắp ghép các feature)
<Stack.Screen
  name="OrderDetail"
  getComponent={() => require('@app/orders').OrderDetailScreen}
/>
