Danh sách todo dùng const [todos, setTodos] = useState<Todo[]>([]). Viết todos.push(newTodo); setTodos(todos); thì giao diện không cập nhật. Vì sao không được sửa state trực tiếp, và cập nhật mảng hay object trong state đúng cách thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
React so sánh state mới với state cũ bằng Object.is, tức so sánh tham chiếu với mảng và object. todos.push(...) sửa ngay mảng cũ rồi truyền lại đúng tham chiếu đó cho setTodos, nên React thấy "không đổi" và bỏ qua lần render. Sửa trực tiếp còn làm hỏng React.memo và các dependency của useEffect, vì chúng cũng dựa vào so sánh tham chiếu. Nguyên tắc: coi state là chỉ đọc, luôn tạo bản sao mới. Với mảng: thêm bằng [...todos, newTodo], xoá bằng filter, sửa một phần tử bằng map (trả về bản sao của đúng phần tử cần đổi, giữ nguyên các phần tử còn lại). Với object: { ...user, name: 'Bình' }; object lồng nhau phải spread từng tầng: { ...user, address: { ...user.address, city } }. Spread chỉ là shallow copy nên tầng sâu rất dễ quên; khi cấu trúc lồng quá sâu có thể dùng Immer (Redux Toolkit đã dùng sẵn). Khi giá trị mới phụ thuộc giá trị cũ, nên dùng dạng hàm setTodos((prev) => ...).
type Todo = { id: number; title: string; done: boolean };

const [todos, setTodos] = useState<Todo[]>([]);

// SAI: sửa mảng cũ, tham chiếu không đổi nên React bỏ qua lần render
// todos.push({ id: 1, title: 'Học RN', done: false });
// setTodos(todos);

const add = (todo: Todo) => setTodos((prev) => [...prev, todo]);
const remove = (id: number) => setTodos((prev) => prev.filter((t) => t.id !== id));
const toggle = (id: number) =>
  setTodos((prev) => prev.map((t) => (t.id === id ? { ...t, done: !t.done } : t)));

// Object lồng nhau: spread từng tầng
const [user, setUser] = useState({ name: 'An', address: { city: 'Hà Nội' } });
const moveTo = (city: string) => setUser((u) => ({ ...u, address: { ...u.address, city } }));
