Bạn cần dùng CLLocationManager (callback qua delegate) trong code async/await, dưới dạng for await location in tracker.updates(). Bạn bọc bằng AsyncStream thế nào, và cần để ý gì về huỷ, buffer và vòng đời?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
AsyncStream chuyển nguồn sự kiện kiểu delegate thành một chuỗi bất đồng bộ: tạo bằng AsyncStream.makeStream(of:bufferingPolicy:) để lấy cả stream lẫn continuation, gọi continuation.yield(value) từ callback (an toàn từ thread bất kỳ) và continuation.finish() khi nguồn kết thúc. Điểm quan trọng nhất là dọn dẹp: gán continuation.onTermination để dừng startUpdatingLocation() khi consumer thoát vòng lặp, Task bị huỷ hay stream kết thúc; thiếu bước này GPS chạy mãi và tốn pin. Về buffer, mặc định là .unbounded; với dữ liệu kiểu 'giá trị mới nhất' như vị trí nên dùng .bufferingNewest(1) để consumer chậm không làm bộ nhớ phình ra, còn sự kiện không được bỏ sót (log, tin nhắn) thì giữ .unbounded hoặc giới hạn có chủ đích. AsyncStream là unicast: nhiều consumer sẽ tranh nhau từng phần tử chứ không mỗi nơi nhận một bản, nên muốn chia sẻ cho nhiều nơi cần tạo stream riêng cho từng người đăng ký hoặc dùng Combine/AsyncChannel của swift-async-algorithms. Nguồn có thể lỗi thì dùng AsyncThrowingStream. Vòng for await nên chạy trong Task gắn với vòng đời UI (.task { } của SwiftUI tự huỷ khi view biến mất) để không tạo task mồ côi. Cuối cùng, tránh retain cycle giữa delegate, continuation và closure onTermination.
final class LocationTracker: NSObject, CLLocationManagerDelegate {
  private let manager = CLLocationManager()
  private var continuation: AsyncStream<CLLocation>.Continuation?

  func updates() -> AsyncStream<CLLocation> {
    let (stream, continuation) = AsyncStream.makeStream(
      of: CLLocation.self,
      bufferingPolicy: .bufferingNewest(1) // chỉ cần vị trí mới nhất
    )
    self.continuation = continuation
    manager.delegate = self
    manager.startUpdatingLocation()
    continuation.onTermination = { [weak self] _ in
      self?.manager.stopUpdatingLocation() // consumer thoát hoặc bị huỷ thì tắt GPS
    }
    return stream
  }

  func locationManager(_ manager: CLLocationManager, didUpdateLocations locations: [CLLocation]) {
    locations.forEach { continuation?.yield($0) }
  }
}

// SwiftUI: .task tự huỷ khi view biến mất, kéo theo onTermination
.task {
  for await location in tracker.updates() { model.update(location) }
}
