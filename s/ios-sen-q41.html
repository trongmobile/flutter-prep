App có 15 module và mỗi team tự xử lý onOpenURL theo cách riêng nên cùng một link mở ra hành vi khác nhau; link khuyến mãi https://shop.vn/promo?next=... còn từng bị lợi dụng để mở trang lạ trong WebView. Bạn thiết kế hệ thống universal link và deep link ở quy mô này thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Tầng xác minh: universal link cần file apple-app-site-association phục vụ qua HTTPS tại /.well-known/ (không redirect, trả JSON), khai appIDs dạng TEAMID.bundleid cùng các components được phép, và app có entitlement Associated Domains applinks:shop.vn. Apple lấy file qua CDN của họ nên sửa file không có hiệu lực tức thì và khó thử trên production; khi phát triển dùng chế độ developer (?mode=developer). Tầng định tuyến: đúng một DeepLinkRouter ở app target; parser thuần chuyển URL thành enum Route có kiểu (dễ unit test hàng trăm URL), mỗi feature module đăng ký handler cho route của mình qua một protocol ở module lõi nên các module không import nhau. Router lo ngữ cảnh: cold start (link tới qua scene(_:willConnectTo:options:) hoặc onOpenURL, phải đợi UI dựng xong), tab và stack hiện tại, và đăng nhập: route cần quyền thì lưu pending, chạy login, xong mới mở, và bỏ pending nếu user huỷ. Bảo mật: mọi thứ trong link là input không đáng tin. Dùng allowlist cho route và domain, validate kiểu và độ dài tham số, chỉ chấp nhận next hay url trỏ về host trong allowlist, và không để link tự kích hoạt hành động nhạy cảm (chuyển tiền, đổi email) mà không hỏi xác nhận. Custom scheme như shop:// không được xác minh, app khác có thể đăng ký trùng, nên không dùng cho dữ liệu nhạy cảm. Với deferred deep link (user chưa cài app), iOS không giữ ngữ cảnh qua App Store nên cần dịch vụ attribution hoặc server ghép phiên; tránh đọc clipboard lén vì hệ thống hiện banner và làm mất lòng tin.
enum Route: Equatable {
  case order(id: Int)
  case promo(code: String)

  var requiresLogin: Bool {
    if case .order = self { return true }
    return false
  }
}

enum RouteParser {
  static let allowedHosts: Set<String> = ["shop.vn", "www.shop.vn"]

  // Hàm thuần: URL vào, Route hoặc nil ra, không side effect nên test được hàng loạt
  static func parse(_ url: URL) -> Route? {
    guard let comps = URLComponents(url: url, resolvingAgainstBaseURL: false),
          let host = comps.host, allowedHosts.contains(host) else { return nil }
    let parts = comps.path.split(separator: "/").map(String.init)

    switch parts.first {
    case "orders"?:
      guard parts.count == 2, let id = Int(parts[1]) else { return nil }
      return .order(id: id)
    case "promo"?:
      let code = comps.queryItems?.first { $0.name == "code" }?.value
      guard let code, code.count <= 20, code.allSatisfy({ $0.isLetter || $0.isNumber }) else { return nil }
      return .promo(code: code)
    default:
      return nil
    }
  }
}

@MainActor
final class DeepLinkRouter {
  private var pending: Route?
  var isLoggedIn: () -> Bool = { false }
  var open: (Route) -> Void = { _ in }
  var showLogin: () -> Void = {}

  func handle(_ url: URL) {
    guard let route = RouteParser.parse(url) else { return } // link lạ thì bỏ qua
    if route.requiresLogin && !isLoggedIn() {
      pending = route
      showLogin()
    } else {
      open(route)
    }
  }

  func didLogin() {
    guard let route = pending else { return }
    pending = nil
    open(route)
  }
}
