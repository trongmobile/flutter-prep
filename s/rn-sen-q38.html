Mỗi bản phát hành app RN lại bị than "chậm hơn bản trước", nhưng team chỉ biết khi user phàn nàn và không ai rõ commit nào gây ra. Bạn xây hệ thống quan sát hiệu năng và chặn thoái lui thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Cần hai lớp bổ sung nhau. Lớp field (dữ liệu từ user thật): Sentry Performance, Firebase Performance hoặc Datadog RUM cho app start, slow/frozen frame và thời gian hiển thị của vài màn then chốt (tự đặt span từ lúc điều hướng tới khi dữ liệu đầu tiên hiện ra, vì RN không có sẵn một con số TTI chuẩn), cộng Android vitals, Xcode Organizer/MetricKit cho startup, hang, ANR, pin. Luôn cắt theo phiên bản app, dòng máy và p75/p90 chứ không nhìn trung bình, và so bản mới với bản cũ ngay trong lúc phát hành từng phần để dừng sớm. Lớp lab (dữ liệu tái lập được): chạy một kịch bản cố định (mở app, vào danh sách, cuộn, vào chi tiết) trên build release, trên một máy thật tầm trung dành riêng, lặp 10-20 lần rồi lấy median vì nhiễu rất lớn; Flashlight (chạy cùng Maestro) cho điểm CPU/FPS/RAM trên Android, còn Perfetto và Instruments dùng để xem chi tiết khi đã có hồi quy. React Profiler chỉ dùng để tìm render thừa lúc phát triển. Guardrail trong CI: so với baseline của nhánh main bằng ngưỡng tương đối (vd. startup tăng quá 10% thì fail hoặc cảnh báo), không dùng ngưỡng tuyệt đối vì máy CI nhiễu; kèm kiểm tra kích thước bundle như chỉ báo rẻ và đẩy kết quả lên comment của PR. Khi alert nổ, đối chiếu release với các commit trong khoảng đó để tìm thủ phạm.
// scripts/check-startup.ts: chạy sau benchmark, mỗi file JSON là mảng thời gian startup (ms) của từng lần chạy
import { readFileSync } from 'node:fs';

const median = (xs: number[]) => {
  const s = [...xs].sort((a, b) => a - b);
  const mid = Math.floor(s.length / 2);
  return s.length % 2 ? s[mid] : (s[mid - 1] + s[mid]) / 2;
};

const baseline = median(JSON.parse(readFileSync('baseline-main.json', 'utf8')));
const current = median(JSON.parse(readFileSync('current-pr.json', 'utf8')));
const change = (current - baseline) / baseline;

console.log(`startup median: ${baseline}ms -> ${current}ms (${(change * 100).toFixed(1)}%)`);
if (change > 0.1) {
  console.error('Startup chậm hơn quá 10% so với main');
  process.exit(1);
}
