Trong codebase có vài chỗ dùng GlobalScope.launch { } để lưu nháp hoặc gửi analytics sau khi người dùng rời màn hình, vì viewModelScope bị huỷ ngay lúc đó; các test cho những hàm này lại hay flaky. Bạn thay bằng gì, khi nào việc đó phải là WorkManager, và inject dispatcher để test thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
GlobalScope là API 'delicate': coroutine không có parent nên không bao giờ bị huỷ và không có structured concurrency, mặc định chạy trên Dispatchers.Default, lỗi chưa bắt đi thẳng thành crash, và test không điều khiển được dispatcher nên không biết khi nào việc chạy xong. Thay bằng một applicationScope được inject (singleton qua Hilt, có qualifier @ApplicationScope): CoroutineScope(SupervisorJob() + dispatcher + handler). SupervisorJob để một việc nền lỗi không kéo chết các việc khác, CoroutineExceptionHandler để ghi log, dispatcher inject từ ngoài. Chọn công cụ theo hậu quả khi process bị kill: việc cần sống lâu hơn một màn hình nhưng mất đi cũng chấp nhận được (lưu nháp, ghi log, làm mới cache) thì dùng applicationScope; việc phải chạy xong bằng được dù process chết hay máy khởi động lại, cần retry và ràng buộc mạng/pin (upload, đồng bộ) thì dùng WorkManager; việc người dùng đang chờ lâu thì foreground service. Cho hàm suspend của repository tự gọi appScope.launch { ... }.join() (hoặc async + await): người gọi chờ được kết quả, còn nếu họ bị huỷ thì việc vẫn chạy tiếp. Để test, repository nhận CoroutineScope và CoroutineDispatcher qua constructor (đừng hardcode Dispatchers.IO trong withContext); trong runTest truyền this hoặc backgroundScope làm scope, StandardTestDispatcher(testScheduler) làm dispatcher, rồi dùng advanceUntilIdle(). Cẩn thận lambda trong applicationScope giữ tham chiếu Activity là leak vĩnh viễn.
@Qualifier @Retention(AnnotationRetention.RUNTIME) annotation class ApplicationScope
@Qualifier @Retention(AnnotationRetention.RUNTIME) annotation class IoDispatcher

@Module @InstallIn(SingletonComponent::class)
object CoroutinesModule {
  @Provides @IoDispatcher
  fun ioDispatcher(): CoroutineDispatcher = Dispatchers.IO

  @Provides @Singleton @ApplicationScope
  fun appScope(@IoDispatcher io: CoroutineDispatcher): CoroutineScope =
    CoroutineScope(SupervisorJob() + io + CoroutineExceptionHandler { _, e -> Log.e("AppScope", "Việc nền lỗi", e) })
}

class DraftRepository @Inject constructor(
  private val dao: DraftDao,
  @ApplicationScope private val appScope: CoroutineScope,
) {
  // Người gọi bị huỷ (đóng màn hình) thì join() ném CancellationException, nhưng việc lưu vẫn chạy tiếp
  suspend fun save(draft: Draft) = appScope.launch { dao.upsert(draft) }.join()
}

@Test fun save_writesToDao() = runTest {
  val repo = DraftRepository(fakeDao, appScope = this) // TestScope làm applicationScope
  repo.save(Draft("nháp"))
  assertEquals(1, fakeDao.items.size)
}
