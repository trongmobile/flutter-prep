Điều nào đúng về universal link so với custom URL scheme (myapp://)?

  1. AChỉ cần khai báo scheme trong mục CFBundleURLTypes của Info.plist là đủ
  2. BKhi máy chưa cài app, link báo lỗi thay vì mở trang web
  3. CCần file apple-app-site-association trên domain và Associated Domains
  4. DApp nào cũng có thể đăng ký cùng domain đó để mở link
Xem đáp án
Đáp án đúng: C
Universal link dùng URL https thật: iOS xác minh app với domain qua file apple-app-site-association và entitlement applinks:, nên app khác không chiếm được, và nếu chưa cài app thì link mở website. CFBundleURLTypes là cách đăng ký custom scheme, loại có thể bị app khác đăng ký trùng.
