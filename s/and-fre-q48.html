Toast, Snackbar và AlertDialog khác nhau thế nào? Khi nào dùng cái nào, và vì sao dialog tạo thẳng trong Activity dễ gặp lỗi khi xoay máy?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Toast là thông báo ngắn tự biến mất, không có nút bấm, hợp cho phản hồi tức thì kiểu "Đã sao chép"; vì không gắn với layout của app nên người dùng dễ bỏ lỡ và không thể thao tác trên nó. Snackbar (Material) hiện ở đáy màn hình trong chính giao diện của app, có thể kèm một action như "Hoàn tác" hay "Thử lại", tự ẩn sau một thời gian hoặc giữ tới khi người dùng xử lý. Trong Compose, đặt SnackbarHost vào Scaffold và gọi snackbarHostState.showSnackbar(...), đây là hàm suspend nên gọi trong coroutine. AlertDialog chặn mọi tương tác phía sau và buộc người dùng quyết định, nên chỉ dùng cho việc quan trọng hoặc khó hoàn tác như xác nhận xoá; dùng bừa sẽ làm phiền. Compose hiển thị dialog theo state (if (showDialog) AlertDialog(...)) nên không cần nhớ gì thêm. Với View system, dialog dựng trực tiếp bằng MaterialAlertDialogBuilder trong Activity sẽ biến mất hoặc gây WindowLeaked khi Activity bị tạo lại lúc xoay máy, nên dùng DialogFragment vì FragmentManager tự khôi phục. Bẫy kinh điển: viết Toast.makeText(...) mà quên .show().
@Composable
fun DeleteNoteScreen(onDelete: suspend () -> Unit) {
  val snackbarHostState = remember { SnackbarHostState() }
  val scope = rememberCoroutineScope()
  var showConfirm by remember { mutableStateOf(false) }

  Scaffold(snackbarHost = { SnackbarHost(snackbarHostState) }) { padding ->
    Button(onClick = { showConfirm = true }, modifier = Modifier.padding(padding)) {
      Text("Xoá ghi chú")
    }
  }

  if (showConfirm) {                                      // dialog điều khiển bằng state
    AlertDialog(
      onDismissRequest = { showConfirm = false },
      title = { Text("Xoá ghi chú?") },
      text = { Text("Hành động này không thể hoàn tác.") },
      confirmButton = {
        TextButton(onClick = {
          showConfirm = false
          scope.launch {
            onDelete()
            snackbarHostState.showSnackbar("Đã xoá ghi chú") // phản hồi nằm trong giao diện app
          }
        }) { Text("Xoá") }
      },
      dismissButton = { TextButton(onClick = { showConfirm = false }) { Text("Huỷ") } },
    )
  }
}

// View system: phản hồi cực ngắn, nhớ gọi show()
Toast.makeText(context, "Đã sao chép", Toast.LENGTH_SHORT).show()
