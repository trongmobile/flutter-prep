Khi xử lý lỗi trong Dart, on, catch (e, st), rethrow và finally khác nhau thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
on FormatException bắt theo kiểu lỗi (viết on X catch (e) nếu cần object lỗi), nên đặt các nhánh cụ thể trước nhánh catch chung. catch (e, st) lấy thêm stack trace để log hoặc gửi lên hệ thống crash report; rethrow ném lại lỗi đang bắt và giữ nguyên stack trace gốc, còn throw e tạo stack trace mới tại chỗ ném lại. finally luôn chạy dù thành công hay lỗi, hợp để tắt loading. Với code async, tất cả chỉ có tác dụng khi lời gọi trong try được await.
Future<User> loadUser() async {
  try {
    return await api.fetchUser();
  } on TimeoutException {
    throw AppException('Mạng chậm, thử lại sau');
  } catch (e, st) {
    logger.error('loadUser failed', e, st);
    rethrow;
  } finally {
    _loading = false;
  }
}
