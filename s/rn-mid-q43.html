App cần đăng nhập bằng Google hoặc Azure AD (OIDC). Một dev mở trang đăng nhập trong react-native-webview rồi bắt URL redirect để lấy token cho nhanh. Vì sao không nên làm vậy, và làm đúng với Authorization Code + PKCE thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
App di động là public client, không giữ được client secret (giải nén IPA hoặc APK là thấy), nên dùng Authorization Code flow kèm PKCE, không dùng implicit flow. PKCE: app sinh code_verifier ngẫu nhiên, gửi code_challenge (băm SHA-256 của verifier) khi xin code, rồi gửi code_verifier lúc đổi code lấy token; kẻ chặn được code (vd. một app độc hại đăng ký cùng URL scheme) cũng không đổi được vì thiếu verifier. Không nên dùng WebView vì app chủ đọc được những gì người dùng gõ và cookie, người dùng không kiểm chứng được mình đang nhập mật khẩu ở đâu, không tận dụng được phiên SSO, mật khẩu đã lưu hay passkey của trình duyệt, và nhiều nhà cung cấp (như Google) chặn đăng nhập trong WebView nhúng. Hãy dùng trình duyệt hệ thống: ASWebAuthenticationSession trên iOS, Custom Tabs trên Android, được bọc bởi expo-auth-session (kèm expo-web-browser) hoặc react-native-app-auth. Redirect URI phải đăng ký khớp chính xác với IdP; ưu tiên universal link/App Link (https) hơn custom scheme vì scheme có thể bị app khác đăng ký; kiểm tra tham số state chống CSRF. Có token rồi: access token ngắn hạn giữ trong bộ nhớ, refresh token lưu Keychain/Keystore, làm mới khi hết hạn (nên xoay vòng), và khi đăng xuất thì thu hồi token ở IdP.
const discovery = AuthSession.useAutoDiscovery('https://login.example.com');
const redirectUri = AuthSession.makeRedirectUri({ scheme: 'myshop', path: 'auth' });

const [request, response, promptAsync] = AuthSession.useAuthRequest(
  {
    clientId: 'myshop-mobile', // public client: không có client secret
    scopes: ['openid', 'profile', 'offline_access'],
    redirectUri,
    usePKCE: true, // thư viện tự sinh code_verifier và code_challenge
  },
  discovery,
);

useEffect(() => {
  if (response?.type !== 'success' || !request || !discovery) return;
  AuthSession.exchangeCodeAsync(
    {
      clientId: 'myshop-mobile',
      code: response.params.code,
      redirectUri,
      extraParams: { code_verifier: request.codeVerifier ?? '' }, // chứng minh cùng một client đã xin code
    },
    discovery,
  ).then(saveTokensSecurely); // refresh token vào Keychain/Keystore
}, [response]);

// Mở trình duyệt hệ thống (không phải WebView): <Button title="Đăng nhập" onPress={() => promptAsync()} />
