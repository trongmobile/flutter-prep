Với cấu hình go_router sau, đang ở HomePage gọi context.go('/products/42') rồi nhấn back. Màn hình nào hiện ra?

GoRouter(routes: [
  GoRoute(path: '/', builder: (c, s) => const HomePage()),
  GoRoute(
    path: '/products',
    builder: (c, s) => const ProductsPage(),
    routes: [
      GoRoute(path: ':id', builder: (c, s) => const DetailPage()),
    ],
  ),
]);
  1. AHomePage, vì go đẩy trang mới lên trên stack hiện tại
  2. BKhông pop được vì stack chỉ còn DetailPage
  3. CProductsPage, vì go dựng stack theo cây route
  4. DHomePage, vì route / luôn nằm ở đáy stack
Xem đáp án
Đáp án đúng: C
go thay toàn bộ stack bằng các trang tương ứng với cây route của URL đích: /products/42 là con của /products nên stack là ProductsPage → DetailPage. Nếu dùng push, DetailPage mới được đặt lên trên HomePage và back sẽ quay về HomePage.
