Module dưới đây cache kết quả theo object product để khỏi tính lại. Sau vài giờ dùng app, memory tăng dần. Cách sửa hợp lý nhất?

const cache = new Map<Product, PriceInfo>();

export function getPriceInfo(product: Product): PriceInfo {
  let info = cache.get(product);
  if (!info) {
    info = computePriceInfo(product); // tốn CPU
    cache.set(product, info);
  }
  return info;
}
  1. AGọi cache.clear() trong cleanup của mọi useEffect có dùng tới getPriceInfo
  2. BĐổi sang WeakMap để entry được thu hồi khi product hết được tham chiếu
  3. CĐổi key thành JSON.stringify(product) để các object giống nhau dùng chung entry
  4. DKhông cần sửa: GC của Hermes tự xoá bớt entry của Map khi thiếu bộ nhớ

Đáp án đúng: B
Map giữ tham chiếu mạnh tới key nên mọi product từng đi qua đều không bao giờ được giải phóng. WeakMap không giữ key sống: object hết được tham chiếu thì entry bị thu hồi theo; key JSON.stringify vẫn tăng không giới hạn và còn tốn CPU serialize mỗi lần gọi.
