App dùng Core Data, thỉnh thoảng crash EXC_BAD_ACCESS hoặc báo truy cập NSManagedObject từ sai queue, và import 50.000 bản ghi từ server làm UI đứng vài giây. Bạn tổ chức concurrency của Core Data thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Core Data không thread-safe theo object: mỗi NSManagedObjectContext gắn với một queue riêng của nó và mọi truy cập context cùng các NSManagedObject của nó phải nằm trong perform/performAndWait; NSManagedObject không được truyền giữa context hay thread, chỉ truyền NSManagedObjectID (hoặc struct DTO) rồi tải lại bằng object(with:) ở context đích. Mô hình tôi dùng: viewContext (main queue) chỉ để đọc cho UI qua NSFetchedResultsController hoặc @FetchRequest, với automaticallyMergesChangesFromParent = true; mọi việc ghi (import, sync) chạy ở background context từ performBackgroundTask hoặc newBackgroundContext(), save ở đó rồi thay đổi tự merge lên viewContext. Với import lớn: xử lý theo từng batch (khoảng 500–1000 bản ghi, save rồi reset() context để nhả object), tìm bản ghi trùng bằng một lần fetch theo tập id thay vì fetch từng dòng, và dùng NSBatchInsertRequest (iOS 13 trở lên) để ghi thẳng xuống store mà không tạo NSManagedObject, nhanh hơn nhiều lần. Đổi lại batch request bỏ qua context nên phải tự báo cho viewContext biết bằng resultType = .objectIDs rồi NSManagedObjectContext.mergeChanges(fromRemoteContextSave:into:). Đặt mergePolicy phù hợp cho context ghi để xử lý xung đột. Để bắt lỗi sớm, bật launch argument -com.apple.CoreData.ConcurrencyDebug 1 để crash ngay lúc truy cập sai queue. Với SwiftData, tương đương là @ModelActor, và ModelContext cũng không thread-safe nên truyền PersistentIdentifier thay vì model giữa các nơi.
func importOrders(_ dtos: [OrderDTO]) async throws {
  try await container.performBackgroundTask { context in
    for chunk in dtos.chunked(into: 1000) { // chunked: helper tự viết
      let rows = chunk.map { ["id": $0.id, "total": $0.total, "status": $0.status] }
      let request = NSBatchInsertRequest(entity: OrderEntity.entity(), objects: rows)
      request.resultType = .objectIDs
      let result = try context.execute(request) as? NSBatchInsertResult

      if let ids = result?.result as? [NSManagedObjectID] {
        // Batch request bỏ qua context: phải tự báo cho viewContext để UI cập nhật
        NSManagedObjectContext.mergeChanges(
          fromRemoteContextSave: [NSInsertedObjectsKey: ids],
          into: [self.container.viewContext]
        )
      }
    }
  }
}
