Khi gọi ReportHelper().countItems('abc'), Isolate.run ném lỗi object không thể gửi qua isolate. Nguyên nhân và cách sửa đúng là gì?

class ReportHelper {
  final _port = ReceivePort();

  Future<int> countItems(String raw) {
    return Isolate.run(() => _parse(raw));
  }

  int _parse(String s) => s.length;
}
  1. AClosure () => _parse(raw) ngầm bắt this chứa ReceivePort; đổi _parse thành static hoặc hàm top-level.
  2. BIsolate.run chỉ nhận hàm top-level làm đối số; bắt buộc tách hẳn cả phần gọi Isolate.run ra ngoài class.
  3. CBiến raw bị giữ tham chiếu ở isolate chính nên không gửi được; cần chuyển raw sang TransferableTypedData.
  4. DHàm _parse là đồng bộ nên không chạy được trong Isolate.run; cần đổi kiểu trả về thành Future<int>.

Đáp án đúng: A
Vì _parse là instance method, () => _parse(raw) thực chất là () => this._parse(raw) nên closure ngầm capture cả instance this (ReportHelper), kéo theo field _port kiểu ReceivePort vốn không gửi được sang isolate khác. Đổi _parse thành static hoặc hàm top-level giúp closure không còn tham chiếu tới this. Isolate.run chấp nhận cả closure lẫn hàm đồng bộ (FutureOr<R> Function()) miễn là các giá trị bị capture gửi được qua isolate; còn String là immutable và gửi trực tiếp được nên không cần TransferableTypedData.
