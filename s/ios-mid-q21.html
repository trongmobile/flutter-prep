Bạn đổi constant của một constraint rồi gọi UIView.animate, nhưng view nhảy ngay sang vị trí mới mà không có animation. Giải thích layout cycle và cách sửa; setNeedsLayout khác layoutIfNeeded thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đổi constraint không cập nhật frame ngay: UIKit chỉ đánh dấu view cần layout lại, tới lần cập nhật kế tiếp của run loop mới chạy layoutSubviews từ trên xuống. setNeedsLayout() chỉ đánh dấu rồi trả về ngay, layout xảy ra sau; layoutIfNeeded() ép layout chạy đồng bộ ngay lập tức nếu đang có đánh dấu. Vì vậy muốn animate thì đổi constant trước, rồi trong block animation gọi layoutIfNeeded() trên view cha chung (thường là view của VC) để frame mới được tính bên trong animation. Nên gọi layoutIfNeeded() một lần trước khi đổi constraint để hoàn tất thay đổi đang chờ, tránh chúng bị cuốn vào animation. Cùng lý do đó, frame đọc trong viewDidLoad thường chưa đúng, hãy dùng viewDidLayoutSubviews.
view.layoutIfNeeded() // hoàn tất layout đang chờ
bottomConstraint.constant = keyboardHeight
UIView.animate(withDuration: 0.25) {
  self.view.layoutIfNeeded() // frame mới được tính trong block animation
}
