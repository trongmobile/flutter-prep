Đồng nghiệp làm đăng nhập vân tay/Face ID bằng LocalAuthentication.authenticateAsync() (expo-local-authentication): nếu success là true thì đọc token từ AsyncStorage và cho vào app. Reviewer cho rằng cách này yếu. Vì sao, và bạn gắn sinh trắc học với Keychain/Keystore thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
authenticateAsync chỉ trả về một boolean cho code JS, tức là một "cổng" trong ứng dụng chứ không bảo vệ dữ liệu. Trên máy root/jailbreak, kẻ tấn công dùng công cụ hook (như Frida) để ép kết quả thành true hoặc bỏ qua bước này, rồi đọc thẳng token trong AsyncStorage (không mã hoá). Cách đúng là để hệ điều hành giữ bí mật: lưu token vào Keychain (iOS) hoặc Keystore (Android) với access control yêu cầu sinh trắc học; khi đọc, chính OS hiện hộp thoại và chỉ giải mã sau khi xác thực thành công, nên bỏ qua UI thì không lấy được dữ liệu. Với react-native-keychain dùng accessControl như BIOMETRY_CURRENT_SET (khoá mất hiệu lực khi người dùng thêm hoặc xoá vân tay) hay BIOMETRY_ANY, kèm accessible: WHEN_UNLOCKED_THIS_DEVICE_ONLY để không đi theo backup sang máy khác; expo-secure-store có requireAuthentication tương tự. Phải có đường lùi: máy không có hoặc chưa đăng ký sinh trắc học (hasHardwareAsync, isEnrolledAsync), người dùng huỷ, bị khoá sau nhiều lần sai, hoặc khoá bị vô hiệu vì đổi vân tay: bắt lỗi rồi quay về đăng nhập bằng mật khẩu và lưu lại bí mật mới. Đừng giữ một cờ "đã xác thực" lâu dài trong state. Phía server vẫn cần refresh token xoay vòng, thu hồi theo thiết bị và bắt xác thực lại với thao tác giá trị cao. Tên option khác nhau giữa các phiên bản thư viện, nên đối chiếu tài liệu bản đang dùng.
import * as Keychain from 'react-native-keychain';

// Lưu: bí mật bị khoá bởi hệ điều hành, đọc ra phải qua sinh trắc học
await Keychain.setGenericPassword('session', refreshToken, {
  accessControl: Keychain.ACCESS_CONTROL.BIOMETRY_CURRENT_SET, // vô hiệu khi thay đổi vân tay đã đăng ký
  accessible: Keychain.ACCESSIBLE.WHEN_UNLOCKED_THIS_DEVICE_ONLY, // không đi theo backup sang máy khác
});

async function unlockWithBiometrics(): Promise<string | null> {
  try {
    // OS hiện hộp thoại sinh trắc học; thất bại hoặc huỷ thì không có dữ liệu trả về
    const creds = await Keychain.getGenericPassword({
      authenticationPrompt: { title: 'Đăng nhập nhanh' },
    });
    return creds ? creds.password : null;
  } catch {
    return null; // huỷ, bị khoá hoặc khoá bị vô hiệu: quay lại đăng nhập bằng mật khẩu
  }
}
