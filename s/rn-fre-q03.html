this trong JavaScript được xác định thế nào? Arrow function khác function thường ở điểm nào về this?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Với function thường, this được quyết định lúc gọi chứ không phải lúc khai báo: gọi user.greet() thì this là user, nhưng gán const f = user.greet rồi gọi f() thì this không còn là user: trong strict mode (mặc định của ES module và class) nó là undefined và truy cập this.name sẽ ném lỗi. Arrow function không có this riêng mà dùng this của scope bao quanh nơi nó được viết, và call/apply/bind cũng không đổi được. Vì vậy arrow function hợp làm callback bên trong method (setTimeout, map), còn method của object cần dùng this thì không nên viết bằng arrow. Với function component và hooks gần như không cần this; nó chủ yếu còn gặp ở class component cũ, nơi phải bind handler hoặc khai báo handler bằng arrow class field.
