Header sản phẩm cần thu nhỏ và mờ dần theo vị trí cuộn của FlatList. Bạn viết onScroll={(e) => setY(e.nativeEvent.contentOffset.y)} rồi tính style từ y, và header bị giật. Vì sao, và làm bằng Reanimated thế nào để animation mượt kể cả khi JS thread đang bận?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
setY mỗi sự kiện cuộn đẩy dữ liệu từ native sang JS rồi re-render cả component, vừa tốn vừa trễ, nên rớt frame ngay khi JS thread bận. Cách đúng là giữ vị trí cuộn trong shared value và tính style trên UI thread. Với Reanimated: useSharedValue cùng useAnimatedScrollHandler gắn vào Animated.FlatList hoặc Animated.ScrollView (handler là worklet chạy thẳng trên UI thread, không đi qua JS), rồi useAnimatedStyle dùng interpolate(scrollY.value, inputRange, outputRange, Extrapolation.CLAMP) để biến offset thành chiều cao hay độ mờ. Extrapolation.CLAMP giữ giá trị trong khoảng đã khai báo; thiếu nó thì khi kéo đàn hồi quá đầu trang trên iOS header sẽ bị nội suy vượt biên. Trên iOS nên đặt scrollEventThrottle={16} để nhận sự kiện mỗi frame. Với core Animated, Animated.event kết hợp useNativeDriver: true cũng chạy được trên native nhưng chỉ animate các thuộc tính hỗ trợ native driver (transform, opacity, không có height), không chạy được logic tuỳ ý như rẽ nhánh, snap hay haptic. Reanimated cho chạy code trong worklet và animate cả layout, nhưng đổi height mỗi frame buộc layout lại nên tốn hơn; nếu thiết kế cho phép, ưu tiên transform (scale, translateY) và opacity. Worklet không gọi được hàm JS thông thường, phải đưa qua cơ chế của thư viện (như runOnJS, tên có thể đổi ở bản mới). Đo trên bản release và theo dõi cả UI FPS lẫn JS FPS.
import Animated, {
  Extrapolation,
  interpolate,
  useAnimatedScrollHandler,
  useAnimatedStyle,
  useSharedValue,
} from 'react-native-reanimated';

const HEADER_MAX = 200;
const HEADER_MIN = 80;
const RANGE = HEADER_MAX - HEADER_MIN;

export function ProductScreen() {
  const scrollY = useSharedValue(0);
  const onScroll = useAnimatedScrollHandler((e) => {
    scrollY.value = e.contentOffset.y; // worklet: chạy trên UI thread, không đi qua JS
  });

  const headerStyle = useAnimatedStyle(() => ({
    height: interpolate(scrollY.value, [0, RANGE], [HEADER_MAX, HEADER_MIN], Extrapolation.CLAMP),
    opacity: interpolate(scrollY.value, [0, RANGE], [1, 0.85], Extrapolation.CLAMP),
  }));

  return (
    <>
      <Animated.View style={[styles.header, headerStyle]} />
      <Animated.FlatList
        data={items}
        renderItem={renderItem}
        onScroll={onScroll}
        scrollEventThrottle={16}
        contentContainerStyle={{ paddingTop: HEADER_MAX }}
      />
    </>
  );
}
