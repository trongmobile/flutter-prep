Feed dùng useInfiniteQuery (TanStack Query v5), mỗi trang API trả về { items: Post[], nextCursor?: string }. Cách đúng để đưa dữ liệu vào FlatList là gì?

  1. Adata={data}, vì data của useInfiniteQuery đã là mảng gộp sẵn item của mọi trang đã được tải
  2. Bdata={data?.pages.map((p) => p.items)}, vì map trả về danh sách item của từng trang
  3. Cdata={data?.pages.flat()}, vì flat() trải mỗi trang thành các item bên trong nó
  4. Ddata={data?.pages.flatMap((p) => p.items) ?? []}, vì mỗi trang là một object cần trải items ra
Xem đáp án
Đáp án đúng: D
data của useInfiniteQuery là { pages, pageParams }, mỗi phần tử của pages là kết quả nguyên vẹn của một trang (ở đây là { items, nextCursor }). flatMap lấy items của từng trang rồi nối thành một mảng phẳng; map cho ra mảng lồng nhau, còn flat() không đụng tới object trang nên renderItem sẽ nhận sai kiểu. data là undefined trước lần tải đầu nên cần ?? [] (hoặc gộp sẵn bằng select).
