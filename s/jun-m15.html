Tạo Future ngay trong build để truyền cho FutureBuilder: vấn đề lớn nhất của đoạn code sau là gì?

@override
Widget build(BuildContext context) {
  return FutureBuilder<List<Product>>(
    future: api.fetchProducts(),
    builder: (context, snapshot) {
      if (!snapshot.hasData) {
        return const CircularProgressIndicator();
      }
      return ProductList(products: snapshot.data!);
    },
  );
}
  1. AFutureBuilder chỉ nhận Stream, không nhận Future
  2. BPhải await api.fetchProducts() trước khi truyền vào
  3. Csnapshot.data! luôn null ở lần build đầu nên app crash
  4. DMỗi lần rebuild lại gọi API và hiện loading từ đầu
Xem đáp án
Đáp án đúng: D
build có thể chạy nhiều lần (setState, đổi theme, bật bàn phím…), mỗi lần lại tạo Future mới nên FutureBuilder quay về trạng thái chờ. Hãy tạo Future một lần trong initState và lưu vào field; snapshot.data! không crash vì chỉ được đọc sau khi hasData là true.
