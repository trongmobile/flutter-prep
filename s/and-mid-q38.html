App bản release nặng 85 MB, Play Console cảnh báo dung lượng tải xuống làm giảm tỉ lệ cài ở thị trường mạng yếu. Bạn phân tích và giảm kích thước app thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đo trước khi cắt: phân biệt download size (Play đã nén và chia split) với install size, rồi mở bản build bằng APK Analyzer (Build > Analyze APK) để xem phần nào lớn nhất: classes.dex, res/, lib/ (thư viện native .so), assets/. Cắt code và resource: bật R8 (isMinifyEnabled = true) cùng isShrinkResources = true (chỉ có tác dụng khi đã minify; resource được tham chiếu động qua getIdentifier cần res/raw/keep.xml để khỏi bị xoá nhầm). Ảnh: đổi PNG sang WebP, icon dùng vector drawable, ảnh lớn thì tải từ server thay vì đóng gói. Phát hành bằng AAB để Play tự tạo split theo ABI, density và ngôn ngữ, nên đừng tự đặt abiFilters trừ khi còn phát hành APK ngoài Play; có thể giới hạn ngôn ngữ do thư viện kéo vào (androidResources.localeFilters, trước đây là resourceConfigurations). Thư viện nặng: xem từng package trong dex và thư mục lib/ để tìm thủ phạm (SDK kéo theo native lib cho cả 4 ABI, một thư viện lớn chỉ để dùng một hàm nhỏ), cân nhắc thay bằng bản nhẹ hơn hoặc tách tính năng ít dùng ra Play Feature Delivery (dynamic feature). Cuối cùng đưa kích thước vào CI, so với bản trước và báo khi tăng quá ngưỡng, vì dung lượng thường phình dần qua từng PR.
android {
  buildTypes {
    release {
      isMinifyEnabled = true
      isShrinkResources = true // chỉ có tác dụng khi isMinifyEnabled = true
      proguardFiles(
        getDefaultProguardFile("proguard-android-optimize.txt"),
        "proguard-rules.pro",
      )
    }
  }
  bundle {
    language { enableSplit = true } // mặc định đã bật: user chỉ tải ngôn ngữ của máy
    density { enableSplit = true }
    abi { enableSplit = true }
  }
}
