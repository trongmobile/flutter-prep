Màn lịch sử giao dịch hiển thị khoảng 5.000 dòng bằng đoạn code sau, mất vài giây mới hiện và memory tăng vọt. Nguyên nhân chính là gì?

ScrollView {
  VStack {
    ForEach(transactions) { tx in // Transaction: Identifiable
      TransactionRow(tx: tx)
    }
  }
}
  1. AForEach thiếu id: \.self nên SwiftUI phải so sánh cả dữ liệu
  2. BTransactionRow là struct nên bị copy lại toàn bộ mỗi lần cuộn
  3. CScrollView vẽ bằng CPU, cần thêm .drawingGroup() để dùng GPU
  4. DVStack dựng và layout cả 5.000 row ngay, nên dùng LazyVStack
Xem đáp án
Đáp án đúng: D
VStack không lazy: nó tạo và đo kích thước mọi view con ngay khi hiển thị, dù chỉ vài chục dòng nằm trên màn hình; LazyVStack hoặc List chỉ tạo row khi sắp xuất hiện. Transaction đã Identifiable nên ForEach có id ổn định, còn copy struct view rất rẻ, không phải nút thắt.
