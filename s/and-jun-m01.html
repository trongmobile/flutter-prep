Kết hợp apply và let trên cùng một MutableList, đoạn code sau in ra gì?

val list = mutableListOf(1, 2)
val a = list.apply { add(3) }.size
val b = list.let { it.add(4) }
println("$a $b")
  1. A3 4
  2. B2 true
  3. C3 true
  4. D3 [1, 2, 3, 4]
Xem đáp án
Đáp án đúng: C
apply trả về chính object nên .size là 3 sau khi thêm phần tử. let trả về kết quả của lambda, ở đây là giá trị Boolean của add(4), nên b là true chứ không phải list hay phần tử vừa thêm.
