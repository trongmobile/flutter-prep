Form đăng ký có nhiều TextField: bấm Enter trên bàn phím phải nhảy sang ô tiếp theo, ô cuối thì gửi form, chạm ra ngoài thì ẩn bàn phím, và khi validate sai thì phải focus vào ô lỗi. Bạn quản lý focus bằng FocusNode, TextInputAction và onTapOutside thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mỗi ô nhập có một FocusNode; TextInputAction.next đổi nút Enter thành 'Tiếp' và onSubmitted/onFieldSubmitted chuyển focus bằng FocusScope.of(context).nextFocus() (đi theo thứ tự traversal mặc định) hoặc requestFocus tới một node cụ thể; ô cuối đặt TextInputAction.done và gọi hàm gửi. FocusNode do bạn tạo phải tạo một lần trong initState và dispose() trong dispose, giống TextEditingController. Ẩn bàn phím khi chạm ra ngoài: TextField(onTapOutside: (_) => FocusManager.instance.primaryFocus?.unfocus()) (có từ Flutter 3.7), hoặc bọc cả màn hình bằng GestureDetector(onTap: () => FocusScope.of(context).unfocus()). Khi validate sai, tìm ô lỗi đầu tiên rồi focusNode.requestFocus() (Flutter tự cuộn tới ô đang focus trong vùng cuộn) hoặc Scrollable.ensureVisible(context, ...); Form với autovalidateMode hiện lỗi sau khi người dùng tương tác và FormState.validate() trả về bool. autofocus: true hợp cho ô đầu của màn đơn giản nhưng đừng dùng ở mọi màn vì bàn phím bật lên bất ngờ. Dùng AutofillGroup và autofillHints (như AutofillHints.email) để hệ điều hành gợi ý email hay mật khẩu. Khi thứ tự tab tự nhiên không đúng (bàn phím cứng, web, desktop) thì dùng FocusTraversalGroup kèm OrderedTraversalPolicy.
class _SignUpFormState extends State<SignUpForm> {
  final _formKey = GlobalKey<FormState>();
  final _emailFocus = FocusNode();
  final _passwordFocus = FocusNode();

  @override
  void dispose() {
    _emailFocus.dispose(); // FocusNode phải được dispose
    _passwordFocus.dispose();
    super.dispose();
  }

  void _submit() {
    if (!_formKey.currentState!.validate()) {
      // Minh hoạ: thực tế tìm ô lỗi đầu tiên rồi requestFocus, Flutter tự cuộn tới ô đang focus
      _emailFocus.requestFocus();
      return;
    }
    // gửi form...
  }

  @override
  Widget build(BuildContext context) {
    return Form(
      key: _formKey,
      child: Column(
        children: [
          TextFormField(
            focusNode: _emailFocus,
            textInputAction: TextInputAction.next, // Enter chuyển sang ô kế tiếp
            keyboardType: TextInputType.emailAddress,
            autofillHints: const [AutofillHints.email],
            onFieldSubmitted: (_) => _passwordFocus.requestFocus(),
            onTapOutside: (_) => FocusManager.instance.primaryFocus?.unfocus(), // chạm ra ngoài thì ẩn bàn phím
          ),
          TextFormField(
            focusNode: _passwordFocus,
            obscureText: true,
            textInputAction: TextInputAction.done, // ô cuối: Enter gửi form
            onFieldSubmitted: (_) => _submit(),
            onTapOutside: (_) => FocusManager.instance.primaryFocus?.unfocus(),
          ),
        ],
      ),
    );
  }
}
