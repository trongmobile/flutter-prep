Khi nào dùng shared_preferences trong Flutter? Cách đọc, ghi thế nào, và những giới hạn cần nhớ (bất đồng bộ, kiểu dữ liệu, không dùng cho dữ liệu nhạy cảm hay dữ liệu lớn)?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
shared_preferences lưu các cặp key–value nhỏ và bền sau khi tắt app (UserDefaults trên iOS, SharedPreferences trên Android), hợp với cài đặt đơn giản như theme, ngôn ngữ, cờ đã xem onboarding. Lấy instance bằng await SharedPreferences.getInstance() (bất đồng bộ, nên khởi tạo một lần ở main() hoặc qua DI rồi tái sử dụng), sau đó dùng getBool, getString, getInt, getDouble, getStringList (trả null nếu chưa có nên kèm ?? giáTrịMặcĐịnh) và các hàm setX (trả Future<bool>, cần await nếu muốn chắc đã ghi xong). Chỉ hỗ trợ kiểu nguyên thuỷ và List<String>; object phức tạp phải tự jsonEncode, và bạn chịu trách nhiệm migrate khi đổi cấu trúc. Giới hạn: không mã hoá nên không lưu token hay mật khẩu (dùng flutter_secure_storage), không dành cho dữ liệu lớn hay cần truy vấn (dùng SQLite, Drift hoặc Isar), và ghi từ nhiều isolate cần cẩn thận vì mỗi isolate có bản cache riêng (dùng reload(), hoặc API SharedPreferencesAsync mới hơn của package). Khi test, dùng SharedPreferences.setMockInitialValues({...}) để đặt dữ liệu giả.
class SettingsRepository {
  SettingsRepository(this._prefs);
  final SharedPreferences _prefs; // lấy instance một lần rồi truyền vào

  bool get seenOnboarding => _prefs.getBool('seen_onboarding') ?? false;
  Future<void> markOnboardingSeen() => _prefs.setBool('seen_onboarding', true);

  ThemeMode get themeMode =>
      ThemeMode.values.byName(_prefs.getString('theme_mode') ?? 'system');
  Future<void> setThemeMode(ThemeMode mode) => _prefs.setString('theme_mode', mode.name);
}

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final prefs = await SharedPreferences.getInstance();
  runApp(MyApp(settings: SettingsRepository(prefs)));
}

// Test: dữ liệu khởi tạo giả
SharedPreferences.setMockInitialValues({'seen_onboarding': true});
