App SwiftUI có AuthService cần dùng ở nhiều màn nằm sâu trong cây view; truyền qua từng init thì rườm rà, còn chuyển sang @EnvironmentObject thì có màn Preview crash với 'No ObservableObject of type AuthService found'. @EnvironmentObject, @Environment với model @Observable và EnvironmentKey khác nhau thế nào, và khi nào nên truyền tham số trực tiếp?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Environment truyền giá trị xuống cây con một cách ngầm. @EnvironmentObject đọc một ObservableObject do view cha gọi .environmentObject(_:); quên inject thì không có lỗi compile mà crash lúc chạy, thường lộ ra ở #Preview, hoặc ở view bọc trong UIHostingController tự tạo vì nó là gốc của một cây mới, không thừa hưởng environment. Từ iOS 17, model @Observable đưa vào bằng .environment(model) và đọc bằng @Environment(AuthService.self); cũng crash nếu thiếu, trừ khi khai báo kiểu optional (AuthService?) thì nhận nil. Giá trị thông thường (cấu hình, theme, service qua protocol) dùng EnvironmentKey tự định nghĩa kèm defaultValue rồi mở rộng EnvironmentValues: không crash vì có sẵn giá trị mặc định, và ghi đè được trong preview hay test bằng .environment(\.key, value); từ Xcode 16 macro @Entry viết gọn phần này. Chỉ nên đưa vào environment thứ thật sự cắt ngang nhiều tầng (người dùng hiện tại, theme, router); màn chỉ cần một hai dependency thì truyền qua init cho tường minh, test dễ và compiler bắt thiếu. Với ObservableObject, mọi thay đổi @Published đều làm view đọc nó vẽ lại, nên đừng nhét một 'god object' vào environment.
@Observable final class AuthService {
  var user: User?
}

@main
struct ShopApp: App {
  @State private var auth = AuthService()

  var body: some Scene {
    WindowGroup { RootView().environment(auth) }
  }
}

struct ProfileView: View {
  @Environment(AuthService.self) private var auth   // thiếu .environment(auth) ở trên thì crash

  var body: some View { Text(auth.user?.name ?? "Khách") }
}

// Giá trị thường: custom key có defaultValue nên không crash
struct AppConfig: Sendable { var baseURL: URL }

private struct AppConfigKey: EnvironmentKey {
  static let defaultValue = AppConfig(baseURL: URL(string: "https://api.example.com")!)
}

extension EnvironmentValues {
  var appConfig: AppConfig {
    get { self[AppConfigKey.self] }
    set { self[AppConfigKey.self] = newValue }
  }
}
// Preview: ProfileView().environment(AuthService()).environment(\.appConfig, staging)
