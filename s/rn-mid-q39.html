Màn theo dõi đơn hàng cần hiện trạng thái và vị trí tài xế gần realtime. Bạn chọn polling, WebSocket hay push? Cần xử lý gì khi app xuống nền, khi mạng chập chờn, và làm sao để không hao pin hay rò rỉ kết nối?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Polling (TanStack Query refetchInterval) đơn giản nhưng tốn request và có độ trễ; hợp khi cập nhật thưa hoặc chưa có kênh realtime. WebSocket (hoặc SSE) hợp khi người dùng đang nhìn màn hình và cần cập nhật liên tục: một kết nối giữ mở, server đẩy sự kiện. Push (FCM/APNs) dùng để báo khi app không ở foreground, không thay được realtime vì thời điểm giao không đảm bảo. Thường kết hợp: socket khi foreground, push khi ở nền. Với AppState: sang background thì đóng socket (OS sớm muộn cũng treo JS và kết nối chết, giữ lại chỉ tốn pin), quay về active thì gọi API lấy snapshot mới nhất rồi mới mở lại socket để không mất sự kiện trong lúc đóng. Mất kết nối thì reconnect với exponential backoff kèm jitter (1s, 2s, 4s… tối đa khoảng 30s, nhân một hệ số ngẫu nhiên) để hàng nghìn client không dồn vào server cùng lúc khi nó hồi phục; reset backoff khi kết nối đã ổn định, và có thể nghe NetInfo để thử lại ngay khi có mạng. Cleanup trong useEffect (đóng socket, clearTimeout, bỏ listener) khi rời màn hình, nếu không mỗi lần vào ra màn hình lại sinh thêm một kết nối; màn nằm trong stack nhưng không focus thì cân nhắc useFocusEffect. Sự kiện có thể đến lặp hoặc sai thứ tự, nên kèm version/sequence để bỏ qua bản cũ.
function useOrderStream(orderId: string, onEvent: (e: OrderEvent) => void) {
  // giả định onEvent ổn định (vd. truyền thẳng setState) để effect không chạy lại
  useEffect(() => {
    let ws: WebSocket | null = null;
    let timer: ReturnType<typeof setTimeout> | undefined;
    let retry = 0;
    let stopped = false;

    const connect = () => {
      ws = new WebSocket('wss://api.shop.vn/orders/' + orderId + '/stream');
      ws.onopen = () => { retry = 0; };
      ws.onmessage = (m) => onEvent(JSON.parse(m.data));
      ws.onclose = () => {
        if (stopped) return;
        // backoff luỹ thừa, trần 30s, nhân jitter 0.5–1 để các client không reconnect cùng lúc
        const delay = Math.min(30_000, 1000 * 2 ** retry++) * (0.5 + Math.random() / 2);
        timer = setTimeout(connect, delay);
      };
    };
    const stop = () => { stopped = true; clearTimeout(timer); ws?.close(); };

    const sub = AppState.addEventListener('change', (state) => {
      if (state === 'background') stop();
      else if (state === 'active' && stopped) {
        stopped = false;
        retry = 0;
        refetchOrderSnapshot(orderId); // lấy trạng thái hiện tại trước, rồi mới nghe tiếp sự kiện
        connect();
      }
    });

    connect();
    return () => { stop(); sub.remove(); };
  }, [orderId]);
}
