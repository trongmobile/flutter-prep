Khi event WatchPrices được add và prices phát dữ liệu mới, đoạn code flutter_bloc (v8+) dưới đây gặp vấn đề gì và cách sửa chuẩn là gì?

class PriceBloc extends Bloc<PriceEvent, PriceState> {
  PriceBloc(Stream<double> prices) : super(PriceInitial()) {
    on<WatchPrices>((event, emit) {
      prices.listen((value) => emit(PriceUpdated(value)));
    });
  }
}
  1. ACode chạy bình thường nhưng stream không tự huỷ khi Bloc đóng; cần gán StreamSubscription rồi cancel trong close().
  2. Bprices.listen chặn event loop của Bloc nên các event khác không chạy được; cần bọc lời gọi trong Isolate.run.
  3. Con<WatchPrices> mặc định bỏ qua stream bất đồng bộ; cần truyền transformer: concurrent() để nhận sự kiện liên tục.
  4. Demit ném lỗi vì handler đã kết thúc trước khi stream phát dữ liệu; cần dùng await emit.forEach hoặc emit.onEach.
Xem đáp án
Đáp án đúng: D
Trong flutter_bloc v8+, handler của on<WatchPrices> trả về ngay sau khi gọi prices.listen(...) vì không có await. Khi stream phát dữ liệu về sau, Emitter đã ở trạng thái hoàn tất nên gọi emit(...) sẽ ném lỗi. Cách đúng là dùng await emit.forEach(...) hoặc await emit.onEach(...) để giữ handler sống theo stream và tự động huỷ subscription khi Bloc đóng hoặc event bị thay thế bởi transformer. Giữ StreamSubscription tự cancel vẫn gặp lỗi emit sau khi handler hoàn tất, listen không chặn event loop, còn concurrent() chỉ điều phối nhiều event chạy song song chứ không giữ handler mở.
