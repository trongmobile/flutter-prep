Bạn muốn [1, 2, 3].total() và [1.5, 2.5].total() đều dùng được, còn ["a"].total() báo lỗi compile. Khai báo nào đúng?

  1. Aextension Array where Element: Equatable { func total() -> Element { reduce(0, +) } }
  2. Bextension Array where Element == Int { func total() -> Element { reduce(0, +) } }
  3. Cextension Array where Element: Numeric { func total() -> Element { reduce(0, +) } }
  4. Dextension Numeric { func total() -> Self { reduce(0, +) } }
Xem đáp án
Đáp án đúng: C
Ràng buộc where Element: Numeric chỉ thêm total() cho mảng phần tử là số; Numeric cho phép dùng literal 0 và toán tử + nên cả Int lẫn Double đều dùng được. Element == Int quá hẹp vì mảng Double không có total(), còn Equatable không đảm bảo có + và literal 0 nên extension đó không compile.
