Scope có CoroutineExceptionHandler, còn coroutine lỗi được tạo bằng async. Chương trình in ra gì?

val handler = CoroutineExceptionHandler { _, e -> println("handled: ${e.message}") }
val scope = CoroutineScope(SupervisorJob() + handler)

fun main() = runBlocking {
  val d = scope.async { throw IllegalStateException("boom") }
  delay(100)
  println("after")
  try { d.await() } catch (e: Exception) { println("caught: ${e.message}") }
}
  1. Ahandled: boom rồi after
  2. Bhandled: boom, after, rồi caught: boom
  3. Cafter rồi chương trình crash vì exception không được bắt
  4. Dafter rồi caught: boom
Xem đáp án
Đáp án đúng: D
CoroutineExceptionHandler chỉ được gọi cho exception không ai xử lý của coroutine kiểu launch. Với async, exception được giữ trong Deferred và ném ra khi await(), nên handler không chạy và lỗi được bắt bởi try/catch quanh await().
