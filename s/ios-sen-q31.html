App UIKit lớn muốn viết màn mới bằng SwiftUI và chuyển dần màn cũ, đồng thời tái dùng một MKMapView đã có trong màn SwiftUI. Bạn nhúng hai chiều thế nào, và những bẫy về vòng đời, kích thước và state là gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
SwiftUI trong UIKit: bọc view bằng UIHostingController, thêm làm child view controller đúng quy trình (addChild, thêm view kèm constraint, didMove(toParent:)) hoặc push thẳng vào UINavigationController; trong cell dùng UIHostingConfiguration (iOS 16 trở lên) để dựng nội dung cell bằng SwiftUI mà vẫn được collection view tái chế. Về kích thước, hosting controller tính kích thước theo nội dung SwiftUI, với self-sizing và Auto Layout cần để ý sizingOptions (iOS 16), và view bên trong không tự nhận safe area hay navigation bar giống màn SwiftUI thuần. Truyền dữ liệu: model @Observable hay ObservableObject do UIKit giữ và đưa vào rootView, còn sự kiện đi ngược bằng closure, để view controller hoặc coordinator vẫn là chủ sở hữu điều hướng. UIKit trong SwiftUI: dùng UIViewRepresentable hay UIViewControllerRepresentable; makeUIView chỉ chạy một lần khi view được tạo, updateUIView chạy mỗi khi state SwiftUI đổi nên phải idempotent và so sánh trước khi cập nhật (đặt lại vùng nhìn của bản đồ mỗi lần SwiftUI render sẽ giật); delegate và target-action đi qua Coordinator (tạo bởi makeCoordinator()), và dọn dẹp ở dismantleUIView. Chiến lược: không viết lại big bang; có design system dùng chung token (màu, font) cho cả hai framework, màn mới bằng SwiftUI, màn cũ chỉ chuyển khi đằng nào cũng phải sửa lớn; test các khác biệt như bàn phím và navigation bar trên nhiều phiên bản iOS, và đo launch time cùng memory vì hosting có chi phí khởi tạo.
// SwiftUI trong UIKit: nhúng đúng quy trình child view controller
let host = UIHostingController(rootView: OrderSummaryView(model: model))
addChild(host)
host.view.translatesAutoresizingMaskIntoConstraints = false
view.addSubview(host.view)
NSLayoutConstraint.activate([
  host.view.topAnchor.constraint(equalTo: view.safeAreaLayoutGuide.topAnchor),
  host.view.leadingAnchor.constraint(equalTo: view.leadingAnchor),
  host.view.trailingAnchor.constraint(equalTo: view.trailingAnchor),
  host.view.bottomAnchor.constraint(equalTo: view.bottomAnchor),
])
host.didMove(toParent: self)

// UIKit trong SwiftUI: makeUIView chạy một lần, updateUIView chạy mỗi khi state đổi
struct StoreMap: UIViewRepresentable {
  var center: CLLocationCoordinate2D

  func makeUIView(context: Context) -> MKMapView {
    let map = MKMapView()
    map.delegate = context.coordinator
    return map
  }

  func updateUIView(_ map: MKMapView, context: Context) {
    // So sánh trước khi cập nhật để không đặt lại vùng nhìn mỗi lần SwiftUI render
    let last = context.coordinator.lastCenter
    guard last?.latitude != center.latitude || last?.longitude != center.longitude else { return }
    context.coordinator.lastCenter = center
    map.setCenter(center, animated: true)
  }

  func makeCoordinator() -> Coordinator { Coordinator() }

  final class Coordinator: NSObject, MKMapViewDelegate {
    var lastCenter: CLLocationCoordinate2D?
  }
}
