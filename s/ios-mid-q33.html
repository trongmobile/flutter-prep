App cần hỗ trợ tiếng Việt và tiếng Anh, sau này có thể thêm tiếng Ả Rập. Bạn tổ chức localization thế nào: String Catalog, số nhiều (plural), định dạng theo locale, layout RTL, và những lỗi nào hay gặp (ghép chuỗi bằng tay, chữ bị cắt)?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Từ Xcode 15, String Catalog (.xcstrings) thay Localizable.strings và .stringsdict: một file chứa mọi chuỗi cùng bản dịch, Xcode tự thu thập chuỗi từ code (String(localized:), Text("...") của SwiftUI dùng LocalizedStringKey, NSLocalizedString) và hiện trạng thái dịch của từng ngôn ngữ. Nên dùng key có ý nghĩa kèm comment để người dịch hiểu ngữ cảnh. Không ghép chuỗi bằng tay ("Bạn có " + n + " tin nhắn") vì thứ tự từ khác nhau giữa các ngôn ngữ; dùng interpolation hoặc placeholder ("%lld tin nhắn") để người dịch sắp xếp lại. Số nhiều: String Catalog hỗ trợ các biến thể theo số (one, other, và few, many với tiếng Nga hay Ả Rập); tiếng Việt chỉ cần other nhưng vẫn nên khai báo đúng để mở rộng. Số, ngày, tiền dùng FormatStyle hoặc formatter theo Locale thay vì tự định dạng. RTL: dùng leading/trailing thay cho left/right trong Auto Layout và SwiftUI để layout tự đảo, ảnh có hướng (mũi tên) thì lật bằng imageFlippedForRightToLeftLayoutDirection(). Bắt lỗi sớm bằng Pseudolanguage trong scheme (Accented, Double-Length, Right-to-Left) để thấy chuỗi bị cắt, chuỗi ghép tay hay chuỗi quên dịch, và thử Dynamic Type lớn vì chuỗi dài làm vỡ layout cố định (dùng numberOfLines = 0, stack view). Từ iOS 13, user chọn được ngôn ngữ riêng cho từng app trong Settings nên thường không cần tự làm màn đổi ngôn ngữ trong app, và nên tránh ép Bundle đổi ngôn ngữ lúc chạy. Chuỗi do server trả về cần cơ chế riêng theo Accept-Language.
// Key mô tả kèm comment cho người dịch; interpolation để người dịch sắp xếp lại thứ tự từ
let title = String(
  localized: "inbox.unread_count \(count)",
  comment: "Số tin nhắn chưa đọc, hiện ở tiêu đề hộp thư"
)

// SwiftUI: chuỗi literal là LocalizedStringKey, các dạng số nhiều khai báo trong String Catalog
Text("cart.item_count \(items.count)")

// Số, ngày, tiền theo Locale của user thay vì tự định dạng
Text(order.total, format: .currency(code: "VND"))
Text(order.createdAt, format: .dateTime.day().month().hour().minute())

// Không ghép chuỗi bằng tay: thứ tự từ khác nhau giữa các ngôn ngữ
// let bad = "Bạn có " + String(count) + " tin nhắn"
