Animated với useNativeDriver: true khác false thế nào? Vì sao animate height lại báo lỗi khi bật native driver?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Với useNativeDriver: false, mỗi frame JS thread phải tính giá trị rồi gửi sang native để cập nhật view, nên khi JS đang bận (render list, parse JSON) animation sẽ giật. Bật native driver thì toàn bộ animation được mô tả và gửi sang native một lần khi start(), sau đó native tự chạy từng frame trên UI thread, không phụ thuộc JS thread. Đổi lại, native driver chỉ hỗ trợ thuộc tính không ảnh hưởng layout như transform và opacity; width, height, top, flex cần tính lại layout nên báo lỗi 'not supported by native animated module'. Muốn hiệu ứng mở rộng thì dùng transform: [{ scaleY }], hoặc chuyển sang Reanimated nếu thật sự cần animate layout; Animated.event cho scroll cũng nên bật native driver.
