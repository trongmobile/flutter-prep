App có đăng nhập Google và Facebook, bị App Review từ chối vì chưa có Sign in with Apple. Khi nào Apple bắt buộc, bạn tích hợp thế nào, xử lý email ẩn (relay) ra sao, và cần kiểm tra gì khi mở lại app hoặc khi user xoá tài khoản?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Guideline 4.8 (Login Services) yêu cầu app dùng đăng nhập bên thứ ba hay mạng xã hội cho tài khoản chính phải cung cấp thêm một lựa chọn đăng nhập hạn chế thu thập dữ liệu ở mức tên và email, cho phép ẩn email và không theo dõi khi chưa có sự đồng ý; Sign in with Apple là lựa chọn phổ biến nhất đáp ứng điều đó. Có vài ngoại lệ (app chỉ dùng tài khoản riêng của mình, app doanh nghiệp/giáo dục...), và chính sách có thể đổi nên cần đọc bản mới. Tích hợp: tạo request từ ASAuthorizationAppleIDProvider, đặt requestedScopes và nonce, chạy ASAuthorizationController (SwiftUI có sẵn SignInWithAppleButton). Credential có user là ID ổn định theo team để làm khoá tài khoản, identityToken (JWT) và authorizationCode gửi cho backend để xác minh và đổi token, còn email, fullName chỉ trả về ở lần cấp quyền đầu tiên nên phải gửi lưu ngay, lần sau là nil. Email có thể là địa chỉ relay dạng ...@privaterelay.appleid.com: muốn gửi mail tới đó thì phải đăng ký domain gửi trong tài khoản developer. Mỗi lần mở app, gọi credentialState(forUserID:) và lắng nghe credentialRevokedNotification để đăng xuất khi user thu hồi quyền trong Settings. Khi user xoá tài khoản (Guideline 5.1.1(v) bắt buộc app cho xoá ngay trong app), backend phải thu hồi token Sign in with Apple qua REST API revoke.
SignInWithAppleButton(.signIn) { request in
    request.requestedScopes = [.fullName, .email]
    request.nonce = sha256(rawNonce) // chống replay; backend kiểm tra lại nonce trong identityToken
} onCompletion: { result in
    guard case .success(let auth) = result,
          let credential = auth.credential as? ASAuthorizationAppleIDCredential,
          let tokenData = credential.identityToken,
          let idToken = String(data: tokenData, encoding: .utf8) else { return }

    // email và fullName chỉ có ở lần đầu: gửi lên server lưu ngay
    Task {
        try? await api.signInWithApple(
            userID: credential.user,
            idToken: idToken,
            authorizationCode: credential.authorizationCode,
            email: credential.email,
            fullName: credential.fullName
        )
    }
}

// Mỗi lần mở app: user có thể đã thu hồi quyền trong Settings
func checkAppleCredential(userID: String) async {
    let state = try? await ASAuthorizationAppleIDProvider().credentialState(forUserID: userID)
    if state == .revoked || state == .notFound { signOut() }
}
