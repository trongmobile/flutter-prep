Viết unit test JUnit cho class CheckoutCalculator phụ thuộc CouponRepository (đọc mã giảm giá từ server). Bạn cấu trúc test và thay thế dependency thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Unit test trong src/test chạy trên JVM của máy dev, nên dependency chạm mạng hay database phải được thay bằng mock hoặc fake; muốn vậy class cần nhận dependency qua constructor và phụ thuộc vào interface. Mỗi test theo cấu trúc Arrange – Act – Assert: cấu hình mock trả về giá trị mong muốn, gọi hàm cần test, rồi kiểm tra bằng assertEquals(expected, actual) với giá trị mong đợi đứng trước. Có thể verify mock được gọi với đúng tham số khi đó là yêu cầu nghiệp vụ, nhưng đừng verify mọi lời gọi vì test sẽ gãy mỗi lần refactor. Đặt tên test mô tả hành vi và giữ các test độc lập; JUnit 4 tạo instance class test mới cho mỗi test nên field khởi tạo inline cũng được làm mới.
class CheckoutCalculatorTest {
    private val repo: CouponRepository = mock() // mockito-kotlin
    private val calculator = CheckoutCalculator(repo)

    @Test
    fun `ma SALE10 giam 10 phan tram`() {
        whenever(repo.findCoupon("SALE10")).thenReturn(Coupon(percent = 10))

        val total = calculator.total(amount = 200_000, couponCode = "SALE10")

        assertEquals(180_000, total)
    }
}
