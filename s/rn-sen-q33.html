Team cần bọc một SDK native nội bộ (đọc thẻ NFC, Bluetooth) thành module cho RN, app có cả Expo lẫn bare workflow. Bạn chọn Expo Modules API hay TurboModule thuần, và thiết kế module (threading, sự kiện, vòng đời) thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Cả hai đều chạy được trên New Architecture, khác nhau ở công sức và mức kiểm soát. TurboModule thuần cần viết spec TypeScript, chạy Codegen rồi cài đặt bằng Objective-C++ (hoặc Swift qua lớp bọc) và Kotlin/Java, tự cấu hình package, podspec, autolinking: kiểm soát tối đa, hợp khi cần C++ hay JSI trực tiếp. Expo Modules API cho viết module bằng Swift và Kotlin với DSL (Name, Function, AsyncFunction, Events, View, OnCreate/OnDestroy) và tự sinh phần kết nối, kiểu dữ liệu (record, enum) được chuyển đổi tự động; nó cũng dùng được trong project bare qua gói expo và có sẵn template (create-expo-module), nên với hầu hết SDK nội bộ nó ít code mẫu hơn nhiều và dễ bảo trì cho dev native thuần. Tôi chọn Expo Modules API, trừ khi cần JSI/C++ thuần hoặc thư viện phải gọn nhẹ và không phụ thuộc expo. Thiết kế: hàm tốn thời gian khai báo bằng AsyncFunction để chạy ngoài JS thread và trả kết quả qua Promise; dữ liệu liên tục (tag NFC, gói tin BLE) phát qua sự kiện (sendEvent), phía JS dùng useEvent hoặc addListener và nhớ gỡ listener; giữ tham chiếu tới SDK trong module và giải phóng ở OnDestroy hoặc khi Activity/Scene bị huỷ, vì module có thể sống lâu hơn màn hình nên tránh giữ Activity hay ViewController; lỗi đi qua exception có code để JS phân biệt thay vì chuỗi tự do. Về quy trình: module có API TypeScript có kiểu, test trên cả hai nền tảng, và coi mọi thay đổi native là phải ra binary mới (đổi runtime version nếu phát hành OTA), giống như TurboModule.
class NfcReaderModule : Module() {
  private var reader: NfcSdkReader? = null

  override fun definition() = ModuleDefinition {
    Name("NfcReader")
    Events("onTag")

    // Chạy ngoài JS thread, trả về Promise
    AsyncFunction("start") { options: ReaderOptions ->
      val activity = appContext.currentActivity
        ?: throw CodedException("ERR_NO_ACTIVITY", "Không có Activity đang hiển thị", null)
      reader = NfcSdkReader(activity).also { r ->
        r.onTag = { tag -> sendEvent("onTag", mapOf("id" to tag.id)) } // dữ liệu liên tục đi qua sự kiện
        r.start(options.timeoutMs)
      }
    }

    Function("stop") {
      reader?.stop()
      reader = null
    }

    // Module bị huỷ: không giữ Activity hay SDK
    OnDestroy {
      reader?.stop()
      reader = null
    }
  }
}

class ReaderOptions : Record {
  @Field val timeoutMs: Int = 15_000
}
