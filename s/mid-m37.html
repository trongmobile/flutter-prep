App cần lưu đơn hàng offline với quan hệ nhiều bảng, query có join/lọc phức tạp, migration schema có kiểm soát và stream tự cập nhật UI. Lựa chọn phù hợp nhất?

  1. ASharedPreferences lưu JSON string của từng đơn hàng
  2. Bdrift (SQLite) với schema và migration khai báo bằng Dart
  3. Cflutter_secure_storage để dữ liệu được mã hoá
  4. DHive box lưu Map theo key, tự join trong code Dart
Xem đáp án
Đáp án đúng: B
drift là lớp type-safe trên SQLite: hỗ trợ join, index, transaction, migration theo schemaVersion và biến query thành Stream bằng watch(). Hive hay SharedPreferences là key-value, phải tự join và tự lo migration; secure storage chỉ dành cho dữ liệu nhỏ, nhạy cảm như token.
