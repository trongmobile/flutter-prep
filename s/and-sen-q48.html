Play Console cảnh báo chất lượng trên màn hình lớn; review của người dùng tablet và Pixel Fold than UI bị kéo giãn, bị khoá dọc, và nội dung đè dưới thanh trạng thái sau khi nâng targetSdk lên 35. Bạn làm app thích ứng cho foldable, tablet và ChromeOS thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Nguyên tắc là app phản ứng theo cửa sổ (window) chứ không theo thiết bị: Activity có thể đang ở chế độ chia đôi màn hình, freeform hay gập mở bất cứ lúc nào. Chia layout theo WindowSizeClass (chiều rộng Compact dưới 600dp, Medium, Expanded từ 840dp; các bản thư viện mới còn thêm lớp lớn hơn) lấy từ currentWindowAdaptiveInfo(), đừng dùng kích thước màn hình vật lý hay Display để quyết định. Điều hướng đổi theo kích thước nhờ NavigationSuiteScaffold (bottom bar, rail, drawer), và dùng layout chuẩn như list-detail (ListDetailPaneScaffold) hoặc supporting pane thay vì kéo giãn một cột. Đừng khoá hướng màn hình hay đặt resizeableActivity="false": trên màn hình lớn hệ thống ngày càng bỏ qua các giới hạn này với app target SDK cao, và đó cũng là một tiêu chí chất lượng của Play. Từ Android 15, app target SDK 35 bị buộc vẽ edge-to-edge: gọi enableEdgeToEdge() rồi tự xử lý inset (Scaffold truyền innerPadding, WindowInsets.safeDrawing, ime), thay vì giả định nội dung nằm dưới thanh hệ thống; đó chính là lỗi đè thanh trạng thái bạn thấy. State phải nằm trong ViewModel hoặc rememberSaveable vì cấu hình đổi liên tục khi gập, xoay, đổi kích thước cửa sổ; foldable có thể đọc FoldingFeature qua WindowInfoTracker cho tư thế tabletop. Đừng quên bàn phím và chuột (hover, phím tắt) cho ChromeOS và tablet. Kiểm thử: resizable emulator (chuyển qua lại phone, foldable, tablet, desktop), @PreviewScreenSizes trong Compose preview, và test UI với nhiều kích thước cửa sổ.
class MainActivity : ComponentActivity() {
  override fun onCreate(savedInstanceState: Bundle?) {
    enableEdgeToEdge()                 // gọi trước super.onCreate: vẽ dưới thanh hệ thống
    super.onCreate(savedInstanceState)
    setContent { ShopApp() }
  }
}

@Composable
fun ShopApp() {
  val widthClass = currentWindowAdaptiveInfo().windowSizeClass.windowWidthSizeClass

  // Tự chọn bottom bar / navigation rail / drawer theo kích thước cửa sổ
  NavigationSuiteScaffold(
    navigationSuiteItems = {
      destinations.forEach { dest ->
        item(
          selected = dest == current,
          onClick = { navigate(dest) },
          icon = { Icon(dest.icon, contentDescription = dest.label) },
          label = { Text(dest.label) },
        )
      }
    },
  ) {
    if (widthClass == WindowWidthSizeClass.COMPACT) ProductListScreen()
    else ProductListDetailScreen() // hai pane song song trên tablet / foldable mở
  }
}
