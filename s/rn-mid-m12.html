Với hàm pluck dùng ràng buộc K extends keyof T, hai lời gọi bên dưới cho kết quả gì?

function pluck<T, K extends keyof T>(items: T[], key: K): T[K][] {
  return items.map((item) => item[key]);
}

const users = [{ id: 1, name: 'An' }];
const ids = pluck(users, 'id');
const emails = pluck(users, 'email');
  1. Aids có kiểu any[]; emails có kiểu undefined[]
  2. Bids có kiểu number[]; dòng emails lỗi compile
  3. Cids có kiểu (string | number)[]; dòng emails lỗi compile
  4. Dids có kiểu number[]; emails có kiểu unknown[]

Đáp án đúng: B
K bị ràng buộc là key của phần tử, nên 'email' không thuộc 'id' | 'name' và bị báo lỗi; còn T[K] với K = 'id' cho ra number. Indexed access type giúp kiểu trả về đi theo đúng key được truyền thay vì gộp mọi kiểu value.
