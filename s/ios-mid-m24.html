Điều nào đúng về modifier .task(id: selectedCategory) { await load(selectedCategory) }?

  1. AChạy một lần khi view xuất hiện; đổi id thì task cũ vẫn chạy song song
  2. BCancel task cũ và chạy lại khi id đổi, tự cancel khi view biến mất
  3. CChạy lại mỗi lần body được tính lại, bất kể id có đổi hay không
  4. DGiống onAppear + Task {}, task không bị cancel khi view biến mất
Xem đáp án
Đáp án đúng: B
.task gắn vòng đời task với view: tự cancel khi view biến mất, và với id thì mỗi lần giá trị đổi SwiftUI cancel task cũ rồi chạy task mới. Task {} tự tạo trong onAppear thì không bị cancel tự động, phải tự giữ handle.
