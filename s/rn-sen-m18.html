Metro đang bật inlineRequires (mặc định trong template React Native) và không module nào khác import ./analytics. Khi app khởi động, log nào xuất hiện?

// analytics.ts
console.log('analytics loaded');
export function track(event: string) { /* ... */ }

// App.tsx
import { track } from './analytics';
console.log('app start');
export const onBuy = () => track('buy');
  1. AChỉ app start; analytics loaded in ra khi onBuy được gọi lần đầu
  2. Banalytics loaded rồi app start, vì import luôn được thực thi trước
  3. Capp start rồi analytics loaded ngay sau đó, khi module App chạy xong
  4. DChỉ app start; analytics loaded không bao giờ in vì Metro đã tree-shake
Xem đáp án
Đáp án đúng: A
Inline requires dời lời gọi require tới chỗ binding được dùng lần đầu, nên analytics.ts chỉ được thực thi khi track được gọi, giảm việc phải làm lúc khởi động. Đổi lại, side effect ở top-level của module (khởi tạo SDK, đăng ký listener) sẽ chạy muộn hơn nhiều người nghĩ.
