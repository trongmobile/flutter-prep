Đoạn code sau in ra gì?

protocol Tracker {
  func track(_ event: String)
}

extension Tracker {
  func track(_ event: String) { print("default track: \(event)") }
  func flush(_ reason: String) { print("default flush: \(reason)") }
}

struct FileTracker: Tracker {
  func track(_ event: String) { print("file track: \(event)") }
  func flush(_ reason: String) { print("file flush: \(reason)") }
}

let tracker: any Tracker = FileTracker()
tracker.track("a")
tracker.flush("b")
  1. Afile track: a rồi default flush: b
  2. Bfile track: a rồi file flush: b
  3. Cdefault track: a rồi default flush: b
  4. DLỗi compile vì FileTracker định nghĩa lại method đã có sẵn trong extension
Xem đáp án
Đáp án đúng: A
track là requirement của protocol nên được dispatch động qua witness table, gọi vào bản của FileTracker. flush chỉ có trong extension, không phải requirement, nên với static type là any Tracker compiler dùng static dispatch tới bản mặc định; nếu khai báo let tracker = FileTracker() thì flush mới gọi bản của struct. Muốn tuỳ biến được thì phải đưa flush vào protocol.
