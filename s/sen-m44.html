Đoạn code polling sau in ra theo thứ tự nào? (Timer chạy mỗi 100ms, mỗi callback await 250ms.)

import 'dart:async';

void main() {
  Timer.periodic(const Duration(milliseconds: 100), (t) async {
    final n = t.tick;
    if (n == 3) t.cancel();
    print('start $n');
    await Future.delayed(const Duration(milliseconds: 250));
    print('end $n');
  });
}
  1. Astart 1, end 1, start 2, end 2, start 3, end 3
  2. Bstart 1, start 2, end 1, start 3, end 2, end 3
  3. Cstart 1, start 2, start 3, end 3, vì cancel() huỷ các lần await đang chờ
  4. Dstart 1, start 2, start 3, end 1, end 2, end 3
Xem đáp án
Đáp án đúng: D
Timer.periodic chỉ bắn theo đồng hồ, không chờ Future mà callback async trả về, nên các lần gọi chồng lên nhau (100ms < 250ms) và cả ba start in ra trước end 1 lúc 350ms. cancel() chỉ chặn các tick sau, không dừng phần await đã chạy dở. Với polling nên dùng vòng while + await Future.delayed hoặc cờ busy để tránh chồng request.
