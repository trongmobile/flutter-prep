Gán thẳng một list lấy từ jsonDecode cho biến List<String>: đoạn code sau cho kết quả gì?

import 'dart:convert';

void main() {
  final data = jsonDecode('{"tags": ["a", "b"]}');
  final List<String> tags = data['tags'];
  print(tags);
}
  1. ALỗi runtime do ép List<dynamic> sang List<String>
  2. BIn ra [a, b] vì Dart tự suy ra kiểu phần tử
  3. CLỗi compile vì không được gán dynamic cho biến có kiểu
  4. DIn ra null vì kiểu dữ liệu không khớp
Xem đáp án
Đáp án đúng: A
jsonDecode tạo list có kiểu runtime là List<dynamic> dù mọi phần tử đều là String; phép gán từ dynamic sinh ra một phép cast ngầm và thất bại lúc chạy. Cách đúng là List<String>.from(data['tags']) hoặc (data['tags'] as List).cast<String>().
