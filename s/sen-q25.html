App ví điện tử cần: đăng nhập bằng vân tay hoặc Face ID, lưu refresh token an toàn, chặn chụp màn hình ở màn nhập PIN, và phát hiện thiết bị root hoặc jailbreak. Bạn thiết kế lớp bảo vệ này trong Flutter thế nào, và giới hạn của từng lớp là gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mọi kiểm tra phía client chỉ là tín hiệu, nên chính sách cuối cùng phải nằm ở server. Lưu token: dùng Keychain (iOS) và Keystore (Android) qua flutter_secure_storage, không dùng SharedPreferences hay file thường; chọn mức truy cập hợp lý (iOS first_unlock_this_device để không đồng bộ qua iCloud và vẫn đọc được khi refresh ở nền). Sinh trắc học: kết quả của local_auth.authenticate() chỉ là một bool trong process của app, nên nếu quyết định mở khoá chỉ dựa vào đó thì có thể bị hook để bỏ qua; bền hơn là gắn bí mật với sinh trắc ở tầng hệ điều hành (khoá Keystore/Keychain yêu cầu xác thực sinh trắc khi dùng, thường cần code native hoặc plugin hỗ trợ), để đọc token phải đi qua hộp thoại sinh trắc thật. Xử lý các trạng thái: máy chưa đăng ký sinh trắc, bị khoá sau nhiều lần sai, dữ liệu sinh trắc đổi làm khoá mất hiệu lực, và luôn có đường đăng nhập thay thế (mật khẩu hoặc PIN). Chặn chụp màn hình và ẩn nội dung trong màn hình app switcher: Android đặt FLAG_SECURE cho cửa sổ (code native trong MainActivity, hoặc bật tắt theo màn hình qua MethodChannel hay plugin), iOS thì che bằng một view phủ khi app inactive (iOS không chặn được việc chụp màn hình mà chỉ phát hiện được quay màn hình và chụp xong). Root hoặc jailbreak: dùng thư viện như freerasp để lấy tín hiệu, rồi kết hợp attestation phía server (Play Integrity API trên Android, App Attest trên iOS) để server xác minh bản app và thiết bị; vì Frida hay công cụ hook vẫn qua được, chính sách nên theo mức rủi ro (xem số dư thì cho, giao dịch lớn cần thêm OTP). Obfuscation (--obfuscate) chỉ làm khó reverse chứ không phải hàng rào. Ngoài ra không log token, tắt log chi tiết ở release và xoá dữ liệu nhạy cảm khi đăng xuất.
// android/app/src/main/kotlin/.../MainActivity.kt
class MainActivity : FlutterFragmentActivity() { // local_auth cần FlutterFragmentActivity
  override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    // Chặn chụp màn hình và ẩn nội dung trong màn hình app switcher
    // (thực tế nên bật tắt theo màn hình, ví dụ chỉ ở màn nhập PIN, qua MethodChannel)
    window.setFlags(
      WindowManager.LayoutParams.FLAG_SECURE,
      WindowManager.LayoutParams.FLAG_SECURE,
    )
  }
}
