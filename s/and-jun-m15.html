Đọc một key không tồn tại trong Map<String, Integer> rồi gán vào biến int thì sao?

Map<String, Integer> stock = new HashMap<>();
stock.put("apple", 3);
int pears = stock.get("pear");
System.out.println(pears);
  1. AIn ra 0 vì int mặc định bằng 0
  2. BLỗi compile vì get trả về Integer
  3. CNém NoSuchElementException vì thiếu key
  4. DNém NullPointerException khi unboxing null
Xem đáp án
Đáp án đúng: D
get trả về null khi không có key, và gán null vào int khiến Java tự gọi intValue() trên null (auto-unboxing) nên ném NullPointerException. Dùng getOrDefault("pear", 0) hoặc giữ kiểu Integer rồi kiểm tra null; trong Kotlin, stock["pear"] có kiểu Int? nên lỗi này bị chặn ngay lúc compile.
