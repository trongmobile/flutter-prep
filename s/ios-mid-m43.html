App dùng Face ID để bảo vệ token như đoạn dưới. Điểm yếu chính so với việc lưu token vào Keychain bằng SecAccessControl yêu cầu sinh trắc học là gì?

let context = LAContext()
context.evaluatePolicy(
  .deviceOwnerAuthenticationWithBiometrics,
  localizedReason: "Mở khoá tài khoản"
) { success, _ in
  guard success else { return }
  let token = Keychain.read("accessToken") // item lưu với accessibility thông thường
  // dùng token...
}
  1. AevaluatePolicy chỉ hỗ trợ Touch ID nên máy có Face ID luôn trả về false
  2. BItem Keychain bị xoá mỗi lần user đăng ký thêm khuôn mặt hoặc vân tay mới
  3. CMọi app khác trên máy đều đọc được token vì Keychain lưu dạng plain text
  4. DCổng sinh trắc chỉ là Bool trong app, hook thành true là đọc được token
Xem đáp án
Đáp án đúng: D
Callback success chỉ là một Bool do code app kiểm tra; trên máy jailbreak, kẻ tấn công hook (Frida…) cho luôn trả true, và token vẫn đọc được vì item Keychain không đòi sinh trắc. Lưu item với SecAccessControlCreateWithFlags và flag như .biometryCurrentSet thì hệ thống buộc xác thực sinh trắc ngay khi đọc item, nên chỉ sửa code app là không đủ. Keychain được mã hoá và cô lập theo access group nên app khác không đọc được.
