Bạn tự viết một store nhỏ (object ở module-level kèm subscribe) và cho component đọc nó bằng useEffect + useState. Với concurrent rendering của React 18, thỉnh thoảng hai component cùng màn hình hiện hai giá trị khác nhau của cùng store (tearing). useSyncExternalStore giải quyết gì, quy tắc bắt buộc của nó là gì, và vì sao Redux, Zustand dùng nó?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Khi render có thể bị ngắt rồi tiếp tục (concurrent), một store nằm ngoài React có thể đổi giữa chừng một lần render: component trước đọc giá trị cũ, component sau đọc giá trị mới, và màn hình hiện trạng thái không nhất quán (tearing). Mẫu useEffect + useState còn có khoảng hở giữa lúc render và lúc effect subscribe nên có thể lỡ một thay đổi. useSyncExternalStore(subscribe, getSnapshot) là API dành cho store bên ngoài: React gọi getSnapshot lúc render và kiểm tra lại trước khi commit; nếu giá trị đã đổi thì render lại đồng bộ, để mọi component trong một lần commit thấy cùng một snapshot. Quy tắc bắt buộc: getSnapshot phải trả về giá trị ổn định, cùng một tham chiếu khi store chưa đổi; nếu mỗi lần gọi lại trả object mới (như () => ({ ...state }) hay .filter trong selector) thì React cảnh báo và có thể render lặp vô hạn. subscribe cũng phải ổn định (khai báo ngoài component hoặc bọc useCallback), nếu không sẽ unsubscribe rồi subscribe lại ở mỗi render. Selector nên trả primitive hoặc một phần state đã có sẵn, để chỉ re-render khi đúng phần đó đổi. Đó là lý do react-redux (v8 trở lên) và Zustand dùng nó bên dưới. Đánh đổi: cập nhật qua useSyncExternalStore luôn đồng bộ nên không hưởng lợi từ transition. Hiếm khi cần tự viết store, nhưng hiểu cơ chế này giúp chọn đúng thư viện và dùng cho các nguồn ngoài React như Appearance, Dimensions, NetInfo.
type Listener = () => void;

function createCounterStore() {
  let state = { count: 0 };
  const listeners = new Set<Listener>();
  return {
    getState: () => state, // cùng một tham chiếu khi chưa đổi
    increment() {
      state = { count: state.count + 1 }; // đổi thì tạo object mới
      listeners.forEach((l) => l());
    },
    subscribe(listener: Listener) {
      listeners.add(listener);
      return () => listeners.delete(listener);
    },
  };
}

const store = createCounterStore();

function useCount() {
  // subscribe ổn định, getSnapshot trả về primitive nên không render thừa
  return useSyncExternalStore(store.subscribe, () => store.getState().count);
}

// Nguồn ngoài React: chế độ sáng/tối của hệ thống
function useColorScheme() {
  return useSyncExternalStore(
    (onChange) => {
      const sub = Appearance.addChangeListener(onChange);
      return () => sub.remove();
    },
    () => Appearance.getColorScheme(),
  );
}
