Ô tìm kiếm lọc một danh sách vài nghìn sản phẩm bị khựng khi gõ: mỗi ký tự làm cả list render lại và TextInput giật. Ngoài debounce, bạn dùng useDeferredValue hay useTransition (concurrent rendering) thế nào trong React Native, và điều kiện để chúng thật sự có tác dụng là gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Gốc vấn đề là cập nhật gấp (giá trị trong ô nhập) và cập nhật nặng (lọc, render list) có cùng mức ưu tiên, nên render list chặn JS thread và TextInput bị trễ. useDeferredValue(query) trả về một bản 'trễ' của giá trị: React render ngay với query cũ để ô nhập phản hồi tức thì, rồi render lại ở ưu tiên thấp với query mới ở nền; nếu có ký tự mới được gõ trong lúc render dở thì lần render đó bị bỏ và làm lại với giá trị mới nhất. useTransition (hoặc startTransition) đánh dấu một lần setState là không khẩn cấp và cho isPending để làm mờ UI trong lúc chờ. Khác debounce: debounce trì hoãn cố định kể cả khi máy nhanh và không làm render bớt chặn, còn deferred value tự thích nghi theo tốc độ máy và có thể ngắt giữa chừng. Điều kiện: concurrent rendering chỉ có đầy đủ trên New Architecture (Fabric, mặc định từ RN 0.76) với React 18 trở lên; phần render nặng phải nằm trong cây con nhận giá trị trễ, và component đó cần memo để khi giá trị trễ chưa đổi thì nó không render lại. Transition không làm việc nặng nhẹ đi, chỉ đổi thứ tự ưu tiên, nên vẫn cần tối ưu thật: ảo hoá list, useMemo cho bước lọc, hoặc lọc ở server khi dữ liệu lớn.
function ProductSearch({ products }: { products: Product[] }) {
  const [query, setQuery] = useState('');
  const deferredQuery = useDeferredValue(query); // bản trễ: render ở ưu tiên thấp, có thể bị bỏ giữa chừng
  const isStale = query !== deferredQuery;

  return (
    <View style={{ flex: 1 }}>
      <TextInput value={query} onChangeText={setQuery} placeholder="Tìm sản phẩm" />
      <View style={{ flex: 1, opacity: isStale ? 0.6 : 1 }}>
        <ProductList products={products} query={deferredQuery} />
      </View>
    </View>
  );
}

// memo để khi query (bản trễ) chưa đổi thì list không render lại
const ProductList = memo(function ProductList({ products, query }: { products: Product[]; query: string }) {
  const filtered = useMemo(
    () => products.filter((p) => p.name.toLowerCase().includes(query.toLowerCase())),
    [products, query],
  );
  return <FlatList data={filtered} renderItem={({ item }) => <ProductRow product={item} />} />;
});
