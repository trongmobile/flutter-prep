Các design token riêng của app (màu thành công, màu cảnh báo, khoảng cách) không nằm trong ColorScheme của Material. Làm sao thêm chúng vào theme bằng ThemeExtension, hỗ trợ dark mode, và lưu lựa chọn sáng/tối của người dùng?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
ThemeExtension<T> cho phép gắn dữ liệu tuỳ biến vào ThemeData và lấy ra qua Theme.of(context).extension<AppColors>(), thay vì rải hằng số màu khắp app. Class extension phải cài copyWith và lerp (để chuyển theme có animation mượt). Khai báo hai bản (sáng và tối) rồi gắn vào ThemeData(extensions: [...]) của theme và darkTheme. Với Material 3, dùng ColorScheme.fromSeed(seedColor:, brightness:) để sinh bảng màu nhất quán và chỉ thêm extension cho phần nằm ngoài scheme. Chọn chế độ bằng MaterialApp(themeMode: ThemeMode.system | light | dark); muốn người dùng đổi và nhớ lựa chọn thì giữ ThemeMode trong một notifier (Riverpod, Provider, Cubit), lưu bằng shared_preferences và đọc lúc khởi động để không nháy sai theme khi mở app. Giữ API gọn bằng extension trên BuildContext (context.appColors.success). Đừng hard-code màu trong widget, và kiểm tra cả hai theme (golden test sáng và tối) cùng độ tương phản.
@immutable
class AppColors extends ThemeExtension<AppColors> {
  const AppColors({required this.success, required this.warning});
  final Color success;
  final Color warning;

  @override
  AppColors copyWith({Color? success, Color? warning}) =>
      AppColors(success: success ?? this.success, warning: warning ?? this.warning);

  @override
  AppColors lerp(ThemeExtension<AppColors>? other, double t) {
    if (other is! AppColors) return this;
    return AppColors(
      success: Color.lerp(success, other.success, t)!,
      warning: Color.lerp(warning, other.warning, t)!,
    );
  }
}

extension AppThemeX on BuildContext {
  AppColors get appColors => Theme.of(this).extension<AppColors>()!;
}

MaterialApp(
  themeMode: themeMode, // đọc từ notifier, lưu bằng shared_preferences
  theme: ThemeData(
    colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo),
    extensions: const [AppColors(success: Color(0xFF2E7D32), warning: Color(0xFFED6C02))],
  ),
  darkTheme: ThemeData(
    colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo, brightness: Brightness.dark),
    extensions: const [AppColors(success: Color(0xFF66BB6A), warning: Color(0xFFFFA726))],
  ),
  home: const HomePage(),
)
