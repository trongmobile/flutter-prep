Codebase có 200 component, mỗi dev tự viết StyleSheet với màu và khoảng cách rải rác, dark mode làm vá víu, và có người đề xuất đổi sang NativeWind (Tailwind) hoặc một thư viện theme như Restyle hay Unistyles. Bạn đánh giá và chọn thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Vấn đề thật là thiếu design token và theming, không hẳn là công cụ. Dù chọn gì cũng cần một nơi định nghĩa token (màu theo ngữ nghĩa như background, textPrimary, khoảng cách, bo góc, typography) với hai bộ giá trị light và dark. StyleSheet.create thuần: không phụ thuộc thư viện, hiệu năng tốt, nhưng theming phải tự làm (hook useTheme và style tạo trong useMemo), dễ lệch giữa các dev. NativeWind: viết className kiểu Tailwind, build ra style lúc biên dịch, dark mode bằng dark:, thân thiện với team đến từ web; đánh đổi là thêm cấu hình build, phụ thuộc phiên bản NativeWind/Tailwind (có lần nâng bản lớn đổi nhiều thứ), khó debug hơn và style động phức tạp vẫn cần quay lại style thường. Thư viện theme/variant (Restyle, Unistyles…): style gắn với theme, breakpoint, variant và có kiểu TypeScript, ép dùng token; đánh đổi là API riêng, lock-in và ít người quen, cách hoạt động bên trong khác nhau theo thư viện nên cần đọc kỹ tài liệu bản đang dùng. Tiêu chí: kỹ năng và quy mô team, kiểu TS cho token, hỗ trợ dark mode, Dynamic Type, RTL, ảnh hưởng hiệu năng (đo trên máy yếu thay vì đoán), và chi phí migrate (chạy song song, đổi dần từng màn). Thực tế nên bắt đầu bằng token, useTheme và vài component nền (Text, Button, Card), rồi mới chốt công cụ; cấm màu hard-code bằng lint (react-native/no-color-literals).
const palette = {
  light: { background: '#FFFFFF', textPrimary: '#111827', primary: '#2563EB' },
  dark: { background: '#0B0F19', textPrimary: '#F9FAFB', primary: '#60A5FA' },
} as const;
const spacing = { xs: 4, sm: 8, md: 16, lg: 24 } as const;

export function useTheme() {
  const scheme = useColorScheme(); // 'light' | 'dark' | null, đổi theo cài đặt hệ thống
  return { colors: palette[scheme === 'dark' ? 'dark' : 'light'], spacing };
}

// Component chỉ nói "màu gì về mặt ngữ nghĩa", không biết hex hay dark mode
function useCardStyles() {
  const { colors, spacing } = useTheme();
  return useMemo(
    () =>
      StyleSheet.create({
        card: { backgroundColor: colors.background, padding: spacing.md, borderRadius: spacing.sm },
        title: { color: colors.textPrimary },
      }),
    [colors, spacing],
  );
}
