map, where, fold và any/every trên List dùng để làm gì? Vì sao kết quả của list.map(...) thường cần thêm .toList()?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
map biến mỗi phần tử thành một giá trị khác (ví dụ danh sách model thành danh sách widget), where giữ lại các phần tử thoả điều kiện, fold gộp cả danh sách thành một giá trị với giá trị khởi đầu (tổng tiền giỏ hàng), any kiểm tra có ít nhất một phần tử thoả, every kiểm tra tất cả đều thoả. map và where trả về Iterable lười (lazy): phép biến đổi chỉ chạy khi bạn duyệt, và chạy lại ở mỗi lần duyệt; muốn có List thật (để dùng index, length nhanh, hoặc truyền vào children:) thì gọi .toList(). Cẩn thận list.where(...).first ném lỗi nếu không có phần tử nào, nên dùng firstWhere(..., orElse: ...) hoặc firstOrNull.
final prices = [120000, 50000, 80000];

final total = prices.fold<int>(0, (sum, p) => sum + p);     // 250000
final expensive = prices.where((p) => p > 60000).toList();  // [120000, 80000]
final labels = prices.map((p) => '$p ₫').toList();          // List<String>
print(prices.any((p) => p > 100000));  // true
print(prices.every((p) => p > 10000)); // true

// Iterable lười: phép map chạy lại ở mỗi lần duyệt nếu không gọi toList()
final lazy = prices.map((p) {
  print('tính $p');
  return p * 2;
});
