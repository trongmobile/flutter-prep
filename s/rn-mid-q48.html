Dự án Expo mới, team phân vân giữa Expo Router (file-based) và tự cấu hình React Navigation. Hai cách khác nhau ở đâu, Expo Router giải quyết được gì, và nếu migrate một dự án React Navigation đang chạy sang thì cần để ý bẫy nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Expo Router xây trên React Navigation: cấu trúc thư mục app/ định nghĩa route (app/index.tsx là /, app/orders/[id].tsx là /orders/123, thư mục (tabs) là nhóm không vào URL), còn _layout.tsx khai báo navigator (Stack, Tabs) cho nhóm đó. Lợi ích: mỗi màn hình tự có URL nên deep link và universal link chạy mà không phải viết cấu hình linking thủ công; typed routes kiểm tra href lúc compile; tổ chức đồng nhất giữa các dev và dùng chung được với web. Đánh đổi: gắn với toolchain và quy ước file của Expo, ít linh hoạt với luồng điều hướng rất động (dù vẫn truy cập được API React Navigation bên dưới). React Navigation tự cấu hình: kiểm soát hoàn toàn, hợp dự án bare hay app lớn có luồng đặc thù, nhưng phải tự viết linking và khai báo kiểu tham số (RootStackParamList). Dự án mới dùng Expo thì Expo Router là mặc định hợp lý; app lớn đang chạy ổn thì đừng migrate chỉ vì xu hướng. Bẫy khi migrate: đổi entry sang expo-router/entry; provider toàn cục chuyển vào root app/_layout.tsx; tham số route đều là chuỗi (useLocalSearchParams trả string hoặc string[]) nên số hay object phải parse lại; navigation.navigate('OrderDetail', { id }) thành router.push('/orders/123'); mọi file trong app/ đều thành route nên component dùng chung phải để ngoài thư mục này; luồng đăng nhập dùng redirect trong layout hoặc cơ chế bảo vệ route của bản Expo Router bạn dùng. Nên chuyển dần từng nhóm màn hình.
// app/_layout.tsx: khai báo navigator cho cả ứng dụng
import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    <Stack>
      <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
      <Stack.Screen name="orders/[id]" options={{ title: 'Chi tiết đơn' }} />
    </Stack>
  );
}

// app/orders/[id].tsx -> URL /orders/123, deep link myshop://orders/123 tự hoạt động
import { router, useLocalSearchParams } from 'expo-router';

export default function OrderDetail() {
  const { id } = useLocalSearchParams<{ id: string }>(); // tham số luôn là chuỗi
  return (
    <View>
      <Text>Đơn #{id}</Text>
      <Button title="Về danh sách" onPress={() => router.push('/orders')} />
    </View>
  );
}
