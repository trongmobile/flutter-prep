Màn hình dưới đây gọi API ngay trong thân component. Sau khi màn hình mở, chuyện gì xảy ra?

function ProductsScreen() {
  const [products, setProducts] = useState<Product[]>([]);

  fetch('https://api.example.com/products')
    .then((res) => res.json())
    .then((data) => setProducts(data));

  return <FlatList data={products} renderItem={renderProduct} />;
}
  1. AGọi API liên tục: mỗi lần setProducts lại render rồi gọi tiếp
  2. BGọi API đúng một lần vì useState nhớ kết quả giữa các lần render
  3. CBáo lỗi ngay vì không được gọi fetch ở ngoài useEffect
  4. DGọi API một lần, sau đó React tự chặn các lời gọi trùng nhau
Xem đáp án
Đáp án đúng: A
Thân component chạy lại ở mỗi lần render, nên fetch đặt thẳng ở đó cũng chạy lại mỗi lần. Khi response về, setProducts nhận một mảng mới nên React render lại, lại gọi fetch, vòng lặp không dừng và dội server liên tục. Side effect như gọi API phải nằm trong useEffect(() => { ... }, []) hoặc trong event handler. React không báo lỗi khi gọi fetch lúc render, cũng không tự khử lời gọi trùng, và useState chỉ nhớ state chứ không nhớ kết quả của các lời gọi hàm.
