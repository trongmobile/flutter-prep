Hai test dưới đây chạy riêng đều pass, nhưng chạy cả file thì test thứ hai ném ArgumentError. Cách xử lý đúng là gì?

final getIt = GetIt.instance;

void main() {
  test('giờ buổi sáng', () {
    getIt.registerSingleton<Clock>(FakeClock(DateTime(2024, 1, 1, 8)));
    expect(greeting(), 'Chào buổi sáng');
  });

  test('giờ buổi tối', () {
    getIt.registerSingleton<Clock>(FakeClock(DateTime(2024, 1, 1, 20)));
    expect(greeting(), 'Chào buổi tối');
  });
}
  1. AĐổi registerSingleton thành registerLazySingleton, vì lazy singleton không bao giờ bị đăng ký trùng
  2. BThêm await Future.delayed(...) giữa hai test để lần đăng ký trước kịp hết hiệu lực trước test sau
  3. CGọi await getIt.reset() trong tearDown, vì GetIt là singleton toàn cục và sống qua các test
  4. DChạy test bằng flutter test --concurrency=1 để không còn test nào chạy cùng lúc với test khác
Xem đáp án
Đáp án đúng: C
GetIt.instance là object toàn cục: đăng ký ở test trước vẫn còn khi test sau chạy, nên đăng ký lại cùng kiểu Clock ném ArgumentError: Type Clock is already registered inside GetIt (khi chạy riêng thì chưa có đăng ký cũ nên pass). Hãy dọn trong tearDown/setUp bằng await getIt.reset() để mỗi test bắt đầu từ trạng thái sạch (hoặc tạo GetIt.asNewInstance() riêng cho từng test). Đổi sang registerLazySingleton vẫn bị báo trùng, chèn delay hay chỉnh concurrency đều không xóa đăng ký cũ.
