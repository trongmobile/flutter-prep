Khi nào chỉ cần useState, khi nào nên dùng Context hoặc thư viện như Redux Toolkit, Zustand?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Hãy bắt đầu bằng state cục bộ: state chỉ phục vụ một component (nội dung ô nhập, bật tắt modal) thì giữ bằng useState ngay tại đó. Khi hai component anh em cần chung dữ liệu thì "nâng state lên" (lifting state up) component cha gần nhất rồi truyền xuống bằng props. Nếu phải truyền qua nhiều tầng chỉ để tới một chỗ sâu (props drilling), hoặc dữ liệu mang tính toàn app mà ít đổi như theme, ngôn ngữ, thông tin người dùng đăng nhập, thì dùng Context. Context không hợp với state đổi liên tục vì mọi component đang dùng context đó đều render lại khi giá trị đổi. Khi state toàn cục lớn, nhiều màn dùng chung, đổi thường xuyên hoặc cần theo dõi từng action thì dùng Redux Toolkit hoặc Zustand, nơi component chỉ đăng ký lấy đúng phần nó cần. Dữ liệu lấy từ server (cache, loading, refetch) nên để thư viện như TanStack Query (React Query) lo thay vì tự nhét vào store. Nguyên tắc: chọn công cụ nhỏ nhất đủ dùng, đừng đưa mọi thứ vào store toàn cục.
// 1. State cục bộ: chỉ một component dùng
const [visible, setVisible] = useState(false);

// 2. Context: dữ liệu toàn app, ít đổi
const ThemeContext = createContext<'light' | 'dark'>('light');
const theme = useContext(ThemeContext);

// 3. Zustand: store toàn cục, component chỉ đăng ký phần cần dùng
const useCartStore = create<CartState>((set) => ({
  items: [],
  add: (item) => set((s) => ({ items: [...s.items, item] })),
}));
const count = useCartStore((s) => s.items.length); // chỉ render lại khi số lượng thay đổi
