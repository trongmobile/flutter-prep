Người dùng mở màn này rồi bấm Back sau 2 giây. Khi nào deinit được in ra?

final class HintViewController: UIViewController {
  override func viewDidLoad() {
    super.viewDidLoad()
    DispatchQueue.main.asyncAfter(deadline: .now() + 10) {
      self.showHint()
    }
  }

  func showHint() { /* hiện gợi ý */ }

  deinit { print("deinit") }
}
  1. ANgay khi bấm Back, vì view controller đã rời khỏi navigation stack nên bị giải phóng tức thì
  2. BKhông bao giờ, vì closure capture self mạnh nên chắc chắn tạo ra retain cycle
  3. CNgay khi bấm Back, và tới giây thứ 10 block gọi self.showHint() lên object đã bị giải phóng
  4. DKhoảng 10 giây sau khi mở màn, ngay sau khi block chạy; self chỉ bị giữ tạm, không có vòng
Xem đáp án
Đáp án đúng: D
GCD giữ block (cùng self mà nó capture) cho tới khi block chạy rồi thả, còn self không giữ block nên không có vòng tham chiếu: view controller sống thêm khoảng 8 giây sau khi bị pop, showHint() vẫn chạy rồi deinit in ngay sau đó. Không crash vì self vẫn còn sống. Muốn không kéo dài vòng đời hoặc không chạy trên màn đã đóng thì dùng [weak self] kèm guard let self.
