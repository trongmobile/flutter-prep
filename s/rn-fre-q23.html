AsyncStorage là gì, lưu một object vào đó thế nào? Có nên lưu mọi thứ vào AsyncStorage không?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
AsyncStorage là kho key–value bất đồng bộ, lưu bền trên máy, hợp với dữ liệu nhỏ như cài đặt, theme hay cờ đã xem onboarding. Bản nằm trong core React Native đã bị tách ra, nay dùng package cộng đồng @react-native-async-storage/async-storage. Cả key và value đều là string và mọi hàm đều trả về Promise, nên object phải JSON.stringify khi ghi, JSON.parse khi đọc, và getItem trả về null khi key chưa tồn tại. Dữ liệu không được mã hoá nên không dùng cho token hay mật khẩu, và nó cũng không thay được database khi dữ liệu lớn hoặc cần truy vấn.
import AsyncStorage from '@react-native-async-storage/async-storage';

type Settings = { darkMode: boolean };

async function saveSettings(settings: Settings) {
  await AsyncStorage.setItem('settings', JSON.stringify(settings));
}

async function loadSettings(): Promise<Settings> {
  const raw = await AsyncStorage.getItem('settings'); // string | null
  return raw ? JSON.parse(raw) : { darkMode: false };
}
