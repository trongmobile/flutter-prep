Hàm dùng guard let sau có vấn đề gì?

func showProfile(name: String?) {
    guard let name = name else {
        print("Thiếu tên")
    }
    print("Xin chào \(name)")
}
  1. AChạy bình thường: khi name là nil thì in Thiếu tên rồi dừng
  2. BCrash khi name là nil vì name bị force unwrap ngầm
  3. CLỗi compile vì không được đặt tên name trùng với tham số
  4. DLỗi compile vì nhánh else của guard không thoát khỏi hàm
Xem đáp án
Đáp án đúng: D
Nhánh else của guard bắt buộc thoát khỏi scope bằng return, throw, break, continue hoặc gọi hàm như fatalError(), nếu không compiler báo lỗi. Viết guard let name = name để shadow tham số là cách hoàn toàn hợp lệ và rất phổ biến.
