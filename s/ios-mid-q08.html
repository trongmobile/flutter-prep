iOSMiddleMemory & ARCCâu hỏi phỏng vấn

ViewModel lắng nghe một AsyncStream bằng Task { for await event in stream { ... } }. Màn hình đã đóng nhưng deinit của ViewModel không bao giờ chạy. Vì sao, và thêm [weak self] có đủ không?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Closure của Task giữ self mạnh suốt thời gian task chạy, mà vòng for await trên một stream không kết thúc thì task chạy mãi, nên ViewModel không bao giờ được giải phóng. Chỉ thêm [weak self] là chưa đủ nếu ngay đầu task viết guard let self rồi mới vào vòng lặp, vì khi đó self lại bị giữ mạnh trong suốt vòng lặp. Cách đúng là giữ handle của task và cancel() khi màn hình biến mất (từ onDisappear hoặc coordinator), hoặc chỉ unwrap self bên trong từng vòng lặp. Trong SwiftUI, modifier .task tự cancel khi view biến mất nên là cách gọn nhất. Lưu ý không thể dựa vào deinit để cancel task, vì deinit chính là thứ đang không chạy.
@MainActor
final class ChatViewModel {
  private var listenTask: Task<Void, Never>?

  func start(stream: AsyncStream<Message>) {
    listenTask = Task { [weak self] in
      for await message in stream {
        guard let self else { return } // chỉ giữ self mạnh trong từng vòng
        self.handle(message)
      }
    }
  }

  func stop() { listenTask?.cancel() }
}
