Widget cha là StatefulWidget dựng CounterScope(count: count, child: const CounterLabel()) và gọi setState(() => count++) khi bấm nút. CounterLabel.build trả Text('${CounterScope.of(context).count}'). Sau lần bấm đầu tiên, label hiển thị gì?

class CounterScope extends InheritedWidget {
  const CounterScope({super.key, required this.count, required super.child});
  final int count;

  static CounterScope of(BuildContext context) =>
      context.getInheritedWidgetOfExactType<CounterScope>()!;

  @override
  bool updateShouldNotify(CounterScope old) => count != old.count;
}
  1. AVẫn 0, vì lời gọi này không đăng ký phụ thuộc nên label không rebuild
  2. B1, vì updateShouldNotify trả true nên mọi widget bên dưới đều bị rebuild
  3. C1, vì setState ở widget cha luôn rebuild toàn bộ subtree, kể cả con const
  4. DNém assertion, vì getInheritedWidgetOfExactType không được phép gọi trong build
Xem đáp án
Đáp án đúng: A
getInheritedWidgetOfExactType chỉ tra cứu mà không đăng ký dependency, nên updateShouldNotify không có dependent nào để báo; con const là instance y hệt nên Element cũng bỏ qua việc rebuild. Phải dùng dependOnInheritedWidgetOfExactType (cách Theme.of làm) để label tự rebuild khi count đổi.
