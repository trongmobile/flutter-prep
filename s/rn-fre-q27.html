map, filter, find và reduce dùng để làm gì? Vì sao render danh sách phải dùng map chứ forEach thì không được?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
map biến mỗi phần tử thành một giá trị mới và trả về mảng mới cùng độ dài, hợp để chuyển dữ liệu thành các element JSX. filter giữ lại phần tử thoả điều kiện và trả về mảng mới. find trả về phần tử đầu tiên thoả điều kiện hoặc undefined. some và every trả về boolean. reduce gộp cả mảng thành một giá trị (tổng, object) bắt đầu từ giá trị khởi tạo. Những hàm này không sửa mảng gốc, rất hợp với state của React vốn phải cập nhật theo kiểu bất biến. forEach luôn trả về undefined và chỉ để chạy side effect, nên viết {items.forEach(...)} trong JSX sẽ không render gì; nó cũng không break được và không đợi await bên trong callback async. Cẩn thận sort() và reverse() thì lại sửa mảng gốc, cần copy trước bằng [...items].sort(...) khi đang làm việc với state.
const cart = [
  { id: 1, name: 'Áo', price: 200, qty: 1 },
  { id: 2, name: 'Mũ', price: 50, qty: 3 },
];

const names = cart.map((i) => i.name);                            // ['Áo', 'Mũ']
const expensive = cart.filter((i) => i.price > 100);              // chỉ còn Áo
const hat = cart.find((i) => i.id === 2);                         // object hoặc undefined
const total = cart.reduce((sum, i) => sum + i.price * i.qty, 0);  // 350

// Cập nhật state mà không sửa mảng gốc
setCart((prev) => prev.map((i) => (i.id === 2 ? { ...i, qty: i.qty + 1 } : i)));
