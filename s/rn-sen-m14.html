App dùng redux-persist lưu toàn bộ Redux store (gồm cả cache danh sách sản phẩm vài MB) xuống AsyncStorage. Thời gian từ lúc mở app tới màn đầu tiên tăng dần theo dung lượng dữ liệu. Hướng sửa phù hợp nhất?

  1. ATăng throttle của persist để giảm số lần ghi xuống storage
  2. BBọc PersistGate quanh toàn app để chờ rehydrate xong mới render
  3. CChuyển cache sản phẩm vào React Context để khỏi phải persist
  4. DChỉ persist slice nhỏ cần thiết, cache dữ liệu server để lớp riêng
Xem đáp án
Đáp án đúng: D
Lúc mở app, redux-persist phải đọc và parse toàn bộ state đã lưu trước khi màn đầu sẵn sàng, nên state càng lớn càng chậm. Dùng whitelist chỉ giữ phần nhỏ như cài đặt, trạng thái onboarding; dữ liệu server để TanStack Query/RTK Query hoặc DB local tải dần. throttle chỉ giảm tần suất ghi, còn PersistGate chính là chỗ đang phải chờ rehydrate.
