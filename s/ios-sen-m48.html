App chia nhiều feature module; Cart cần mở màn của Profile và Profile cũng cần mở màn của Cart. Cách tách nào tránh phụ thuộc vòng, giữ type-safety và giới hạn phạm vi phải compile lại khi đổi code nội bộ của một feature?

  1. ACho hai module import lẫn nhau, vì SwiftPM chấp nhận phụ thuộc vòng trong cùng package
  2. BMỗi feature xuất module interface (protocol, route); app target nối implementation
  3. CĐưa view và logic dùng chung của cả hai vào module Common để cả hai cùng import
  4. DChuyển màn bằng NotificationCenter với tên chuỗi để các module khỏi cần biết nhau
Xem đáp án
Đáp án đúng: B
Module interface nhỏ và ổn định, feature chỉ phụ thuộc interface của nhau còn implementation được nối ở composition root (app target), nên không có vòng và đổi code nội bộ không lan sang feature khác. SwiftPM từ chối phụ thuộc vòng; Common dễ phình thành nơi mọi module phụ thuộc nên đổi gì cũng build lại hết, còn NotificationCenter mất type-safety và khó truy vết luồng điều hướng.
