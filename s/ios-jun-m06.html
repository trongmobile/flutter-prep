ViewModel lưu closure completion vào property để gọi lại khi có kết quả tìm kiếm. Đoạn code này có vấn đề gì?

final class SearchViewModel {
  private var onResult: (([String]) -> Void)?

  func search(_ text: String, completion: ([String]) -> Void) {
    onResult = completion
    // ... gọi API, khi xong thì onResult?(items)
  }
}
  1. ALỗi compile: completion phải được đánh dấu @escaping
  2. BCompile được nhưng tạo retain cycle giữa self và closure
  3. CLỗi compile: không gán closure cho property optional
  4. DCompile được, onResult tự về nil khi hàm return
Xem đáp án
Đáp án đúng: A
Tham số closure mặc định là non-escaping, không được sống lâu hơn lời gọi hàm; gán nó vào property là cho nó 'thoát' ra ngoài nên compiler báo lỗi và gợi ý thêm @escaping. Bản thân việc gán không tạo retain cycle; chỉ khi closure capture self mạnh mà self lại giữ closure thì mới thành chu trình.
