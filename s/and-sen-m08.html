Khối addIdleHandler dưới đây được đăng ký trong onCreate của Activity, trên main thread. Nó chạy khi nào?

override fun onCreate(savedInstanceState: Bundle?) {
  super.onCreate(savedInstanceState)
  setContentView(R.layout.activity_home)
  Looper.myQueue().addIdleHandler {
    analytics.warmUp() // việc không gấp, muốn dời ra sau khi UI sẵn sàng
    false
  }
}
  1. ANgay lập tức, trước khi onCreate trả về
  2. BTrên một background thread do MessageQueue tạo riêng
  3. CMỗi lần main thread rảnh, lặp lại cho tới khi Activity bị huỷ
  4. DMột lần, khi queue của main thread tạm hết message đến hạn
Xem đáp án
Đáp án đúng: D
IdleHandler.queueIdle() được gọi trên chính thread của Looper khi queue không còn message đến hạn cần xử lý; trả false thì nó bị gỡ sau lần chạy đầu, chỉ trả true mới được gọi lại ở các lần rảnh sau. Nếu main thread liên tục bận (vd. animation chạy mãi), khối này có thể bị hoãn rất lâu, nên đừng dùng cho việc bắt buộc phải xảy ra.
