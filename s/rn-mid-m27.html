Animation thay đổi width dưới đây chạy thế nào khi bật useNativeDriver: true?

const width = useRef(new Animated.Value(100)).current;

Animated.timing(width, {
  toValue: 300,
  duration: 300,
  useNativeDriver: true,
}).start();

// <Animated.View style={{ width, height: 40 }} />
  1. AChạy mượt trên UI thread vì toàn bộ animation đã gửi sang native
  2. BBáo lỗi vì native driver không hỗ trợ thuộc tính layout như width
  3. CTự chuyển về JS driver cho riêng width và chạy bình thường
  4. DChạy được trên iOS nhưng báo lỗi khi chạy trên Android
Xem đáp án
Đáp án đúng: B
Native driver chỉ hỗ trợ thuộc tính không ảnh hưởng layout như transform và opacity; width cần tính lại layout nên RN báo lỗi 'not supported by native animated module'. Hãy dùng transform: [{ scaleX }], hoặc Reanimated nếu thật sự cần animate kích thước.
