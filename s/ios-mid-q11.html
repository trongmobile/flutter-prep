View cha cần biết chiều cao thực tế của một view con (để làm header co giãn hoặc căn các cột bằng nhau). GeometryReader và PreferenceKey phối hợp thế nào, và vì sao không nên bọc cả màn hình trong GeometryReader?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Trong SwiftUI dữ liệu chảy từ cha xuống con; muốn đẩy thông tin ngược lên thì dùng PreferenceKey: con gắn .preference(key:value:), cha đọc bằng .onPreferenceChange, còn reduce quyết định cách gộp khi nhiều con cùng gửi giá trị (lấy max, cộng dồn…). Để đo kích thước, đặt GeometryReader trong .background của view con: nó được đề xuất đúng kích thước của con và không làm thay đổi layout. Bọc trực tiếp nội dung trong GeometryReader thì nó chiếm toàn bộ không gian được đề xuất và đặt con ở góc trên bên trái, rất dễ phá layout. Cẩn thận vòng lặp: đo kích thước rồi set state làm đổi chính kích thước đó sẽ khiến layout cập nhật liên tục.
struct HeightKey: PreferenceKey {
  static let defaultValue: CGFloat = 0
  static func reduce(value: inout CGFloat, nextValue: () -> CGFloat) {
    value = max(value, nextValue()) // nhiều con: lấy cao nhất
  }
}

HeaderView()
  .background(GeometryReader { proxy in
    Color.clear.preference(key: HeightKey.self, value: proxy.size.height)
  })
  .onPreferenceChange(HeightKey.self) { headerHeight = $0 }
