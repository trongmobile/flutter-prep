Tính năng quét mã cần camera và tính năng gửi ảnh cần thư viện ảnh. Trên Android quyền được cấp, nhưng iOS trả về blocked, và user đã từ chối một lần thì không bao giờ thấy hộp thoại nữa. Bạn xin và xử lý quyền trong React Native thế nào (khai báo native, các trạng thái, luồng UX)?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Quyền phải được khai báo phía native trước: iOS cần chuỗi mô tả trong Info.plist (NSCameraUsageDescription...), Android cần <uses-permission> trong Manifest (với Expo thì khai báo qua app.json hoặc config plugin của từng thư viện như expo-camera). Trong code dùng thư viện có API thống nhất: expo-camera (useCameraPermissions), expo-image-picker hay react-native-permissions (check, request trả granted, denied, blocked, limited, unavailable). Ý nghĩa: denied là chưa xin hoặc vừa bị từ chối nhưng còn xin lại được (Android); blocked là bị chặn vĩnh viễn (iOS sau lần từ chối đầu, hoặc Android khi user chọn 'Don't ask again') và chỉ mở Settings (Linking.openSettings()) mới đổi được; limited là iOS chỉ cấp một phần ảnh; unavailable là thiết bị không có tính năng đó. Luồng tốt: kiểm tra trạng thái trước, chỉ xin khi user thực hiện hành động cần quyền kèm giải thích ngắn trước hộp thoại hệ thống, nếu blocked thì hiện hướng dẫn cùng nút mở Settings, và luôn có phương án dự phòng (chọn ảnh bằng picker hệ thống không cần quyền thư viện, nhập mã thủ công). Kiểm tra lại quyền khi app quay về foreground (AppState thành active) vì user có thể đổi trong Settings. Bẫy: Android 13 trở lên tách quyền ảnh và video (READ_MEDIA_IMAGES) khỏi READ_EXTERNAL_STORAGE, Android 14 thêm lựa chọn chỉ cấp một phần ảnh; thông báo (POST_NOTIFICATIONS) cũng phải xin lúc chạy từ Android 13; và khai báo thừa quyền có thể bị store hỏi hoặc từ chối. Với react-native-permissions trên iOS phải bật đúng nhóm quyền trong Podfile (setup_permissions) để không kéo thêm quyền không dùng.
function ScannerScreen() {
  const [permission, requestPermission] = useCameraPermissions(); // expo-camera

  if (!permission) return <Splash />; // đang kiểm tra trạng thái

  if (!permission.granted) {
    return (
      <View style={styles.center}>
        <Text>Cần quyền camera để quét mã QR.</Text>
        {permission.canAskAgain ? (
          <Button title="Cho phép" onPress={requestPermission} /> // còn xin lại được: hiện hộp thoại hệ thống
        ) : (
          <Button title="Mở Cài đặt" onPress={() => Linking.openSettings()} /> // bị chặn vĩnh viễn
        )}
        <Button title="Nhập mã thủ công" onPress={openManualEntry} /> {/* phương án dự phòng */}
      </View>
    );
  }

  return <CameraView style={{ flex: 1 }} onBarcodeScanned={onScan} />;
}
