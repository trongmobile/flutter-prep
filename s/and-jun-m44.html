Project khai báo buildTypes { debug; release } và productFlavors { free; paid } (cùng một flavorDimensions). Gradle tạo ra những build variant nào?

  1. A2 variant debug và release, flavor chỉ thêm thư mục tài nguyên
  2. B4 variant: freeDebug, freeRelease, paidDebug, paidRelease
  3. C2 variant free và paid, mỗi variant tự chọn debug hay release
  4. DKhông build được, vì chỉ khai báo được một trong hai khối đó
Xem đáp án
Đáp án đúng: B
Build variant là tổ hợp của một flavor và một build type: 2 flavor × 2 build type ra 4 variant, tên ghép flavor trước rồi tới build type. Flavor khác nhau ở source set riêng (src/free/, src/paid/), applicationId, buildConfigField; build type khác nhau ở các cờ như isMinifyEnabled, isDebuggable và signing. Hai khối dùng song song được, không loại trừ nhau.
