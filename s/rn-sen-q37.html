App RN 5 năm tuổi dùng Redux cổ điển (connect, saga, hơn 200 reducer, dữ liệu API nằm chung với state UI). Team muốn chuyển sang RTK Query hoặc React Query kết hợp Zustand mà không viết lại cả app. Bạn lập lộ trình và chọn công cụ thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Việc đầu tiên là phân loại state, vì nhiều thứ trong Redux thật ra là server state (dữ liệu API cần cache, refetch, invalidate), mảng này RTK Query hay TanStack Query làm tốt hơn nhiều so với reducer và saga viết tay; phần còn lại là client state (đăng nhập, theme, giỏ hàng nháp, state UI phức tạp) cần một store nhỏ gọn. Nếu app đã dùng Redux thì tiến hoá trong cùng hệ sinh thái rẻ hơn: Redux Toolkit (createSlice, configureStore) tương thích với reducer cũ (gộp được vào cùng store), và RTK Query dùng chung store và devtools; chuyển sang TanStack Query cộng Zustand thì nhẹ hơn nhưng phải chạy hai hệ thống song song trong thời gian dài. Tôi chọn theo nỗi đau thực tế: đau nhất là boilerplate và cache API thì RTK Query, còn team muốn bỏ hẳn Redux thì TanStack Query cho server state và Zustand cho phần còn lại. Lộ trình kiểu strangler, không dừng việc làm tính năng: feature mới viết bằng kiến trúc mới, feature cũ chỉ chuyển khi đằng nào cũng phải sửa lớn; ưu tiên những nơi gây đau nhất (list hay bị stale, loading và error lặp lại khắp nơi). Bước kỹ thuật: bọc truy cập state bằng custom hook và selector, thay connect bằng hook trước (giữ nguyên store), chuyển saga gọi API thành query hoặc mutation, xoá reducer khi không còn ai đọc. Kiểm soát bằng lint cấm code mới import từ module cũ, đếm số file còn dùng kiến trúc cũ như một chỉ số tiến độ, và viết test theo hành vi (không test chi tiết reducer) để refactor an toàn. Tránh tranh luận công cụ kéo dài: viết một ADR ngắn, thử trên một feature thật rồi quyết định.
// Bước 1: giữ nguyên reducer cũ, gắn thêm RTK Query vào cùng store (chưa động tới feature cũ)
export const ordersApi = createApi({
  reducerPath: 'ordersApi',
  baseQuery: fetchBaseQuery({ baseUrl: API_URL }),
  tagTypes: ['Order'],
  endpoints: (build) => ({
    getOrders: build.query<Order[], void>({
      query: () => '/orders',
      providesTags: ['Order'],
    }),
    completeOrder: build.mutation<void, string>({
      query: (id) => ({ url: `/orders/${id}/complete`, method: 'POST' }),
      invalidatesTags: ['Order'], // tự refetch danh sách, thay cho saga và reducer viết tay
    }),
  }),
});

export const store = configureStore({
  reducer: { ...legacyReducers, [ordersApi.reducerPath]: ordersApi.reducer }, // legacyReducers: các reducer hiện có
  middleware: (getDefault) => getDefault().concat(sagaMiddleware, ordersApi.middleware),
});
