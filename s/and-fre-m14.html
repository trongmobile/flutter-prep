Phát biểu nào đúng về interface trong Java (từ Java 8 trở đi)?

  1. AInterface khai báo được field instance như class thường
  2. BMột class chỉ được implements một interface
  3. CInterface có thể có default method kèm phần cài đặt
  4. DInterface có constructor để class con gọi super()
Xem đáp án
Đáp án đúng: C
Từ Java 8, interface có thêm default và static method có thân hàm, nhưng vẫn không có field instance (field nào cũng là hằng public static final) và không có constructor. Một class có thể implements nhiều interface, chỉ có extends là giới hạn một class.
