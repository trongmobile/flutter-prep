UICollectionView của màn hình chat thỉnh thoảng crash với lỗi Invalid update: invalid number of items in section 0 khi tin nhắn đến liên tục cùng lúc với sửa hay xoá tin, dù đã dùng performBatchUpdates. Bạn xử lý bằng UICollectionViewDiffableDataSource thế nào, và có bẫy gì về identity?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Lỗi đó có nguyên nhân gốc là số item trong data source không khớp với những gì bạn khai báo trong batch update: khi dữ liệu đổi từ nhiều luồng hay giữa lúc animation đang chạy, bạn phải tự tính chính xác từng index insert/delete/move. Diffable data source đổi cách làm: bạn mô tả trạng thái đích bằng một snapshot (NSDiffableDataSourceSnapshot), hệ thống tự tính diff và animate, nên không còn lệch index; mỗi lần dữ liệu đổi chỉ cần dựng snapshot mới rồi apply, có thể gọi từ background queue miễn là luôn dùng đúng một queue nhất quán. Điểm quan trọng là identifier: nó phải là Hashable định danh thực thể (id ổn định), không phải toàn bộ nội dung. Nếu dùng nguyên struct Message làm identifier thì khi tin nhắn được sửa, nội dung đổi nên hash đổi và snapshot hiểu đó là một item bị xoá cộng một item mới (cell nhấp nháy, mất vị trí cuộn). Hãy dùng Message.ID làm identifier và lấy dữ liệu hiện tại từ một nguồn riêng trong cell registration; khi nội dung đổi nhưng id giữ nguyên thì gọi reconfigureItems (iOS 15 trở lên): nó cập nhật chính cell đang hiển thị, nhẹ hơn reloadItems vốn dựng lại cell mới. Identifier trùng nhau trong cùng một snapshot sẽ crash, nên phải đảm bảo id duy nhất. Dùng animatingDifferences: false cho lần tải đầu hoặc khi dữ liệu thay đổi quá lớn.
private var messages: [Message.ID: Message] = [:] // nguồn dữ liệu hiện tại

private lazy var registration = UICollectionView.CellRegistration<MessageCell, Message.ID> { [weak self] cell, _, id in
  guard let message = self?.messages[id] else { return }
  cell.configure(with: message)
}

func update(with new: [Message]) {
  // id còn nguyên nhưng nội dung đổi: cần cập nhật lại cell chứ không phải xoá và thêm
  let changed = new.filter { messages[$0.id] != nil && messages[$0.id] != $0 }.map(\.id)
  messages = Dictionary(uniqueKeysWithValues: new.map { ($0.id, $0) })

  var snapshot = NSDiffableDataSourceSnapshot<Int, Message.ID>()
  snapshot.appendSections([0])
  snapshot.appendItems(new.map(\.id)) // identifier là id ổn định, không phải cả struct
  snapshot.reconfigureItems(changed) // cập nhật cell đang có, không dựng cell mới
  dataSource.apply(snapshot, animatingDifferences: true)
}
