Khi nào cần viết Fabric Native Component thay vì Turbo Native Module? Props và event của component được khai báo thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Turbo Native Module dành cho chức năng không có giao diện: gọi API hệ thống, trả dữ liệu về JS. Khi cần đặt một view native vào cây layout của RN, như map, camera preview, video player hay một chart viết sẵn bằng native, thì viết native component. Spec là file <Tên>NativeComponent.ts export codegenNativeComponent<NativeProps>(...); props dùng kiểu của Codegen (Int32, Double, WithDefault…) còn event là prop kiểu DirectEventHandler hoặc BubblingEventHandler. Phía native viết ViewManager (Android) hoặc component view (iOS) để nhận props và bắn event, còn view vẫn được Yoga layout như View thường. Muốn gọi lệnh mệnh lệnh như zoomTo() từ JS thì khai báo thêm codegenNativeCommands.
// MapViewNativeComponent.ts
import type { ViewProps } from 'react-native';
import type { Double, DirectEventHandler } from 'react-native/Libraries/Types/CodegenTypes';
import codegenNativeComponent from 'react-native/Libraries/Utilities/codegenNativeComponent';

type RegionEvent = Readonly<{ latitude: Double; longitude: Double }>;

export interface NativeProps extends ViewProps {
  zoomLevel?: Double;
  onRegionChange?: DirectEventHandler<RegionEvent>;
}

export default codegenNativeComponent<NativeProps>('CustomMapView');
