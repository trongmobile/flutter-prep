Kết hợp Future(...) với code đồng bộ: đoạn code sau in ra theo thứ tự nào?

Future<void> main() async {
  print('A');
  final f = Future(() => print('B'));
  print('C');
  await f;
  print('D');
}
  1. AA B C D
  2. BA C D B
  3. CA B D C
  4. DA C B D
Xem đáp án
Đáp án đúng: D
Future(() => ...) chỉ lên lịch callback vào event queue, nên code đồng bộ phía sau (print('C')) chạy trước. Tới await f, hàm tạm dừng cho tới khi callback in B chạy xong rồi mới in D.
