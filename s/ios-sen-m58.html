Helper này làm mọi test gọi nó đều fail dù FeedViewModel không leak. Vì sao?

extension XCTestCase {
  func trackForMemoryLeaks(_ instance: AnyObject,
                           file: StaticString = #filePath, line: UInt = #line) {
    addTeardownBlock {
      XCTAssertNil(instance, "Có thể bị leak", file: file, line: line)
    }
  }
}

func test_load_deliversItems() {
  let sut = FeedViewModel(service: ServiceStub())
  trackForMemoryLeaks(sut)
  // ... gọi sut rồi assert
}
  1. AaddTeardownBlock chạy trước khi test method kết thúc nên object luôn còn sống; phải kiểm tra trong tearDown()
  2. BXCTAssertNil không nhận được AnyObject vì đây không phải Optional; phải đổi tham số thành AnyObject?
  3. CObject chỉ được giải phóng khi XCTestCase bị huỷ, nên việc kiểm tra leak phải đặt trong deinit của test case
  4. DTeardown block capture instance mạnh nên chính nó giữ object sống; cần [weak instance] mới đúng
Xem đáp án
Đáp án đúng: D
Closure của addTeardownBlock capture instance mặc định là strong, nên block (do test case giữ) giữ object sống cho tới lúc nó chạy và XCTAssertNil luôn fail. Chỉ cần { [weak instance] in XCTAssertNil(instance, ...) }: sau khi test method kết thúc, biến sut cục bộ được thả, nên instance chỉ còn khác nil khi có retain cycle thật. Teardown block chạy sau test method, và XCTAssertNil nhận Any? nên truyền AnyObject được.
