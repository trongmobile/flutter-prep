Bạn viết một plugin nội bộ (ví dụ đọc thẻ NFC) dùng cho nhiều app, hỗ trợ Android, iOS và sau này cả web. Kiến trúc federated plugin gồm những package nào, PlatformInterface làm gì, và nó giúp ích gì so với một plugin đơn lẻ?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Federated plugin tách một plugin thành nhiều package: package app-facing (API Dart mà app gọi), package *_platform_interface (lớp trừu tượng định nghĩa hợp đồng, kế thừa PlatformInterface, kèm implementation mặc định dùng MethodChannel), và mỗi nền tảng một package implementation (*_android, *_ios, *_web), mỗi cái đăng ký bản của mình lúc khởi động (registerWith hoặc dartPluginClass). Trong pubspec.yaml của package app-facing, mục flutter: plugin: platforms: ghi default_package cho từng nền tảng (endorsed), còn package implementation khai báo implements: cho nền tảng của nó. PlatformInterface có token verify để chặn việc cài đặt bằng implements (chỉ cho extends hoặc mixin), nhờ đó thêm method mới vào interface không phá các implementation bên thứ ba vì luôn có bản mặc định. Lợi ích: nhóm khác thêm được nền tảng (Windows, web) mà không cần quyền sửa package gốc; test code app bằng cách đặt Plugin.instance = FakePlatform() mà không cần native; mỗi nền tảng phát hành và đặt version độc lập; ranh giới hợp đồng rõ ràng, và có thể sinh code kênh bằng Pigeon. Chi phí: nhiều package hơn phải quản lý version và publish (nên dùng monorepo với Melos hoặc pub workspaces), cần bài test hợp đồng chung cho mọi implementation, và breaking change ở interface là breaking cho cả hệ sinh thái nên phải theo semver chặt. Nếu plugin chỉ dùng nội bộ cho hai nền tảng và một team duy nhất thì plugin đơn (một package có android/ và ios/) là đủ; federated chỉ đáng khi có nhu cầu mở rộng nền tảng hoặc nhiều bên cùng đóng góp. Với thư viện C hoặc C++ có sẵn, plugin FFI (ffiPlugin: true) là một lựa chọn khác.
// nfc_reader_platform_interface
abstract class NfcReaderPlatform extends PlatformInterface {
  NfcReaderPlatform() : super(token: _token);
  static final Object _token = Object();

  static NfcReaderPlatform _instance = MethodChannelNfcReader();
  static NfcReaderPlatform get instance => _instance;
  static set instance(NfcReaderPlatform value) {
    PlatformInterface.verify(value, _token); // chặn cài đặt bằng `implements`, chỉ cho extends
    _instance = value;
  }

  Stream<String> tags() => throw UnimplementedError('tags() chưa được hỗ trợ trên nền tảng này');
}

// nfc_reader (app-facing): app chỉ gọi API này
class NfcReader {
  Stream<String> get tags => NfcReaderPlatform.instance.tags();
}

// Test phía app: thay bằng bản giả, không cần native
