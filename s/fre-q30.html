Làm sao chuyển một chuỗi JSON thành object Dart?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Dùng jsonDecode trong dart:convert để chuyển chuỗi thành Map<String, dynamic> (hoặc List<dynamic> nếu JSON là mảng), rồi viết factory constructor fromJson để map từng key sang field có kiểu rõ ràng. Nhờ vậy phần còn lại của app làm việc với object type-safe thay vì map['name'] rải rác khắp nơi. Pitfall: số trong JSON có thể là int hoặc double, nên với giá tiền hay dùng (json['price'] as num).toDouble(); dự án lớn thường dùng json_serializable để sinh code.
import 'dart:convert';

class User {
  final String name;
  final int age;
  User({required this.name, required this.age});

  factory User.fromJson(Map<String, dynamic> json) =>
      User(name: json['name'] as String, age: json['age'] as int);
}

final user = User.fromJson(jsonDecode('{"name":"An","age":20}'));
