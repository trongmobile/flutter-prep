Màn danh sách đơn hàng SwiftUI cần kéo để làm mới, ô tìm kiếm trên thanh điều hướng và vuốt dòng để xoá. Bạn dùng .refreshable, .searchable, .swipeActions thế nào, và vì sao spinner của pull-to-refresh hay quay mãi hoặc biến mất quá sớm?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
.refreshable { await vm.reload() } gắn vào List (hoặc ScrollView): closure là async và SwiftUI giữ spinner cho tới khi nó return, nên phải await đúng việc tải. Nếu bên trong chỉ Task { await load() } (fire-and-forget) thì closure return ngay và spinner tắt sớm; ngược lại hàm không có timeout mà treo thì spinner quay mãi. Task này bị huỷ khi view biến mất, nên URLSession có thể ném URLError.cancelled, hãy bỏ qua thay vì hiện lỗi. .searchable(text: $query) phải nằm trong NavigationStack (đặt ngoài thì không có ô tìm kiếm); đừng gọi API mỗi lần gõ, dùng .task(id: query) với Task.sleep ngắn làm debounce, vì task cũ tự bị huỷ khi query đổi; view con đọc @Environment(\.isSearching) để biết đang tìm. .swipeActions gắn lên từng dòng bên trong List, chứa các Button; role: .destructive cho màu đỏ và animation xoá, nhưng bạn vẫn phải xoá thật khỏi data source, nếu không dòng sẽ hiện lại. .swipeActions chỉ chạy trong List, không có tác dụng trong LazyVStack.
struct OrderListView: View {
  @State private var vm = OrderListViewModel()
  @State private var query = ""

  var body: some View {
    NavigationStack {
      List {
        ForEach(vm.orders) { order in
          OrderRow(order: order)
            .swipeActions(edge: .trailing) {
              Button(role: .destructive) { vm.delete(order) } label: {
                Label("Xoá", systemImage: "trash")
              }
            }
        }
      }
      .navigationTitle("Đơn hàng")
      .searchable(text: $query)                    // nằm trong NavigationStack
      .refreshable { await vm.reload() }           // spinner chạy tới khi reload() xong
      .task(id: query) {                           // task cũ tự bị huỷ khi query đổi
        try? await Task.sleep(for: .milliseconds(300))
        guard !Task.isCancelled else { return }
        await vm.search(query)
      }
    }
  }
}
