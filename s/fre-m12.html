Đoạn code sau in ra các số theo thứ tự nào?

Future<void> load() async {
  print('1');
  await Future.delayed(const Duration(milliseconds: 100));
  print('2');
}

void main() {
  load();
  print('3');
}
  1. A1, 2, 3
  2. B3, 1, 2
  3. C3, 2, 1
  4. D1, 3, 2
Xem đáp án
Đáp án đúng: D
Thân hàm async chạy đồng bộ cho tới await đầu tiên nên 1 được in ngay; tại await hàm tạm dừng và trả quyền về main nên 3 in tiếp; khoảng 100ms sau mới in 2. Nhiều người nghĩ cả hàm load() chạy sau nên chọn 3, 1, 2.
