Ở mức tổng quan, Flutter khác gì so với phát triển native (Kotlin/Swift) và React Native?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Flutter dùng một codebase Dart cho nhiều nền tảng và tự vẽ toàn bộ UI bằng engine riêng (Impeller/Skia) thay vì dùng component có sẵn của hệ điều hành, nên giao diện đồng nhất giữa Android và iOS. React Native viết bằng JavaScript/TypeScript và hiển thị bằng component native của từng nền tảng; còn native thuần phải viết riêng Kotlin cho Android và Swift cho iOS nhưng truy cập API nền tảng trực tiếp nhất. Trên mobile, bản release của Flutter được compile AOT ra mã máy nên hiệu năng tốt, và khi cần tính năng nền tảng chưa có package thì gọi code native qua platform channel.
