Parse JSON thiếu key role bằng Gson vào data class Kotlin có default value. Dòng println in ra gì?

data class User(
    val name: String,
    val role: String = "member"
)

val user = Gson().fromJson("""{"name":"An"}""", User::class.java)
println(user.role)
  1. Anull
  2. Bmember
  3. CNém JsonSyntaxException vì thiếu key
  4. DNém NullPointerException khi parse
Xem đáp án
Đáp án đúng: A
User không có constructor không tham số nên Gson tạo object mà không chạy constructor Kotlin: default value "member" không được gán và field non-null role mang giá trị null, lỗi chỉ lộ ra khi dùng tới. Với Kotlin nên dùng kotlinx.serialization hoặc Moshi (có hỗ trợ Kotlin) vì chúng tôn trọng default value và nullability.
