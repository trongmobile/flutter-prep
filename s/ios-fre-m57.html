Test này thỉnh thoảng pass, thỉnh thoảng fail dù code không đổi. Nguyên nhân và cách sửa phù hợp nhất là gì?

struct User: Codable {
    let id: Int
    let name: String
    let email: String
}

func testEncodeUser() throws {
    let user = User(id: 1, name: "An", email: "an@x.vn")
    let data = try JSONEncoder().encode(user)
    let json = String(data: data, encoding: .utf8)
    XCTAssertEqual(json, #"{"id":1,"name":"An","email":"an@x.vn"}"#)
}
  1. AString(data:encoding:) đôi khi trả về nil, nên phải unwrap bằng XCTUnwrap trước khi so sánh
  2. BXCTAssertEqual không so sánh được String? nên đôi khi bỏ qua kiểm tra mà không báo lỗi
  3. CThứ tự key JSON không cố định giữa các lần chạy; đặt .sortedKeys hoặc decode lại rồi so sánh
  4. DJSONEncoder thêm khoảng trắng ngẫu nhiên giữa các key, nên cần bật .withoutEscapingSlashes
Xem đáp án
Đáp án đúng: C
JSONEncoder không đảm bảo thứ tự key trong object JSON và thứ tự có thể khác nhau giữa các lần chạy, nên so sánh chuỗi thô là test flaky. Đặt encoder.outputFormatting = .sortedKeys để có thứ tự ổn định, hoặc tốt hơn là decode lại rồi so sánh model. .prettyPrinted chỉ đổi khoảng trắng, không cố định thứ tự; còn XCTAssertEqual so sánh được String? bình thường.
