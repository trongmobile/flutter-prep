Bạn cài một thư viện có code native cho camera, chạy lại app thì màn hình đỏ báo ... could not be found. Verify that a module by this name is registered in the native binary. Khi nào phải chạm vào code native trong dự án React Native, autolinking là gì, sau khi cài thư viện native cần làm gì, và vì sao có thư viện không chạy được trong Expo Go?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Phần lớn tính năng chỉ viết bằng JS/TS. Bạn mới phải mở android/ hoặc ios/ khi cần đổi cấu hình hệ thống (quyền trong AndroidManifest.xml và Info.plist, icon, splash, URL scheme, signing), thêm SDK native chưa có thư viện React Native, hoặc tự viết native module. Thư viện có code native phải được liên kết vào project native; từ RN 0.60 việc đó là autolinking: khi build, CLI quét node_modules, thấy thư viện nào có code native thì tự thêm vào Gradle và CocoaPods, không phải sửa tay. Sau khi cài, iOS cần chạy pod install trong ios/, rồi phải build lại app; chỉ reload JS hay Fast Refresh là không đủ vì file cài đặt (binary) đang chạy chưa chứa module mới, và đó chính là nguyên nhân của lỗi "could not be found". Expo Go là app dựng sẵn chỉ chứa một tập module native cố định, nên thư viện native ngoài tập đó không có trong Expo Go; khi đó dùng development build (npx expo run:android, npx expo run:ios hoặc EAS Build) cùng expo-dev-client.
<!-- android/app/src/main/AndroidManifest.xml -->
<uses-permission android:name="android.permission.CAMERA" />

<!-- ios/<TênApp>/Info.plist: thiếu mô tả này thì iOS đóng app ngay khi xin quyền camera -->
<key>NSCameraUsageDescription</key>
<string>Ứng dụng cần camera để quét mã đơn hàng</string>

<!-- Sau khi cài thư viện native: cd ios && pod install, rồi build lại app (không chỉ reload JS) -->
