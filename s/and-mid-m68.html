App có minSdk = 24 dùng java.time.LocalDate (API 26). Lint báo NewApi, còn trên máy Android 7 app crash NoClassDefFoundError. Cách nào cho phép dùng java.time trên mọi phiên bản mà không nâng minSdk?

  1. AThêm @SuppressLint("NewApi") lên hàm gọi để Lint không báo lỗi NewApi nữa, code vẫn chạy
  2. BTăng compileSdk lên 34 để class java.time được đóng gói kèm vào APK khi build
  3. CBật android.enableJetifier=true để Gradle chuyển các class mới sang bản tương thích
  4. DBật core library desugaring trong compileOptions và thêm dependency coreLibraryDesugaring
Xem đáp án
Đáp án đúng: D
compileSdk chỉ quyết định API dùng để biên dịch chứ không đóng gói class vào APK, @SuppressLint("NewApi") chỉ che cảnh báo còn crash trên Android 7 vẫn còn, và Jetifier chuyển thư viện support cũ sang AndroidX nên không liên quan. Core library desugaring làm D8 đóng gói bản backport của một phần thư viện Java (trong đó có java.time) vào app, nên chạy được trên máy cũ mà không cần nâng minSdk. Cần bật isCoreLibraryDesugaringEnabled = true trong compileOptions và thêm dependency coreLibraryDesugaring trỏ tới desugar_jdk_libs.
