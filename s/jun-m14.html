Dùng await for trên một Stream đã lọc: đoạn code sau in ra gì?

Future<void> main() async {
  final stream = Stream.fromIterable([1, 2, 3, 4]);
  var sum = 0;
  await for (final n in stream.where((n) => n.isEven)) {
    sum += n;
  }
  print(sum);
}
  1. A10
  2. B6
  3. C4
  4. DLỗi vì Stream không có method where
Xem đáp án
Đáp án đúng: B
Stream cũng có các method biến đổi giống Iterable (where, map…), ở đây chỉ giữ lại 2 và 4. await for nhận lần lượt từng event cho tới khi stream đóng rồi mới chạy tiếp tới print, nên in ra 6.
