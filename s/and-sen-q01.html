App có cold start khoảng 2,5 giây trên máy tầm trung, trong Application.onCreate đang khởi tạo cả chục SDK. Bạn đo và tối ưu thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Trước hết phải đo đúng: dùng Macrobenchmark với StartupTimingMetric trên máy thật, bản release (R8 bật, không debuggable), và gọi reportFullyDrawn() để có cả TTFD chứ không chỉ TTID; mở Perfetto/System Trace để xem main thread bận gì trong bindApplication và activityStart. Tối ưu theo thứ tự: SDK nào chưa cần cho frame đầu thì init lazy hoặc dời ra sau first frame; gom các ContentProvider tự khởi tạo của thư viện bằng App Startup (có thể tắt auto-init rồi gọi khi cần); đưa I/O ra khỏi main thread và tránh khởi tạo eager các object nặng trong DI graph. Sau đó thêm Baseline Profile để ART AOT-compile sẵn đường code startup ngay khi cài, cùng Startup Profile để R8 xếp các class startup vào DEX chính. Cuối cùng đưa benchmark vào CI để bắt regression thay vì đo một lần rồi thôi.
class LoggerInitializer : Initializer<Logger> {
  override fun create(context: Context): Logger =
    Logger.init(context.applicationContext)

  // Khai báo phụ thuộc thay vì tự sắp thứ tự trong Application
  override fun dependencies(): List<Class<out Initializer<*>>> = emptyList()
}

// Đã tắt auto-init trong Manifest, chỉ init khi thật sự cần:
AppInitializer.getInstance(context)
  .initializeComponent(LoggerInitializer::class.java)
