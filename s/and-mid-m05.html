Một MutableStateFlow được gán liên tiếp nhiều giá trị trong khi collector chưa kịp chạy. Collector in ra gì?

fun main() = runBlocking {
  val state = MutableStateFlow("A")
  val job = launch { state.collect { println(it) } }
  yield()
  state.value = "B"
  state.value = "B"
  state.value = "C"
  yield()
  job.cancel()
}
  1. AA, B, C
  2. BA, C
  3. CA, B, B, C
  4. DChỉ C
Xem đáp án
Đáp án đúng: B
StateFlow là conflated: collector chậm chỉ đọc giá trị mới nhất khi được chạy lại, nên B bị bỏ qua và nó thấy C. Ngoài ra StateFlow không phát lại giá trị bằng giá trị cũ, nên gán B hai lần cũng không tạo thêm emission.
