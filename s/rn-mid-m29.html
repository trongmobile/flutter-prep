Trong useAnimatedScrollHandler, gọi thẳng setHeaderHidden(true) khi cuộn quá 100px thì sao, và cách đúng là gì?

const onScroll = useAnimatedScrollHandler({
  onScroll: (e) => {
    if (e.contentOffset.y > 100) {
      setHeaderHidden(true);
    }
  },
});
  1. ALỗi vì handler chạy trên UI thread; phải gọi qua runOnJS
  2. BChạy bình thường vì setter của useState an toàn đa luồng
  3. CChạy được nhưng trễ đúng một frame so với runOnJS
  4. DLỗi vì phải bọc setHeaderHidden trong useCallback trước
Xem đáp án
Đáp án đúng: A
Handler là worklet chạy trên UI runtime, không gọi trực tiếp được hàm của JS runtime như setter của React; phải lên lịch chạy trên JS thread bằng runOnJS(setHeaderHidden)(true) (Reanimated 4 tách các API luồng này sang react-native-worklets). Nên chỉ gọi khi trạng thái thật sự đổi để tránh bắn lời gọi sang JS ở mọi frame.
