Review trên App Store than app hao pin dù user ít dùng, và Xcode Organizer cũng báo mức tiêu thụ năng lượng cao. Bạn điều tra thế nào, và giảm tiêu thụ ở vị trí, mạng và tác vụ nền ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Pin hao chủ yếu do app giữ CPU, GPS và radio mạng hoạt động khi không cần. Điều tra: Energy gauge trong Debug Navigator của Xcode cho cái nhìn nhanh; Instruments (Energy Log, và Power Profiler ở Xcode mới) đo trên máy thật; Organizer và MetricKit cho số liệu từ user thật (thời gian dùng vị trí, CPU nền, mạng). Vị trí thường là thủ phạm lớn nhất: đặt desiredAccuracy thấp nhất đủ dùng (vài trăm mét chứ không phải kCLLocationAccuracyBest), thêm distanceFilter, dùng startMonitoringSignificantLocationChanges hoặc region monitoring khi chỉ cần biết user di chuyển; allowsBackgroundLocationUpdates chỉ bật khi tính năng thật sự cần theo dõi nền (kèm Background Mode và giải thích với user), và luôn stopUpdatingLocation() khi xong. Mạng: thay polling bằng push (APNs), gom các request nhỏ thành một lần vì radio di động còn giữ trạng thái tốn điện một lúc sau mỗi lần truyền, tải nền dùng URLSession background với isDiscretionary để hệ thống chọn lúc có điện và Wi-Fi. Việc nền định kỳ dùng BGTaskScheduler thay vì giữ app sống bằng beginBackgroundTask kéo dài; Timer đặt tolerance để hệ thống gộp các lần đánh thức. Cuối cùng, tôn trọng Low Power Mode (ProcessInfo.isLowPowerModeEnabled, thông báo NSProcessInfoPowerStateDidChange) bằng cách giảm tần suất đồng bộ, tắt prefetch và animation nặng.
final class TrackingService: NSObject, CLLocationManagerDelegate {
    private let manager = CLLocationManager()

    func startCoarseTracking() {
        manager.delegate = self
        manager.desiredAccuracy = kCLLocationAccuracyHundredMeters // chỉ cần độ chính xác vừa đủ
        manager.distanceFilter = 200                               // bỏ qua dịch chuyển nhỏ
        manager.pausesLocationUpdatesAutomatically = true          // tự tạm dừng khi user đứng yên
        manager.startUpdatingLocation()
    }

    func stop() { manager.stopUpdatingLocation() } // luôn dừng khi xong việc
}

// Hạ tần suất đồng bộ khi user bật Low Power Mode (syncInterval là cấu hình của scheduler)
NotificationCenter.default.addObserver(forName: .NSProcessInfoPowerStateDidChange, object: nil, queue: .main) { _ in
    syncInterval = ProcessInfo.processInfo.isLowPowerModeEnabled ? 900 : 120
}
