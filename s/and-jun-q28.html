Một BroadcastReceiver khai báo trong Manifest không nhận được broadcast hệ thống trên Android 8 trở lên, còn đăng ký bằng registerReceiver thì chạy. Vì sao, và đăng ký bằng code đúng cách cần lưu ý gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Receiver trong Manifest được hệ thống đánh thức kể cả khi app không chạy, còn receiver đăng ký bằng code chỉ sống cùng component đăng ký nó. Từ Android 8.0 (API 26), app nhắm tới API 26+ không nhận được phần lớn broadcast ngầm định (implicit) qua Manifest, chỉ còn vài ngoại lệ như BOOT_COMPLETED; một số broadcast như ACTION_BATTERY_CHANGED chỉ nhận được bằng registerReceiver. Đăng ký bằng code thì ghép cặp registerReceiver/unregisterReceiver theo onStart/onStop: quên huỷ thì Activity bị leak (logcat báo IntentReceiverLeaked), huỷ khi chưa đăng ký thì ném IllegalArgumentException. Từ Android 14, app nhắm tới API 34 đăng ký receiver cho broadcast không phải của hệ thống phải truyền RECEIVER_EXPORTED hoặc RECEIVER_NOT_EXPORTED (dùng ContextCompat.registerReceiver cho mọi phiên bản). onReceive chạy trên main thread, việc nặng giao cho WorkManager.
class BatteryActivity : AppCompatActivity() {
    private val batteryReceiver = object : BroadcastReceiver() {
        override fun onReceive(context: Context, intent: Intent) {
            showBattery(intent.getIntExtra(BatteryManager.EXTRA_LEVEL, -1))
        }
    }

    override fun onStart() {
        super.onStart()
        // Chỉ nghe broadcast hệ thống nên không cần cờ export
        registerReceiver(batteryReceiver, IntentFilter(Intent.ACTION_BATTERY_CHANGED))
        // Broadcast do chính app gửi: ContextCompat.registerReceiver(this, r, filter,
        //     ContextCompat.RECEIVER_NOT_EXPORTED)
    }

    override fun onStop() {
        super.onStop()
        unregisterReceiver(batteryReceiver)
    }
}
