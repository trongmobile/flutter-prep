Với cấu hình package sau, app target link cả SharedKit (dynamic) lẫn AnalyticsCore (static). Hệ quả dễ gặp nhất là gì?

// Package.swift
products: [
  .library(name: "AnalyticsCore", type: .static, targets: ["AnalyticsCore"]),
  .library(name: "SharedKit", type: .dynamic, targets: ["SharedKit"]),
],
targets: [
  .target(name: "AnalyticsCore"),
  .target(name: "SharedKit", dependencies: ["AnalyticsCore"]),
]
  1. ALinker tự gộp lại thành một bản nên không có vấn đề gì
  2. BCó hai bản copy, singleton trong AnalyticsCore thành hai instance
  3. CKhông build được vì static library không thể link vào dynamic framework
  4. DSharedKit tự chuyển AnalyticsCore sang dynamic lúc chạy
Xem đáp án
Đáp án đúng: B
Static library được copy vào từng binary link nó, nên app và SharedKit mỗi bên có một bản code cùng một bản biến global hay singleton; runtime Objective-C còn cảnh báo class được implement ở cả hai nơi. Cách xử lý là chỉ link AnalyticsCore vào một chỗ, hoặc biến nó thành dynamic dùng chung.
