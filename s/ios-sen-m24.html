Hàm đặt hàng sau thỉnh thoảng tạo đơn trùng khi mạng chập chờn, dù server đã nhận đơn đầu tiên. Cách sửa căn bản nhất?

func placeOrder(_ draft: OrderDraft) async throws -> Order {
  var request = URLRequest(url: ordersURL)
  request.httpMethod = "POST"
  request.httpBody = try JSONEncoder().encode(draft)
  // thử lại tối đa 3 lần khi timeout hoặc lỗi mạng
  return try await withRetry(times: 3) {
    try await client.send(request, as: Order.self)
  }
}
  1. ATăng timeout để request đầu tiên luôn kịp nhận response
  2. BSinh UUID mới cho header Idempotency-Key ở mỗi lần gửi lại request
  3. CSinh idempotency key một lần cho mỗi đơn, gửi lại ở mọi lần retry
  4. DBỏ retry cho POST, báo lỗi để user tự bấm đặt hàng lại
Xem đáp án
Đáp án đúng: C
Timeout không cho biết server đã xử lý hay chưa, nên retry chỉ an toàn khi server nhận ra đó là cùng một thao tác qua idempotency key; key phải sinh một lần cho mỗi đơn (thường lưu cùng bản nháp hoặc outbox), sinh mới mỗi lần retry thì server lại coi là đơn mới. Tăng timeout chỉ giảm xác suất, còn để user bấm lại vẫn tạo đơn trùng.
