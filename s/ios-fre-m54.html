start() được gọi trong viewDidLoad. Các dòng được in ra theo thứ tự nào?

func fetchName() async -> String {
    try? await Task.sleep(for: .seconds(1))
    return "An"
}

func start() {
    print("A")
    Task {
        let name = await fetchName()
        print("B", name)
    }
    print("C")
}
  1. AA, chờ khoảng 1 giây, B An, rồi mới tới C vì await chặn start()
  2. BA, C, còn B An không bao giờ in vì Task bị huỷ khi start() kết thúc
  3. CA, C, rồi khoảng 1 giây sau mới in B An khi Task chạy xong
  4. DLỗi compile vì dùng await trong Task mà start() không phải hàm async
Xem đáp án
Đáp án đúng: C
Task { } khởi chạy công việc bất đồng bộ rồi trả quyền điều khiển ngay, nên start() chạy tiếp và in C trước. await chỉ tạm dừng chính task đó (không chặn main thread) khoảng 1 giây rồi mới in B An. await hợp lệ vì nằm trong closure của Task, và task không bị huỷ khi hàm tạo ra nó kết thúc: đây là unstructured task, sống độc lập với start().
