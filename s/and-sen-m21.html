Bản release bật isShrinkResources = true và bị mất drawable khi tên icon lấy từ API như sau. Cách sửa đúng?

val iconName = response.iconName // ví dụ "ic_badge_gold"
val resId = resources.getIdentifier(iconName, "drawable", packageName)
badgeView.setImageResource(resId)
  1. AGiữ các resource đó bằng tools:keep trong một file XML ở res/raw/
  2. BThêm @Keep cho hàm gọi getIdentifier để R8 giữ resource liên quan
  3. CTắt R8 code shrinking nhưng vẫn để isShrinkResources = true
  4. DChuyển icon sang drawable-nodpi để resource shrinker bỏ qua thư mục đó
Xem đáp án
Đáp án đúng: A
Resource shrinker chỉ giữ resource được tham chiếu tĩnh hoặc có tên khớp với chuỗi hằng trong code; tên đến từ API thì nó không thể biết. Khai báo tools:keep="@drawable/ic_badge_*" trong res/raw/keep.xml; còn shrink resource bắt buộc phải bật code shrinking.
