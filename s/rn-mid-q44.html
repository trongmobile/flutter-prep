Danh sách sản phẩm dùng useInfiniteQuery + FlatList. Lỗi đang gặp: onEndReached bắn liên tục làm tải trùng trang, bản ghi bị lặp trong list (báo trùng key) khi server có dữ liệu mới chèn vào lúc đang cuộn, và kéo để làm mới thì cả 10 trang đã tải bị refetch lần lượt. Bạn cấu hình thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Ở TanStack Query v5, useInfiniteQuery cần initialPageParam và getNextPageParam: hàm sau trả về param của trang kế (cursor hay số trang), trả undefined khi hết dữ liệu thì hasNextPage thành false. Cursor (id hoặc mốc thời gian của item cuối) an toàn hơn offset: nếu có item mới chèn vào đầu trong lúc người dùng cuộn, offset làm lệch trang nên trùng hoặc sót bản ghi. Tải trùng trang: onEndReached có thể bắn khi layout đổi hay nội dung chưa đủ cao, nên guard if (hasNextPage && !isFetchingNextPage) fetchNextPage() và đặt onEndReachedThreshold vừa phải. Dù dùng cursor, vẫn nên gộp các trang rồi loại trùng theo id trong select (khai báo hàm ổn định bên ngoài component) và dùng keyExtractor theo id. Làm mới: refetch của infinite query chạy lại tất cả các trang đã tải theo thứ tự, danh sách càng dài càng chậm; với kéo-để-làm-mới thì nên reset về trang đầu (resetQueries, hoặc cắt pages còn trang đầu rồi refetch), và có thể đặt maxPages để giới hạn số trang giữ trong cache (khi đó cần cả getPreviousPageParam). Dùng refreshing={isRefetching && !isFetchingNextPage} để vòng xoay kéo-làm-mới không bật lên mỗi lần tải thêm.
const dedupeById = (items: Product[]) => [...new Map(items.map((p) => [p.id, p])).values()];
const selectProducts = (d: InfiniteData<ProductPage>) => dedupeById(d.pages.flatMap((p) => p.items));

function ProductList() {
  const { data, fetchNextPage, hasNextPage, isFetchingNextPage, refetch, isRefetching } =
    useInfiniteQuery({
      queryKey: ['products'],
      queryFn: ({ pageParam }) => api.getProducts({ cursor: pageParam, limit: 20 }),
      initialPageParam: undefined as string | undefined,
      getNextPageParam: (last) => last.nextCursor ?? undefined, // undefined = hết dữ liệu
      select: selectProducts,
    });

  return (
    <FlatList
      data={data}
      keyExtractor={(p) => p.id}
      renderItem={({ item }) => <ProductRow product={item} />}
      onEndReached={() => {
        if (hasNextPage && !isFetchingNextPage) fetchNextPage();
      }}
      onEndReachedThreshold={0.5}
      refreshing={isRefetching && !isFetchingNextPage}
      onRefresh={refetch}
      ListFooterComponent={isFetchingNextPage ? <ActivityIndicator /> : null}
    />
  );
}
