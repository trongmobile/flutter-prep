Khi khai báo mixin, từ khoá on dùng để làm gì? Cho ví dụ trong Flutter.

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
on giới hạn mixin chỉ được dùng cho class là subtype của một kiểu nhất định; đổi lại, bên trong mixin được gọi các member của kiểu đó như setState, mounted, super.dispose(). Ví dụ quen thuộc là SingleTickerProviderStateMixin được khai báo on State<T> nên chỉ dùng được trong State. Bạn có thể tự viết mixin như LoadingMixin bên dưới rồi dùng class _LoginPageState extends State<LoginPage> with LoadingMixin để tái sử dụng logic loading cho nhiều màn hình. Từ Dart 3, chỉ những gì khai báo bằng mixin (hoặc mixin class) mới dùng được sau with.
mixin LoadingMixin<T extends StatefulWidget> on State<T> {
  bool isLoading = false;

  Future<void> runWithLoading(Future<void> Function() task) async {
    setState(() => isLoading = true);
    try {
      await task();
    } finally {
      if (mounted) setState(() => isLoading = false);
    }
  }
}
