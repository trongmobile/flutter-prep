Effect gọi API theo bộ lọc dưới đây gặp vấn đề gì?

function Products({ category }: { category: string }) {
  const [items, setItems] = useState<Product[]>([]);
  const filter = { category, inStock: true };

  useEffect(() => {
    api.getProducts(filter).then(setItems);
  }, [filter]);

  return <ProductList items={items} />;
}
  1. AEffect chỉ chạy một lần vì filter được so sánh theo nội dung
  2. BLỗi compile vì object không được dùng làm dependency
  3. CChỉ gọi lại API khi category đổi, đúng như mong muốn
  4. DGọi API liên tục vì filter là object mới mỗi lần render
Xem đáp án
Đáp án đúng: D
React so sánh dependency bằng Object.is, object literal tạo lại mỗi render nên luôn khác; effect chạy, setItems gây render mới, lại tạo filter mới, thành vòng lặp gọi API. Sửa bằng cách dùng giá trị nguyên thuỷ [category] làm deps và tạo object bên trong effect, hoặc dùng useMemo.
