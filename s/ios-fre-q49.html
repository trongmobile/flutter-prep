Vì sao không nên hardcode API key hoặc secret trong code app iOS? Người ta lấy ra bằng cách nào, và cách xử lý đúng là gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
App được phát tới máy người dùng nên mọi thứ nằm trong file .ipa đều có thể bị xem. File tài nguyên như Info.plist, JSON, plist đọc được ngay sau khi đổi đuôi .ipa thành .zip rồi giải nén; chuỗi hằng trong binary thì lấy ra bằng strings hay công cụ như Hopper sau khi dump bản đã giải mã (có sẵn công cụ làm việc này), hoặc đọc thẳng từ bản build của chính họ. Nghe lén request bằng Charles hay Proxyman cũng thấy key nếu app gửi nó đi. Đưa key vào .xcconfig, Base64 hay XOR chỉ làm chậm chứ không ngăn được. Vì vậy secret thật sự (khoá dịch vụ trả phí, khoá ký, mật khẩu database, token quản trị) không bao giờ được nằm trong app: để backend giữ secret và gọi dịch vụ thay cho app, app chỉ gọi backend bằng token của người dùng đã đăng nhập. Nếu SDK buộc có key ở client (bản đồ, analytics) thì dùng loại key dành cho client và hạn chế quyền ở phía nhà cung cấp: giới hạn theo bundle ID, theo API được phép, đặt hạn mức và xoay key khi lộ. Token đăng nhập của người dùng thì lưu ở Keychain, không để trong UserDefaults. Lỡ commit key lên Git thì coi như đã lộ: phải thu hồi và đổi key, chỉ xoá khỏi lịch sử là chưa đủ.
// SAI: secret nằm trong binary, ai lấy được app cũng đọc được
enum Secrets {
    static let paymentSecretKey = "sk_live_xxxxxxxx"
    static let aiServiceKey = "sk-xxxxxxxx"
}

// ĐÚNG: app chỉ gọi backend của bạn bằng token đăng nhập, backend giữ secret
struct APIClient {
    let baseURL = URL(string: "https://api.shop.vn")!
    let tokenProvider: () -> String      // access token của user, lấy từ Keychain

    func request(path: String) -> URLRequest {
        var request = URLRequest(url: baseURL.appendingPathComponent(path))
        request.setValue("Bearer \(tokenProvider())", forHTTPHeaderField: "Authorization")
        return request
    }
}
// Backend nhận request, tự gắn secret rồi gọi dịch vụ bên thứ ba và trả kết quả về cho app
