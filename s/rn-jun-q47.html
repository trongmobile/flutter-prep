Nút "Gọi hotline", "Mở app đối tác" và "Mở cài đặt để cấp quyền" dùng Linking.openURL. Trên iOS Linking.canOpenURL('someapp://') luôn trả false dù máy đã cài app đó, còn trên Android 11+ thì bấm nút không có gì xảy ra. Vì sao, và bạn xử lý trường hợp không có app nào mở được link thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Linking.openURL(url) nhờ hệ điều hành mở URL bằng app phù hợp (https:, tel:, mailto: hay scheme riêng) và trả Promise bị reject nếu không có app nào xử lý. canOpenURL bị giới hạn vì quyền riêng tư: trên iOS, với scheme tuỳ chỉnh bạn phải khai báo trong LSApplicationQueriesSchemes của Info.plist, không thì luôn trả false; trên Android 11 trở lên (package visibility) phải khai báo <queries> trong AndroidManifest.xml. Code kiểu if (await canOpenURL(url)) openURL(url) vì vậy âm thầm không làm gì trên máy thật. Cách làm ổn hơn là gọi thẳng openURL trong try/catch và có phương án dự phòng (trang web, link tải app trên store, thông báo rõ ràng); chỉ dùng canOpenURL khi cần ẩn hoặc hiện nút, kèm khai báo đầy đủ. Mở trang cài đặt của chính app (cấp lại quyền sau khi người dùng từ chối) dùng Linking.openSettings(). Thêm vài bẫy: tel: không làm gì trên iOS Simulator hoặc thiết bị không có SIM, nên đừng vội kết luận code sai; nội dung ghép vào mailto: hay query string phải qua encodeURIComponent.
async function openWithFallback(url: string, fallbackUrl: string) {
  try {
    await Linking.openURL(url); // thử mở thẳng, không chặn bằng canOpenURL
  } catch {
    await Linking.openURL(fallbackUrl).catch(() =>
      Alert.alert('Không mở được liên kết', 'Máy chưa có ứng dụng phù hợp.'),
    );
  }
}

openWithFallback('tel:19001234', 'https://shop.vn/lien-he');
openWithFallback('someapp://profile/42', 'https://shop.vn/tai-app-doi-tac');

Linking.openSettings(); // mở trang cài đặt của chính app

// Chỉ cần khi dùng canOpenURL với scheme riêng:
// Info.plist: <key>LSApplicationQueriesSchemes</key><array><string>someapp</string></array>
// AndroidManifest.xml:
//   <queries><intent><action android:name="android.intent.action.VIEW" /><data android:scheme="someapp" /></intent></queries>
