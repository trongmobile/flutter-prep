Hai class giữ strong reference tới nhau như sau; console in ra gì sau khi gán cả p và apt về nil?

class Person {
    var apartment: Apartment?
    deinit { print("Person deinit") }
}
class Apartment {
    var tenant: Person?
    deinit { print("Apartment deinit") }
}

var p: Person? = Person()
var apt: Apartment? = Apartment()
p?.apartment = apt
apt?.tenant = p
p = nil
apt = nil
  1. APerson deinit rồi Apartment deinit
  2. BKhông in gì, vì hai object giữ strong reference lẫn nhau
  3. CChỉ in Person deinit, vì p được gán nil trước nên được giải phóng trước
  4. DApartment deinit rồi Person deinit
Xem đáp án
Đáp án đúng: B
Person giữ Apartment và Apartment giữ ngược Person bằng strong reference, nên khi p và apt về nil mỗi object vẫn còn bộ đếm 1 và không được giải phóng (retain cycle). Khai báo weak var tenant: Person? sẽ phá vòng, khi đó cả hai deinit đều chạy.
