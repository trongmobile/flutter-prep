Màn debug có nút "Xuất database" bằng cách copy file app.db sang thư mục chia sẻ. QA nhận file nhưng thiếu các dòng vừa ghi gần nhất dù app vẫn hiển thị đủ. Nguyên nhân khả dĩ nhất là gì?

  1. ARoom gom các lần ghi trong bộ nhớ và chỉ flush xuống app.db khi app thoát hẳn
  2. BRoom mặc định bật WAL: dữ liệu mới có thể còn nằm ở file -wal, chưa được gộp vào app.db
  3. CAndroid tự khoá file app.db khi app đang chạy nên bản copy chỉ chứa phần dữ liệu cũ
  4. D@Insert chạy bất đồng bộ nên các dòng mới chưa kịp ghi xuống đĩa vào lúc copy file
Xem đáp án
Đáp án đúng: B
Room dùng journal mode WAL theo mặc định (trừ máy RAM thấp): mỗi giao dịch được ghi nối vào file app.db-wal, và chỉ được gộp vào app.db khi checkpoint (tự động khi WAL đủ lớn, hoặc khi đóng connection cuối). Copy riêng app.db vì thế có thể thiếu dữ liệu mới. Cách xuất đúng là copy cả app.db, app.db-wal và app.db-shm cùng lúc, hoặc chạy PRAGMA wal_checkpoint(FULL) (hay TRUNCATE) rồi mới copy. Room không giữ dữ liệu ghi trong RAM chờ flush, không khoá file với bản copy của chính app, và một giao dịch đã commit thì đã nằm trong file WAL chứ không phải còn chờ ghi.
