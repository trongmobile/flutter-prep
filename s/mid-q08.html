Bạn thiết lập đa ngôn ngữ cho app Flutter bằng intl + ARB như thế nào? Xử lý tham số và số nhiều ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Thêm flutter_localizations và intl, bật generate: true trong pubspec.yaml, khai báo l10n.yaml (thư mục ARB, file template) và viết mỗi ngôn ngữ một file app_xx.arb; flutter gen-l10n (hoặc tự chạy khi build) sinh class AppLocalizations type-safe — các bản Flutter gần đây sinh file thẳng vào source thay vì synthetic package flutter_gen cũ. Đăng ký localizationsDelegates và supportedLocales vào MaterialApp, rồi gọi AppLocalizations.of(context)!.key. Tham số và số nhiều viết theo cú pháp ICU ({count, plural, =0{…} other{…}}) để mỗi ngôn ngữ có quy tắc riêng; tránh tự ghép chuỗi vì thứ tự từ khác nhau giữa các ngôn ngữ.
// lib/l10n/app_vi.arb
// {
//   "hello": "Xin chào {name}",
//   "cartItems": "{count, plural, =0{Giỏ hàng trống} other{{count} sản phẩm}}"
// }

MaterialApp(
  localizationsDelegates: AppLocalizations.localizationsDelegates,
  supportedLocales: AppLocalizations.supportedLocales,
  home: Builder(
    builder: (context) => Text(AppLocalizations.of(context)!.cartItems(3)),
  ),
)
