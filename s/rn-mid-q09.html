Sau khi đăng nhập, app gọi navigation.navigate('Home'), nhưng bấm back trên Android lại quay về màn Login; đăng xuất xong cũng có thể back vào màn cần đăng nhập. Bạn tổ chức auth flow với React Navigation thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Vấn đề là màn Login và màn chính nằm chung một stack, nên navigate chỉ đẩy thêm màn mới và Login vẫn còn trong lịch sử. Cách React Navigation khuyến nghị là khai báo màn hình có điều kiện theo trạng thái đăng nhập: chưa đăng nhập thì navigator chỉ có nhóm màn auth, đã đăng nhập thì chỉ có nhóm màn chính. Khi state auth đổi (lưu trong Context hoặc store), navigator tự chuyển sang nhóm màn mới và các màn của nhóm cũ bị gỡ khỏi lịch sử, nên không back lại được, cũng không cần tự gọi navigate hay reset sau khi đăng nhập. Lúc mở app, trong khi đọc token từ secure storage thì hiển thị splash, tránh nháy màn Login. Deep link tới màn cần đăng nhập phải được xử lý sau khi auth sẵn sàng, vì lúc chưa đăng nhập màn đó chưa tồn tại trong navigator.
function RootNavigator() {
  const { isLoading, token } = useAuth();
  if (isLoading) return <SplashScreen />;

  return (
    <Stack.Navigator>
      {token == null ? (
        <Stack.Screen name="Login" component={LoginScreen} />
      ) : (
        <Stack.Screen name="Home" component={HomeScreen} />
      )}
    </Stack.Navigator>
  );
}
