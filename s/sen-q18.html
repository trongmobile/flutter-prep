Bạn cần biết app của người dùng thật có bị giật không, theo từng màn hình và dòng máy, chứ không chỉ đo trên máy dev. Dùng FrameTiming và addTimingsCallback thế nào để thu thập số liệu frame ở production, và gửi lên mà không ảnh hưởng hiệu năng?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Flutter báo thời gian từng frame cho app qua SchedulerBinding.instance.addTimingsCallback, nhận danh sách FrameTiming theo lô (không phải từng frame một); mỗi phần tử có buildDuration (UI thread), rasterDuration (raster thread), totalSpan và vsyncOverhead, và callback có cả ở release nên dùng được cho telemetry. Quy trình: coi một frame là chậm khi totalSpan vượt chu kỳ vsync của máy (16,7 ms ở 60Hz, 8,3 ms ở 120Hz, nên đọc refresh rate thay vì hard-code), 'đóng băng' khi quá 700 ms (cách Android vitals phân loại), rồi gom theo màn hình (gắn tên route hiện tại qua NavigatorObserver) thành bộ đếm và phân vị (p50, p90, p99, tỉ lệ frame chậm) thay vì gửi từng frame. Tách build và raster để biết nguyên nhân: build chậm là do logic hay rebuild, raster chậm là do hiệu ứng đắt (saveLayer, blur, shader). Gửi theo lô định kỳ hoặc khi app ra background, lấy mẫu một phần người dùng, kèm phiên bản app, model máy, bản OS và việc có bật Impeller hay không. Callback phải rẻ vì nó chạy trong lúc app đang vẽ: tránh I/O hay gọi mạng bên trong. Số liệu thực tế bổ sung cho DevTools chứ không thay thế: khi telemetry báo một màn có tỉ lệ jank cao thì dùng DevTools ở profile mode để tìm nguyên nhân. Có thể thêm marker tuỳ chỉnh bằng Timeline.startSync hay TimelineTask để thấy trong DevTools, và đưa kiểm tra hiệu năng vào CI bằng integration_test kèm binding.traceAction và TimelineSummary để bắt hồi quy trước khi phát hành.
class FrameMonitor {
  FrameMonitor(this.currentScreen);
  final String Function() currentScreen; // tên route hiện tại, lấy từ NavigatorObserver
  final _stats = <String, ScreenStats>{};

  void start() {
    SchedulerBinding.instance.addTimingsCallback(_onTimings);
  }

  void _onTimings(List<FrameTiming> timings) {
    // Callback phải rẻ: chỉ cộng dồn bộ đếm, không I/O hay gọi mạng
    final budget = frameBudget(); // 16.7ms ở 60Hz, 8.3ms ở 120Hz
    final stats = _stats.putIfAbsent(currentScreen(), ScreenStats.new);
    for (final t in timings) {
      stats.frames++;
      if (t.totalSpan > budget) stats.slowFrames++;
      if (t.totalSpan > const Duration(milliseconds: 700)) stats.frozenFrames++;
      if (t.buildDuration > budget) stats.slowBuild++; // nghi do logic hay rebuild
      if (t.rasterDuration > budget) stats.slowRaster++; // nghi do hiệu ứng đắt
    }
  }

  // Gửi theo lô khi app ra nền hoặc theo chu kỳ dài, rồi reset bộ đếm
  Map<String, Object> flush() => {
    for (final e in _stats.entries) e.key: e.value.toJson(),
  };
}
