API gateway trả HTTP 502 kèm một trang lỗi HTML. Đoạn code sau in ra gì?

try {
  const res = await fetch(`${API_URL}/orders`);
  const data = await res.json();
  if (!res.ok) throw new Error(data.message);
  setOrders(data);
} catch (e) {
  console.log((e as Error).name);
}
  1. AError, ném ra từ dòng kiểm tra res.ok
  2. BSyntaxError, vì res.json() gặp HTML
  3. CTypeError, vì fetch reject khi gặp 502
  4. DKhông in gì, orders nhận chuỗi HTML thô
Xem đáp án
Đáp án đúng: B
Status 502 không làm fetch reject, nhưng res.json() parse body là HTML nên ném SyntaxError trước khi tới dòng kiểm tra res.ok; đây là nguồn gốc của lỗi JSON Parse error hay gặp. Nên kiểm tra res.ok (và nếu cần cả Content-Type) trước khi gọi res.json().
