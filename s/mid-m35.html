Phát biểu nào đúng về golden test trong Flutter?

  1. AChỉ so sánh cấu trúc widget tree, bỏ qua pixel
  2. BBắt buộc chạy trên thiết bị thật để chụp màn hình
  3. CTự bỏ qua khác biệt font nên ảnh giống hệt trên mọi OS
  4. DSo ảnh render với PNG chuẩn; tạo bằng --update-goldens
