Màn theo dõi đơn giao hàng cần hiện trạng thái và vị trí shipper gần như realtime. Bạn chọn polling, WebSocket hay push? Vòng đời foreground/background, mất mạng và tiết kiệm pin xử lý thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Chọn theo tần suất cập nhật và ngữ cảnh. Polling đơn giản, hợp khi dữ liệu đổi chậm (hàng chục giây), nhưng tốn pin và mạng nếu interval ngắn; chỉ poll khi màn đang mở, có backoff khi dữ liệu không đổi. WebSocket (URLSessionWebSocketTask) hợp cho luồng cập nhật liên tục khi màn đang mở: một kết nối, độ trễ thấp. Bạn phải tự lo heartbeat (sendPing), reconnect với exponential backoff kèm jitter, và sau mỗi lần nối lại phải lấy lại trạng thái hiện tại bằng REST vì có thể đã lỡ message. Push (APNs) hợp cho mốc quan trọng khi app không chạy ("shipper đã tới"); silent push không đảm bảo tới và bị giới hạn tần suất nên không dùng làm kênh realtime. Live Activity (ActivityKit) hợp cho trải nghiệm theo dõi đơn ngay trên màn hình khoá, cập nhật qua push. Vòng đời: mở socket khi màn xuất hiện, đóng khi màn biến mất hoặc app vào background (hệ thống sẽ treo app và socket chết lặng lẽ), mở lại khi quay về foreground rồi đồng bộ lại. Dùng NWPathMonitor để biết khi nào có mạng trở lại thay vì retry mù, và giới hạn tần suất vẽ lại marker trên bản đồ (1–2 giây) để đỡ tốn CPU.
@MainActor @Observable
final class TrackingViewModel {
    private(set) var status: OrderStatus?
    private var socket: URLSessionWebSocketTask?
    private var loop: Task<Void, Never>?

    func start(url: URL) {
        loop = Task { [weak self] in
            var attempt = 0
            while !Task.isCancelled {
                guard let self else { return }
                let socket = URLSession.shared.webSocketTask(with: url)
                self.socket = socket
                socket.resume()
                do {
                    while true {
                        let message = try await socket.receive()
                        attempt = 0
                        if case .string(let text) = message { self.apply(text) }
                    }
                } catch {
                    if Task.isCancelled { return }
                    attempt += 1
                    let delay = Double(min(30, 1 << min(attempt, 5))) + .random(in: 0...1) // backoff + jitter
                    try? await Task.sleep(for: .seconds(delay))
                    await self.refreshFromREST() // có thể đã lỡ message trong lúc mất kết nối
                }
            }
        }
    }

    func stop() { // gọi khi màn biến mất hoặc app vào background
        loop?.cancel()
        socket?.cancel(with: .goingAway, reason: nil) // receive() đang chờ sẽ ném lỗi để vòng lặp thoát
    }
}
