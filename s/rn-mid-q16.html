Reanimated chạy animation 'trên UI thread' nghĩa là gì? Shared value và worklet khác useState và hàm JS thường ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Reanimated tạo một JS runtime thứ hai chạy trên UI thread; worklet là hàm được đánh dấu để chạy trên runtime đó (callback của useAnimatedStyle, useAnimatedScrollHandler được Babel plugin tự biến thành worklet). Shared value (useSharedValue) đọc/ghi được từ cả hai runtime qua .value; gán nó không gây React re-render, và useAnimatedStyle phụ thuộc vào nó được tính lại ngay trên UI thread mỗi frame, nên animation vẫn mượt khi JS thread đang bận. Bẫy thường gặp: worklet không gọi trực tiếp được hàm JS thường như setState hay navigation mà phải lên lịch chạy về JS thread bằng runOnJS (ở Reanimated 4, các API luồng này được tách sang thư viện react-native-worklets); và không nên đọc hay ghi .value trong lúc component đang render.
const offset = useSharedValue(0);

const animatedStyle = useAnimatedStyle(() => ({
  transform: [{ translateX: offset.value }], // worklet, chạy trên UI thread
}));

const onPress = () => {
  offset.value = withSpring(offset.value === 0 ? 120 : 0); // không re-render
};

return <Animated.View style={[styles.box, animatedStyle]} />;
