Bạn cần cache ảnh avatar trong app. NSCache, Dictionary và URLCache khác nhau thế nào, và bạn kết hợp chúng ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
NSCache là cache trong RAM, thread-safe, tự giải phóng phần tử khi hệ thống thiếu bộ nhớ, đặt được countLimit/totalCostLimit (chỉ là giới hạn mềm) và key phải là object như NSString/NSURL. Dictionary thì không tự dọn khi thiếu bộ nhớ và không an toàn khi đọc ghi từ nhiều thread. URLCache cache response HTTP trên RAM và disk theo header của server (Cache-Control, ETag…), nên chỉ hiệu quả khi server trả header phù hợp và response không quá lớn so với dung lượng cache. Kiến trúc hay dùng là hai tầng: NSCache giữ UIImage đã decode để hiển thị tức thì, tầng disk (URLCache hoặc tự ghi file vào thư mục Caches) giữ dữ liệu qua các lần mở app. Ngoài ra nên gộp các request trùng URL đang chạy để không tải một ảnh nhiều lần.
