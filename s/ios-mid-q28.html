Bạn gọi withAnimation { isExpanded.toggle() } nhưng view mới xuất hiện bị nhảy vào chứ không animate, còn .animation(.easeInOut) đặt ở cuối chain làm cả màn hình animate lung tung. Giải thích animation tường minh và ngầm định, transition, và matchedGeometryEffect?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
SwiftUI animate sự khác biệt giữa hai lần render của các thuộc tính có thể nội suy. Animation ngầm định: .animation(_:value:) gắn vào một view chỉ animate khi value đổi và chỉ ảnh hưởng thuộc tính của view đó cùng các con; bản không có value (.animation(.easeInOut)) đã bị deprecated vì animate mọi thứ đổi bên dưới, gây hiệu ứng ngoài ý muốn. Animation tường minh: withAnimation { state.toggle() } animate mọi thay đổi do state đó gây ra trong cây view, tức kiểm soát theo nguyên nhân, hợp khi một hành động làm đổi nhiều view. View được thêm hoặc xoá khỏi cây (nhánh if) không có giá trị để nội suy nên cần .transition(.opacity), .move, .scale hoặc .asymmetric, và transition chỉ chạy khi thay đổi nằm trong một animation (withAnimation hoặc modifier .animation đặt ở view cha còn tồn tại, vì đặt ngay trên view đang bị xoá thì modifier biến mất cùng view). Animation trong list cần identity ổn định (id), nếu không view bị tạo mới thay vì di chuyển. matchedGeometryEffect(id:in:) cùng một @Namespace làm hai view ở hai chỗ khác nhau (ảnh nhỏ thành ảnh lớn) trông như một view di chuyển, tại mỗi thời điểm chỉ một view tồn tại. Animatable và animatableData để animate dữ liệu tuỳ biến như thuộc tính riêng của một Shape. Animate frame hay layout đắt hơn opacity hoặc offset, và có thể tắt tạm animation bằng .transaction { $0.animation = nil }.
struct ExpandableRow: View {
  let card: Card
  @State private var isExpanded = false

  var body: some View {
    VStack(alignment: .leading) {
      HStack {
        Text(card.title)
        Spacer()
        Image(systemName: "chevron.down")
          .rotationEffect(.degrees(isExpanded ? 180 : 0))
          .animation(.easeInOut(duration: 0.2), value: isExpanded) // ngầm định: chỉ animate khi isExpanded đổi
      }
      .contentShape(Rectangle())
      .onTapGesture {
        withAnimation(.easeInOut(duration: 0.35)) { isExpanded.toggle() } // tường minh: mọi thay đổi do hành động này
      }

      if isExpanded {
        CardDetail(card: card)
          .transition(.opacity.combined(with: .move(edge: .top))) // view được thêm vào hoặc xoá đi cần transition
      }
    }
    .clipped()
  }
}
