Tải file PDF 80MB bằng URLSession.shared.downloadTask(with:completionHandler:) rồi mở file trong completion thì lúc được lúc báo file không tồn tại, không có thanh tiến độ, và khi người dùng chuyển sang app khác một lúc thì việc tải dừng luôn. Giải thích và sửa thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
downloadTask ghi dữ liệu vào một file tạm do hệ thống quản lý rồi đưa URL tạm đó cho bạn; ngay khi completion (hoặc urlSession(_:downloadTask:didFinishDownloadingTo:)) return, hệ thống xoá file tạm. Vì vậy phải moveItem sang thư mục của app ngay trong hàm đó; chuyển sang DispatchQueue.main.async rồi mới di chuyển thì file đã mất. Bản completion-handler không báo tiến độ: muốn có thì tạo session với delegate và cài urlSession(_:downloadTask:didWriteData:totalBytesWritten:totalBytesExpectedToWrite:), nhớ về main thread khi cập nhật UI và kiểm tra totalBytesExpectedToWrite > 0 vì server không gửi Content-Length thì giá trị là -1. Để tải tiếp khi app bị suspend hoặc bị hệ thống kill, dùng URLSessionConfiguration.background(withIdentifier:): việc tải chạy ngoài process của app và bắt buộc dùng delegate (không dùng completion handler). Khi xong, hệ thống đánh thức app và gọi application(_:handleEventsForBackgroundURLSession:completionHandler:); app tạo lại session cùng identifier và gọi completion handler đó trong urlSessionDidFinishEvents(forBackgroundURLSession:). Cần biết thêm: nếu người dùng tự vuốt tắt app thì hệ thống huỷ các task nền.
final class Downloader: NSObject, URLSessionDownloadDelegate {
  var onProgress: ((Double) -> Void)?
  private lazy var session = URLSession(configuration: .default, delegate: self, delegateQueue: nil)

  func start(_ url: URL) { session.downloadTask(with: url).resume() }

  func urlSession(_ session: URLSession, downloadTask: URLSessionDownloadTask,
                  didWriteData bytesWritten: Int64, totalBytesWritten: Int64,
                  totalBytesExpectedToWrite: Int64) {
    guard totalBytesExpectedToWrite > 0 else { return } // -1 khi không có Content-Length
    let progress = Double(totalBytesWritten) / Double(totalBytesExpectedToWrite)
    DispatchQueue.main.async { self.onProgress?(progress) }
  }

  func urlSession(_ session: URLSession, downloadTask: URLSessionDownloadTask,
                  didFinishDownloadingTo location: URL) {
    // location bị xoá ngay khi hàm return: phải di chuyển ở đây, đồng bộ
    let dest = URL.documentsDirectory.appending(path: "report.pdf")
    try? FileManager.default.removeItem(at: dest)
    try? FileManager.default.moveItem(at: location, to: dest)
  }
}

// Tải khi app bị suspend: đổi configuration, vẫn dùng delegate như trên
let config = URLSessionConfiguration.background(withIdentifier: "com.example.downloads")
