Người dùng vào vùng sóng yếu, màn hình quay spinner mãi vì fetch không bao giờ trả về; thoát màn hình giữa chừng thì request vẫn chạy và setState vẫn bị gọi. Bạn thêm timeout và huỷ request thế nào với fetch và Axios, và phân biệt lỗi do huỷ, do timeout với lỗi mạng ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
fetch không có tuỳ chọn timeout; nếu mạng treo, Promise có thể chờ rất lâu. Cách chuẩn là AbortController: tạo controller, truyền signal cho fetch, đặt setTimeout(() => controller.abort(), ms) (nhớ clearTimeout khi xong) và gọi controller.abort() trong cleanup của useEffect để huỷ khi rời màn hình. Axios có sẵn timeout (mili giây) và nhận signal tương tự; CancelToken là cách cũ đã bị loại bỏ dần. Phân biệt lỗi: fetch bị huỷ ném lỗi có name === 'AbortError' (do timeout hay do rời màn hình trông giống nhau, nên dùng một cờ timedOut để tách), Axios dùng axios.isCancel(error) cho huỷ chủ động và error.code === 'ECONNABORTED' cho timeout, còn mất mạng với fetch là TypeError: Network request failed. Xử lý khác nhau: huỷ chủ động thì im lặng, không hiện lỗi và không setState; timeout hiện "Mạng chậm" kèm nút thử lại; mất mạng hiện thông báo offline. Lưu ý timeout không có nghĩa server chưa xử lý: đừng tự retry mù quáng với thao tác ghi như tạo đơn, cần idempotency key.
async function fetchWithTimeout(url: string, ms: number, outer?: AbortSignal) {
  const controller = new AbortController();
  let timedOut = false;
  const timer = setTimeout(() => {
    timedOut = true;
    controller.abort();
  }, ms);
  outer?.addEventListener('abort', () => controller.abort());

  try {
    return await fetch(url, { signal: controller.signal });
  } catch (e) {
    if ((e as Error).name === 'AbortError') {
      throw new Error(timedOut ? 'TIMEOUT' : 'CANCELLED');
    }
    throw e; // lỗi mạng thật: TypeError 'Network request failed'
  } finally {
    clearTimeout(timer);
  }
}

useEffect(() => {
  const controller = new AbortController();

  fetchWithTimeout(url, 10_000, controller.signal)
    .then((res) => res.json())
    .then(setData)
    .catch((e) => {
      if (e.message !== 'CANCELLED') setError(e); // rời màn hình thì không báo lỗi
    });

  return () => controller.abort();
}, [url]);
