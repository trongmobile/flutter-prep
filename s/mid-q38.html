App cần chạy với ba môi trường (dev, staging, production) có API URL, application id và icon khác nhau, cài song song được trên một máy. Bạn cấu hình thế nào bằng flavor và --dart-define-from-file, và nên hay không nên đặt gì vào đó?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Có hai lớp. Lớp native (flavor): Android dùng productFlavors (applicationIdSuffix, tên app, icon, google-services.json riêng), iOS dùng scheme và build configuration kèm xcconfig; chạy bằng flutter run --flavor dev. Lớp Dart: truyền cấu hình lúc build bằng --dart-define-from-file=config/dev.json (hoặc nhiều --dart-define=KEY=value) và đọc bằng String.fromEnvironment('API_URL'); lưu ý các hàm fromEnvironment phải được gọi với const thì giá trị mới được thay lúc compile. Có thể dùng appFlavor (tên flavor đọc lúc chạy) để chọn cấu hình. Gói các giá trị vào một class AppConfig tạo một lần ở main() rồi inject, thay vì rải fromEnvironment khắp app. Nên để vào đây: URL, tên môi trường, cờ bật tắt log, id dịch vụ analytics theo môi trường. Không nên để secret thật (khoá thanh toán, khoá quản trị) vì giá trị --dart-define nằm trong binary nên trích xuất được, secret phải ở backend. Giữ file cấu hình theo môi trường trong repo (không có secret), còn giá trị riêng của CI đặt qua biến môi trường của pipeline. Đừng quên phần phụ trợ theo flavor: bundle id khác nhau thì cần Firebase app riêng, domain deep link riêng và push token riêng. Các công cụ như flutter_flavorizr giúp sinh cấu hình native, nhưng vẫn cần kiểm tra lại build release của từng flavor.
// config/dev.json: {"API_URL": "https://dev.api.shop.vn", "ENV": "dev", "ENABLE_LOGS": "true"}
// Chạy: flutter run --flavor dev --dart-define-from-file=config/dev.json

class AppConfig {
  const AppConfig({required this.apiUrl, required this.env, required this.enableLogs});

  // fromEnvironment phải được gọi với const thì giá trị mới được thay lúc compile
  factory AppConfig.fromEnvironment() => const AppConfig(
    apiUrl: String.fromEnvironment('API_URL', defaultValue: 'https://api.shop.vn'),
    env: String.fromEnvironment('ENV', defaultValue: 'production'),
    enableLogs: bool.fromEnvironment('ENABLE_LOGS'),
  );

  final String apiUrl;
  final String env;
  final bool enableLogs;
}

void main() {
  final config = AppConfig.fromEnvironment(); // tạo một lần rồi inject, không rải fromEnvironment khắp app
  runApp(App(config: config));
}
