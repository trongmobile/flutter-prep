Phát biểu nào đúng về các giá trị truyền qua --dart-define / --dart-define-from-file?

// flutter run --dart-define-from-file=config/prod.json
const apiUrl = String.fromEnvironment('API_URL');
const flavor = String.fromEnvironment('FLAVOR', defaultValue: 'dev');
  1. AĐược mã hoá khi build nên an toàn để chứa API secret
  2. BĐổi được lúc runtime bằng cách sửa file JSON trên máy user
  3. CĐược nhúng vào binary lúc build và có thể bị trích xuất
  4. DChỉ đọc được qua Platform.environment khi app chạy
Xem đáp án
Đáp án đúng: C
Giá trị được compile thành hằng số trong binary (vì thế nên đọc bằng const), ai decompile app cũng có thể thấy; chỉ dùng cho config như base URL, flavor, không dùng cho secret. Muốn đổi giá trị phải build lại, còn Platform.environment là biến môi trường của tiến trình, không liên quan.
