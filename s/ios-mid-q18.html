Bạn import vài nghìn record từ API vào Core Data và UI bị giật. Chuyển sang background context thế nào cho đúng, và làm sao để viewContext thấy dữ liệu mới?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Dùng newBackgroundContext() hoặc performBackgroundTask và làm mọi thao tác bên trong perform, vì mỗi NSManagedObjectContext gắn với queue riêng và không thread-safe; viewContext chỉ dùng trên main thread cho UI. Đặt viewContext.automaticallyMergesChangesFromParent = true để sau khi background context save(), thay đổi được merge sang context của UI. Với lượng rất lớn, NSBatchInsertRequest nhanh hơn nhiều vì ghi thẳng xuống store, nhưng nó bỏ qua context nên phải tự merge (qua persistent history tracking hoặc mergeChanges(fromRemoteContextSave:into:)). Không truyền NSManagedObject giữa các context, hãy truyền objectID. Đặt mergePolicy phù hợp để tránh lỗi conflict khi hai context cùng sửa một record.
container.viewContext.automaticallyMergesChangesFromParent = true

func importProducts(_ dtos: [ProductDTO]) async throws {
  let context = container.newBackgroundContext()
  context.mergePolicy = NSMergePolicy.mergeByPropertyObjectTrump
  try await context.perform {
    for dto in dtos {
      let product = Product(context: context)
      product.id = dto.id
      product.name = dto.name
    }
    try context.save() // viewContext tự merge thay đổi
  }
}
