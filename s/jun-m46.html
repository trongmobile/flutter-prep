Test sau fail ngay ở pumpWidget với lỗi No Directionality widget found. Cách sửa đúng là gì?

class ProfilePage extends StatelessWidget {
  const ProfilePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Text('Xin chào', style: Theme.of(context).textTheme.titleLarge),
    );
  }
}

testWidgets('hiển thị lời chào', (tester) async {
  await tester.pumpWidget(const ProfilePage());
  expect(find.text('Xin chào'), findsOneWidget);
});
  1. AThêm await tester.pumpAndSettle() ngay sau pumpWidget
  2. BBọc ProfilePage trong Theme(data: ThemeData(), child: ...)
  3. CĐặt ProfilePage làm home của một MaterialApp khi pump
  4. DDùng find.textContaining('Xin chào') thay cho find.text
Xem đáp án
Đáp án đúng: C
pumpWidget chỉ dựng đúng widget bạn đưa vào, không có MaterialApp bao ngoài nên thiếu Directionality, Navigator, theme, localizations... mà Scaffold và Text cần. MaterialApp(home: ProfilePage()) cung cấp đủ chúng. Theme không tạo ra Directionality, còn pumpAndSettle hay đổi finder đều không sửa được lỗi xảy ra ở bước build.
