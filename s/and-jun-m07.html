Với user = User(name = "An", avatarUrl = null), đoạn ?.let { } ?: sau in ra những gì?

user?.let {
    println("Xin chào ${it.name}")
    it.avatarUrl
} ?: println("Chưa đăng nhập")
  1. AChỉ in Xin chào An
  2. BIn Xin chào An rồi in Chưa đăng nhập
  3. CChỉ in Chưa đăng nhập
  4. DLỗi compile vì hai vế của ?: khác kiểu
Xem đáp án
Đáp án đúng: B
let trả về giá trị dòng cuối của lambda, ở đây là avatarUrl bằng null, nên vế phải của ?: vẫn chạy dù user khác null. Khi muốn rẽ nhánh theo user thì viết if (user != null) ... else ... cho rõ ràng.
