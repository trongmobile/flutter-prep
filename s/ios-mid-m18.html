Khai báo func total(_ prices: some Collection<Int>) -> Int tương đương với cách viết nào?

  1. Afunc total<C: Collection>(_ prices: C) -> Int where C.Element == Int
  2. Bfunc total(_ prices: any Collection<Int>) -> Int
  3. Cfunc total(_ prices: [Int]) -> Int
  4. Dfunc total<C: Collection>(_ prices: C) -> Int where C.Element: Numeric
Xem đáp án
Đáp án đúng: A
some ở vị trí tham số là cách viết gọn của generic, còn Collection<Int> ràng buộc primary associated type Element bằng Int. any Collection<Int> nhận được cùng giá trị nhưng là existential (box, dynamic dispatch), không phải generic được specialize.
