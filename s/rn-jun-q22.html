README cũ của một thư viện native (ví dụ react-native-keychain) vẫn hướng dẫn chạy react-native link và sửa tay MainApplication, Podfile. Với React Native hiện tại, autolinking làm thay bạn những gì, và bạn vẫn phải tự làm bước nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Autolinking (có từ 0.60) tự tìm các dependency có code native khai báo trong package.json: trên Android, Gradle sinh danh sách package và tự đăng ký, trên iOS Podfile của template gọi use_native_modules! để thêm pod; vì vậy không cần react-native link (lệnh này đã bị bỏ) hay sửa tay MainApplication. Bạn vẫn phải build lại binary vì reload hay Fast Refresh chỉ nạp lại JS bundle: iOS chạy pod install trong thư mục ios rồi build, Android build lại. Các bước cấu hình riêng của thư viện như khai báo quyền, key trong Info.plist vẫn phải làm theo README; muốn loại một thư viện khỏi autolinking trên một nền tảng thì cấu hình trong react-native.config.js. Với Expo, thư viện native không có sẵn trong Expo Go thì cần development build.
