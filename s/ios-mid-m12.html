Với var a = [1, 2, 3], tiếp theo var b = a rồi b.append(4): buffer phần tử của Array thực sự bị copy khi nào?

  1. ANgay ở var b = a, vì Array là value type nên phải copy
  2. BỞ b.append(4), khi ghi lúc buffer đang dùng chung
  3. CKhông bao giờ, a và b dùng chung buffer mãi
  4. DKhi b được đọc lần đầu sau phép gán
Xem đáp án
Đáp án đúng: B
Gán Array chỉ tăng reference count của buffer chung; khi b.append thấy buffer không được tham chiếu duy nhất thì mới copy rồi ghi. Value semantics vẫn được đảm bảo: a vẫn là [1, 2, 3].
