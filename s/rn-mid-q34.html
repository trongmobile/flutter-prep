App dùng React Navigation với TypeScript nhưng navigation.navigate('OrderDetail', { id }) hay bị sai tên màn hoặc thiếu params mà chỉ lỗi lúc chạy; điều hướng từ tab sang màn nằm sâu trong một stack khác thì báo The action 'NAVIGATE' ... was not handled. Bạn định kiểu navigation và xử lý navigator lồng nhau thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Định nghĩa một ParamList cho mỗi navigator (map tên route sang kiểu params, undefined nếu không có), truyền nó làm generic cho createNativeStackNavigator<RootStackParamList>() và dùng NativeStackScreenProps<RootStackParamList, 'OrderDetail'> cho props của màn; khi đó route.params.id có kiểu và navigate('OrderDetail', { id }) bị TypeScript báo nếu sai tên hay thiếu params. Muốn useNavigation() có kiểu mà không phải gán generic mỗi lần thì khai báo toàn cục ReactNavigation.RootParamList mở rộng từ RootStackParamList. Với navigator lồng nhau (stack bọc tab bọc stack), params của màn con không nằm trong RootStackParamList mà trong list của navigator con; dùng NavigatorScreenParams<TabParamList> để mô tả màn cha nhận params cho navigator con, và CompositeScreenProps hoặc CompositeNavigationProp để màn con gọi được cả hành động của navigator cha. Điều hướng sâu bằng navigate('Main', { screen: 'Orders', params: { screen: 'OrderDetail', params: { id } } }); lỗi 'was not handled' xảy ra khi navigator chứa màn đích chưa được mount (tab chưa render, hoặc màn nằm trong nhóm có điều kiện như chưa đăng nhập), nên phải đảm bảo navigator đó đã tồn tại hoặc điều hướng theo đúng cấp. Params phải serializable và nhỏ (id, không phải object lớn hay hàm) để deep link, state restoration và nút back hoạt động; dữ liệu chi tiết tải lại theo id. Lưu ý navigate không nhân đôi màn đang ở trên cùng stack, còn push luôn thêm một màn mới. Với Expo Router, kiểu của route được sinh tự động (typedRoutes) nên phần lớn bước định kiểu thủ công này không còn cần thiết.
type OrdersStackParamList = {
  OrderList: undefined;
  OrderDetail: { id: string }; // params phải serializable: truyền id, không truyền object lớn
};

type TabParamList = {
  Home: undefined;
  Orders: NavigatorScreenParams<OrdersStackParamList>; // tab Orders chứa một stack con
};

type RootStackParamList = {
  Login: undefined;
  Main: NavigatorScreenParams<TabParamList>;
};

// Khai báo toàn cục: useNavigation() có kiểu mà không cần gán generic mỗi lần
declare global {
  namespace ReactNavigation {
    interface RootParamList extends RootStackParamList {}
  }
}

// Màn nằm sâu: kiểu bao gồm cả navigator cha
type Props = CompositeScreenProps<
  NativeStackScreenProps<OrdersStackParamList, 'OrderDetail'>,
  BottomTabScreenProps<TabParamList>
>;

// Điều hướng từ nơi bất kỳ tới màn sâu
navigation.navigate('Main', { screen: 'Orders', params: { screen: 'OrderDetail', params: { id } } });
