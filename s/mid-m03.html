Bạn viết một package và muốn class Logger được phép extends ở package khác nhưng cấm implements (để sau này thêm method không làm vỡ code người dùng). Dùng modifier nào?

  1. Ainterface class Logger
  2. Bbase class Logger
  3. Cfinal class Logger
  4. Dsealed class Logger
Xem đáp án
Đáp án đúng: B
base cho phép kế thừa ngoài library nhưng cấm implements, đảm bảo mọi subtype đều thừa hưởng implementation gốc. interface thì ngược lại (cho implements, cấm extends), còn final và sealed cấm cả hai ngoài library.
