Màn danh sách có hàng chục nghìn sản phẩm tải theo trang, cần xem được khi offline và không mất vị trí cuộn khi xoay máy. Bạn dùng Paging 3 thế nào (PagingSource, cachedIn, LoadState, RemoteMediator)?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Paging 3 tải dữ liệu theo trang khi user cuộn gần cuối danh sách. PagingSource.load(params) trả LoadResult.Page(data, prevKey, nextKey) hoặc LoadResult.Error, còn getRefreshKey cho Paging biết key nào để làm mới quanh vị trí đang xem. Pager(config, pagingSourceFactory) tạo Flow<PagingData<T>>; gọi cachedIn(viewModelScope) để giữ dữ liệu đã tải qua xoay màn hình và cho phép nhiều collector dùng chung, và các phép map/filter trên PagingData phải đặt trước cachedIn. UI dùng collectAsLazyPagingItems() trong Compose hoặc PagingDataAdapter với View; loadState cho các trạng thái refresh, append, prepend để hiện skeleton, spinner cuối danh sách và nút thử lại (retry()). Với offline, đặt Room làm nguồn dữ liệu duy nhất: Room tự sinh PagingSource từ query, kèm RemoteMediator gọi mạng khi dữ liệu cục bộ hết rồi ghi vào DB (cùng bảng lưu trang kế tiếp), nên UI chỉ đọc từ DB và luôn nhất quán. Bẫy: PagingSource không dùng lại được sau khi bị invalidate() nên factory phải trả instance mới; và muốn sửa một item phải ghi vào DB để nó tự invalidate, không sửa trong adapter.
class ProductViewModel(repo: ProductRepository) : ViewModel() {
  val products: Flow<PagingData<ProductUi>> = Pager(
    config = PagingConfig(pageSize = 20, prefetchDistance = 10),
    remoteMediator = ProductRemoteMediator(repo.api, repo.db), // gọi mạng và ghi vào Room
    pagingSourceFactory = { repo.db.productDao().pagingSource() }, // Room sinh PagingSource
  ).flow
    .map { page -> page.map { it.toUi() } } // map trước cachedIn
    .cachedIn(viewModelScope) // giữ dữ liệu qua xoay màn hình
}

@Composable
fun ProductList(vm: ProductViewModel) {
  val items = vm.products.collectAsLazyPagingItems()
  LazyColumn {
    items(items.itemCount, key = items.itemKey { it.id }) { index ->
      items[index]?.let { ProductRow(it) }
    }
    if (items.loadState.append is LoadState.Loading) {
      item { CircularProgressIndicator() }
    }
  }
}
