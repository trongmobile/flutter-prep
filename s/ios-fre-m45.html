Đoạn code dùng delegate sau bị lỗi compile ở dòng weak var delegate. Cách sửa đúng là gì?

protocol DetailDelegate {
    func detailDidSave()
}

class DetailViewController: UIViewController {
    weak var delegate: DetailDelegate?
}
  1. AKhai báo protocol DetailDelegate: AnyObject để protocol chỉ dành cho class
  2. BĐổi weak thành unowned, vì unowned dùng được với cả những protocol thường
  3. CBỏ dấu ? sau DetailDelegate vì biến weak bắt buộc phải là kiểu non-optional
  4. DThêm @objc trước weak var delegate để Swift chấp nhận tham chiếu yếu tới protocol
Xem đáp án
Đáp án đúng: A
weak chỉ áp dụng được cho reference type; protocol thường có thể được struct hay enum conform nên compiler báo lỗi 'weak' must not be applied to non-class-bound. Thêm ràng buộc : AnyObject là cách sửa chuẩn, còn unowned cũng đòi protocol class-bound và biến weak luôn phải là Optional.
