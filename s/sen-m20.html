Repository phát dữ liệu cache rồi gọi API và phát tiếp kết quả mới, qua hai nguồn riêng tới UI. Bug: thỉnh thoảng dữ liệu cũ hiển thị đè lên dữ liệu mới. Thiết kế nào loại bỏ triệt để lớp lỗi này mà vẫn hiển thị cache ngay lập tức?

  1. AThêm debounce khoảng 300ms trước khi cập nhật UI để kết quả về sau cùng thắng
  2. BUI chỉ observe một stream từ DB local; kết quả network chỉ được ghi vào DB
  3. CGọi cache và API cùng lúc bằng Future.wait rồi hiển thị bản có timestamp mới hơn
  4. DBỏ hẳn cache và hiển thị loading cho tới khi API trả về để tránh race condition
Xem đáp án
Đáp án đúng: B
Khi hai nguồn cùng đẩy dữ liệu lên UI, thứ tự hoàn thành không xác định nên race là tất yếu. Single source of truth — UI chỉ đọc DB, mọi ghi đi qua DB — loại bỏ race và vẫn hiển thị cache ngay; debounce chỉ giảm xác suất, còn Future.wait buộc chờ cả network nên mất lợi ích của cache.
