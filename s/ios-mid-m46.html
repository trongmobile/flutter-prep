Test dưới đây fail dù StubAPI trả về ["Swift"] ngay lập tức. Nguyên nhân và cách sửa phù hợp nhất là gì?

@MainActor
final class SearchViewModel {
  private(set) var results: [String] = []
  let api: SearchAPI
  init(api: SearchAPI) { self.api = api }

  func search(_ query: String) {
    Task { results = (try? await api.search(query)) ?? [] }
  }
}

@MainActor
final class SearchTests: XCTestCase {
  func testSearch() async {
    let vm = SearchViewModel(api: StubAPI())
    vm.search("swift")
    XCTAssertEqual(vm.results, ["Swift"])
  }
}
  1. Aresults là private(set) nên test không đọc được giá trị mới gán
  2. BThêm try await Task.sleep(for: .milliseconds(500)) trước XCTAssertEqual
  3. CTask chưa chạy khi assert thực thi; đổi search thành async và await nó
  4. DTask bị cancel khi hàm test return; dùng Task.detached để task sống lâu hơn
Xem đáp án
Đáp án đúng: C
Task { } kế thừa main actor, mà test đang chiếm main actor và chưa có await nào nên task chưa kịp chạy lúc XCTAssertEqual thực thi: results vẫn là []. Cách ổn định là để search là async (hoặc trả về Task để await task.value) rồi await ngay trong test; sleep làm test chậm và flaky, còn private(set) vẫn cho đọc từ bên ngoài.
