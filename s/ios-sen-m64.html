Bạn xoá hàng loạt bản ghi bằng NSBatchDeleteRequest chạy trên background context như dưới. NSFetchedResultsController của viewContext vẫn hiển thị các dòng đã xoá. Cách sửa đúng là gì?

let request = NSBatchDeleteRequest(fetchRequest: Order.fetchRequest())
request.resultType = .resultTypeObjectIDs
let result = try backgroundContext.execute(request) as? NSBatchDeleteResult
// viewContext (automaticallyMergesChangesFromParent = true) vẫn còn các dòng đã xoá
  1. AGọi backgroundContext.save() ngay sau execute để thay đổi đã xoá được tự động đẩy sang viewContext
  2. BMerge objectIDs đã xoá vào viewContext bằng NSManagedObjectContext.mergeChanges(fromRemoteContextSave:into:)
  3. CĐặt viewContext.stalenessInterval = 0 để context luôn đọc lại dữ liệu mới nhất từ persistent store
  4. DThay bằng context.delete(_:) cho từng object, vì batch delete không dùng được với SQLite store thông thường
Xem đáp án
Đáp án đúng: B
Batch request chạy thẳng trên persistent store (SQLite), bỏ qua mọi context nên các object đã nạp vào viewContext vẫn còn nguyên và isDeleted vẫn là false (đã chạy thử: fetch lại trả về 0 nhưng registeredObjects còn đủ). automaticallyMergesChangesFromParent cũng không tự nhận thay đổi này (đã chạy thử với đúng cấu hình đó). Đặt resultType = .resultTypeObjectIDs rồi merge các ID đã xoá vào context để chúng bị đánh dấu xoá và NSFetchedResultsController cập nhật; save() không có gì để lưu, còn stalenessInterval chỉ liên quan tới việc làm mới dữ liệu của object.
