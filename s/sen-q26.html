App Flutter cần đăng nhập qua SSO của công ty (OIDC/OAuth2). Vì sao dùng Authorization Code kèm PKCE với trình duyệt hệ thống thay vì WebView hay lưu client secret trong app, và bạn xử lý redirect, lưu token, refresh, đăng xuất ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
App di động là public client: mọi thứ trong binary đều có thể bị trích xuất nên không thể giữ client_secret. Authorization Code kèm PKCE thay secret bằng một cặp giá trị động: app sinh code_verifier ngẫu nhiên, gửi code_challenge (băm SHA-256 của verifier, phương thức S256) trong yêu cầu đăng nhập, rồi gửi verifier khi đổi code lấy token; kẻ chặn được authorization code (qua custom scheme bị app khác đăng ký trùng) cũng không đổi được token vì không có verifier. Phải mở trang đăng nhập bằng trình duyệt hệ thống (Custom Tabs trên Android, ASWebAuthenticationSession trên iOS) chứ không phải WebView nhúng: app không thấy mật khẩu của người dùng, dùng được phiên SSO sẵn có của trình duyệt, và đó cũng là khuyến nghị của chuẩn (RFC 8252). Package flutter_appauth bọc các SDK AppAuth native và lo PKCE, state, nonce; dùng discovery document (.well-known/openid-configuration) để cấu hình. Redirect URI: App Links hay Universal Links (https đã xác minh) tốt hơn custom scheme vì custom scheme có thể bị app khác chiếm; luôn kiểm tra state để chống CSRF. Token: access token ngắn hạn giữ trong bộ nhớ, refresh token lưu Keychain/Keystore (flutter_secure_storage), bật refresh token rotation phía server và xử lý nhiều request cùng gặp 401 bằng một lần refresh dùng chung. Đăng xuất: xoá token cục bộ, gọi endpoint thu hồi token (revocation) và, nếu cần, end session của IdP để phiên SSO cũng kết thúc. ID token do server xác minh chữ ký cùng aud, iss, exp, đừng tin dữ liệu người dùng chỉ vì app giải mã được. Không dùng implicit flow hay password grant vì chúng đã bị khuyến cáo bỏ.
final appAuth = FlutterAppAuth();

Future<void> signIn() async {
  final result = await appAuth.authorizeAndExchangeCode(
    AuthorizationTokenRequest(
      'mobile-app-client-id', // public client: không có client secret
      'vn.shop.app:/oauth2redirect', // nên dùng App Links https đã xác minh nếu IdP hỗ trợ
      discoveryUrl: 'https://sso.example.vn/.well-known/openid-configuration',
      scopes: ['openid', 'profile', 'offline_access'],
      // PKCE (S256), state và nonce do AppAuth tự sinh và kiểm tra
    ),
  );

  final refresh = result.refreshToken;
  if (refresh != null) {
    await secureStorage.write(key: 'refresh_token', value: refresh); // Keychain hoặc Keystore
  }
  tokenStore.setAccessToken(result.accessToken); // access token ngắn hạn: chỉ giữ trong bộ nhớ
}
