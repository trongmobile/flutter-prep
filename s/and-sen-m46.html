Màn hình mở lên bắn 8 request song song, access token vừa hết hạn nên cả 8 nhận 401. Server dùng refresh token rotation (mỗi refresh token chỉ dùng được một lần). Authenticator của OkHttp đang gọi API refresh riêng cho từng request, kết quả 7 lần lỗi và user bị đăng xuất. Cách sửa đúng là gì?

  1. AKéo dài hạn access token lên vài ngày để các request song song hiếm khi cùng gặp 401
  2. BChủ động refresh token ở Interceptor trước mỗi request để token luôn còn mới
  3. CSerialize refresh bằng khoá; request đến sau thấy token đã đổi thì chỉ retry
  4. DRetry API refresh tối đa ba lần với backoff để một trong các lần chắc chắn thành công
Xem đáp án
Đáp án đúng: C
Các request song song cùng thấy 401 và cùng refresh bằng một refresh token đã bị rotate, nên chỉ lần đầu thành công. Cần cơ chế single-flight: trong Authenticator lấy khoá (synchronized hoặc Mutex), rồi so token trong header của request lỗi với token đang lưu; đã khác thì dùng token mới để retry, chỉ khi còn giống mới gọi refresh. Kéo dài hạn token chỉ làm race hiếm đi, còn retry refresh vô ích vì refresh token cũ đã bị vô hiệu.
