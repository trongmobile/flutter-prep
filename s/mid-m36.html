Sau khi thêm interceptor dưới đây, mọi request đều treo, không bao giờ trả về. Vì sao?

dio.interceptors.add(InterceptorsWrapper(
  onRequest: (options, handler) async {
    final token = await storage.read(key: 'token');
    options.headers['Authorization'] = 'Bearer $token';
  },
));
  1. AThiếu handler.next(options) để chuyển request đi tiếp
  2. BKhông được dùng async trong onRequest
  3. CHeader phải set qua dio.options, không phải options
  4. DPhải chuyển sang QueuedInterceptor khi đọc storage
Xem đáp án
Đáp án đúng: A
Interceptor của Dio chỉ đi tiếp khi bạn gọi handler.next, handler.resolve hoặc handler.reject; quên gọi thì request chờ mãi. Dùng async trong callback là hợp lệ, miễn là cuối cùng có gọi handler.
