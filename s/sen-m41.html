Đoạn code sau in ra theo thứ tự nào?

String _init(String name) {
  print('init $name');
  return name;
}

final a = _init('a');
final b = _init('b');

void main() {
  print('main');
  print(b);
  print(a);
}
  1. Ainit a, init b, main, b, a
  2. Bmain, init a, init b, b, a
  3. Cmain, init b, b, init a, a
  4. DLỗi compile vì initializer của biến top-level phải là hằng số
Xem đáp án
Đáp án đúng: C
Biến top-level và biến static được khởi tạo lười: initializer của từng biến chỉ chạy ở lần truy cập đầu tiên, không chạy trước main và cũng không chạy cả loạt. Hệ quả thực tế: một singleton top-level có side effect (đăng ký listener, khởi tạo SDK) sẽ không bao giờ chạy nếu không có code nào tham chiếu tới nó.
