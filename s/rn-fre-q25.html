Metro là gì? Fast Refresh hoạt động thế nào và khi nào bạn buộc phải build lại app?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Metro là bundler của React Native: dùng Babel biên dịch JSX/TypeScript, gộp các module và asset thành bundle, khi phát triển thì chạy dev server (mặc định cổng 8081) để app tải bundle về. Babel chỉ bỏ phần type chứ không kiểm tra type, nên muốn bắt lỗi TypeScript phải chạy tsc hoặc dựa vào editor. Với Fast Refresh, khi bạn lưu file chỉ export component thì chỉ component đó được cập nhật và state của useState được giữ; nếu file export cả thứ khác, module đó cùng các module import nó được chạy lại nên state có thể mất. Mọi thay đổi native như cài thư viện có native code, sửa AndroidManifest.xml, Info.plist hay Podfile đều phải build lại app; reload JS hay xoá cache Metro không giải quyết được.
