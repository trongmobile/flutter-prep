Build sạch của app mất 12 phút, build tăng dần vẫn vài chục giây và dev than Xcode đứng ở bước "Compiling Swift source files". Với codebase Swift lớn, bạn đo, khoanh vùng và giảm thời gian build thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đo trước khi sửa. xcodebuild -showBuildTimingSummary hoặc Product > Perform Action > Build With Timing Summary cho biết thời gian theo từng task, còn Build Timeline (Xcode 14 trở lên, mở từ build log trong Report navigator) cho thấy chỗ nghẽn tuần tự, ví dụ một module lớn chặn cả đường phụ thuộc. Nếu phần lớn thời gian nằm ở compile Swift, bật cảnh báo type-checker chậm trong Other Swift Flags: -Xfrontend -warn-long-function-bodies=300 và -Xfrontend -warn-long-expression-type-checking=200 (đơn vị ms) để Xcode chỉ đích danh hàm và biểu thức quá ngưỡng. Thủ phạm quen thuộc là biểu thức dài trộn toán tử với literal không có kiểu, closure nhiều dòng không khai kiểu trả về, dictionary hay array literal lớn không ghi kiểu; cách sửa là tách biểu thức và ghi kiểu rõ ràng. Về cấu hình: Debug dùng -Onone cùng incremental compilation và ONLY_ACTIVE_ARCH = YES, còn whole-module để dành cho Release; mọi Run Script phase phải khai input/output để không chạy lại ở mỗi lần build; tránh bridging header khổng lồ vì sửa nó kéo biên dịch lại gần hết. Về cấu trúc: tách module giúp build song song và chỉ biên dịch lại phần bị ảnh hưởng, nhưng chia quá vụn lại tốn thời gian link và quét module; giữ bề mặt public nhỏ để đổi code bên trong không kéo cả cây phụ thuộc build lại. Xcode mới còn có explicit modules và compilation caching, nên thử bật rồi đo, vì lợi ích phụ thuộc phiên bản Xcode và hình dạng dự án. Mỗi thay đổi đều cần số đo trước và sau, và nên ghi lại thời gian build trên CI theo từng commit để regression bị bắt sớm.
// Other Swift Flags (Debug):
//   -Xfrontend -warn-long-function-bodies=300
//   -Xfrontend -warn-long-expression-type-checking=200

// Chậm: toán tử + trộn Int/Double với literal, compiler thử rất nhiều tổ hợp overload
let slowTotal = price * 1.1 + Double(shipping) + (coupon?.value ?? 0) - Double(points) / 100

// Nhanh hơn: tách bước và ghi kiểu rõ ràng
let withTax: Double = price * 1.1
let discount: Double = (coupon?.value ?? 0) + Double(points) / 100
let total: Double = withTax + Double(shipping) - discount
