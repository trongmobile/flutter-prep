Trong SwiftUI, $name khác name thế nào? Vì sao TextField cần $name còn Text thì chỉ cần name?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Với @State var name, viết name là đọc giá trị String hiện tại, còn $name là projected value của property wrapper: một Binding<String>, tức một "tay cầm" vừa đọc vừa ghi vào chính nơi lưu của state. Text(name) chỉ hiển thị nên nhận giá trị thường. TextField("Tên", text: $name) phải ghi ngược lại mỗi khi người dùng gõ nên tham số text có kiểu Binding<String>; Toggle(isOn: $isOn), Slider(value: $volume), Picker(selection: $choice) cũng vậy. Luồng hai chiều: state đổi thì view vẽ lại, người dùng gõ thì binding ghi vào state rồi view vẽ lại. Form là container gom các điều khiển thành biểu mẫu theo kiểu của hệ thống, chia nhóm bằng Section. Binding cũng là cách cho view con sửa state của view cha mà không sở hữu dữ liệu (@Binding var); với model dùng macro @Observable thì dùng @Bindable để lấy $model.name. Bẫy: viết TextField("Tên", text: name) sẽ báo lỗi không chuyển được String sang Binding<String>; và @State nên khai báo private vì nó thuộc riêng view đó.
struct ProfileForm: View {
    @State private var name = ""
    @State private var notificationsOn = true

    var body: some View {
        Form {
            Section("Thông tin") {
                TextField("Tên hiển thị", text: $name)       // $name: Binding<String>, gõ là ghi ngược vào name
                Toggle("Nhận thông báo", isOn: $notificationsOn)
            }
            Section {
                Text("Xin chào \(name)")                      // name: String, chỉ đọc
                    .foregroundStyle(notificationsOn ? .primary : .secondary)
            }
        }
    }
}
