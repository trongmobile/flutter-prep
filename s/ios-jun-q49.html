Security review của app ví điện tử chỉ ra: token bị print ra console (và vẫn nằm trong log ở bản release), số dư hiện nguyên trong ảnh chụp của App Switcher, và ô nhập mật khẩu cho phép copy-paste sang app khác. Bạn xử lý thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Log: print và NSLog không có mức độ lẫn quyền riêng tư, bản release vẫn ghi ra console nên cắm máy vào Mac là đọc được. Dùng os.Logger (Logger(subsystem:category:)): chuỗi động trong message mặc định bị che thành <private> khi không gắn debugger, còn số và bool mặc định là public; nên ghi rõ privacy: .private, hoặc .private(mask: .hash) để đối chiếu cùng một giá trị qua các dòng log mà không lộ nội dung. Tốt nhất là không log token, mật khẩu, số thẻ dù đã che, và để log chi tiết trong #if DEBUG. App Switcher: iOS chụp snapshot khi app vào background nên phải che nội dung nhạy cảm trước đó, bằng cách thêm một view mờ hoặc logo lên window trong sceneWillResignActive (SwiftUI: scenePhase == .inactive) và gỡ ra trong sceneDidBecomeActive. Ô mật khẩu/OTP: isSecureTextEntry = true (SwiftUI: SecureField) ẩn ký tự và không cho copy ra ngoài; thêm textContentType đúng (.password, .oneTimeCode) để dùng autofill hợp lệ. iOS không cho chặn chụp ảnh màn hình, chỉ phát hiện được qua userDidTakeScreenshotNotification và UIScreen.isCaptured (đang ghi hình), nên đừng hiển thị dữ liệu quá nhạy cảm nếu không cần.
import os

let log = Logger(subsystem: "com.example.wallet", category: "auth")

func didLogin(userId: Int, token: String) {
  // print("token = \(token)")  // SAI: lộ token ở cả bản release
  log.info("login ok user=\(userId) token=\(token, privacy: .private(mask: .hash))")
}

// UIKit: che nội dung khi app vào App Switcher
final class SceneDelegate: UIResponder, UIWindowSceneDelegate {
  var window: UIWindow?
  private var cover: UIView?

  func sceneWillResignActive(_ scene: UIScene) {
    guard let window else { return }
    let blur = UIVisualEffectView(effect: UIBlurEffect(style: .systemThickMaterial))
    blur.frame = window.bounds
    window.addSubview(blur)
    cover = blur
  }

  func sceneDidBecomeActive(_ scene: UIScene) {
    cover?.removeFromSuperview()
    cover = nil
  }
}
