Banner mờ dần rồi bị gỡ khỏi màn hình bằng đoạn code dưới đây. Nếu 100ms sau khi bấm, một animation khác (toValue: 1) bắt đầu chạy trên cùng fade, điều gì xảy ra với callback của animation đầu?

const hide = () => {
  Animated.timing(fade, {
    toValue: 0,
    duration: 300,
    useNativeDriver: true,
  }).start(({ finished }) => {
    if (finished) setVisible(false);
  });
};
  1. ACallback chạy với finished: false nên setVisible(false) bị bỏ qua
  2. BCallback không bao giờ được gọi, vì animation đầu đã bị huỷ giữa chừng
  3. CCallback chạy với finished: true ngay vào lúc animation bị ngắt
  4. DCallback chờ animation mới xong rồi chạy với finished: true sau đó
Xem đáp án
Đáp án đúng: A
Một Animated.Value chỉ chịu sự điều khiển của một animation tại một thời điểm: bắt đầu animation mới trên cùng giá trị sẽ dừng animation đang chạy, và callback của animation bị dừng vẫn được gọi, nhưng với { finished: false }. Kiểm tra finished giúp tránh chạy bước kế tiếp (như setVisible(false)) khi animation chưa hoàn tất. Callback không bị bỏ rơi, không được báo là hoàn tất và cũng không chờ animation sau.
