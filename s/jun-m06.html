Class dùng nhiều mixin có method trùng tên: đoạn code sau in ra gì?

mixin Logger {
  String tag() => 'Logger';
}
mixin Tracker {
  String tag() => 'Tracker';
}
class Base {
  String tag() => 'Base';
}
class Screen extends Base with Logger, Tracker {}

void main() => print(Screen().tag());
  1. ATracker
  2. BLogger
  3. CBase
  4. DLỗi compile vì hai mixin trùng tên method
Xem đáp án
Đáp án đúng: A
Mixin được áp dụng lần lượt từ trái sang phải chồng lên superclass, nên mixin đứng sau cùng (Tracker) override các tầng trước nó. Trùng tên method giữa các mixin không gây lỗi compile, chỉ tầng gần nhất được dùng.
