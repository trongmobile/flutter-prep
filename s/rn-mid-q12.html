Màn Home có ô tìm kiếm ở đầu và một feed nặng bên dưới; mỗi lần gõ phím cả feed render lại. Trước khi rải React.memo khắp nơi, bạn có thể tái cấu trúc component thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Nguyên nhân là state text của ô tìm kiếm nằm ở component Home, nên mỗi lần gõ Home render lại và kéo theo toàn bộ cây con, trong đó có feed. Cách đầu tiên là đưa state xuống gần nơi dùng (state colocation): tách SearchBar tự giữ text, chỉ báo lên cha khi thật sự cần (ví dụ lúc submit hoặc sau debounce), khi đó gõ phím chỉ render lại SearchBar. Cách thứ hai khi component giữ state phải bao quanh nội dung nặng: truyền phần nặng qua children hoặc prop; element đó do cha tạo ra nên giữ nguyên reference khi component bọc ngoài render lại, và React bỏ qua nó. Hai cách này giảm re-render mà không phải thêm memo/useCallback và lo deps; chỉ khi state buộc phải dùng chung mới cân nhắc memo hoá hoặc store có selector, và luôn kiểm chứng bằng Profiler.
// State `text` nằm trong SearchBar: gõ phím không làm Home và HeavyFeed render lại
function SearchBar({ onSubmit }: { onSubmit: (q: string) => void }) {
  const [text, setText] = useState('');
  return <TextInput value={text} onChangeText={setText} onSubmitEditing={() => onSubmit(text)} />;
}

function Home() {
  const [query, setQuery] = useState('');
  return (
    <>
      <SearchBar onSubmit={setQuery} />
      <HeavyFeed query={query} />
    </>
  );
}
