Chạy Jest cho component dùng thư viện có native module (AsyncStorage, camera…) bị lỗi native module là null. Vì sao, và nên mock thế nào cho hợp lý?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Jest chạy component trong Node với preset react-native, không có runtime native nào phía sau, nên mọi NativeModules.X hay Turbo Module đều không tồn tại. Nhiều thư viện cung cấp sẵn mock (ví dụ @react-native-async-storage/async-storage/jest/async-storage-mock), chỉ cần jest.mock trong file setupFiles. Với module tự viết thì mock chính file spec/wrapper JS để trả giá trị cố định, dùng jest.fn() để kiểm tra lời gọi. Nên bọc native module sau một hook hoặc service của mình để test logic với mock, còn hành vi native thật thì để E2E (Detox, Maestro) kiểm tra.
// jest.setup.ts
jest.mock('@react-native-async-storage/async-storage', () =>
  require('@react-native-async-storage/async-storage/jest/async-storage-mock'),
);

// Mock Turbo Module tự viết
jest.mock('./specs/NativeBattery', () => ({
  __esModule: true,
  default: {
    getBatteryLevel: jest.fn().mockResolvedValue(0.8),
    isCharging: jest.fn(() => false),
  },
}));
