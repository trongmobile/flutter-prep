Bottom sheet kéo thả của bạn bị giật khi JS thread bận (ví dụ lúc list phía sau đang render), dù đã dùng Animated của core. Bạn dựng lại bằng Reanimated và Gesture Handler thế nào để animation chạy mượt, và những bẫy khi chuyển logic sang UI thread là gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Với Animated của core, animation chỉ mượt khi dùng useNativeDriver: true và chỉ cho một số thuộc tính (transform, opacity); còn gesture thì phải đi qua JS để cập nhật giá trị, nên JS bận là kéo bị trễ. Reanimated cho viết worklet: hàm JS được biên dịch để chạy thẳng trên UI thread; useSharedValue là giá trị chia sẻ giữa hai thread, còn useAnimatedStyle ánh xạ giá trị đó thành style và cập nhật view mà không cần render lại React. Gesture Handler (API Gesture.Pan()) chạy các callback onStart/onChange/onEnd cũng dưới dạng worklet, nên cả chuỗi 'chạm → tính toán → cập nhật vị trí' nằm trên UI thread và không bị ảnh hưởng khi JS thread bận. Khi thả tay dùng withSpring hay withDecay để chuyển động nối tiếp theo vận tốc. Muốn gọi lại phần JS (đóng sheet, setState, analytics) thì dùng runOnJS (ở Reanimated 4 mới dần chuyển sang scheduleOnRN của react-native-worklets) và chỉ gọi lúc kết thúc, không gọi mỗi frame. Các bẫy: đọc sharedValue.value từ JS thread là một lời gọi đồng bộ sang UI thread nên tránh làm thường xuyên; worklet chỉ thấy giá trị biến capture lúc nó được tạo (không tự cập nhật theo state React sau đó) nên giá trị thay đổi phải truyền qua shared value; capture object lớn vào worklet làm tốn chi phí sao chép; và animate thuộc tính layout (height, top) kích hoạt layout mỗi frame, đắt hơn transform hay opacity nhiều. Cuối cùng phải kiểm tra trên build release và máy Android yếu, vì dev mode làm worklet chậm hơn thực tế.
const SNAP_OPEN = 0;
const SNAP_CLOSED = 400;

function BottomSheet({ onClose, children }: { onClose: () => void; children: React.ReactNode }) {
  const translateY = useSharedValue(SNAP_CLOSED);
  const startY = useSharedValue(0);

  useEffect(() => {
    translateY.value = withSpring(SNAP_OPEN); // mở sheet
  }, [translateY]);

  const pan = Gesture.Pan()
    .onStart(() => {
      startY.value = translateY.value; // chạy trên UI thread
    })
    .onChange((e) => {
      translateY.value = Math.max(SNAP_OPEN, startY.value + e.translationY);
    })
    .onEnd((e) => {
      const shouldClose = translateY.value > SNAP_CLOSED / 2 || e.velocityY > 800;
      translateY.value = withSpring(
        shouldClose ? SNAP_CLOSED : SNAP_OPEN,
        { velocity: e.velocityY },
        (finished) => {
          if (finished && shouldClose) runOnJS(onClose)(); // chỉ gọi sang JS một lần khi xong
        },
      );
    });

  const style = useAnimatedStyle(() => ({ transform: [{ translateY: translateY.value }] }));

  return (
    <GestureDetector gesture={pan}>
      <Animated.View style={[styles.sheet, style]}>{children}</Animated.View>
    </GestureDetector>
  );
}
