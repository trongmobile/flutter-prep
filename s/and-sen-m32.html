Với Network Security Config sau, chuyện gì xảy ra khi app kết nối tới api.example.com sau ngày 2026-01-01?

<network-security-config>
  <domain-config>
    <domain includeSubdomains="true">api.example.com</domain>
    <pin-set expiration="2026-01-01">
      <pin digest="SHA-256">7HIpactkIAq2Y49orFOOQKurWxmmSFZhBCoQYcRhJ3Y=</pin>
    </pin-set>
  </domain-config>
</network-security-config>
  1. AMọi kết nối tới domain đó bị từ chối cho tới khi app cập nhật pin mới
  2. BHệ thống tự tải pin mới từ server qua HTTPS rồi tiếp tục kiểm tra
  3. CKhông còn kiểm tra pin, chỉ xác thực certificate như cấu hình thông thường
  4. DApp crash ngay khi khởi động vì file cấu hình chứa pin đã hết hạn
Xem đáp án
Đáp án đúng: C
Sau expiration, pin-set bị bỏ qua để app cũ không bị khoá vĩnh viễn khi key server đã đổi; kết nối vẫn được xác thực bằng trust anchor thông thường. Cấu hình này còn thiếu backup pin: nên có ít nhất một pin cho key dự phòng.
