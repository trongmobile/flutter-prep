Sau khi release, Sentry báo crash-free session 99.6% nhưng nhiều user phàn nàn 'app tự tắt' mà không có lỗi tương ứng; đội đã bọc ErrorBoundary ở root nhưng vẫn có màn hình trắng. Hệ thống xử lý lỗi của RN gồm những tầng nào, và bạn thiết kế việc quan sát lỗi thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Lỗi trong RN thuộc ba nhóm, mỗi nhóm có đường bắt riêng. Một: lỗi lúc render hay lifecycle của React, được ErrorBoundary bắt; ErrorBoundary không bắt lỗi trong event handler, setTimeout, Promise hay async, nên nhiều lỗi JS không đi qua đây. Hai: lỗi JS không được bắt (uncaught exception) đi tới ErrorUtils.setGlobalHandler (Sentry hay Crashlytics gắn handler ở đây); lỗi fatal ở bản release làm app thoát, còn ở dev thì hiện LogBox; unhandled promise rejection mặc định chỉ cảnh báo ở dev nên SDK như Sentry cài thêm hook để ghi nhận. Ba: crash native (lỗi trong thư viện native, OOM, bị kill vì memory, ANR trên Android, watchdog trên iOS) không có JS stack và JS không bắt được vì process đã chết; cần SDK native (Sentry, Crashlytics) cùng các nguồn như Android vitals, Xcode Organizer, MetricKit. Vì vậy 'app tự tắt' mà không có lỗi tương ứng thường là OOM hay jetsam hoặc ANR, còn màn hình trắng thường do lỗi render ở nơi không có ErrorBoundary hoặc lỗi nằm ngay trong fallback. Thiết kế: nhiều ErrorBoundary theo vùng (root, từng màn, từng widget quan trọng) với fallback có nút thử lại; thêm breadcrumb (điều hướng, request, hành động của user), gắn đúng release, dist và source map, theo dõi crash-free users chứ không chỉ session, và đặt cảnh báo theo ngưỡng; lỗi nhẹ như API fail thì ghi ở mức handled kèm context. Kiểm chứng bằng cách giả lập từng loại lỗi (ném lỗi trong handler, Promise reject, crash native) trên bản staging để biết SDK bắt được chưa.
// Lỗi JS không bắt được (event handler, setTimeout...): Sentry/Crashlytics gắn handler này
const defaultHandler = ErrorUtils.getGlobalHandler();
ErrorUtils.setGlobalHandler((error, isFatal) => {
  logger.captureException(error, { fatal: isFatal });
  defaultHandler(error, isFatal); // vẫn giữ hành vi mặc định (fatal thì app thoát)
});

// Lỗi render: ErrorBoundary theo từng vùng, không chỉ ở root
class SectionBoundary extends React.Component<
  { name: string; children: React.ReactNode },
  { failed: boolean }
> {
  state = { failed: false };

  static getDerivedStateFromError() {
    return { failed: true };
  }

  componentDidCatch(error: Error, info: React.ErrorInfo) {
    logger.captureException(error, { section: this.props.name, componentStack: info.componentStack });
  }

  render() {
    return this.state.failed ? (
      <Button title="Thử lại" onPress={() => this.setState({ failed: false })} />
    ) : (
      this.props.children
    );
  }
}
