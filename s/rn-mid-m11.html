Với function first<T>(arr: T[]): T | undefined, biến x trong const x = first(['a', 1]) được suy ra kiểu gì?

  1. Astring | number
  2. Bunknown
  3. Cstring | number | undefined
  4. D[string, number] | undefined
Xem đáp án
Đáp án đúng: C
Mảng literal ['a', 1] được suy ra là (string | number)[], nên T là string | number và kiểu trả về có thêm undefined. TypeScript không tự suy ra tuple cho mảng literal truyền vào tham số T[].
