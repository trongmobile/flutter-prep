Một bộ đếm hay một cờ bật/tắt đơn giản có cần dùng Provider hay Bloc không? ValueNotifier, ValueListenableBuilder và ListenableBuilder hoạt động thế nào, và những bẫy nào hay gặp (đổi nội dung list bên trong, quên dispose)?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Không cần: Flutter có sẵn Listenable. ValueNotifier<T> giữ một giá trị và gọi các listener mỗi khi value được gán một giá trị khác (so bằng ==); ValueListenableBuilder lắng nghe nó và chỉ rebuild phần builder, nên hợp với state cục bộ nhỏ (tiến độ upload, ẩn hiện mật khẩu) mà không phải setState làm rebuild cả màn hình. ChangeNotifier dùng cho nhiều trường và tự gọi notifyListeners(); ListenableBuilder (Flutter 3.10 trở lên) rebuild theo bất kỳ Listenable nào, kể cả Listenable.merge([a, b]) để lắng nghe nhiều nguồn và AnimationController. Các bẫy: gán cùng giá trị thì không thông báo; với ValueNotifier<List<int>>, value.add(1) sửa tại chỗ không thông báo vì tham chiếu không đổi, phải gán list mới (value = [...value, 1]); notifier tạo trong build sẽ bị tạo lại mỗi lần rebuild, nên tạo trong initState (hoặc là field của State) và dispose() khi xong; truyền child cho builder với những phần không đổi để khỏi rebuild. Khi state cần dùng chung nhiều màn, cần test logic hay có phụ thuộc phức tạp thì dùng giải pháp state management (Riverpod, Bloc); ValueNotifier là lựa chọn nhẹ cho phạm vi nhỏ.
class _PasswordFieldState extends State<PasswordField> {
  final _obscure = ValueNotifier<bool>(true); // tạo một lần trong State

  @override
  void dispose() {
    _obscure.dispose(); // quên dispose là rò rỉ
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return ValueListenableBuilder<bool>(
      valueListenable: _obscure,
      builder: (context, obscure, child) => TextField(
        obscureText: obscure,
        decoration: InputDecoration(
          suffixIcon: IconButton(
            icon: Icon(obscure ? Icons.visibility : Icons.visibility_off),
            onPressed: () => _obscure.value = !obscure, // chỉ TextField này rebuild, không rebuild cả màn hình
          ),
        ),
      ),
    );
  }
}

// List: phải gán list mới thì mới thông báo
final items = ValueNotifier<List<int>>([]);
items.value = [...items.value, 1]; // items.value.add(1) sẽ không thông báo
