Hàm xuất thumbnail sau chạy trên background thread; memory tăng liên tục suốt vòng lặp và chỉ giảm khi hàm kết thúc. Cách sửa phù hợp nhất?

func exportThumbnails(_ paths: [String]) {
  for path in paths { // vài nghìn ảnh
    guard let image = UIImage(contentsOfFile: path) else { continue }
    let thumb = image.preparingThumbnail(of: CGSize(width: 200, height: 200))
    let data = thumb?.jpegData(compressionQuality: 0.8)
    try? data?.write(to: outputURL(for: path))
  }
}
  1. AKhai báo image là optional rồi gán nil cuối mỗi vòng lặp
  2. BChuyển vòng lặp sang main thread vì run loop chính tự xả pool
  3. CBọc thân vòng lặp trong autoreleasepool { }
  4. DGiữ ảnh bằng biến weak để ARC không giữ lại bitmap đã decode

Đáp án đúng: C
Bên dưới UIKit/Foundation vẫn là Objective-C và tạo nhiều object autoreleased; chúng chỉ được giải phóng khi pool bao ngoài được xả, tức sau khi cả hàm chạy xong. autoreleasepool trong mỗi lượt lặp giữ đỉnh memory ở mức một ảnh; còn ARC vốn đã thả biến local khi hết scope nên gán nil không giúp gì.
