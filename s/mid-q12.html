Làm auth guard với go_router như thế nào? Deep link vào một trang cần đăng nhập sẽ được xử lý ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Khai báo redirect (top-level hoặc trên từng GoRoute): trả về path mới để chuyển hướng, trả null để đi tiếp; truyền refreshListenable (ví dụ ChangeNotifier giữ trạng thái auth) để router chạy lại redirect khi đăng nhập/đăng xuất. Deep link cũng đi qua cùng cấu hình route, nên link /orders/42 khi chưa login sẽ bị chuyển sang /login; hãy lưu đích ban đầu (query from) để quay lại sau khi đăng nhập, và cẩn thận tránh hai route redirect qua lại lẫn nhau. Phía native vẫn phải cấu hình App Links/intent-filter (Android) và Universal Links/Associated Domains (iOS) thì OS mới mở app bằng URL đó.
final router = GoRouter(
  refreshListenable: auth, // ChangeNotifier giữ trạng thái login
  redirect: (context, state) {
    final atLogin = state.matchedLocation == '/login';
    if (!auth.isLoggedIn) {
      if (atLogin) return null;
      final from = Uri.encodeComponent(state.uri.toString());
      return '/login?from=$from';
    }
    if (atLogin) return state.uri.queryParameters['from'] ?? '/';
    return null;
  },
  routes: routes,
);
