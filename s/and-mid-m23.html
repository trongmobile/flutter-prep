Trong class Account, deposit() là instance method synchronized, còn audit() là static synchronized. Hai thread gọi account.deposit() và Account.audit() cùng lúc thì sao?

  1. AChạy song song được vì hai method khoá trên hai monitor khác nhau
  2. BMột thread phải chờ vì mọi synchronized trong class dùng chung khoá
  3. CDeadlock vì method static giữ khoá của mọi instance của class
  4. DLỗi compile vì không được trộn method static và instance synchronized
Xem đáp án
Đáp án đúng: A
Instance method synchronized khoá trên this, còn static synchronized khoá trên object Account.class, nên chúng không chặn nhau. Nếu hai method cùng đụng tới một state dùng chung thì phải dùng chung một khoá rõ ràng.
