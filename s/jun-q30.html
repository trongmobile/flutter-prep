Một widget test cơ bản gồm những bước nào? Vì sao thường phải bọc widget cần test trong MaterialApp?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Các bước: pumpWidget để render, dùng find (find.text, find.byType, find.byKey) để tìm widget, tương tác bằng tester.tap/tester.enterText, gọi pump() để frame mới được build, rồi expect với matcher như findsOneWidget/findsNothing. Phải bọc trong MaterialApp vì nhiều widget cần Theme, Directionality, MediaQuery hay Navigator ở phía trên, thiếu sẽ lỗi ngay khi build. Các phụ thuộc như API nên thay bằng fake/mock để test chạy nhanh và ổn định.
testWidgets('bấm + thì counter tăng', (tester) async {
  await tester.pumpWidget(const MaterialApp(home: CounterPage()));
  expect(find.text('0'), findsOneWidget);

  await tester.tap(find.byIcon(Icons.add));
  await tester.pump();

  expect(find.text('1'), findsOneWidget);
});
