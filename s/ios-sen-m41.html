Đoạn code tự cài copy-on-write sau in ra gì, và cách sửa đúng để Buffer thực sự có value semantics là gì?

final class Storage {
  var values: [Int]
  init(_ values: [Int]) { self.values = values }
}

struct Buffer {
  private var storage = Storage([1, 2, 3])
  var values: [Int] { storage.values }

  mutating func append(_ x: Int) {
    storage.values.append(x)
  }
}

var a = Buffer()
var b = a
b.append(4)
print(a.values)
  1. A[1, 2, 3]; không cần sửa vì gán struct luôn sao chép toàn bộ dữ liệu bên trong
  2. B[1, 2, 3, 4]; khoá append bằng NSLock để hai biến không ghi cùng lúc được
  3. C[1, 2, 3, 4]; gọi isKnownUniquelyReferenced rồi clone Storage nếu dùng chung
  4. D[1, 2, 3]; ARC tự copy Storage khi retain count lớn hơn 1 nên không cần sửa gì
Xem đáp án
Đáp án đúng: C
Gán b = a chỉ copy tham chiếu storage, nên hai biến cùng trỏ một Storage và append trên b làm a đổi theo (in ra [1, 2, 3, 4]). Phải gọi isKnownUniquelyReferenced(&storage) trước khi mutate và tạo bản sao nếu chưa duy nhất; ARC không tự copy, còn lock chỉ lo thread safety chứ không tạo ra value semantics.
