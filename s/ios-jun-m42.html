Observer đăng ký qua addObserver(forName:object:queue:using:) với queue: nil, rồi code post notification ngay trên cùng thread. Thứ tự in ra là gì?

extension Notification.Name {
  static let ping = Notification.Name("ping")
}

let token = NotificationCenter.default.addObserver(forName: .ping, object: nil, queue: nil) { _ in
  print("nhận")
}
print("trước")
NotificationCenter.default.post(name: .ping, object: nil)
print("sau")
  1. Atrước, nhận, sau
  2. Btrước, sau, nhận
  3. Cnhận, trước, sau
  4. DChỉ trước và sau, observer chưa chạy vì chưa có RunLoop
Xem đáp án
Đáp án đúng: A
post(name:object:) là đồng bộ: nó gọi lần lượt các observer rồi mới return. Khi queue là nil, block chạy ngay trên thread đang post, nên nhận in trước sau. Muốn việc xử lý không chặn nơi post thì phải tự đẩy sang queue khác bên trong observer.
