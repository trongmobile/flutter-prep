Màn hình có nhiều icon local trong assets/icons, tên icon cần hiển thị nằm trong biến name (ví dụ 'home', 'cart'). Cách nào chọn ảnh theo name đúng cách?

  1. ALập bảng { home: require('./icons/home.png'), cart: require('./icons/cart.png') } rồi lấy icons[name]
  2. BViết source={require('./icons/' + name + '.png')} vì Metro tự dò mọi file có thể khớp với đường dẫn lúc bundle app
  3. CViết source={{ uri: './icons/' + name + '.png' }} vì uri nhận đường dẫn tương đối trong project
  4. DViết import('./icons/' + name + '.png') trong lúc render để nạp ảnh khi thực sự cần dùng đến
Xem đáp án
Đáp án đúng: A
Ảnh local được Metro phân tích và đóng gói lúc bundle, nên require phải nhận chuỗi cố định để biết chính xác file nào cần đưa vào app; ghép chuỗi bằng biến sẽ bị bundler từ chối. Bảng ánh xạ gồm các require tĩnh giải quyết gọn việc chọn theo tên. uri dành cho URL mạng hoặc đường dẫn file có thật trên máy, đường dẫn tương đối trong source thì không tồn tại lúc chạy; import() với đường dẫn ghép cũng không được Metro phân tích tĩnh, lại còn bất đồng bộ nên không đặt thẳng vào source được.
