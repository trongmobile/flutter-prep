Bạn lỡ commit file lib/secrets.dart chứa API key trả phí lên repo GitHub công khai. Vài phút sau bạn xoá file, commit và push lại. Key đã an toàn chưa?

  1. ARồi, vì commit mới nhất không còn chứa key nên người khác không truy cập được nữa
  2. BChưa, vì key vẫn nằm trong lịch sử git, nên cần thu hồi (revoke) key cũ và cấp key mới
  3. CRồi, nếu thêm lib/secrets.dart vào .gitignore để file không bị commit lại lần nữa
  4. DRồi, nếu build bản release với --obfuscate vì key sẽ bị mã hoá trong file thực thi của ứng dụng
Xem đáp án
Đáp án đúng: B
Git lưu toàn bộ lịch sử: ai đã clone, fork hoặc bot quét repo đều lấy được key từ commit cũ, nên việc đầu tiên là revoke key và tạo key mới (xoá khỏi lịch sử bằng công cụ như git filter-repo chỉ là bước dọn dẹp thêm, không thay được việc thu hồi). .gitignore chỉ ngăn file chưa được theo dõi bị thêm vào, không xoá những gì đã commit. --obfuscate đổi tên symbol Dart chứ không mã hoá chuỗi, và không liên quan tới key đã nằm trên GitHub. Về lâu dài, đừng nhúng secret trả phí vào app: gọi qua backend của bạn hoặc giới hạn key theo package/bundle id và quota.
