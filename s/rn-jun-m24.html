Đoạn code sau nằm trong một màn hình đang được focus. Nó có vấn đề gì?

useFocusEffect(() => {
  fetchNotifications().then(setItems);
});
  1. AGọi API mỗi khi màn hình được focus, đúng mong muốn
  2. BEffect không bao giờ chạy vì thiếu mảng dependency
  3. CGọi API liên tục vì callback mới sau mỗi render
  4. DLỗi compile vì useFocusEffect chỉ nhận useCallback
Xem đáp án
Đáp án đúng: C
useFocusEffect chạy lại effect khi callback đổi tham chiếu; hàm inline là hàm mới sau mỗi render, nên setItems gây render, render lại chạy effect gọi API, thành vòng lặp. Bọc callback trong useCallback với deps phù hợp để effect chỉ chạy khi màn hình được focus.
