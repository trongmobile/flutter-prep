startActivityForResult và onRequestPermissionsResult đã deprecated. Bạn xin quyền camera bằng Activity Result API thế nào và xử lý các trường hợp bị từ chối ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đăng ký launcher bằng registerForActivityResult(ActivityResultContracts.RequestPermission()) dưới dạng property, tức trước khi Activity/Fragment vào STARTED (không đăng ký trong click listener), rồi gọi launch(Manifest.permission.CAMERA) khi người dùng bấm tính năng; kết quả về thẳng callback, không cần so request code. Trước khi xin, kiểm tra ContextCompat.checkSelfPermission; nếu shouldShowRequestPermissionRationale() trả true nghĩa là người dùng từng từ chối, nên giải thích lý do rồi mới xin lại. Từ Android 11, người dùng từ chối hai lần thì hệ thống không hiện hộp thoại nữa, lúc đó chỉ còn cách hướng họ vào màn hình cài đặt của app. Quyền vẫn phải khai báo <uses-permission> trong Manifest.
private val cameraPermission = registerForActivityResult(
    ActivityResultContracts.RequestPermission()
) { granted ->
    if (granted) openCamera() else showPermissionDenied()
}

fun onScanClick() {
    when {
        ContextCompat.checkSelfPermission(this, Manifest.permission.CAMERA) ==
            PackageManager.PERMISSION_GRANTED -> openCamera()
        shouldShowRequestPermissionRationale(Manifest.permission.CAMERA) -> showRationale()
        else -> cameraPermission.launch(Manifest.permission.CAMERA)
    }
}
