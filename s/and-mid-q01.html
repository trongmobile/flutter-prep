Màn Home tải song song banner và danh sách gợi ý bằng hai async trong coroutineScope. Chỉ cần API gợi ý lỗi là cả màn hình báo lỗi, banner cũng mất. Vì sao, và sửa thế nào để khối nào lỗi thì chỉ khối đó lỗi?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đây là structured concurrency: trong coroutineScope, một coroutine con thất bại sẽ huỷ cả scope, kéo theo huỷ mọi coroutine anh em, rồi exception được ném ra khỏi coroutineScope. Muốn các khối độc lập thì dùng supervisorScope: con lỗi không huỷ anh em và không huỷ scope. Với async, exception được giữ trong Deferred và chỉ ném ra khi gọi await(), nên bọc từng await() trong try/catch để biến lỗi thành trạng thái riêng của khối đó, nhớ ném lại CancellationException. supervisorScope vẫn chờ mọi con hoàn thành và vẫn bị huỷ khi scope cha bị huỷ, nên không phá vỡ tính structured.
suspend fun loadHome(): HomeUi = supervisorScope {
  val banner = async { api.banners() }
  val suggestions = async { api.suggestions() }
  // khối nào lỗi thì null, khối còn lại vẫn hiển thị
  HomeUi(banner.awaitOrNull(), suggestions.awaitOrNull())
}

suspend fun <T> Deferred<T>.awaitOrNull(): T? = try {
  await()
} catch (e: CancellationException) {
  throw e // không nuốt cancellation
} catch (e: Exception) {
  null
}
