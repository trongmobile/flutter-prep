Bạn thêm đăng nhập bằng vân tay/khuôn mặt để mở app và xác nhận chuyển tiền. Bản đầu gọi BiometricPrompt, khi onAuthenticationSucceeded thì đặt isAuthenticated = true rồi gọi API. Security review chặn vì sao, và bạn làm đúng thế nào với authenticators và CryptoObject?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Cờ boolean là điểm yếu vì toàn bộ logic nằm trong process của app: trên máy root, chỉ cần hook onAuthenticationSucceeded hoặc gọi thẳng đường code thành công là qua mặt được mà chưa hề quét sinh trắc học. Cách đúng cho thao tác nhạy cảm là gắn khoá Android Keystore vào việc xác thực. Tạo khoá với setUserAuthenticationRequired(true) và (API 30+) setUserAuthenticationParameters(0, KeyProperties.AUTH_BIOMETRIC_STRONG) để mỗi lần dùng khoá đều phải xác thực, truyền BiometricPrompt.CryptoObject(cipher) vào authenticate(), và chỉ sau khi thành công mới dùng result.cryptoObject?.cipher để giải mã token hoặc ký challenge của server. Khoá chưa mở thì code app không dùng được nó. Bẫy: mặc định khoá bị vô hiệu khi người dùng thêm vân tay mới (KeyPermanentlyInvalidatedException), cần tạo khoá mới và bắt đăng nhập lại bằng mật khẩu. Về authenticators: BIOMETRIC_STRONG (Class 3) là mức cần cho CryptoObject; BIOMETRIC_WEAK thì không đủ. DEVICE_CREDENTIAL cho phép PIN/hình mở khoá làm đường lui, nhưng kết hợp với CryptoObject chỉ từ API 30, và khi cho phép nó thì không được gọi setNegativeButtonText (sẽ ném IllegalArgumentException). Trước khi hiện prompt, gọi BiometricManager.canAuthenticate() để xử lý chưa đăng ký sinh trắc (BIOMETRIC_ERROR_NONE_ENROLLED), không có phần cứng hay đang tạm không dùng được. Luôn có đường dự phòng (mật khẩu, OTP), xử lý onAuthenticationError như người dùng huỷ hay bị khoá (ERROR_LOCKOUT), và với giao dịch lớn thì để server xác minh chữ ký thay vì tin cờ từ client.
val spec = KeyGenParameterSpec.Builder(
  "login_key",
  KeyProperties.PURPOSE_ENCRYPT or KeyProperties.PURPOSE_DECRYPT,
)
  .setBlockModes(KeyProperties.BLOCK_MODE_GCM)
  .setEncryptionPaddings(KeyProperties.ENCRYPTION_PADDING_NONE)
  .setUserAuthenticationRequired(true)
  .setUserAuthenticationParameters(0, KeyProperties.AUTH_BIOMETRIC_STRONG) // API 30+: mỗi lần dùng khoá đều phải xác thực
  .build()
KeyGenerator.getInstance(KeyProperties.KEY_ALGORITHM_AES, "AndroidKeyStore")
  .apply { init(spec) }
  .generateKey()

val promptInfo = BiometricPrompt.PromptInfo.Builder()
  .setTitle("Xác nhận chuyển khoản")
  .setAllowedAuthenticators(BiometricManager.Authenticators.BIOMETRIC_STRONG)
  .setNegativeButtonText("Dùng mật khẩu") // bắt buộc khi không cho phép DEVICE_CREDENTIAL
  .build()

val cipher = createDecryptCipher() // init DECRYPT_MODE với khoá Keystore và IV đã lưu
val prompt = BiometricPrompt(activity, ContextCompat.getMainExecutor(activity),
  object : BiometricPrompt.AuthenticationCallback() {
    override fun onAuthenticationSucceeded(result: BiometricPrompt.AuthenticationResult) {
      val unlocked = result.cryptoObject?.cipher ?: return
      val token = unlocked.doFinal(encryptedToken) // chỉ giải mã được sau khi quét thành công
      submit(token)
    }
  })
prompt.authenticate(promptInfo, BiometricPrompt.CryptoObject(cipher))
