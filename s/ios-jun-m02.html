Protocol Describable có requirement describe() kèm cài đặt mặc định trong extension; Book dùng bản mặc định, còn Movie tự cài đặt. Vòng lặp in ra gì?

protocol Describable {
  var title: String { get }
  func describe() -> String
}
extension Describable {
  func describe() -> String { "Mục: \(title)" }
}
struct Book: Describable { let title: String }
struct Movie: Describable {
  let title: String
  func describe() -> String { "Phim: \(title)" }
}
let items: [any Describable] = [Book(title: "Swift"), Movie(title: "iOS")]
items.forEach { print($0.describe()) }
  1. AMục: Swift rồi Mục: iOS
  2. BLỗi compile vì Book chưa cài đặt describe()
  3. CLỗi compile vì mảng chứa hai kiểu khác nhau
  4. DMục: Swift rồi Phim: iOS
Xem đáp án
Đáp án đúng: D
Protocol extension cung cấp default implementation nên Book conform hợp lệ mà không cần tự viết describe(). Vì describe() là requirement của protocol, lời gọi qua any Describable được dispatch động tới bản của từng kiểu: Movie dùng bản riêng, Book dùng bản mặc định; mảng [any Describable] chứa được mọi kiểu conform protocol.
