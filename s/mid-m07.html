Đoạn code dùng generator async* sau in ra gì?

Stream<int> count() async* {
  print('start');
  yield 1;
  yield 2;
  print('end');
}

Future<void> main() async {
  final s = count();
  print('created');
  await for (final v in s) print(v);
  print('done');
}
  1. Astart, created, 1, 2, end, done
  2. Bcreated, start, 1, 2, done, end
  3. Cstart, 1, 2, end, created, done
  4. Dcreated, start, 1, 2, end, done
Xem đáp án
Đáp án đúng: D
Gọi hàm async* chỉ tạo ra Stream; body chưa chạy cho tới khi có người listen (ở đây là await for). Vòng await for chỉ kết thúc khi stream đóng, tức sau khi body in end, nên done in cuối cùng.
