Bấm vào Counter 3 lần (không có gì khác làm nó re-render). Màn hình hiển thị gì?

function Counter() {
  const countRef = useRef(0);

  return (
    <Pressable onPress={() => { countRef.current += 1; }}>
      <Text>{countRef.current}</Text>
    </Pressable>
  );
}
  1. A3, mỗi lần bấm hiển thị số mới
  2. B0, vì đổi ref.current không gây re-render
  3. C1, vì ref chỉ được ghi một lần trong mỗi lần render
  4. DLỗi runtime vì ref.current chỉ đọc được
Xem đáp án
Đáp án đúng: B
countRef.current thực sự tăng lên 3, nhưng thay đổi ref không báo cho React render lại nên UI vẫn hiển thị giá trị của lần render đầu. Giá trị cần hiện lên màn hình phải để trong state.
