Một suite Swift Testing dùng chung biến static var mockStore mà nhiều test cùng sửa. Chạy riêng từng test thì pass, chạy cả suite thì fail ngẫu nhiên. Nguyên nhân hợp lý nhất?

  1. ASwift Testing chạy test theo thứ tự ngẫu nhiên nhưng luôn tuần tự
  2. BSwift Testing mặc định chạy song song, các test ghi đè state chung
  3. CMỗi test tạo instance suite mới nên biến static bị reset giữa chừng
  4. D#expect đánh giá bất đồng bộ nên kết quả về sau khi test kết thúc
