App có bottom navigation 4 tab, mỗi tab có back stack riêng. User mở chi tiết trong tab Feed, chuyển sang tab Profile rồi quay lại thì phải thấy đúng màn chi tiết cũ. Ngoài ra màn Chọn địa chỉ cần trả kết quả về màn Checkout. Bạn cấu hình Navigation Compose thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Navigation hỗ trợ nhiều back stack: khi chuyển tab, navigate kèm popUpTo(startDestination) { saveState = true }, launchSingleTop = true và restoreState = true. saveState lưu back stack (cùng state rememberSaveable của các entry) của tab đang rời, restoreState khôi phục nó khi quay lại; thiếu restoreState thì tab luôn về màn đầu, thiếu saveState thì stack cũ bị bỏ, còn launchSingleTop tránh đẩy thêm một bản sao khi bấm lại tab đang chọn. Mỗi tab nên là một nested graph hoặc route gốc có start destination riêng. State UI như vị trí cuộn muốn sống qua việc đổi tab cần rememberSaveable hoặc rememberLazyListState (đã có saver); ViewModel gắn với entry nên hãy đặt state quan trọng vào SavedStateHandle. Trả kết quả giữa các màn: màn Chọn địa chỉ ghi vào previousBackStackEntry?.savedStateHandle rồi popBackStack(), màn Checkout đọc getStateFlow. Kết quả nằm trong SavedStateHandle nên sống cả qua process death, vì thế chỉ truyền thứ lưu được vào Bundle (id chứ không phải object lớn). Cũng tránh truyền NavController xuống sâu trong cây composable: hoist thành callback (onOpenOrder, onBack) để màn dễ test và tái sử dụng. Tránh tạo NavHost riêng cho từng tab trừ khi các tab thật sự độc lập, vì mất khả năng điều hướng chéo và deep link tập trung.
fun NavController.navigateToTab(route: Any) {
  navigate(route) {
    popUpTo(graph.findStartDestination().id) { saveState = true } // lưu back stack của tab đang rời
    launchSingleTop = true // bấm lại tab đang chọn không đẩy thêm màn
    restoreState = true // quay lại tab thì khôi phục stack và state cũ
  }
}

// Màn Chọn địa chỉ trả kết quả về màn trước đó
navController.previousBackStackEntry?.savedStateHandle?.set("addressId", address.id)
navController.popBackStack()

// Màn Checkout: nhận kết quả, sống cả qua process death vì nằm trong SavedStateHandle
composable<CheckoutRoute> { entry ->
  val addressId by entry.savedStateHandle
    .getStateFlow<String?>("addressId", null)
    .collectAsStateWithLifecycle()

}
