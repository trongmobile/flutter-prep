Màn SwiftUI gọi API trong .onAppear và bị gọi lại mỗi lần quay về từ màn con; .onChange(of:) thì bắn hay không bắn lúc mở màn hình, và app muốn dừng polling khi vào background. .onAppear, .task, .task(id:), .onChange và scenePhase khác nhau thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
.onAppear chạy mỗi lần view xuất hiện trong hierarchy (cả khi quay lại từ màn push lên trên hoặc đổi tab) và là đồng bộ, nên muốn gọi API phải tự tạo Task, và task đó không bị huỷ khi view biến mất. .task { } chạy closure async khi view xuất hiện và tự huỷ khi view biến mất; .task(id: value) còn tự huỷ và chạy lại khi value đổi, hợp cho việc tải theo tham số. Cả hai chạy lại mỗi lần view xuất hiện lại, nên muốn 'chỉ tải một lần' phải có cờ hoặc kiểm tra dữ liệu đã có trong model. .onChange(of:) bắn khi giá trị đổi; từ iOS 17 closure nhận (oldValue, newValue) hoặc không tham số, và mặc định không bắn lúc đầu trừ khi truyền initial: true; bản một tham số cũ đã deprecated. Trong closure đừng sửa chính state đang theo dõi để tránh vòng lặp cập nhật. @Environment(\.scenePhase) cho biết scene đang .active, .inactive hay .background: dùng nó để dừng polling, lưu nháp khi sang .background và làm mới khi về .active. Lưu ý onAppear/onDisappear không phản ánh việc app vào background. Một mẹo gọn: đặt vòng polling trong .task(id: scenePhase) và guard scenePhase == .active, nó tự dừng khi vào nền, chạy lại khi quay về, và tự huỷ khi view biến mất.
struct OrderScreen: View {
  @Environment(\.scenePhase) private var scenePhase
  @State private var model = OrderModel()
  let orderID: String

  var body: some View {
    OrderContent(model: model)
      .task(id: orderID) { // tự huỷ và chạy lại khi orderID đổi, tự huỷ khi view biến mất
        await model.load(orderID)
      }
      .task(id: scenePhase) { // chạy lại mỗi khi scenePhase đổi
        guard scenePhase == .active else { return } // vào background thì dừng polling
        while !Task.isCancelled {
          try? await Task.sleep(for: .seconds(30))
          await model.refreshStatus()
        }
      }
      .onChange(of: scenePhase) { _, phase in // iOS 17: closure (giá trị cũ, giá trị mới)
        if phase == .background { model.saveDraft() }
      }
  }
}
