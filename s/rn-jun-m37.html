Với React Native bản mới chạy Hermes, công cụ debug JS mặc định là gì?

  1. ABật "Debug JS Remotely" để chạy JS trong Chrome V8
  2. BReact Native DevTools (Dev Menu hoặc phím j ở Metro)
  3. CCài Flipper, vì template mặc định vẫn tích hợp sẵn nó
  4. DSafari Web Inspector, chọn JSContext của app đang chạy
Xem đáp án
Đáp án đúng: B
React Native DevTools là công cụ debug mặc định cho Hermes, có Console, breakpoint và tab Components/Profiler của React DevTools. Remote JS Debugging chạy JS trên V8 của Chrome nên hành vi khác thiết bị thật và đã deprecated; Flipper cũng đã bị bỏ khỏi template mặc định.
