frame và bounds của UIView khác nhau thế nào? Vì sao in view.frame trong viewDidLoad ra kích thước sai, và safeAreaLayoutGuide dùng để làm gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
frame là vị trí và kích thước của view trong hệ toạ độ của view cha; bounds là kích thước của chính view trong hệ toạ độ riêng, origin mặc định là (0, 0). Hai giá trị lệch nhau khi view bị transform (xoay hoặc scale: frame là hộp bao ngoài của hình đã xoay, còn bounds không đổi) hoặc khi bounds.origin bị dịch, đó chính là cách UIScrollView cuộn nội dung. Vẽ hoặc căn thứ bên trong view thì dùng bounds; đặt view vào đâu trong cha thì dùng frame. Trong viewDidLoad, view vừa được tải và chưa qua vòng layout nên frame/bounds chỉ là giá trị tạm (theo storyboard hoặc bằng 0 với view tạo bằng code dùng constraint). Muốn đọc kích thước thật, ví dụ bo tròn avatar bằng bounds.width / 2, hãy đặt trong viewDidLayoutSubviews (hàm này chạy nhiều lần nên đừng làm việc nặng). Đừng gán frame cho view đã có constraint vì Auto Layout sẽ ghi đè. Safe area là vùng không bị notch/Dynamic Island, home indicator hay thanh điều hướng che; neo constraint vào view.safeAreaLayoutGuide để nội dung không bị che, còn nền phủ kín màn hình thì vẫn neo vào mép view.
final class AvatarViewController: UIViewController {
    private let avatarView = UIImageView()

    override func viewDidLoad() {
        super.viewDidLoad()
        avatarView.translatesAutoresizingMaskIntoConstraints = false
        view.addSubview(avatarView)

        let guide = view.safeAreaLayoutGuide     // tránh notch và home indicator
        NSLayoutConstraint.activate([
            avatarView.topAnchor.constraint(equalTo: guide.topAnchor, constant: 16),
            avatarView.centerXAnchor.constraint(equalTo: view.centerXAnchor),
            avatarView.widthAnchor.constraint(equalToConstant: 80),
            avatarView.heightAnchor.constraint(equalTo: avatarView.widthAnchor)
        ])
        print(avatarView.bounds.width)           // 0: chưa layout xong
    }

    override func viewDidLayoutSubviews() {
        super.viewDidLayoutSubviews()
        avatarView.layer.cornerRadius = avatarView.bounds.width / 2  // 40: đã có kích thước thật
        avatarView.clipsToBounds = true
    }
}
