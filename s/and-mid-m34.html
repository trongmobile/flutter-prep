Với bottom navigation trong Navigation Compose, đoạn navigate(route) { popUpTo(startId) { saveState = true }; launchSingleTop = true; restoreState = true } dùng saveState/restoreState để làm gì?

  1. AGiữ back stack và state của từng tab khi chuyển qua lại giữa các tab
  2. BBỏ qua animation chuyển màn khi quay lại tab đã mở trước đó
  3. CNgăn tạo nhiều bản sao của cùng destination trên đỉnh back stack
  4. DGiữ ViewModel của tab cũ sống mãi kể cả khi rời khỏi graph
Xem đáp án
Đáp án đúng: A
saveState = true lưu back stack và state của các destination bị pop, restoreState = true khôi phục chúng khi chọn lại tab đó, nên mỗi tab giữ được màn hình và vị trí cuộn riêng. Chống tạo bản sao trên đỉnh stack là việc của launchSingleTop.
