Với chuỗi JSON là một object ({"name": "An", "age": 20}), jsonDecode trả về giá trị có kiểu runtime nào?

  1. AMap<String, String>
  2. BList<dynamic>
  3. CMap<String, dynamic>
  4. DString đã được chuẩn hóa
Xem đáp án
Đáp án đúng: C
Kiểu khai báo của jsonDecode là dynamic, còn giá trị thực tế với object JSON là Map<String, dynamic> vì value có thể là số, chuỗi, bool, list hay map lồng nhau. Không phải Map<String, String> vì age vẫn là int; chỉ mảng JSON mới cho ra List<dynamic>.
