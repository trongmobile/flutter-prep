Sếp muốn có bản web từ app RN "dùng lại code" để khỏi lập team web riêng. Bạn đánh giá thế nào: khi nào dùng react-native-web/Expo web thì đáng, khi nào không, và tổ chức code ra sao để chia sẻ được phần có giá trị nhất?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
"Dùng lại code" nên tách thành ba lớp có giá trị và rủi ro rất khác nhau. Lớp logic (kiểu dữ liệu, API client, validate, state, hook, quy tắc nghiệp vụ, i18n) chia sẻ gần như miễn phí và lợi nhất; lớp UI mới là chỗ đau. react-native-web ánh xạ View, Text, Pressable, StyleSheet sang DOM và CSS nên hợp với web kiểu ứng dụng (dashboard, công cụ nội bộ sau đăng nhập, PWA, bản xem nhanh) và khi đội đã giỏi RN. Không hợp khi cần SEO và nội dung (trang marketing, blog, danh mục sản phẩm công khai) vì cần render phía server và HTML ngữ nghĩa tốt (Expo Router có static rendering nhưng vẫn phải cân nhắc kỹ), hay khi web phải mượt như web thật. Bẫy thường gặp: kích thước bundle; kỳ vọng của web mà app không có (hover, focus ring, điều hướng bàn phím, chuột phải, bôi chọn text, URL và nút Back của trình duyệt, responsive thật sự thay vì co giãn màn hình điện thoại); accessibility phải ánh xạ đúng role sang HTML; FlatList ảo hoá khác cuộn của trình duyệt; nhiều thư viện native (camera, Keychain, Bluetooth, một số hiệu ứng) không chạy trên web nên cần file .web.ts hoặc Platform.OS làm phương án thay thế. Cấu trúc: monorepo với packages/core thuần TypeScript (cấm import react-native bằng lint để luôn dùng được cả trên web), packages/ui dùng primitive RN kèm file theo nền tảng, apps/mobile và apps/web. Quyết định: web cần SEO thì dựng stack web riêng (Next.js...) chỉ dùng chung core; web kiểu ứng dụng thì RN Web. Đo thực tế bằng kích thước bundle, Lighthouse, kiểm tra accessibility, và dựng thử một màn thật trước khi cam kết.
// eslint.config.js: packages/core không được phụ thuộc vào nền tảng
export default [
  {
    files: ['packages/core/**/*.ts'],
    rules: { 'no-restricted-imports': ['error', { patterns: ['react-native*', 'expo*'] }] },
  },
];

// share.ts (mobile)
import { Share } from 'react-native';
export const shareLink = (url: string) => Share.share({ message: url });

// share.web.ts: bundler chọn file .web.ts khi build web
export const shareLink = async (url: string) => {
  if (navigator.share) await navigator.share({ url });
  else await navigator.clipboard.writeText(url);
};
