Hai lệnh async và một lệnh sync được đưa vào cùng một queue tạo bằng DispatchQueue(label:). Thứ tự in ra là gì?

let queue = DispatchQueue(label: "com.app.storage")
queue.async { print("ghi 1") }
queue.async { print("ghi 2") }
queue.sync { print("đọc") }
print("xong")
  1. Aghi 1, ghi 2, đọc, xong
  2. Bđọc, xong, ghi 1, ghi 2
  3. Cđọc, ghi 1, ghi 2, xong
  4. DKhông xác định vì các task async chạy song song

Đáp án đúng: A
Queue tạo bằng DispatchQueue(label:) mặc định là serial, chạy từng task theo đúng thứ tự đưa vào. sync xếp task đọc sau hai task ghi rồi chặn thread gọi tới khi nó chạy xong, nên xong luôn in cuối; async chỉ có nghĩa là nơi gọi không chờ, không làm queue serial chạy song song.
