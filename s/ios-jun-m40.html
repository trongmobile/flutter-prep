Hai test cùng tăng một stored property count của test case rồi kiểm tra bằng 1. Kết quả khi chạy cả hai là gì?

final class CounterTests: XCTestCase {
  var count = 0

  func testA() {
    count += 1
    XCTAssertEqual(count, 1)
  }

  func testB() {
    count += 1
    XCTAssertEqual(count, 1)
  }
}
  1. ATest chạy sau fail vì count lúc đó bằng 2
  2. BCả hai test đều pass
  3. CKết quả phụ thuộc vào thứ tự chạy test
  4. DLỗi compile vì XCTestCase không cho stored property
Xem đáp án
Đáp án đúng: B
XCTest tạo một instance riêng của test case cho mỗi method test, nên count luôn bắt đầu từ 0. Tuy vậy, state static hay singleton vẫn dùng chung giữa các test, nên cần reset trong setUp()/tearDown().
