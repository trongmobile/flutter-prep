Team cần ba môi trường dev, staging, prod với base URL khác nhau và muốn cài song song trên cùng một máy. buildTypes và productFlavors khác nhau thế nào, bạn cấu hình ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
buildTypes mô tả cách build (debug, release): bật R8 không, ký bằng keystore nào, có debuggable không. productFlavors mô tả biến thể của sản phẩm (dev/staging/prod): base URL, tên app, applicationId, resource riêng trong src/<flavor>. Gradle ghép hai phía thành build variant như devDebug, prodRelease, và mỗi flavor phải thuộc một dimension khai báo trong flavorDimensions. Android định danh app bằng applicationId nên muốn cài song song phải đặt applicationIdSuffix khác nhau (.dev, .staging). Giá trị theo môi trường đưa vào buildConfigField rồi đọc qua BuildConfig.BASE_URL; từ AGP 8.0 BuildConfig không còn được sinh mặc định nên cần bật buildFeatures { buildConfig = true }, và giá trị chuỗi phải có thêm cặp nháy kép bên trong, thiếu thì lỗi compile. Bẫy hay gặp là test nhầm variant nên trỏ nhầm môi trường.
android {
    buildFeatures { buildConfig = true }
    flavorDimensions += "env"
    productFlavors {
        create("dev") {
            dimension = "env"
            applicationIdSuffix = ".dev"
            buildConfigField("String", "BASE_URL", "\"https://dev.api.shop.vn/\"")
        }
        create("prod") {
            dimension = "env"
            buildConfigField("String", "BASE_URL", "\"https://api.shop.vn/\"")
        }
    }
    buildTypes {
        release {
            isMinifyEnabled = true
            proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")
        }
    }
}
