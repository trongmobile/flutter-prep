Gọi API bằng fetch thế nào? Vì sao server trả 404 hoặc 500 mà code không nhảy vào catch?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
fetch(url, options) trả về Promise của Response; với POST cần method, header Content-Type: application/json và body: JSON.stringify(data), còn body trả về đọc bằng await res.json() (cũng là Promise). Promise của fetch chỉ reject khi có lỗi mạng như mất kết nối hay không phân giải được tên miền; HTTP 404 hay 500 vẫn là một response hợp lệ nên Promise vẫn resolve. Vì vậy phải tự kiểm tra res.ok (status 200–299) hoặc res.status rồi ném lỗi để tầng trên xử lý. Lưu ý thêm: bản release trên Android và iOS mặc định chặn request http:// không mã hoá, nên API thật cần dùng HTTPS.
async function createTodo(title: string) {
  const res = await fetch('https://api.example.com/todos', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ title }),
  });
  if (!res.ok) {
    throw new Error(`HTTP ${res.status}`); // 4xx/5xx không tự reject
  }
  return res.json();
}
