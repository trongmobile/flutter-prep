Bạn sửa giá trị khởi tạo trong initState() (ví dụ count = 10 thay vì 0) rồi hot reload, nhưng màn hình không đổi. Vì sao?

  1. AHot reload chỉ áp dụng thay đổi trong main.dart
  2. BHot reload giữ State cũ nên initState() không chạy lại
  3. CThay đổi trong initState() chỉ có hiệu lực ở release mode
  4. DPhải chạy flutter pub get sau mỗi lần sửa code
Xem đáp án
Đáp án đúng: B
Hot reload chỉ chạy lại build() với code mới và giữ nguyên các object State, nên logic khởi tạo đã chạy rồi không chạy lại. Hot restart chạy lại từ main() và tạo State mới nên sẽ thấy thay đổi.
