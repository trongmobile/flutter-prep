Hiển thị hộp thoại xác nhận, bottom sheet và thông báo ngắn (SnackBar) trong Flutter thế nào? Làm sao nhận được kết quả người dùng chọn?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
showDialog<T> mở một hộp thoại (thường là AlertDialog) và trả về Future<T?> hoàn tất khi dialog đóng; đóng bằng Navigator.pop(context, giáTrị) thì giá trị đó là kết quả, còn bấm ra ngoài thì kết quả là null, nên hãy await rồi so sánh == true. showModalBottomSheet<T> hoạt động tương tự cho bottom sheet. SnackBar hiện qua ScaffoldMessenger.of(context).showSnackBar(...), hợp để báo kết quả ngắn và có thể kèm SnackBarAction (ví dụ 'Hoàn tác'). Sau mỗi await, widget có thể đã bị gỡ khỏi cây, nên kiểm tra if (!context.mounted) return; trước khi dùng context tiếp (lint use_build_context_synchronously nhắc điều này). Không dùng dialog cho nội dung dài hoặc nhiều bước, hãy dùng một màn hình riêng.
Future<void> confirmDelete(BuildContext context) async {
  final ok = await showDialog<bool>(
    context: context,
    builder: (ctx) => AlertDialog(
      title: const Text('Xoá sản phẩm?'),
      content: const Text('Thao tác này không thể hoàn tác.'),
      actions: [
        TextButton(onPressed: () => Navigator.pop(ctx, false), child: const Text('Huỷ')),
        FilledButton(onPressed: () => Navigator.pop(ctx, true), child: const Text('Xoá')),
      ],
    ),
  );
  if (ok != true || !context.mounted) return; // bấm ra ngoài thì ok == null
  ScaffoldMessenger.of(context).showSnackBar(const SnackBar(content: Text('Đã xoá')));
}
