App dùng SQLite qua Drift: danh sách giỏ hàng cần tự cập nhật khi dữ liệu trong DB đổi, và bản cập nhật sau thêm cột mới vào bảng orders cho người dùng đang có dữ liệu. Bạn dùng watch(), schemaVersion và MigrationStrategy thế nào, và kiểm thử migration ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Drift sinh code type-safe từ khai báo bảng và query. select(table).watch() trả về một Stream phát lại kết quả mỗi khi bảng liên quan bị ghi (insert, update, delete), nên UI chỉ cần StreamBuilder hoặc provider bọc stream mà không phải tự làm mới; cẩn thận query nặng vì stream chạy lại mỗi lần bảng đổi, nên dùng where hẹp và index. Ghi nhiều dòng thì gom trong transaction hoặc batch để nhanh và atomic. Về migration: tăng schemaVersion và khai báo MigrationStrategy(onUpgrade: (m, from, to) async { if (from < 2) await m.addColumn(orders, orders.note); }); dùng onCreate: (m) => m.createAll() cho cài mới và beforeOpen để bật PRAGMA foreign_keys = ON. Cột NOT NULL thêm mới cần giá trị mặc định cho các dòng cũ. Kiểm thử bằng công cụ schema của Drift (dart run drift_dev schema dump lưu schema của từng version, rồi SchemaVerifier tạo DB ở version cũ, chạy migration và so với schema mong đợi); thiếu đường nâng cấp hay làm mất dữ liệu người dùng chỉ lộ ra sau khi phát hành. Cho DB chạy ở isolate nền (NativeDatabase.createInBackground) để query nặng không chặn UI, và đừng xoá DB khi migration lỗi nếu đó là dữ liệu của người dùng.
@DriftDatabase(tables: [Orders])
class AppDatabase extends _$AppDatabase {
  AppDatabase(super.e);

  @override
  int get schemaVersion => 2;

  @override
  MigrationStrategy get migration => MigrationStrategy(
    onCreate: (m) => m.createAll(),
    onUpgrade: (m, from, to) async {
      if (from < 2) {
        await m.addColumn(orders, orders.note); // cột mới phải nullable hoặc có default cho dữ liệu cũ
      }
    },
    beforeOpen: (details) async {
      await customStatement('PRAGMA foreign_keys = ON');
    },
  );

  // UI tự cập nhật: stream phát lại mỗi khi bảng orders bị ghi
  Stream<List<Order>> watchOpenOrders() =>
      (select(orders)..where((o) => o.status.equals('open'))).watch();
}
