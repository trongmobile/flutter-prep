Đoạn code sau in ra những gì trên console?

func expensiveDump() -> String {
  print("dump")
  return "state"
}

func log(_ message: @autoclosure () -> String, enabled: Bool) {
  if enabled { print(message()) }
}

log(expensiveDump(), enabled: false)
log(expensiveDump(), enabled: true)
  1. Adump, dump rồi state, vì đối số luôn được tính trước khi vào hàm log
  2. BChỉ state, vì print bên trong expensiveDump() bị bỏ qua khi nằm trong autoclosure
  3. CLỗi compile vì phải viết log({ expensiveDump() }, enabled: false) mới truyền được closure
  4. Ddump rồi state, vì lần gọi đầu không bao giờ tính expensiveDump()
Xem đáp án
Đáp án đúng: D
@autoclosure tự bọc đối số thành closure và chỉ chạy khi hàm gọi message(). Lần gọi enabled: false không gọi message() nên expensiveDump() không chạy; lần enabled: true chạy đúng một lần nên in dump rồi state. Không có @autoclosure, đối số luôn được tính trước và sẽ in dump cả hai lần. Không cần viết { } khi dùng @autoclosure, đó chính là mục đích của nó (cùng cơ chế với && và ??).
