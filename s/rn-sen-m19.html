List dùng FlashList, mỗi item có nút 'Xem thêm' mở rộng nội dung bằng state cục bộ. Khi cuộn, user thấy cả những item chưa từng bấm cũng đang mở rộng. Nguyên nhân?

function ReviewItem({ review }: { review: Review }) {
  const [expanded, setExpanded] = useState(false);
  return (
    <Pressable onPress={() => setExpanded((e) => !e)}>
      <Text numberOfLines={expanded ? undefined : 3}>{review.body}</Text>
    </Pressable>
  );
}
  1. AnumberOfLines={undefined} bị FlashList cache theo layout của item trước đó
  2. BThiếu keyExtractor nên FlashList dùng index làm key và gộp state các item
  3. CFlashList tái sử dụng component đã cuộn khỏi màn hình, state cũ đi theo
  4. DuseState trong item của list được React chia sẻ giữa các item cùng loại

FlashList recycle view: thay vì unmount/mount, nó đem component đã cuộn khỏi viewport đi hiển thị dữ liệu khác, nên state cục bộ của item cũ vẫn còn. Cách sửa là đưa state ra ngoài theo id (ví dụ một Set các id đang mở) hoặc reset state khi item đổi dữ liệu.
