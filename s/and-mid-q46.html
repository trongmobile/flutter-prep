AndroidMiddleJetpack Compose & ViewCâu hỏi phỏng vấn

App có 40 màn XML, bạn muốn viết màn mới bằng Compose và nhúng dần: một Fragment XML chứa ComposeView, một item của RecyclerView là composable, và ngược lại một màn Compose cần nhúng WebView. Các cách interop là gì và có những bẫy nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Có hai chiều. View trong Compose: AndroidView(factory, update, onRelease); factory chạy một lần để tạo view, update chạy lại khi state mà nó đọc đổi (nơi đẩy dữ liệu mới vào view mà không tạo lại view), onRelease để dọn tài nguyên như WebView.destroy(). View có vòng đời riêng nên MapView hay player phải tự nối lifecycle (DisposableEffect kèm LifecycleEventObserver). Compose trong View: ComposeView đặt trong XML hoặc tạo bằng code với setContent. Quan trọng nhất là ViewCompositionStrategy, quyết định khi nào composition bị huỷ. Mặc định là DisposeOnDetachedFromWindowOrReleasedFromPool, phù hợp cho item RecyclerView vì view bị tái sử dụng. Mặc định composition bị huỷ mỗi khi view detach khỏi window, nên khi nhúng dần vào app cũ có thể mất state remember; trong Fragment hãy dùng DisposeOnViewTreeLifecycleDestroyed để composition gắn với vòng đời view của Fragment. Các bẫy khác: mỗi ComposeView cần android:id duy nhất để rememberSaveable khôi phục đúng; theme XML và theme Compose là hai hệ thống nên phải bọc AppTheme trong từng setContent; đừng lồng LazyColumn vào view cuộn dọc cùng hướng (chiều cao vô hạn gây crash). Chiến lược migrate: bắt đầu từ các màn lá, giữ nguyên ViewModel và StateFlow để chỉ đổi lớp UI, giữ Navigation Fragment cho đến khi đa số màn đã là Compose rồi mới chuyển navigation.
class ProfileFragment : Fragment() {
  private val viewModel: ProfileViewModel by viewModels()

  override fun onCreateView(inflater: LayoutInflater, container: ViewGroup?, state: Bundle?) =
    ComposeView(requireContext()).apply {
      // View của Fragment bị huỷ trước Fragment: gắn composition theo lifecycle của view
      setViewCompositionStrategy(ViewCompositionStrategy.DisposeOnViewTreeLifecycleDestroyed)
      setContent { AppTheme { ProfileScreen(viewModel) } }
    }
}

@Composable
fun WebPage(url: String, modifier: Modifier = Modifier) {
  AndroidView(
    modifier = modifier,
    factory = { context -> WebView(context) },   // tạo một lần
    update = { webView -> webView.loadUrl(url) }, // chạy lại khi url đổi
    onRelease = { webView -> webView.destroy() },
  )
}
