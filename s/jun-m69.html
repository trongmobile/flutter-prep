Thêm một plugin mới xong, build Android báo lỗi Manifest merger failed : uses-sdk:minSdkVersion 21 cannot be smaller than version 23 declared in library. Cách xử lý đúng là gì?

  1. AHạ minSdkVersion của plugin xuống 21 bằng cách sửa trực tiếp build.gradle trong thư mục pub cache
  2. BChạy flutter clean rồi flutter pub get để Gradle tự chọn lại phiên bản SDK tối thiểu phù hợp
  3. CNâng minSdk trong android/app/build.gradle lên ít nhất 23, hoặc chọn plugin khác hỗ trợ SDK thấp hơn
  4. DThêm quyền android.permission.INTERNET vào AndroidManifest.xml để plugin được phép đọc phần khai báo SDK của app
Xem đáp án
Đáp án đúng: C
Mỗi plugin khai báo minSdk thấp nhất mà code native của nó hỗ trợ; Gradle gộp manifest của app với các thư viện và báo lỗi khi minSdk của app thấp hơn yêu cầu của thư viện, vì thư viện có thể gọi API không có trên máy cũ. Cách đúng là nâng minSdk của app (ví dụ minSdk = 23 thay cho flutter.minSdkVersion trong android/app/build.gradle) và chấp nhận bỏ các máy cũ hơn, hoặc dùng plugin khác. Sửa file trong pub cache sẽ mất khi cập nhật package, flutter clean không đổi yêu cầu này, còn quyền INTERNET không liên quan. Dùng tools:overrideLibrary có thể làm hết lỗi nhưng app sẽ crash trên máy cũ.
