Test dưới đây chạy trong runTest mà không thay dispatcher nào. Nó chạy mất bao lâu?

class Repo {
  suspend fun load(): String = withContext(Dispatchers.Default) {
    delay(2_000)
    "data"
  }
}

@Test
fun load_returnsData() = runTest {
  assertEquals("data", Repo().load())
}
  1. AGần như tức thì, vì runTest tua nhanh mọi delay kể cả trong withContext(Dispatchers.Default)
  2. BFail ngay với IllegalStateException vì không được đổi dispatcher bên trong runTest
  3. CTreo tới khi quá timeout, vì scheduler ảo không bao giờ chạy code của Dispatchers.Default
  4. DKhoảng 2 giây thật, vì delay trên Dispatchers.Default chạy theo đồng hồ thật
Xem đáp án
Đáp án đúng: D
runTest chỉ tua nhanh delay chạy trên TestDispatcher của nó. withContext(Dispatchers.Default) chuyển sang dispatcher thật nên delay(2_000) chờ đủ 2 giây (delay lớn hơn có thể chạm timeout của test). Cách sửa: inject CoroutineDispatcher vào Repo rồi truyền StandardTestDispatcher(testScheduler) trong test để dùng chung virtual time.
