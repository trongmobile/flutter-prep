Khi nào nên dùng json_serializable thay vì tự viết fromJson/toJson? Cần thiết lập những gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Tự viết ổn với vài model nhỏ, nhưng khi model nhiều và lồng nhau thì rất dễ gõ sai key hoặc cast sai kiểu; json_serializable sinh code từ annotation nên an toàn và đồng bộ hơn. Thiết lập: thêm json_annotation vào dependencies, json_serializable và build_runner vào dev_dependencies; đánh dấu class bằng @JsonSerializable(), khai báo part 'user.g.dart'; và hai hàm trỏ tới _$UserFromJson/_$UserToJson, rồi chạy dart run build_runner build. Dùng @JsonKey(name: 'full_name') khi tên key trong JSON khác tên field Dart.
part 'user.g.dart';

@JsonSerializable()
class User {
  final int id;
  @JsonKey(name: 'full_name')
  final String fullName;
  User({required this.id, required this.fullName});
  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
  Map<String, dynamic> toJson() => _$UserToJson(this);
}
