Thêm phần tử vào mảng khai báo bằng let như đoạn code sau thì kết quả thế nào?

let fruits = ["Táo", "Cam"]
fruits.append("Xoài")
print(fruits.count)

  2. BIn ra 2 vì thao tác sửa trên hằng số bị bỏ qua
  3. CLỗi compile vì mảng khai báo bằng let không thể thay đổi
  4. DCrash lúc runtime vì mảng let có kích thước cố định

Đáp án đúng: C
Array là value type, nên let làm cả mảng bất biến và gọi method mutating như append là lỗi compile. Hiểu lầm hay gặp là nghĩ let chỉ cố định tham chiếu như với class; muốn thêm phần tử thì khai báo var fruits.
