React Native là gì? Khác gì với app hybrid dùng WebView (Ionic, Cordova) và với Flutter?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
React Native cho phép viết app bằng JavaScript/TypeScript với React, nhưng giao diện được dựng bằng view native thật của hệ điều hành: <View> thành UIView trên iOS và ViewGroup trên Android, <Text> thành UILabel/TextView. Code JS chạy trong một JS engine (Hermes) trên JS thread, tính ra cây UI rồi ra lệnh cho phía native tạo và cập nhật view, còn việc vẽ và cuộn do native đảm nhiệm nên cảm giác gần với app native. Khác app hybrid như Ionic hay Cordova: những app đó chạy giao diện HTML/CSS bên trong WebView và không có component native. Khác Flutter: Flutter tự vẽ mọi pixel bằng engine riêng (Skia/Impeller) và dùng ngôn ngữ Dart, còn React Native dùng component của nền tảng nên giao diện mang sẵn phong cách hệ thống và tận dụng được hệ sinh thái JavaScript/React. Đổi lại phải xử lý khác biệt giữa iOS và Android, và lớp giao tiếp JS với native (New Architecture dùng JSI thay cho bridge bất đồng bộ cũ). Khi cần tính năng native chưa có sẵn thì viết module bằng Swift/Kotlin.
