Người dùng bấm thêm nhiều sản phẩm vào giỏ rất nhanh. Rủi ro của cách cập nhật state dưới đây là gì?

private val _cart = MutableStateFlow(CartState())

fun add(item: Item) {
  viewModelScope.launch(Dispatchers.Default) {
    _cart.value = _cart.value.copy(items = _cart.value.items + item)
  }
}
  1. ANém exception vì MutableStateFlow chỉ được ghi trên main thread
  2. BKhông có rủi ro vì mọi thao tác trên MutableStateFlow đã atomic
  3. CUI nhận state trùng lặp nên danh sách bị nháy liên tục
  4. DMất cập nhật khi hai lần đọc–ghi đan xen; nên dùng update { }
Xem đáp án
Đáp án đúng: D
Đọc value rồi gán lại là hai bước tách rời; hai coroutine trên Dispatchers.Default có thể cùng đọc state cũ và một lần thêm bị ghi đè. _cart.update { it.copy(...) } dùng vòng compare-and-set nên an toàn; MutableStateFlow ghi được từ thread bất kỳ.
