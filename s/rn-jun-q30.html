Trên Android, ở màn Home bấm back là thoát app ngay, nhưng PM muốn "nhấn back hai lần để thoát" và khi bottom sheet tự dựng đang mở thì back phải đóng sheet trước. Bạn dùng BackHandler thế nào, và có bẫy gì khi dùng cùng React Navigation?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
BackHandler chỉ có tác dụng trên Android. Nút back cứng gọi các handler đã đăng ký theo thứ tự ngược lại (đăng ký sau chạy trước); handler nào trả về true thì chuỗi dừng, nếu không ai trả true thì hệ thống làm hành vi mặc định (quay lại hoặc thoát app). Nên nếu sheet đang mở thì đóng nó và trả true; lần back đầu ở Home hiện toast và trả true, lần thứ hai trong 2 giây thì trả false để thoát. Bẫy với React Navigation: màn nằm dưới trong stack hoặc tab khác đã mở vẫn đang mounted, đăng ký bằng useEffect thường thì handler của chúng chặn nhầm nút back ở màn khác. Hãy đăng ký trong useFocusEffect để chỉ có hiệu lực khi màn đang focus, và gỡ bằng sub.remove() trong cleanup. Với Modal có sẵn của RN thì dùng prop onRequestClose, không cần BackHandler.
function HomeScreen() {
  const [sheetOpen, setSheetOpen] = useState(false);
  const lastBackRef = useRef(0);

  useFocusEffect(
    useCallback(() => {
      const sub = BackHandler.addEventListener('hardwareBackPress', () => {
        if (sheetOpen) {
          setSheetOpen(false); // đóng sheet trước
          return true; // true: đã xử lý, không chạy handler nào khác
        }
        const now = Date.now();
        if (now - lastBackRef.current < 2000) return false; // false: để hệ thống thoát app
        lastBackRef.current = now;
        ToastAndroid.show('Nhấn back lần nữa để thoát', ToastAndroid.SHORT);
        return true;
      });
      return () => sub.remove(); // mất focus thì gỡ, không chặn back của màn khác
    }, [sheetOpen]),
  );

  return <HomeContent sheetOpen={sheetOpen} onCloseSheet={() => setSheetOpen(false)} />;
}
