Bạn viết unit test cho hàm fetchUser(completion:) chạy bất đồng bộ; test luôn pass dù cố tình sửa cho kết quả sai. Vì sao, và viết lại bằng XCTest thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Hàm test kết thúc ngay sau khi gọi fetchUser, trước khi completion kịp chạy, nên các XCTAssert bên trong completion không được đánh giá trong lúc test còn chạy và test pass một cách vô nghĩa. Cần tạo XCTestExpectation, gọi fulfill() trong completion, rồi wait(for:timeout:) để test chờ tới khi có kết quả, quá thời gian thì fail. Unit test cũng không nên gọi mạng thật: inject một API giả qua protocol trả dữ liệu cố định để test nhanh và ổn định. Nếu hàm đã viết bằng async thì đơn giản đánh dấu test là async và await trực tiếp.
func testFetchUserReturnsName() {
  let sut = UserService(api: StubAPI(name: "An")) // không gọi mạng thật
  let exp = expectation(description: "fetchUser hoàn tất")

  sut.fetchUser { result in
    XCTAssertEqual(try? result.get().name, "An")
    exp.fulfill()
  }

  wait(for: [exp], timeout: 1)
}
