Với store Zustand dưới đây, sau khi gọi setTheme('dark'), giá trị settings là gì?

type State = {
  settings: { theme: string; lang?: string };
  setTheme: (theme: string) => void;
};

const useStore = create<State>()((set) => ({
  settings: { theme: 'light', lang: 'vi' },
  setTheme: (theme) => set({ settings: { theme } }),
}));
  1. A{ theme: 'dark', lang: 'vi' }, vì Zustand tự merge sâu các object lồng nhau
  2. B{ theme: 'light', lang: 'vi' }, vì Zustand bỏ qua object mới có ít trường hơn
  3. C{ theme: 'dark' }, vì set chỉ merge nông ở cấp cao nhất nên lang biến mất
  4. DNém TypeError, vì set không nhận một object thiếu trường lang đã khai báo
Xem đáp án
Đáp án đúng: C
set của Zustand merge nông (shallow) phần state mới vào state cũ ở cấp cao nhất: settings bị thay nguyên bằng { theme: 'dark' }, nên lang biến mất. Với object lồng nhau phải tự trải rộng: set((s) => ({ settings: { ...s.settings, theme } })) (hoặc dùng middleware immer). Zustand không merge sâu và không bỏ qua cập nhật có ít trường hơn; lang là trường tuỳ chọn nên cũng không có lỗi nào. Muốn thay toàn bộ state thay vì merge thì truyền true ở tham số thứ hai của set.
