Đoạn code sau in ra gì và vào lúc nào?

const wait = (ms: number, v: string, fail = false) =>
  new Promise<string>((resolve, reject) =>
    setTimeout(() => (fail ? reject(new Error(v)) : resolve(v)), ms),
  );

async function main() {
  try {
    const r = await Promise.all([wait(300, 'a'), wait(100, 'b', true), wait(200, 'c')]);
    console.log(r);
  } catch (e) {
    console.log((e as Error).message);
  }
}
main();
  1. AIn b sau khoảng 300ms, khi mọi promise đã xong
  2. BIn b sau khoảng 100ms
  3. CIn ['a', undefined, 'c'] sau khoảng 300ms
  4. DIn ['a', 'c'] vì promise lỗi bị bỏ qua
Xem đáp án
Đáp án đúng: B
Promise.all reject ngay khi có promise đầu tiên reject (fail-fast), với lý do của chính promise đó, không chờ các promise còn lại. Muốn đợi đủ và biết kết quả của từng promise thì dùng Promise.allSettled.
