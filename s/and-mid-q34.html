AndroidMiddleTesting & CI/CDCâu hỏi phỏng vấn

Bạn muốn test tầng data chạy thật sự: Retrofit gọi đúng endpoint, parse JSON, xử lý 401, và DAO Room trả đúng dữ liệu. Làm sao test Retrofit mà không chạm server thật, test DAO nhanh, và loại test này bắt được những lỗi gì mà mock repository không bắt được?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mock repository chỉ kiểm tra logic phía trên; lỗi hay vỡ ở production lại nằm ở ranh giới: sai đường dẫn, sai tên field JSON, query SQL sai. Với mạng, dùng MockWebServer của OkHttp: khởi động server cục bộ trên cổng ngẫu nhiên, trỏ baseUrl của Retrofit vào server.url("/"), enqueue(MockResponse()...) để trả response theo thứ tự từng request, rồi gọi API thật qua Retrofit và assert; server.takeRequest() cho phép kiểm tra request đã gửi (path, method, header Authorization, body). Giả lập được các tình huống khó: 401 kèm body lỗi, JSON thiếu field hay sai kiểu, 500, mất kết nối (SocketPolicy.DISCONNECT_AT_START) hoặc không phản hồi (SocketPolicy.NO_RESPONSE) để test timeout. Nhớ tắt server ở @After. Với Room, tạo database in-memory (Room.inMemoryDatabaseBuilder) cho mỗi test: nhanh và không để lại dữ liệu; test được query, quan hệ (@Relation), ràng buộc unique, và migration (kèm MigrationTestHelper). Có thể chạy trên JVM với Robolectric hoặc trên thiết bị (androidTest); DAO trả Flow thì dùng runTest cùng Turbine. allowMainThreadQueries() chỉ nên dùng trong test, và phải close() database ở @After. Loại test này chậm hơn unit test thuần nên chỉ viết cho các đường quan trọng, nhưng nó bắt được lỗi hợp đồng API mà mock không thấy. Lưu ý API của MockResponse ở OkHttp 5 chuyển sang dạng builder.
class UserApiTest {
  private val server = MockWebServer()
  private lateinit var api: UserApi

  @Before
  fun setUp() {
    server.start()
    api = Retrofit.Builder()
      .baseUrl(server.url("/")) // trỏ Retrofit vào server cục bộ
      .addConverterFactory(Json.asConverterFactory("application/json".toMediaType()))
      .build()
      .create(UserApi::class.java)
  }

  @After
  fun tearDown() = server.shutdown()

  @Test
  fun parsesUserAndSendsCorrectRequest() = runTest {
    server.enqueue(MockResponse().setResponseCode(200).setBody("""{"id":"1","name":"An"}"""))

    val user = api.getUser("1")

    assertEquals("An", user.name)
    assertEquals("/users/1", server.takeRequest().path) // kiểm tra request thật sự đã gửi
  }

  @Test
  fun throwsHttpExceptionOn401() = runTest {
    server.enqueue(MockResponse().setResponseCode(401))
    assertFailsWith<HttpException> { api.getUser("1") }
  }
}

// Room: database in-memory cho mỗi test
@Before
fun createDb() {
  db = Room.inMemoryDatabaseBuilder(context, AppDatabase::class.java)
    .allowMainThreadQueries() // chỉ dùng trong test
    .build()
}

@After
fun closeDb() = db.close()
