Mạng yếu khiến request treo rất lâu. Bạn muốn fetch tự huỷ nếu sau 10 giây chưa xong. Cách nào đúng?

  1. ATruyền { timeout: 10000 } vào options của fetch
  2. BGọi fetch bên trong setTimeout(..., 10000)
  3. CDùng AbortController, hẹn giờ gọi abort()
  4. DĐặt header Connection: close cho request
Xem đáp án
Đáp án đúng: C
fetch không có option timeout, key lạ trong options bị bỏ qua. Cách chuẩn là tạo AbortController, hẹn setTimeout(() => controller.abort(), 10000), truyền signal vào fetch và clearTimeout khi xong; bọc fetch trong setTimeout chỉ làm request bắt đầu muộn 10 giây. Nếu dùng axios thì có sẵn option timeout.
