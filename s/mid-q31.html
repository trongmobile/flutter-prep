Cần upload ảnh (vài MB) từ điện thoại lên server, có thanh tiến độ, cho phép huỷ, và không làm tràn bộ nhớ. Bạn dùng Dio với FormData, onSendProgress và CancelToken thế nào, và xử lý các lỗi hay gặp ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Dùng FormData.fromMap với MultipartFile.fromFile(path, filename:): nó đọc file theo luồng khi gửi nên không nạp cả file vào RAM (khác MultipartFile.fromBytes). Tiến độ lấy từ onSendProgress: (sent, total) {...}; đẩy giá trị vào ValueNotifier<double> rồi hiển thị bằng ValueListenableBuilder để chỉ thanh tiến độ rebuild, và nhớ total có thể là -1 khi chưa biết. CancelToken gắn vào request, gọi cancelToken.cancel() khi người dùng bấm huỷ hoặc rời màn hình; request ném DioException có type == DioExceptionType.cancel, cần phân biệt để không hiện như lỗi. Nên nén và đổi kích thước ảnh trước khi gửi (ảnh chụp 12MP thường nặng vài MB, không cần gửi bản gốc), đặt sendTimeout đủ dài cho mạng yếu. Mạng chập chờn cần phân biệt lỗi tạm thời (timeout, mất kết nối) để cho thử lại với backoff, và file lớn nên chia chunk hoặc dùng giao thức resumable để không gửi lại từ đầu. Với upload dài khi app ra nền, Dio trong Dart không đảm bảo sống khi app bị hệ thống tạm dừng, cần plugin dùng cơ chế native (WorkManager, URLSession nền). Phía server cần idempotency hoặc id upload để retry không tạo bản trùng.
class UploadController {
  final progress = ValueNotifier<double>(0);
  CancelToken? _cancelToken;

  Future<String?> upload(File file) async {
    _cancelToken = CancelToken();
    final form = FormData.fromMap({
      'file': await MultipartFile.fromFile(file.path, filename: 'photo.jpg'), // đọc theo luồng, không nạp cả file vào RAM
    });
    try {
      final res = await dio.post<Map<String, dynamic>>(
        '/uploads',
        data: form,
        cancelToken: _cancelToken,
        onSendProgress: (sent, total) {
          if (total > 0) progress.value = sent / total;
        },
      );
      return res.data?['url'] as String?;
    } on DioException catch (e) {
      if (e.type == DioExceptionType.cancel) return null; // người dùng huỷ: không phải lỗi
      rethrow;
    }
  }

  void cancel() => _cancelToken?.cancel('người dùng huỷ');
}

// UI: chỉ thanh tiến độ rebuild
ValueListenableBuilder<double>(
  valueListenable: controller.progress,
  builder: (_, value, __) => LinearProgressIndicator(value: value),
)
