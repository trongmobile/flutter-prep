Activity đăng ký hai observer vào cùng một Lifecycle, theo thứ tự first rồi second. Người dùng bấm Home (Activity đi qua onStop) rồi mở lại app (đi qua onStart). Log của hai observer theo thứ tự nào?

class LogObserver(private val name: String) : DefaultLifecycleObserver {
  override fun onStart(owner: LifecycleOwner) { Log.d("Obs", "$name start") }
  override fun onStop(owner: LifecycleOwner) { Log.d("Obs", "$name stop") }
}

override fun onCreate(savedInstanceState: Bundle?) {
  super.onCreate(savedInstanceState)
  lifecycle.addObserver(LogObserver("first"))
  lifecycle.addObserver(LogObserver("second"))
}
  1. Afirst stop, second stop, rồi first start, second start
  2. Bfirst stop, second stop, rồi second start, first start
  3. Csecond stop, first stop, rồi first start, second start
  4. Dsecond stop, first stop, rồi second start, first start
Xem đáp án
Đáp án đúng: C
LifecycleRegistry giữ observer theo thứ tự đăng ký và xử lý như một ngăn xếp: khi đi lên (ON_CREATE, ON_START, ON_RESUME) nó gọi từ observer đăng ký trước tới sau, còn khi đi xuống (ON_PAUSE, ON_STOP, ON_DESTROY) nó gọi ngược lại, từ observer đăng ký sau tới trước. Nhờ vậy cái được thiết lập sau (có thể phụ thuộc vào cái trước) sẽ được dọn dẹp trước, giống thứ tự dựng và huỷ object.
