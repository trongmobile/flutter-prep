Trong project React Native CLI, bạn vừa cài một thư viện có native code (ví dụ camera) và app báo không tìm thấy native module. Cần làm gì?

  1. ANhấn r trong terminal Metro để reload bundle
  2. BBuild lại app (iOS chạy pod install trước)
  3. CChạy Metro với --reset-cache là đủ
  4. DBật lại Fast Refresh trong Dev Menu
Xem đáp án
Đáp án đúng: B
Native code chỉ vào được app khi build lại binary: autolinking chạy lúc build, iOS còn cần pod install. Reload, xoá cache Metro hay Fast Refresh đều chỉ thay đổi phần JavaScript.
