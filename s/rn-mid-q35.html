Tính năng chạy tốt khi debug nhưng crash hoặc hành xử khác ở bản release: ảnh không hiện, app chậm vì console.log, thư viện native báo ClassNotFoundException. Những khác biệt nào giữa debug và release trong React Native hay gây ra điều này, và bạn kiểm tra thế nào trước khi phát hành?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Debug chạy bundle lấy từ Metro (có dev server, __DEV__ = true, không minify, thêm các kiểm tra và cảnh báo của React, Strict Mode chạy effect hai lần); release dùng bundle đã minify, biên dịch thành bytecode Hermes đóng gói sẵn trong app, __DEV__ = false và loại bỏ các nhánh if (__DEV__). Các nguyên nhân hay gặp: một là trên Android, R8/ProGuard ở release thu nhỏ và đổi tên lớp, xoá các lớp được dùng qua reflection (SDK native, thư viện serialize), gây ClassNotFoundException hay NoSuchMethodError chỉ ở release; sửa bằng keep rule theo hướng dẫn của thư viện. Hai là phụ thuộc vào môi trường dev: URL localhost hoặc 10.0.2.2, HTTP cleartext (Android chặn cleartext với app target API 28 trở lên, iOS App Transport Security chặn HTTP), chứng chỉ tự ký. Ba là asset và đường dẫn: tên file khác hoa thường (Mac không phân biệt, CI Linux thì có), require ảnh động. Bốn là biến môi trường hay config khác giữa các profile (key API, URL) chưa có trong build release. Năm là khối lượng console.log lớn làm chậm JS thread ở release (có thể bỏ bằng babel-plugin-transform-remove-console), và lỗi runtime ở release không hiện redbox mà chỉ có trong Logcat hay Console. Sáu là timing: animation và race condition lộ ra vì release chạy nhanh hơn. Cách phòng: chạy định kỳ build release thật (--mode release hoặc --configuration Release, hay eas build --profile preview) trên máy thật, đưa vào QA và CI chứ không chỉ test debug; có source map và Sentry để đọc crash ở release; dùng adb logcat hoặc Console.app để xem log; và có smoke test E2E chạy trên bản release.
// babel.config.js: bỏ console.log ở bản production để không làm chậm JS thread
module.exports = (api) => {
  api.cache(true);
  return {
    presets: ['module:@react-native/babel-preset'],
    env: {
      // Metro build release đặt NODE_ENV=production
      production: { plugins: ['transform-remove-console'] }, // babel-plugin-transform-remove-console
    },
  };
};
