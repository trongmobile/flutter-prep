Ở màn thanh toán, mạng chập chờn: người dùng bấm 'Đặt hàng', request treo 10 giây nên họ bấm lại, kết quả là hai đơn trùng. Có lúc app báo timeout nhưng server đã tạo đơn. Bạn thiết kế phía Android và API thế nào để không bao giờ tạo đơn trùng?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Chỉ chặn ở UI là chưa đủ, vì phải xử lý cả trường hợp 'không rõ kết quả'. Lớp UI: ViewModel giữ state Idle → Submitting → Success/Failed và bỏ qua lệnh đặt hàng khi đang Submitting (đừng chỉ dựa vào việc disable nút, vì hai lần bấm có thể tới trước khi UI kịp vẽ lại). Lớp API: dùng idempotency key. Client sinh một UUID cho mỗi ý định đặt hàng (không phải mỗi lần bấm hay mỗi lần retry), gửi qua header Idempotency-Key; server lưu key cùng kết quả, nhận lại cùng key thì trả về đúng đơn đã tạo thay vì tạo mới. Key phải sống qua xoay máy và process death nên lưu trong SavedStateHandle (hoặc Room nếu luồng kéo dài). Timeout không có nghĩa là thất bại: cho thử lại với cùng key, hoặc hỏi server trạng thái theo key trước khi cho đặt lại. Chỉ tự retry lỗi mạng và 5xx, kèm backoff có jitter; không retry 4xx. Nếu đơn phải được gửi đi kể cả khi người dùng tắt app thì đẩy vào WorkManager với unique work theo key. Với thanh toán thật, cổng thanh toán cũng cần idempotency key riêng. Nguyên tắc: client chỉ giảm khả năng trùng, server mới là nơi bảo đảm.
interface OrderApi {
  @POST("orders")
  suspend fun place(@Header("Idempotency-Key") key: String, @Body body: OrderRequest): OrderDto
}

@HiltViewModel
class CheckoutViewModel @Inject constructor(
  private val repo: OrderRepository,
  private val saved: SavedStateHandle,
) : ViewModel() {
  private val _state = MutableStateFlow<CheckoutState>(CheckoutState.Idle)
  val state = _state.asStateFlow()

  // Sinh một lần cho mỗi ý định đặt hàng, sống sót qua process death
  private val key: String = saved["key"] ?: UUID.randomUUID().toString().also { saved["key"] = it }

  fun placeOrder(cart: Cart) {
    if (_state.value is CheckoutState.Submitting) return // bấm lần hai bị bỏ qua
    _state.value = CheckoutState.Submitting
    viewModelScope.launch {
      _state.value = repo.place(cart, key).fold(
        onSuccess = { CheckoutState.Success(it.id) },
        onFailure = { CheckoutState.Failed(it) }, // cho thử lại với CÙNG key
      )
    }
  }
}
