UICollectionView khác UITableView ở điểm nào? Khi nào bạn chọn cái nào, và UICollectionViewFlowLayout dùng để làm gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Cả hai đều là danh sách có data source, delegate và cơ chế tái sử dụng cell. UITableView chỉ có một cột dọc, mỗi dòng rộng hết chiều ngang, hợp với danh sách và màn cài đặt. UICollectionView tách việc bố trí ra khỏi view bằng một đối tượng layout, nên làm được lưới, cuộn ngang, section nhiều hình dạng, header/footer tuỳ biến. Layout đơn giản nhất là UICollectionViewFlowLayout: xếp item thành hàng, hết chỗ thì xuống dòng, chỉnh bằng itemSize (mặc định chỉ 50×50), minimumInteritemSpacing, minimumLineSpacing, sectionInset, scrollDirection; bố cục phức tạp hơn thì dùng UICollectionViewCompositionalLayout (iOS 13+). Danh sách một cột thì UITableView là đủ; cần lưới hoặc bố cục tự do thì chọn UICollectionView (từ iOS 14 danh sách một cột cũng làm được bằng list configuration của collection view). Bẫy: phải register cell trước khi dequeue; tính itemSize phải trừ cả inset và khoảng cách giữa các cột, nếu không tổng chiều rộng vượt bề rộng thì item bị rớt xuống dòng và lưới lệch; xoay màn hình thì cần invalidateLayout() để tính lại.
final class GridViewController: UIViewController {
    private let columns: CGFloat = 3
    private let spacing: CGFloat = 8

    private lazy var collectionView: UICollectionView = {
        let layout = UICollectionViewFlowLayout()
        layout.scrollDirection = .vertical
        layout.minimumInteritemSpacing = spacing
        layout.minimumLineSpacing = spacing
        layout.sectionInset = UIEdgeInsets(top: spacing, left: spacing, bottom: spacing, right: spacing)

        let view = UICollectionView(frame: .zero, collectionViewLayout: layout)
        view.register(UICollectionViewCell.self, forCellWithReuseIdentifier: "PhotoCell")
        view.delegate = self
        // dataSource: numberOfItemsInSection / cellForItemAt, dequeue cell giống UITableView
        return view
    }()
}

extension GridViewController: UICollectionViewDelegateFlowLayout {
    func collectionView(_ collectionView: UICollectionView,
                        layout collectionViewLayout: UICollectionViewLayout,
                        sizeForItemAt indexPath: IndexPath) -> CGSize {
        // 3 cột: trừ lề trái/phải và 2 khoảng cách giữa các cột
        let totalSpacing = spacing * (columns + 1)
        let side = floor((collectionView.bounds.width - totalSpacing) / columns)
        return CGSize(width: side, height: side)
    }
}
