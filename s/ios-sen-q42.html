Time Profiler cho thấy hàm parse tin nhắn và tính layout chạy hàng chục nghìn lần mỗi giây, còn swift_retain, swift_release và swift_beginAccess chiếm phần lớn thời gian. Bạn tối ưu code Swift ở hot path thế nào, và đo ra sao để biết chắc mình tối ưu đúng chỗ?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đo trước, và chỉ trên bản Release chạy máy thật: Debug (-Onone) không inline hay specialize nên số liệu vô nghĩa. Time Profiler với "Invert Call Tree" cho thấy hàm tốn nhất, Allocations cho thấy số lần cấp phát; nếu retain/release hoặc swift_allocObject đứng đầu thì đó là ARC traffic và allocation. Các hướng thường hiệu quả: (1) existential any Shape phải đóng hộp giá trị (lớn hơn vùng đệm inline thì cấp phát heap) và gọi qua witness table; generic <S: Shape> hoặc some Shape được specialize nên gọi tĩnh và inline được, nhưng chỉ khi compiler thấy được thân hàm, tức cùng module hoặc có @inlinable (đổi lại thân hàm trở thành một phần ABI công khai, chỉ nên dùng cho code ổn định). (2) Class mặc định gọi method qua vtable; final và private cho phép compiler gọi trực tiếp, và còn có thể giảm các lần kiểm tra exclusivity động (swift_beginAccess) trên property của class. (3) Struct nhỏ toàn kiểu giá trị thì không có refcount, nhưng struct chứa nhiều String, mảng hay tham chiếu class vẫn retain/release từng field mỗi lần copy. (4) Copy-on-write: sửa mảng khi buffer còn được biến khác tham chiếu thì Swift sao chép cả buffer; tránh giữ bản sao thừa và dùng reserveCapacity. (5) Đánh chỉ số String theo ký tự là O(n), nên dùng utf8 view hoặc Substring. -Osize thay cho -O giảm kích thước nhờ inline ít hơn nên có thể chậm hơn ở hot path; hãy quyết định theo số đo chứ không theo cảm giác. Bẫy lớn nhất là tối ưu chỗ không nóng và làm code khó đọc.
protocol Shape { func area() -> Double }

// Chậm hơn: existential, mỗi phần tử đóng hộp và gọi qua witness table
func total(_ shapes: [any Shape]) -> Double {
  shapes.reduce(0) { $0 + $1.area() }
}

// Nhanh hơn khi mọi phần tử cùng kiểu: generic được specialize, gọi tĩnh và inline được
func total<S: Shape>(_ shapes: [S]) -> Double {
  var sum = 0.0
  for shape in shapes { sum += shape.area() }
  return sum
}

// final + private giúp compiler bỏ dynamic dispatch và bớt kiểm tra exclusivity
final class MessageLayouter {
  private var cache: [Int: CGSize] = [:]

  func size(for id: Int) -> CGSize { cache[id, default: .zero] }
}
