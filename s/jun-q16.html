MediaQuery.sizeOf(context) và LayoutBuilder khác nhau thế nào khi làm giao diện responsive?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
MediaQuery.sizeOf trả về kích thước của cả cửa sổ ứng dụng, hợp với quyết định ở cấp màn hình như hiện NavigationRail hay NavigationBar. LayoutBuilder đưa ra constraints mà widget cha thực sự cấp cho widget đó, nên hợp với component tái sử dụng (một card đặt trong cột hẹp hay full màn hình đều tự đổi bố cục). Nên dùng MediaQuery.sizeOf(context) thay vì MediaQuery.of(context).size vì nó chỉ rebuild khi kích thước đổi, không rebuild khi các giá trị khác như viewInsets lúc bật bàn phím thay đổi.
LayoutBuilder(
  builder: (context, constraints) {
    if (constraints.maxWidth >= 600) {
      return const TwoColumnLayout();
    }
    return const SingleColumnLayout();
  },
)
