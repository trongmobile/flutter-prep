Thiết lập Room cơ bản gồm những thành phần nào? Vì sao gọi DAO đồng bộ trên main thread thì app crash?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Ba thành phần: @Entity mô tả bảng, @Dao khai báo các thao tác (@Query, @Insert, @Update, @Delete), và một class abstract kế thừa RoomDatabase gắn @Database(entities = [...], version = ...) để cung cấp DAO; database nên tạo một instance dùng chung vì khởi tạo tốn kém. Room kiểm tra câu SQL lúc compile nên sai tên bảng, tên cột là lỗi build chứ không đợi tới runtime. Mặc định Room ném IllegalStateException khi chạy query đồng bộ trên main thread, vì truy cập đĩa có thể chặn UI lâu và gây ANR; cách đúng là khai báo DAO suspend hoặc trả về Flow để Room tự chạy ở background. allowMainThreadQueries() chỉ nên dùng trong test.
@Entity(tableName = "notes")
data class Note(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    val title: String,
    val updatedAt: Long
)

@Dao
interface NoteDao {
    @Query("SELECT * FROM notes ORDER BY updatedAt DESC")
    fun observeAll(): Flow<List<Note>> // tự phát lại khi bảng đổi

    @Insert(onConflict = OnConflictStrategy.REPLACE)
    suspend fun upsert(note: Note)
}
