Màn hình Home gọi 3 API song song (banner, danh mục, sản phẩm gợi ý). Chỉ cần API banner lỗi là cả màn hình trắng. Bạn dùng Promise.all hay Promise.allSettled, và vì sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Promise.all reject ngay khi một promise reject (fail-fast), nên chỉ cần banner lỗi là mất luôn dữ liệu hai API kia dù chúng thành công; nó hợp khi các kết quả phụ thuộc nhau, thiếu một cái là vô nghĩa. Promise.allSettled chờ tất cả xong và trả về mảng { status: 'fulfilled', value } hoặc { status: 'rejected', reason }, nên từng khu vực tự hiển thị dữ liệu hoặc trạng thái lỗi riêng. Cả hai đều chạy các request song song, khác với await lần lượt từng cái làm tổng thời gian cộng dồn. Lưu ý Promise.all reject sớm không huỷ các request còn lại, chúng vẫn chạy tới khi xong.
const [banner, categories, products] = await Promise.allSettled([
  api.getBanner(),
  api.getCategories(),
  api.getRecommended(),
]);

setBanner(banner.status === 'fulfilled' ? banner.value : null);
setCategories(categories.status === 'fulfilled' ? categories.value : []);
setProductsError(products.status === 'rejected' ? products.reason : null);
