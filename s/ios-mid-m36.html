Theo Clean Architecture, protocol OrderRepository và class RemoteOrderRepository (gọi API) nên đặt ở tầng nào?

  1. ACả hai ở Data, Domain import Data để dùng
  2. BProtocol ở Domain, implementation ở Data
  3. CProtocol ở Data, implementation ở Domain
  4. DCả hai ở Presentation, cạnh ViewModel
Xem đáp án
Đáp án đúng: B
Dependency rule: tầng trong (Domain) không phụ thuộc tầng ngoài. Domain định nghĩa protocol mà use case cần, Data implement nó (dependency inversion), nhờ vậy Domain không biết gì về URLSession hay Core Data và test được bằng fake.
