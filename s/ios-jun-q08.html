Phân biệt serial queue với concurrent queue, sync với async trong GCD. Cần một logger được gọi từ nhiều thread trong app thì bạn thiết kế thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Serial hay concurrent là tính chất của queue: serial chạy từng task một theo thứ tự FIFO, concurrent cho phép nhiều task chạy song song dù vẫn bắt đầu theo thứ tự đưa vào. sync hay async là cách gọi: sync chặn thread hiện tại tới khi task chạy xong, async đưa task vào queue rồi đi tiếp ngay. DispatchQueue.main là serial, DispatchQueue.global() là concurrent. Với logger, dùng một serial queue riêng: ghi bằng async để nơi gọi (kể cả main thread) không bị chặn, đọc bằng sync khi cần lấy kết quả; mọi truy cập đi qua cùng một queue nên không có data race và log giữ đúng thứ tự.
final class Logger {
  private let queue = DispatchQueue(label: "com.app.logger") // serial mặc định
  private var lines: [String] = []

  func log(_ message: String) {
    queue.async { self.lines.append(message) } // không chặn nơi gọi
  }

  func allLines() -> [String] {
    queue.sync { lines } // đọc cũng đi qua queue
  }
}
