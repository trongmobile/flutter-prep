Đoạn code dưới in ra các dòng nào, theo thứ tự?

final class Frame {
  let id: Int
  init(_ id: Int) { self.id = id }
  deinit { print("deinit", id) }
}

var frames: [Frame]? = (0..<3).map(Frame.init)
var recent: ArraySlice<Frame>? = frames![0..<1]
frames = nil
print("A")
recent = nil
print("B")
  1. Adeinit 1, deinit 2, A, deinit 0, B
  2. BA, deinit 0, deinit 1, deinit 2, B
  3. Cdeinit 0, deinit 1, deinit 2, A, B
  4. DA, deinit 0, B, còn Frame 1 và 2 bị rò rỉ
Xem đáp án
Đáp án đúng: B
ArraySlice không copy phần tử mà chia sẻ buffer với mảng gốc: giữ recent (chỉ một phần tử) vẫn giữ sống cả buffer nên cả ba Frame còn sống sau frames = nil, và A in trước. Khi recent = nil, buffer được giải phóng và cả ba deinit chạy (theo thứ tự 0, 1, 2) trước B. Tài liệu Swift cảnh báo không nên lưu slice lâu dài; muốn thả phần còn lại thì copy sang Array(frames[0..<1]) (tương tự Substring với String).
