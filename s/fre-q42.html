Làm sao thêm font tuỳ chỉnh và một file dữ liệu JSON vào app Flutter, đặt font mặc định cho cả app và đọc file JSON lúc chạy? Vì sao sửa pubspec.yaml xong mà font hay file vẫn không được nhận?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Font: đặt file .ttf hoặc .otf trong dự án và khai báo trong mục fonts: của pubspec.yaml với family cùng danh sách asset kèm weight và style cho từng biến thể (Regular, Bold, Italic); sau đó dùng TextStyle(fontFamily: 'Inter', fontWeight: FontWeight.w700) hoặc đặt font mặc định cho cả app bằng ThemeData(fontFamily: 'Inter'). Dữ liệu tĩnh như JSON cấu hình thì khai báo trong assets: rồi đọc lúc chạy bằng rootBundle.loadString('assets/data/config.json') (bất đồng bộ) và jsonDecode. Các lỗi hay gặp: YAML nhạy cảm với thụt lề (dùng 2 dấu cách, không dùng tab) nên sai một cấp là Flutter không nhận; tên family trong code không khớp với pubspec.yaml; đường dẫn sai chữ hoa chữ thường gây lỗi trên Android và Linux dù chạy được trên macOS; và thiếu một biến thể (không khai báo bản Bold thì Flutter tự 'làm đậm giả', nhìn xấu hơn). Sau khi sửa pubspec.yaml hãy chạy flutter pub get rồi chạy lại app (hot restart hoặc chạy lại hẳn) vì tài nguyên mới không có hiệu lực chỉ bằng hot reload. Font có dung lượng đáng kể (nhất là font tiếng Việt đầy đủ dấu) nên chỉ đóng gói các weight thật sự dùng, hoặc dùng package google_fonts (tải lúc chạy và cache) khi chấp nhận phụ thuộc mạng ở lần đầu.
# pubspec.yaml
flutter:
  assets:
    - assets/data/config.json
  fonts:
    - family: Inter
      fonts:
        - asset: assets/fonts/Inter-Regular.ttf
        - asset: assets/fonts/Inter-Bold.ttf
          weight: 700
        - asset: assets/fonts/Inter-Italic.ttf
          style: italic

// Font mặc định cho cả app
MaterialApp(theme: ThemeData(fontFamily: 'Inter'), home: const HomePage());

// Đọc file JSON đã khai báo trong assets
Future<Map<String, dynamic>> loadConfig() async {
  final raw = await rootBundle.loadString('assets/data/config.json');
  return jsonDecode(raw) as Map<String, dynamic>;
}
