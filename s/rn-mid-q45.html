App lưu giỏ hàng và cài đặt bằng Zustand persist với AsyncStorage. Mỗi lần mở app, người dùng thấy giỏ hàng trống một nhịp rồi mới có dữ liệu, và sau khi bản mới đổi cấu trúc store thì máy đang chạy bản cũ lên bản mới bị crash. MMKV khác AsyncStorage ra sao, và bạn xử lý hai lỗi này thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
AsyncStorage bất đồng bộ (đọc qua native module, trả Promise) nên rehydrate xong sau lần render đầu; lần render đầu dùng state mặc định nên giao diện nhấp nháy. Cách xử lý: giữ splash (SplashScreen.preventAutoHideAsync) hoặc hiện loading cho tới khi hydrate xong (persist.hasHydrated(), onFinishHydration; Redux Persist có PersistGate). MMKV (react-native-mmkv) đọc ghi đồng bộ qua JSI, rất nhanh, nên dùng làm storage cho persist thì state có sẵn ngay khi tạo store và không còn flicker. Đánh đổi: là native module (cần build lại hay dev client), đọc đồng bộ trên JS thread nên không hợp để nhét blob rất lớn, không phải database (không query), và dù có tuỳ chọn mã hoá thì vẫn không thay Keychain cho bí mật như token. Lỗi crash đến từ việc state cũ được merge vào store có cấu trúc mới: thiếu field hoặc sai kiểu. Dùng version và migrate(persistedState, version), mỗi lần đổi cấu trúc thì tăng version và chuyển dữ liệu cũ sang dạng mới (đổi tên field, đặt giá trị mặc định). Chỉ persist phần cần thiết bằng partialize (không lưu dữ liệu từ server vì đã có TanStack Query, không lưu hàm hay dữ liệu dẫn xuất), và bọc việc đọc để dữ liệu hỏng rơi về giá trị mặc định thay vì làm app chết.
import { create } from 'zustand';
import { createJSONStorage, persist } from 'zustand/middleware';
import { MMKV } from 'react-native-mmkv';

const mmkv = new MMKV(); // API khác nhau giữa các phiên bản (bản mới hơn dùng createMMKV và remove)
const mmkvStorage = {
  getItem: (key: string) => mmkv.getString(key) ?? null, // đồng bộ, không cần await
  setItem: (key: string, value: string) => mmkv.set(key, value),
  removeItem: (key: string) => mmkv.delete(key),
};

export const useCart = create<CartState>()(
  persist(
    (set) => ({
      items: [],
      add: (p: Product) => set((s) => ({ items: [...s.items, { ...p, qty: 1 }] })),
    }),
    {
      name: 'cart',
      version: 2,
      storage: createJSONStorage(() => mmkvStorage),
      partialize: (s) => ({ items: s.items }), // chỉ lưu dữ liệu, không lưu hàm
      migrate: (persisted: any, version) => {
        if (version < 2) {
          // v1 chưa có qty: bổ sung giá trị mặc định thay vì để undefined chạy vào UI
          return { ...persisted, items: (persisted.items ?? []).map((i: any) => ({ ...i, qty: i.qty ?? 1 })) };
        }
        return persisted;
      },
    },
  ),
);
