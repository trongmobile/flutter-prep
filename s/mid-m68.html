Class Debouncer chạy action sau 300ms kể từ lần gọi cuối. Cách viết unit test nào chạy gần như tức thì và ổn định, không phụ thuộc đồng hồ thật?

class Debouncer {
  Debouncer(this.delay);
  final Duration delay;
  Timer? _timer;

  void run(void Function() action) {
    _timer?.cancel();
    _timer = Timer(delay, action);
  }
}
  1. AGọi run, rồi await Future.delayed(const Duration(milliseconds: 350)) trong test và kiểm tra kết quả
  2. BBọc test trong fakeAsync của package fake_async và dùng async.elapse(...) để tua thời gian giả
  3. CGọi sleep(const Duration(milliseconds: 350)) để Dart VM chờ đủ thời gian rồi mới kiểm tra kết quả
  4. DĐặt delay bằng Duration.zero trong test rồi kiểm tra ngay, vì khi đó Timer chạy đồng bộ lập tức
Xem đáp án
Đáp án đúng: B
fakeAsync chạy code trong một Zone có đồng hồ giả: Timer và Future.delayed không dựa vào thời gian thật mà chạy khi bạn tua bằng async.elapse(Duration), nên test debounce 300ms hoàn thành trong vài mili giây và cho kết quả xác định (ví dụ gọi run, elapse(200ms), gọi run lần nữa rồi elapse(299ms) thì action vẫn chưa chạy). await Future.delayed(350ms) và sleep làm test chậm và dễ flaky khi máy tải nặng (sleep còn chặn cả isolate); Timer(Duration.zero) vẫn chạy bất đồng bộ ở vòng sự kiện sau chứ không đồng bộ. Trong testWidgets đồng hồ giả đã có sẵn, dùng tester.pump(Duration).
