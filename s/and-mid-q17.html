Bạn thêm cột avatar_url vào bảng users của Room và tăng version database. Bản release lên, một số người dùng bị crash ngay khi mở app. Vì sao, và quy trình migration đúng là gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Khi version tăng mà Room không tìm thấy đường migrate từ version cũ trên máy người dùng, nó ném IllegalStateException báo thiếu migration; còn nếu đổi schema mà quên tăng version thì Room báo không xác minh được data integrity. Cách đúng: viết Migration(1, 2) với câu ALTER TABLE tương ứng, hoặc dùng @AutoMigration cho thay đổi đơn giản (cần exportSchema = true, cấu hình thư mục schema và commit file schema JSON vào git). fallbackToDestructiveMigration() chỉ chấp nhận khi dữ liệu là cache tải lại được, vì nó xoá sạch database. Cuối cùng viết test với MigrationTestHelper để chạy migration trên database ở version cũ, đảm bảo đi được từ mọi version mà người dùng có thể còn giữ.
val MIGRATION_1_2 = object : Migration(1, 2) {
  override fun migrate(db: SupportSQLiteDatabase) {
    db.execSQL("ALTER TABLE users ADD COLUMN avatar_url TEXT")
  }
}

Room.databaseBuilder(context, AppDatabase::class.java, "app.db")
  .addMigrations(MIGRATION_1_2)
  .build()
