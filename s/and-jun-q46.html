Bạn viết @Query có ORDER BY, LIKE và một @Transaction xoá rồi chèn lại, nhưng chỉ phát hiện sai khi chạy app. Bạn test DAO của Room thế nào để chắc query và transaction đúng, và vì sao nên dùng in-memory database thay vì mock DAO?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mock DAO chỉ chứng minh bạn có gọi hàm; thứ dễ sai lại nằm ở câu SQL, ánh xạ cột-entity và transaction, những thứ chỉ kiểm được trên SQLite thật. Vì vậy test DAO là instrumented test (src/androidTest, AndroidJUnit4) hoặc Robolectric trong src/test, tạo database bằng Room.inMemoryDatabaseBuilder(context, AppDatabase::class.java): database nằm trong RAM, mỗi test dựng cái mới nên không dính dữ liệu của test khác và biến mất sau db.close(); allowMainThreadQueries() chỉ nên dùng trong test cho gọn. Cách kiểm: insert dữ liệu mẫu rồi gọi query, so thứ tự ORDER BY, mẫu LIKE và trường hợp rỗng (SQLite chỉ coi LIKE là không phân biệt hoa thường với ký tự ASCII, nên chữ có dấu như Á và á bị coi là khác nhau, chạy test mới lộ ra). Hàm suspend dùng runTest; Flow dùng first() hoặc Turbine (awaitItem()), insert thêm rồi kiểm Flow phát lại; với @Transaction thì cố tình ném lỗi giữa chừng và kiểm dữ liệu cũ còn nguyên (rollback). Đừng dùng Thread.sleep để chờ Flow.
@RunWith(AndroidJUnit4::class)
class OrderDaoTest {
    private lateinit var db: AppDatabase
    private lateinit var dao: OrderDao

    @Before
    fun setUp() {
        db = Room.inMemoryDatabaseBuilder(
            ApplicationProvider.getApplicationContext(),
            AppDatabase::class.java,
        ).allowMainThreadQueries().build()
        dao = db.orderDao()
    }

    @After
    fun tearDown() = db.close()

    @Test
    fun search_returnsMatchingOrdersNewestFirst() = runTest {
        dao.insertAll(
            Order(id = 1, title = "Áo thun", createdAt = 100),
            Order(id = 2, title = "Áo khoác", createdAt = 200),
            Order(id = 3, title = "Mũ", createdAt = 300),
        )

        val result = dao.search("%Áo%")

        assertEquals(listOf(2L, 1L), result.map { it.id })
    }

    @Test
    fun observeAll_emitsAgainAfterInsert() = runTest {
        dao.observeAll().test {
            assertEquals(0, awaitItem().size)
            dao.insertAll(Order(id = 1, title = "Áo", createdAt = 1))
            assertEquals(1, awaitItem().size)
            cancelAndIgnoreRemainingEvents()
        }
    }
}
