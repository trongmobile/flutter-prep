Đồng nghiệp hỏi @ViewBuilder thực chất là gì mà trong VStack { ... } viết được nhiều view liền nhau, có cả if/switch mà không cần return. Result builder hoạt động thế nào, và bạn tự viết một DSL nhỏ (vd. dựng menu) ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
@resultBuilder là một type có các static method; compiler biến chuỗi câu lệnh trong closure thành các lời gọi tới chúng. buildBlock gom các thành phần thành một giá trị, buildExpression (tuỳ chọn) chuyển kiểu từng biểu thức, buildOptional xử lý if không có else, buildEither(first:) và buildEither(second:) xử lý if/else và switch, buildArray xử lý for ... in, buildLimitedAvailability xử lý if #available, buildFinalResult đổi kết quả trung gian thành kiểu cuối. @ViewBuilder là result builder của SwiftUI: nhiều view liền nhau thành TupleView, if/else thành _ConditionalContent, nhờ vậy SwiftUI giữ được cấu trúc view để diff. Giới hạn đến từ cách builder cụ thể được khai báo chứ không phải từ Swift: buildBlock có số tham số cố định nên một closure @ViewBuilder từng chỉ nhận tối đa 10 view con trực tiếp; gặp lỗi này thì bọc bớt vào Group hoặc tách subview. Khi tự viết DSL, mỗi dạng câu lệnh cần overload tương ứng: thiếu buildOptional thì if không có else không biên dịch được, thiếu buildEither thì if/else cũng vậy. Lỗi biên dịch bên trong block thường hiện thành thông báo khó hiểu, nên khi gặp hãy tách từng phần ra kiểm tra.
struct MenuItem { let title: String }

@resultBuilder
enum MenuBuilder {
    static func buildExpression(_ item: MenuItem) -> [MenuItem] { [item] }        // mỗi dòng MenuItem(...)
    static func buildBlock(_ parts: [MenuItem]...) -> [MenuItem] { parts.flatMap { $0 } }
    static func buildOptional(_ items: [MenuItem]?) -> [MenuItem] { items ?? [] } // if không có else
    static func buildEither(first items: [MenuItem]) -> [MenuItem] { items }      // if/else, switch
    static func buildEither(second items: [MenuItem]) -> [MenuItem] { items }
    static func buildArray(_ groups: [[MenuItem]]) -> [MenuItem] { groups.flatMap { $0 } } // for ... in
}

func makeMenu(@MenuBuilder _ content: () -> [MenuItem]) -> [MenuItem] { content() }

let isAdmin = true
let tags = ["Khuyến mãi", "Mới về"]

let menu = makeMenu {
    MenuItem(title: "Trang chủ")
    if isAdmin { MenuItem(title: "Quản trị") }
    for tag in tags { MenuItem(title: tag) }
}
// menu.map(\.title) == ["Trang chủ", "Quản trị", "Khuyến mãi", "Mới về"]
