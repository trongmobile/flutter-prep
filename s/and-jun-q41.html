QA báo nút "Yêu thích" chỉ có icon trái tim nên TalkBack đọc là "nút không có nhãn", người dùng ngón tay to khó bấm, và khi bật cỡ chữ lớn nhất thì chữ trong thẻ bị cắt. Bạn xử lý các vấn đề accessibility cơ bản này thế nào (View và Compose)?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Ba việc cơ bản. (1) Nhãn: icon hoặc ảnh có ý nghĩa cần mô tả để TalkBack đọc, View dùng android:contentDescription, Compose dùng tham số contentDescription; ảnh chỉ để trang trí thì đặt null (hoặc importantForAccessibility="no") để bị bỏ qua. Mô tả nên nói chức năng ("Thêm vào yêu thích") và không thêm chữ "nút", vì TalkBack tự đọc theo role. (2) Vùng chạm tối thiểu 48dp × 48dp: icon 24dp thì mở rộng vùng bấm bằng padding hoặc minWidth/minHeight chứ không phải phóng to hình; IconButton và các component Material đã đảm bảo sẵn, còn Modifier.clickable trên composable nhỏ thì phải tự thêm padding. (3) Cỡ chữ: dùng sp để chữ theo cài đặt của người dùng (Android 14 cho phóng tới 200%), tránh đặt chiều cao cố định cho khối chứa chữ, dùng wrap_content hoặc heightIn(min = ...) và thử với cỡ chữ lớn nhất. Compose dùng Modifier.semantics { } để bổ sung thông tin cho TalkBack (stateDescription, role, contentDescription); clickable hoặc semantics(mergeDescendants = true) gộp icon cùng chữ thành một mục thay vì đọc rời. Kiểm tra bằng TalkBack thật và Accessibility Scanner; độ tương phản chữ nên đạt tối thiểu 4,5:1.
@Composable
fun FavoriteButton(isFavorite: Boolean, onToggle: () -> Unit) {
    IconButton(onClick = onToggle) { // vùng chạm đã đủ 48dp
        Icon(
            imageVector = if (isFavorite) Icons.Filled.Favorite else Icons.Outlined.FavoriteBorder,
            contentDescription = if (isFavorite) "Bỏ khỏi yêu thích" else "Thêm vào yêu thích",
        )
    }
}

@Composable
fun StockRow(name: String, inStock: Boolean, onClick: () -> Unit) {
    Row(
        modifier = Modifier
            .clickable(onClick = onClick) // gộp các phần tử con thành một mục cho TalkBack
            .semantics { stateDescription = if (inStock) "Còn hàng" else "Hết hàng" }
            .padding(16.dp),
    ) {
        Icon(Icons.Default.ShoppingCart, contentDescription = null) // trang trí, TalkBack bỏ qua
        Spacer(Modifier.width(8.dp))
        Text(name, fontSize = 16.sp) // sp: chữ nở theo cỡ chữ hệ thống
    }
}
