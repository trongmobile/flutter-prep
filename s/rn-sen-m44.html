App dùng Redux Toolkit với redux-persist (AsyncStorage, cấu hình mặc định, chưa đặt version). Bản 2.0 đổi slice cart từ { items } sang { lines, coupon }. Sau phát hành, user cập nhật từ 1.x crash ở cart.lines.map ngay khi mở app, còn user cài mới thì bình thường. Cách xử lý đúng để user cũ không crash mà vẫn giữ được giỏ hàng là gì?

  1. AGọi persistor.purge() mỗi lần khởi động để mọi user luôn bắt đầu từ state mặc định của bản mới
  2. BĐặt version trong persist config và viết migrate (ví dụ createMigrate) đổi items thành lines
  3. CDùng optional chaining và giá trị mặc định ở mọi chỗ đọc cart.lines để state cũ không còn gây lỗi nữa
  4. DBọc app trong PersistGate để slice cart mới được khởi tạo trước khi state cũ được nạp vào

Đáp án đúng: B
Mặc định redux-persist hợp nhất ở mức 1 (autoMergeLevel1): slice cart đã lưu ghi đè nguyên slice khởi tạo của reducer, nên user cũ có cart = { items } mà không có lines. version cùng migrate cho phép biến đổi state cũ sang shape mới đúng một lần khi nâng version. Purge làm mất mọi dữ liệu đã lưu, optional chaining chỉ che lỗi và coi giỏ hàng cũ là rỗng, còn PersistGate chỉ trì hoãn render tới khi rehydrate xong chứ không đổi cách merge.
