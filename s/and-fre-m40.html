Trong build.gradle.kts của module app, minSdk có ý nghĩa gì?

  1. APhiên bản SDK dùng để compile code của app
  2. BPhiên bản Android mà app đã kiểm thử và chọn hành vi theo
  3. CPhiên bản Android thấp nhất mà app cài được
  4. DPhiên bản Android Studio tối thiểu để mở project
Xem đáp án
Đáp án đúng: C
minSdk là API level thấp nhất app hỗ trợ; máy thấp hơn không cài được, và muốn gọi API mới hơn thì phải kiểm tra Build.VERSION.SDK_INT. Phiên bản dùng để compile là compileSdk, còn targetSdk cho hệ thống biết app đã được kiểm thử với phiên bản nào để áp dụng hành vi tương ứng.
