Strong reference và weak reference khác nhau thế nào? Vì sao biến weak luôn phải có kiểu Optional?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Strong reference (mặc định) giữ object sống: còn ít nhất một strong reference thì object chưa bị giải phóng. Weak reference trỏ tới object nhưng không tăng bộ đếm; khi object bị giải phóng, ARC tự đặt mọi weak reference tới nó về nil. Chính vì có thể tự thành nil bất cứ lúc nào nên biến weak bắt buộc có kiểu Optional. Dùng weak để phá vòng tham chiếu trong quan hệ cha – con: cha giữ con bằng strong, con trỏ ngược về cha bằng weak, như delegate hay department trong ví dụ dưới.
class Department {
    var manager: Employee?           // strong: phòng ban giữ nhân viên
    deinit { print("Department deinit") }
}

class Employee {
    weak var department: Department? // weak: không giữ ngược phòng ban
    deinit { print("Employee deinit") }
}

var d: Department? = Department()
let e = Employee()
d?.manager = e
e.department = d
d = nil // in "Department deinit", e.department tự thành nil
