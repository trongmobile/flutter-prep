Màn Chi tiết cần hiện tên sản phẩm làm tiêu đề (chỉ biết sau khi gọi API) và một nút "Chia sẻ" ở bên phải header. Tuỳ biến header với React Navigation thế nào, options khác navigation.setOptions ra sao, và khi nào dùng useNavigation, useRoute?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mỗi Screen có prop options để cấu hình header: title, headerRight, headerLeft, headerShown... Giá trị tĩnh viết thẳng options={{ title: 'Chi tiết' }}; giá trị theo params thì truyền hàm options={({ route }) => ({ title: route.params.name })}. Khi giá trị chỉ có sau khi dữ liệu tải xong, hoặc phụ thuộc state của chính màn hình (nút Lưu bật/tắt theo form), dùng navigation.setOptions({ ... }) trong useLayoutEffect hoặc useEffect, và nhớ đưa state vào dependency để headerRight không giữ giá trị cũ. Không gọi setOptions thẳng trong thân component vì đó là side effect lúc render. Component được khai báo làm Screen đã nhận sẵn navigation và route qua props. useNavigation() dành cho component con nằm sâu hơn và không nhận props đó, ví dụ một nút quay lại dùng chung; useRoute() lấy route để đọc params. Cả hai hook chỉ chạy được bên trong cây của NavigationContainer.
type Props = NativeStackScreenProps<RootStackParamList, 'Detail'>;

function DetailScreen({ navigation, route }: Props) {
  const [product, setProduct] = useState<Product | null>(null);

  useEffect(() => {
    fetchProduct(route.params.id).then(setProduct);
  }, [route.params.id]);

  // Tiêu đề và nút phụ thuộc dữ liệu tải sau: dùng setOptions
  useLayoutEffect(() => {
    navigation.setOptions({
      title: product?.name ?? 'Đang tải...',
      headerRight: () => (
        <Button title="Chia sẻ" disabled={!product} onPress={() => Share.share({ message: product?.name ?? '' })} />
      ),
    });
  }, [navigation, product]);

  return <ProductDetail product={product} />;
}

// Giá trị theo params biết ngay: khai báo ở Screen
<Stack.Screen
  name="Detail"
  component={DetailScreen}
  options={({ route }) => ({ title: route.params.name ?? 'Chi tiết' })}
/>

// Component sâu hơn không nhận props navigation
function BackButton() {
  const navigation = useNavigation();
  return <Button title="Quay lại" onPress={() => navigation.goBack()} />;
}
