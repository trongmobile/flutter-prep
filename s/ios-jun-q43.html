Màn danh sách sản phẩm tải 20 item mỗi trang. Bạn gọi trang tiếp theo trong willDisplay khi cell cuối xuất hiện, nhưng cuộn nhanh thì cùng một trang bị gọi 3 lần, danh sách có item trùng, và khi mạng lỗi thì spinner ở cuối quay mãi. Bạn làm load more đúng cách thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Giữ trạng thái phân trang trong ViewModel: trang hoặc cursor kế tiếp, isLoading, hasMore, lỗi. Điều kiện gọi là guard !isLoading, hasMore, và phải đặt isLoading = true đồng bộ ngay trước khi bắt đầu request: đặt sau await thì hai lần gọi liền nhau vẫn lọt qua. willDisplay được gọi lại mỗi lần cell hiện ra khi cuộn lên xuống nên bắt buộc chống gọi trùng; nên kích hoạt sớm (khi còn cách cuối vài dòng, ví dụ row >= count - 5) để người dùng không phải chờ, hoặc dùng UITableViewDataSourcePrefetching (prefetchRowsAt), cơ chế hệ thống báo trước các dòng sắp hiện. Khi nhận trang mới: nối vào danh sách và loại item trùng theo id, vì phân trang bằng offset có thể lệch khi server thêm hoặc xoá dữ liệu giữa hai lần gọi (cursor ổn định hơn); hasMore lấy từ cursor kế tiếp hoặc từ việc trang trả về đủ pageSize. Footer thể hiện ba trạng thái: spinner khi đang tải, nút 'Thử lại' khi lỗi (không tự lặp vô hạn), ẩn khi hết dữ liệu. Pull-to-refresh thì reset về trang đầu và bỏ qua response của lần gọi cũ về muộn, nếu không dữ liệu cũ sẽ đè dữ liệu mới.
@MainActor
final class ProductListViewModel {
  private(set) var items: [Product] = []
  private(set) var loadError: Error?
  private var nextPage = 1
  private var isLoading = false
  private var hasMore = true
  var onChange: (() -> Void)?

  func loadMoreIfNeeded(currentRow row: Int) async {
    guard !isLoading, hasMore, row >= items.count - 5 else { return }
    isLoading = true                    // đặt cờ đồng bộ, trước khi await
    defer { isLoading = false }
    do {
      let page = try await api.products(page: nextPage, size: 20)
      let known = Set(items.map(\.id))
      items += page.filter { !known.contains($0.id) }  // bỏ item trùng
      hasMore = page.count == 20
      nextPage += 1
      loadError = nil
    } catch {
      loadError = error                 // footer hiện nút "Thử lại"
    }
    onChange?()
  }
}

// Trong ViewController
func tableView(_ tableView: UITableView, willDisplay cell: UITableViewCell,
               forRowAt indexPath: IndexPath) {
  Task { await viewModel.loadMoreIfNeeded(currentRow: indexPath.row) }
}
