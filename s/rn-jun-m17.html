Hàm run in ra giá trị xấp xỉ bao nhiêu (ms)?

const delay = (ms: number) => new Promise((r) => setTimeout(r, ms));

async function run() {
  const start = Date.now();
  for (const ms of [300, 300, 300]) {
    await delay(ms);
  }
  console.log(Date.now() - start);
}

run();
  1. AKhoảng 300, vì ba delay chạy song song
  2. BKhoảng 900, ba lần chờ nối tiếp nhau
  3. CKhoảng 0, vì for...of không chờ await
  4. DKhoảng 600, vì vòng đầu tiên không phải chờ
Xem đáp án
Đáp án đúng: B
await trong for...of thực sự tạm dừng hàm async ở mỗi vòng, nên ba lần chờ nối tiếp nhau; chỉ forEach mới bỏ qua promise của callback. Muốn chạy song song (khoảng 300ms) thì tạo hết các promise rồi await Promise.all(...).
