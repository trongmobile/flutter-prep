App chính, widget và Notification Service Extension cần dùng chung trạng thái đăng nhập và database. Bạn tổ chức thế nào, cần lưu ý gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Extension là process riêng với sandbox riêng, nên các target phải bật cùng một App Group: file và database đặt trong container của group, cấu hình nhỏ dùng UserDefaults(suiteName:), còn token để trong Keychain với access group dùng chung. Hai process có thể ghi cùng lúc nên cần cơ chế phối hợp: SQLite chạy WAL, Core Data bật persistent history tracking để app thấy thay đổi do extension ghi, và báo widget vẽ lại bằng WidgetCenter. Extension có giới hạn memory chặt hơn app nhiều, nên đừng khởi tạo cả dependency graph của app bên trong. Bẫy nặng nhất là crash 0xdead10cc: process bị suspend khi đang giữ file lock hoặc transaction SQLite trong shared container sẽ bị hệ thống kill, vì vậy phải ghi xong trước khi vào background hoặc bọc thao tác ghi bằng background task.
let groupID = "group.vn.shop.app"
// Database dùng chung giữa app và extension
let container = FileManager.default
  .containerURL(forSecurityApplicationGroupIdentifier: groupID)!
let storeURL = container.appendingPathComponent("Shop.sqlite")
// Cấu hình nhỏ dùng chung
let sharedDefaults = UserDefaults(suiteName: groupID)
// Sau khi app ghi dữ liệu mới, yêu cầu widget vẽ lại
WidgetCenter.shared.reloadTimelines(ofKind: "OrderStatusWidget")
