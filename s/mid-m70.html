Class User có field kiểu Address (cũng dùng @JsonSerializable()). print(user.toJson()) in ra {name: An, address: Instance of 'Address'}. Nguyên nhân và cách sửa là gì?

@JsonSerializable()
class User {
  User(this.name, this.address);
  final String name;
  final Address address;

  Map<String, dynamic> toJson() => _$UserToJson(this);
}
  1. AThiếu @JsonKey(toJson: ...) trên address; json_serializable không biết Address có thể mã hóa được
  2. BPhải chạy lại dart run build_runner build vì file .g.dart đang là bản cũ chưa có phần address
  3. CAddress cần extends Equatable để json_serializable đọc được các field bên trong của nó
  4. DtoJson mặc định giữ nguyên object lồng nhau; dùng explicitToJson: true để gọi toJson() của Address
Xem đáp án
Đáp án đúng: D
Code mà json_serializable sinh ra chỉ gán 'address': instance.address, giữ nguyên object Address chứ không gọi address.toJson(), trừ khi bật explicitToJson: true (trong annotation, hoặc trong build.yaml cho cả dự án). jsonEncode vẫn tự gọi toJson() của object lồng nhau nên lỗi này hay bị che; nhưng khi truyền thẳng map cho thư viện chỉ nhận Map/List/giá trị cơ bản (ví dụ set(...) của Firestore) hoặc khi print/so sánh, giá trị lồng vẫn là object. Không cần @JsonKey, Equatable hay chạy lại build_runner: code sinh ra đang đúng theo mặc định.
