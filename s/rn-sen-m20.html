Heap snapshot của Hermes cho thấy JS heap ổn định quanh 40MB, nhưng tổng memory của process (theo Android Studio/Xcode) tăng liên tục khi lướt gallery. Nghi phạm hợp lý nhất?

  1. AHermes báo sai, vì heap snapshot không tính bộ nhớ của các closure
  2. BBộ nhớ native: bitmap đã decode, cache ảnh hoặc view native chưa giải phóng
  3. CCác hằng const ở top-level module không bao giờ được GC thu hồi
  4. DBản release giữ source map trong memory để phục vụ việc báo lỗi lên Sentry sau này

Heap snapshot chỉ phản ánh object JS; ảnh đã decode, cache của thư viện ảnh, view native và buffer của SDK nằm ở bộ nhớ native nên không hiện trong đó. Lúc này cần Memory Profiler/heap dump trên Android hoặc Allocations/Memory Graph trên iOS để khoanh vùng.
