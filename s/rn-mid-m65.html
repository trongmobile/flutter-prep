Chạy file test dưới đây, Jest báo lỗi ngay khi biên dịch, trước khi test nào chạy. Nguyên nhân và cách sửa đúng là gì?

import { getUser } from './api';

const fakeUser = { id: 1, name: 'An' };

jest.mock('./api', () => ({
  getUser: jest.fn().mockResolvedValue(fakeUser),
}));

test('lấy user', async () => {
  expect(await getUser()).toEqual(fakeUser);
});
  1. AThiếu await trước jest.mock, vì mock phải được đăng ký bất đồng bộ
  2. BFactory bị hoist lên đầu file, không được tham chiếu biến ngoài fakeUser
  3. Cjest.mock chỉ dùng được cho module trong node_modules, không cho file dự án
  4. DmockResolvedValue không dùng được trong factory, phải bọc Promise thủ công
Xem đáp án
Đáp án đúng: B
Babel plugin của Jest hoist jest.mock lên đầu file, trước cả import và các khai báo const; factory tham chiếu biến ngoài phạm vi như fakeUser bị chặn ngay lúc biên dịch với lỗi The module factory of jest.mock() is not allowed to reference any out-of-scope variables, vì lúc factory chạy biến đó có thể chưa được khởi tạo. Hãy tạo dữ liệu ngay trong factory (hoặc require từ file riêng bên trong factory); tên biến bắt đầu bằng mock được ngoại lệ nhưng chỉ an toàn khi dùng lười. jest.mock là lời gọi đồng bộ, dùng được cho cả file dự án, và mockResolvedValue chạy bình thường trong factory.
