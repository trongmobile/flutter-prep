Đoạn code sau in ra gì (theo thứ tự từng dòng)?

String describe(Object o) => switch (o) {
  (int x, int y) when x == y => 'diag',
  (int x, _) => 'x=$x',
  [_, ...] => 'list',
  _ => 'other',
};

void main() {
  print(describe((2, 2)));
  print(describe((3, 'a')));
  print(describe([]));
}
  1. Adiag, x=3, other
  2. Bdiag, x=3, list
  3. Cx=2, x=3, list
  4. DLỗi compile vì switch không exhaustive
Xem đáp án
Đáp án đúng: A
(2, 2) khớp case đầu nhờ guard when x == y, (3, 'a') khớp (int x, _). List rỗng không khớp [_, ...] (cần ít nhất một phần tử) nên rơi vào _; và vì có _ nên switch luôn exhaustive.
