Sau khi đóng màn hình, deinit của WebViewController không bao giờ chạy. Nguyên nhân là gì?

final class WebViewController: UIViewController, WKScriptMessageHandler {
  private var webView: WKWebView!

  override func viewDidLoad() {
    super.viewDidLoad()
    let config = WKWebViewConfiguration()
    config.userContentController.add(self, name: "checkout")
    webView = WKWebView(frame: view.bounds, configuration: config)
    view.addSubview(webView)
  }

  func userContentController(_ controller: WKUserContentController,
                             didReceive message: WKScriptMessage) { /* xử lý */ }

  deinit { print("deinit") }
}
  1. AWKWebView luôn giữ view controller cha bằng strong reference cho tới khi gọi stopLoading()
  2. BwebView là property mạnh; đổi sang weak var webView là vòng tham chiếu biến mất
  3. CHandler WKScriptMessageHandler được lưu trong JavaScript context và chỉ thả khi trang tải xong
  4. Dadd(_:name:) giữ handler bằng strong reference, tạo vòng self → webView → controller → self
Xem đáp án
Đáp án đúng: D
WKUserContentController.add(_:name:) giữ handler bằng tham chiếu mạnh, và controller này nằm trong configuration của WKWebView; view controller lại giữ web view (qua view), thành vòng self → webView → userContentController → self. Đổi webView sang weak không phá được vòng vì view.addSubview vẫn giữ nó. Cách sửa: truyền một wrapper giữ weak tới handler thật, hoặc gỡ handler bằng removeScriptMessageHandler(forName:) trước khi đóng màn.
