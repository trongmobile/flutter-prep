App cần hỗ trợ tiếng Việt và tiếng Anh, tự chọn theo ngôn ngữ máy nhưng user đổi được trong app; có câu 'Bạn có 1 tin nhắn' và 'Bạn có 5 tin nhắn' (số nhiều), và vài thị trường cần RTL. Bạn dựng i18n trong React Native thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Cách phổ biến là i18next kèm react-i18next, dùng expo-localization để biết ngôn ngữ thiết bị. Tách chuỗi ra file theo ngôn ngữ (vi.json, en.json), dùng key có ý nghĩa (inbox.unreadCount) và gọi t('inbox.unreadCount', { count }) qua hook useTranslation() để component render lại khi đổi ngôn ngữ. Ngôn ngữ ban đầu lấy từ getLocales()[0].languageCode; user chọn thủ công thì lưu vào storage và ưu tiên hơn ngôn ngữ máy; đặt fallbackLng: 'en' để thiếu bản dịch vẫn hiện được chữ. Số nhiều: i18next dựa vào Intl.PluralRules nên khai báo các dạng theo từng ngôn ngữ (unreadCount_one, unreadCount_other; tiếng Việt chỉ có other, tiếng Ả Rập có nhiều dạng) và truyền count. Không ghép chuỗi bằng tay ('Bạn có ' + n + ' tin nhắn') vì thứ tự từ khác nhau giữa các ngôn ngữ, hãy dùng placeholder {{count}}, {{name}}. Số, ngày, tiền định dạng bằng Intl theo locale thay vì hard-code. Với TypeScript, sinh kiểu cho key (type augmentation của i18next) để gõ sai key bị báo ngay. RTL: I18nManager.forceRTL(true) đổi chiều layout nhưng cần khởi động lại app mới có hiệu lực, và nên dùng start/end (marginStart, paddingEnd) thay cho left/right, lật icon có hướng bằng transform: [{ scaleX: -1 }] khi RTL. Sót chuỗi là lỗi hay gặp nên cần script kiểm tra key thiếu ở CI, và bản dịch dài hơn (tiếng Đức, tiếng Pháp) làm vỡ layout cố định chiều rộng nên cần thử với chuỗi dài và cỡ chữ lớn. Chuỗi từ server cần theo Accept-Language. Để user chọn ngôn ngữ riêng cho từng app trong Settings của iOS và Android 13 trở lên, cần khai báo các ngôn ngữ hỗ trợ ở cấu hình native (Expo: locales trong app.json).
import i18n from 'i18next';
import { initReactI18next, useTranslation } from 'react-i18next';
import { getLocales } from 'expo-localization';

const deviceLang = getLocales()[0]?.languageCode ?? 'en';

i18n.use(initReactI18next).init({
  lng: savedLang ?? deviceLang, // lựa chọn của user (lưu trong storage) ưu tiên hơn ngôn ngữ máy
  fallbackLng: 'en', // thiếu bản dịch thì dùng tiếng Anh thay vì hiện key
  resources: {
    vi: { translation: { inbox: { unreadCount_other: 'Bạn có {{count}} tin nhắn' } } },
    en: {
      translation: {
        inbox: {
          unreadCount_one: 'You have {{count}} message',
          unreadCount_other: 'You have {{count}} messages',
        },
      },
    },
  },
});

function Inbox({ count }: { count: number }) {
  const { t } = useTranslation(); // component render lại khi đổi ngôn ngữ
  return <Text>{t('inbox.unreadCount', { count })}</Text>; // i18next chọn dạng số nhiều theo ngôn ngữ
}
