Server trả HTTP 404 cho users/{id}. Với Retrofit 2.6+ và đoạn code dưới đây, điều gì xảy ra?

interface UserApi {
  @GET("users/{id}")
  suspend fun getUser(@Path("id") id: Long): User
}

suspend fun load(id: Long): UiState = try {
  UiState.Success(api.getUser(id))
} catch (e: IOException) {
  UiState.Offline
}
  1. ATrả UiState.Offline, vì Retrofit bọc mọi lỗi HTTP và lỗi mạng thành IOException
  2. BNém JsonDataException vì body 404 không parse được thành User
  3. CHttpException bay ra khỏi load vì không phải IOException, có thể gây crash
  4. DgetUser trả null vì body của response 404 rỗng
Xem đáp án
Đáp án đúng: C
Với hàm suspend trả thẳng kiểu body, Retrofit ném HttpException cho mọi mã không phải 2xx; đây là RuntimeException, còn IOException chỉ dành cho lỗi mạng như mất kết nối hay timeout. Cần bắt riêng HttpException (đọc code()), hoặc khai báo hàm trả Response<User> để tự kiểm tra isSuccessful.
