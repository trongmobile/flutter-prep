Bạn dùng TanStack Query (React Query) cho app RN và cần cho phép user thao tác (đánh dấu hoàn thành, sửa đơn) khi mất mạng, rồi tự đồng bộ khi có mạng lại. Bạn cấu hình persist cache, mutation offline và optimistic update thế nào, và những bẫy nào hay làm hỏng?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Có ba phần. Cache: dùng PersistQueryClientProvider với persister lưu vào MMKV hoặc AsyncStorage để mở app offline vẫn có dữ liệu cũ; gcTime phải lớn hơn hoặc bằng maxAge của persister (mặc định cache bị dọn sau 5 phút, nên khi persist thường cần gcTime từ 24 giờ), nếu không dữ liệu bị dọn trước khi kịp khôi phục. Mạng: nối onlineManager với NetInfo để React Query biết trạng thái thật (RN không có sự kiện online/offline như trình duyệt) và focusManager với AppState để refetch khi app trở lại foreground. Mutation: mặc định networkMode: 'online' nên mutation khi offline bị tạm dừng (paused) và tự chạy khi có mạng; để giữ qua lần khởi động lại app thì mutation cũng được persist, nhưng mutationFn không serialize được nên phải đăng ký sẵn bằng queryClient.setMutationDefaults(key, { mutationFn, ... }), rồi sau khi hydrate gọi queryClient.resumePausedMutations(). Optimistic update: trong onMutate huỷ query liên quan (cancelQueries), lưu snapshot, cập nhật cache; onError thì hoàn tác, onSettled thì invalidateQueries. Bẫy: mutation phải idempotent vì resume hay retry có thể gửi lặp (dùng idempotency key sinh ở client); thứ tự các mutation trên cùng một đối tượng (dùng scope.id để chạy tuần tự); xung đột khi server đã đổi dữ liệu; và schema cache đổi giữa các bản app (dùng buster của persister để bỏ cache cũ). Với nghiệp vụ offline phức tạp (xung đột, hàng nghìn bản ghi) cache của React Query không thay được DB local kèm sync engine.
// Báo cho React Query biết trạng thái mạng thật (RN không có sự kiện online/offline như trình duyệt)
onlineManager.setEventListener((setOnline) =>
  NetInfo.addEventListener((state) => setOnline(!!state.isConnected)),
);

const queryClient = new QueryClient({
  defaultOptions: { queries: { gcTime: 1000 * 60 * 60 * 24 } }, // >= maxAge của persister
});

// Đăng ký mutationFn theo key để mutation đã persist vẫn chạy lại được sau khi khởi động lại app
queryClient.setMutationDefaults(['order', 'complete'], {
  mutationFn: (vars: { orderId: string; requestId: string }) => api.completeOrder(vars), // requestId: idempotency key
  onMutate: async ({ orderId }) => {
    await queryClient.cancelQueries({ queryKey: ['orders'] });
    const previous = queryClient.getQueryData<Order[]>(['orders']);
    queryClient.setQueryData<Order[]>(['orders'], (old) =>
      old?.map((o) => (o.id === orderId ? { ...o, done: true } : o)),
    );
    return { previous };
  },
  onError: (_err, _vars, ctx) => queryClient.setQueryData(['orders'], ctx?.previous), // lỗi vĩnh viễn thì hoàn tác
  onSettled: () => queryClient.invalidateQueries({ queryKey: ['orders'] }),
});

<PersistQueryClientProvider
  client={queryClient}
  persistOptions={{ persister: mmkvPersister, maxAge: 1000 * 60 * 60 * 24, buster: APP_CACHE_VERSION }}
  onSuccess={() => queryClient.resumePausedMutations()} // chạy lại mutation đang chờ sau khi hydrate
>
  <App />
</PersistQueryClientProvider>
