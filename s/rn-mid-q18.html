Bạn cần viết một Turbo Native Module đọc mức pin cho cả Android và iOS. Các bước với Codegen là gì, và được lợi gì so với native module kiểu cũ?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Bước một: viết spec bằng TypeScript trong file có tên bắt đầu bằng Native (như NativeBattery.ts), gồm interface Spec extends TurboModule và export TurboModuleRegistry.getEnforcing<Spec>('NativeBattery'). Bước hai: khai báo codegenConfig trong package.json (name, type: "modules", jsSrcsDir). Codegen chạy khi build Android hoặc khi pod install trên iOS, sinh ra abstract class Java và protocol Objective-C++ để bạn implement phía native. So với module cũ đi qua bridge: lời gọi đi qua JSI nên không phải serialize JSON bất đồng bộ, có thể khai báo hàm đồng bộ khi thật cần, module chỉ được khởi tạo khi dùng lần đầu, và kiểu dữ liệu giữa JS với native được kiểm tra lúc build thay vì vỡ lúc runtime.
// specs/NativeBattery.ts
import type { TurboModule } from 'react-native';
import { TurboModuleRegistry } from 'react-native';

export interface Spec extends TurboModule {
  getBatteryLevel(): Promise<number>;
  isCharging(): boolean; // hàm đồng bộ
}

export default TurboModuleRegistry.getEnforcing<Spec>('NativeBattery');
