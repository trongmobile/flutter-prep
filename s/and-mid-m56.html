Class test dưới khai báo MainDispatcherRule (rule tự viết, kế thừa TestWatcher) bằng cú pháp sau rồi chạy bằng JUnit 4. Kết quả là gì?

class SearchViewModelTest {
  @Rule
  val mainRule = MainDispatcherRule()

  @Test
  fun search_updatesState() = runTest {
    // ...
  }
}
  1. ATest chạy bình thường, rule được áp dụng cho mọi @Test như cú pháp Java
  2. BFail ngay với lỗi validate The @Rule 'mainRule' must be public
  3. CTest chạy nhưng rule bị bỏ qua vì @Rule chỉ áp dụng cho property var
  4. DLỗi compile vì Kotlin không cho gắn @Rule lên một property
Xem đáp án
Đáp án đúng: B
Trong Kotlin, val mainRule sinh ra một field private và một getter public. @Rule là annotation Java (target field hoặc method) nên khi không có use-site target nó rơi vào field private, mà JUnit 4 yêu cầu rule phải public, nên class test báo lỗi The @Rule 'mainRule' must be public trước khi chạy test nào. Sửa bằng @get:Rule val mainRule = ... (gắn annotation vào getter public) hoặc @Rule @JvmField val mainRule = .... @Rule không giới hạn ở var và cú pháp trên vẫn compile bình thường.
