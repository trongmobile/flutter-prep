AndroidSeniorGradle & BuildCâu hỏi phỏng vấn

Codebase có khoảng 60 module, mỗi build.gradle.kts lặp lại cùng đoạn cấu hình (compileSdk, Compose, Hilt, lint...), còn file gốc dùng subprojects { } để ép cấu hình chung. Mỗi lần nâng AGP hay Kotlin lại phải sửa nhiều nơi và luôn có module bị lệch. Bạn tổ chức lại bằng build-logic và convention plugin thế nào, và vì sao cách này tốt hơn allprojects { }/subprojects { }?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Tách logic build thành một included build build-logic (khai báo pluginManagement { includeBuild("build-logic") }), trong đó mỗi convention plugin lo một việc: app.android.library, app.android.compose, app.hilt...; module chỉ cần plugins { id("app.android.library") }. Phiên bản thư viện và plugin để ở một nơi là version catalog gradle/libs.versions.toml (các mục [versions], [libraries], [plugins], [bundles]); build-logic dùng chung file này bằng cách khai báo catalog trong settings.gradle.kts của nó, và class plugin đọc catalog qua VersionCatalogsExtension vì accessor libs không có sẵn ở đó. So với subprojects { }/allprojects { }: đó là cross-project configuration ngầm, file gốc phải biết và chỉnh mọi module, kết quả phụ thuộc thứ tự đánh giá nên dễ phải afterEvaluate, khó thấy một module thực sự được cấu hình gì, và là rào cản của configuration cache lẫn Isolated Projects. Convention plugin thì tường minh (nhìn khối plugins {} là biết), ghép được như lego, là code Kotlin được type-check, được biên dịch và cache một lần, thậm chí viết test được. Lưu ý giữ mỗi plugin nhỏ và một mục đích, đừng gom thành 'god plugin' đầy cờ bật tắt; và vì sửa build-logic làm mất configuration cache, nên giữ nó ổn định, đừng nhét logic hay đổi vào đó.
// settings.gradle.kts (gốc)
pluginManagement { includeBuild("build-logic") }

// build-logic/convention/build.gradle.kts
plugins { `kotlin-dsl` }
dependencies {
  compileOnly(libs.android.gradlePlugin) // khai báo trong libs.versions.toml, build-logic trỏ catalog về ../gradle/libs.versions.toml
  compileOnly(libs.kotlin.gradlePlugin)
}
gradlePlugin {
  plugins {
    register("androidLibrary") {
      id = "app.android.library"
      implementationClass = "AndroidLibraryConventionPlugin"
    }
  }
}

// build-logic/convention/src/main/kotlin/AndroidLibraryConventionPlugin.kt
class AndroidLibraryConventionPlugin : Plugin<Project> {
  override fun apply(target: Project) = with(target) {
    pluginManager.apply("com.android.library")
    pluginManager.apply("org.jetbrains.kotlin.android")
    extensions.configure<LibraryExtension> {
      compileSdk = 35
      defaultConfig.minSdk = 24
    }
    val libs = extensions.getByType<VersionCatalogsExtension>().named("libs")
    dependencies { add("implementation", libs.findLibrary("androidx-core-ktx").get()) }
  }
}

// feature/cart/build.gradle.kts: chỉ còn một dòng cấu hình chung
plugins { id("app.android.library") }
