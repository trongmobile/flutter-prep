Bạn cần làm component Tabs dùng cho cả app. Phiên bản đầu nhận một mảng tabs cùng hàng chục prop (renderHeader, tabBarStyle, showBadge…), và team nào cần khác một chút lại xin thêm prop. Compound components, render props, custom hook và HOC khác nhau thế nào, và bạn thiết kế API này ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Compound components: nhiều component con chia sẻ state ngầm qua Context (<Tabs.Trigger>, <Tabs.Panel> đặt trong <Tabs>), người dùng tự sắp xếp và chèn phần tử tuỳ ý nên bỏ được phần lớn prop cấu hình; hợp với UI gồm nhiều phần tạo thành một khối (Tabs, Accordion, Menu). Cần ném lỗi rõ khi con dùng ngoài cha, và nhớ rằng Context đổi sẽ làm các con dùng nó render lại. Render props (như renderItem của FlatList): cha giữ logic, con quyết định vẽ gì ở một vị trí cụ thể; hợp khi cần tuỳ biến cách vẽ từng phần với dữ liệu của cha, nhưng khó đọc khi lồng nhiều tầng. Custom hook: tái dùng logic mà không kèm giao diện (useDisclosure, useTabs), là lựa chọn mặc định để chia sẻ logic và tách phần "headless" khỏi UI. HOC bọc component để thêm hành vi (withAuth…): ngày nay ít dùng cho logic mới vì hook thay được, nhược điểm là props ẩn, bọc nhiều tầng, kiểu TypeScript khó; vẫn gặp ở memo hay forwardRef. Nguyên tắc chọn: chia sẻ logic thì hook; UI nhiều phần cần linh hoạt thì compound; cần tuỳ biến một điểm vẽ thì render prop. Giữ API nhỏ, hỗ trợ cả controlled (value/onValueChange) lẫn uncontrolled (defaultValue). Ở React 19, ref là prop thường nên không cần forwardRef cho component mới.
import { createContext, useContext, useMemo, useState, type ReactNode } from 'react';

const TabsContext = createContext<{ value: string; setValue: (v: string) => void } | null>(null);

function useTabs() {
  const ctx = useContext(TabsContext);
  if (!ctx) throw new Error('Tabs.* phải nằm trong <Tabs>');
  return ctx;
}

function Tabs({ defaultValue, children }: { defaultValue: string; children: ReactNode }) {
  const [value, setValue] = useState(defaultValue);
  const ctx = useMemo(() => ({ value, setValue }), [value]);
  return <TabsContext.Provider value={ctx}>{children}</TabsContext.Provider>;
}

function Trigger({ value, children }: { value: string; children: ReactNode }) {
  const { value: active, setValue } = useTabs();
  return (
    <Pressable onPress={() => setValue(value)} accessibilityRole="tab" accessibilityState={{ selected: active === value }}>
      <Text style={active === value && styles.active}>{children}</Text>
    </Pressable>
  );
}

function Panel({ value, children }: { value: string; children: ReactNode }) {
  return useTabs().value === value ? <View>{children}</View> : null;
}

Tabs.Trigger = Trigger;
Tabs.Panel = Panel;

// Người dùng tự bố trí, thêm badge hay icon mà không cần thêm prop mới cho Tabs
<Tabs defaultValue="info">
  <View style={styles.row}>
    <Tabs.Trigger value="info">Thông tin</Tabs.Trigger>
    <Tabs.Trigger value="reviews">Đánh giá <Badge count={3} /></Tabs.Trigger>
  </View>
  <Tabs.Panel value="info"><Info /></Tabs.Panel>
  <Tabs.Panel value="reviews"><Reviews /></Tabs.Panel>
</Tabs>;
