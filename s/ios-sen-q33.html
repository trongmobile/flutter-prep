Bạn xây luồng mua gói đăng ký (subscription) bằng StoreKit 2. Làm sao để không mất giao dịch khi app bị kill giữa lúc mua, chống gian lận, đồng bộ quyền lợi với server và xử lý hoàn tiền?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Với StoreKit 2, giao dịch là dữ liệu đã được Apple ký (JWS). Kết quả Product.purchase() có thể là .success(.verified(transaction)), .pending (chờ Ask to Buy hay xác thực thêm) hoặc .userCancelled; chỉ cấp quyền lợi khi .verified, còn .unverified thì từ chối. Quan trọng là phải lắng nghe Transaction.updates ngay từ lúc app khởi động (một Task sống suốt vòng đời app), vì giao dịch có thể hoàn tất ngoài luồng mua: khoản pending được duyệt sau, gia hạn tự động, mua trên thiết bị khác, hoàn tiền hay thu hồi; bỏ sót listener này là nguyên nhân phổ biến khiến user trả tiền mà không có quyền lợi. Xử lý xong mới gọi transaction.finish(); giao dịch chưa finish sẽ được giao lại ở lần khởi động sau nên không mất khi app bị kill. Để biết user đang có gì, đọc Transaction.currentEntitlements (kiểm tra revocationDate cho hoàn tiền và expirationDate cho hết hạn). Verify phía client chỉ là lớp đầu: backend nên nhận JWS (hoặc originalTransactionId), xác minh qua App Store Server API và nhận App Store Server Notifications V2 để biết gia hạn, hết hạn, hoàn tiền, billing retry mà không cần app đang mở. Khi mua, gắn giao dịch với tài khoản bằng appAccountToken (UUID do server sinh). Cần có nút 'Khôi phục giao dịch' gọi AppStore.sync(), và test bằng StoreKit configuration file hoặc sandbox.
@main
struct ShopApp: App {
  // Bắt đầu ngay lúc app khởi động và sống suốt vòng đời app
  private let updatesTask = Task.detached {
    for await result in Transaction.updates {
      guard case .verified(let transaction) = result else { continue }
      await EntitlementStore.shared.apply(transaction) // cấp hoặc thu hồi (xem revocationDate)
      await transaction.finish() // chưa finish thì lần sau StoreKit giao lại
    }
  }
  // ...
}

func buy(_ product: Product, accountToken: UUID) async throws {
  let result = try await product.purchase(options: [.appAccountToken(accountToken)])
  switch result {
  case .success(.verified(let transaction)):
    await EntitlementStore.shared.apply(transaction)
    await transaction.finish()
  case .success(.unverified):
    throw PurchaseError.verificationFailed
  case .pending:
    break // Ask to Buy hoặc cần xác thực thêm: kết quả sẽ tới qua Transaction.updates
  case .userCancelled:
    break
  @unknown default:
    break
  }
}
