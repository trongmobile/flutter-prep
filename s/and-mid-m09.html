Hàm repository dưới đây đổi dispatcher bằng withContext bên trong builder flow { }. Collect nó từ viewModelScope thì sao?

fun loadUsers(): Flow<List<User>> = flow {
  withContext(Dispatchers.IO) {
    emit(api.getUsers())
  }
}
  1. AChạy đúng: gọi API trên IO, collector nhận kết quả trên Main
  2. BNém IllegalStateException vì vi phạm context preservation
  3. CLỗi compile vì không được gọi emit bên trong withContext
  4. DChạy được, nhưng khối collect cũng bị chuyển sang IO
Xem đáp án
Đáp án đúng: B
Flow yêu cầu context preservation: emit phải được gọi trong cùng context với collector, nếu không sẽ ném IllegalStateException (Flow invariant is violated). Cách đúng là bỏ withContext và thêm .flowOn(Dispatchers.IO) sau builder.
