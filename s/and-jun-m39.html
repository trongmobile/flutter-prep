Trong JUnit 4, class test có 3 method @Test. Method gắn @Before chạy bao nhiêu lần?

  1. A1 lần, trước test đầu tiên của class
  2. B3 lần, trước mỗi method @Test
  3. C1 lần, khi class test được nạp
  4. DKhông chạy nếu đã có constructor khởi tạo field
Xem đáp án
Đáp án đúng: B
@Before chạy trước mỗi test (JUnit 4 còn tạo instance class test mới cho mỗi test) để các test độc lập với nhau. Cần chạy đúng một lần cho cả class thì dùng @BeforeClass trên hàm static, trong Kotlin là hàm trong companion object gắn @JvmStatic.
