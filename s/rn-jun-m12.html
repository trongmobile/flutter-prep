Đoạn code sau in ra theo thứ tự nào?

async function load() {
  console.log('1');
  await null;
  console.log('2');
}

console.log('3');
load();
console.log('4');
  1. A3 1 2 4
  2. B3 4 1 2
  3. C1 2 3 4
  4. D3 1 4 2
Xem đáp án
Đáp án đúng: D
Thân hàm async chạy đồng bộ cho tới await đầu tiên nên 1 in ngay sau 3; phần sau await được đẩy thành microtask, chỉ chạy khi code đồng bộ hiện tại (in 4) xong. Vì vậy gọi hàm async mà không await thì code phía sau không chờ nó.
