Gọi API bằng enqueue của Retrofit ngay trong Activity với cấu hình mặc định trên Android. Hàm onResponse chạy trên thread nào?

api.getUsers().enqueue(object : Callback<List<User>> {
  override fun onResponse(call: Call<List<User>>, response: Response<List<User>>) {
    adapter.submitList(response.body())
  }

  override fun onFailure(call: Call<List<User>>, t: Throwable) {
    showError(t)
  }
})
  1. AThread nền của OkHttp, nên phải dùng runOnUiThread mới cập nhật được UI
  2. BMain thread, nên cập nhật UI trực tiếp trong callback được
  3. CChính thread đã gọi enqueue, nên chạy nền nếu bạn gọi từ thread nền
  4. DMột thread mới do Retrofit tạo riêng cho từng request
Xem đáp án
Đáp án đúng: B
Retrofit trên Android mặc định đưa callback về main thread bằng Handler của main Looper, bất kể request chạy ở thread nào, nên onResponse và onFailure cập nhật UI trực tiếp được; đổi lại, việc nặng đặt trong callback cũng chạy trên main thread. Phần gọi mạng chạy ở thread của OkHttp, còn execute() mới chạy đồng bộ trên thread gọi (gọi trên main thread sẽ bị NetworkOnMainThreadException).
