Làm sao bắt lỗi khi gọi một hàm async, ví dụ gọi API thất bại?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đặt lời gọi await bên trong try/catch giống code đồng bộ, và dùng finally cho việc luôn phải làm như tắt loading. Nếu không dùng await thì có thể nối .then(...).catchError(...), nhưng try/catch dễ đọc hơn. Lỗi thường gặp là gọi hàm async mà quên await, khi đó lỗi xảy ra sau khi đã ra khỏi khối try nên catch không bắt được.
Future<void> loadUser() async {
  isLoading = true;
  try {
    final user = await api.getUser();
    print(user.name);
  } catch (e) {
    print('Lỗi: $e');
  } finally {
    isLoading = false;
  }
}
