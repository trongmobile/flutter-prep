Android Studio (Lint) cảnh báo onDraw của custom view dưới đây. Vấn đề hiệu năng chính là gì?

class BadgeView(context: Context) : View(context) {
    override fun onDraw(canvas: Canvas) {
        super.onDraw(canvas)
        val paint = Paint().apply { color = Color.RED }
        canvas.drawCircle(width / 2f, height / 2f, 20f, paint)
    }
}
  1. AKotlin cấm tạo object trong onDraw, nên đoạn code này không compile
  2. BPaint giữ tham chiếu tới Canvas nên không bao giờ được thu hồi
  3. CTạo Paint mới ở mỗi frame làm tăng áp lực GC, dễ gây giật
  4. DMỗi lần vẽ đều kích hoạt requestLayout(), đo lại cả cây View
Xem đáp án
Đáp án đúng: C
onDraw có thể chạy mỗi frame khi có animation hay cuộn, nên tạo Paint mới trong đó sinh ra rác liên tục, kích hoạt GC và có thể làm lỡ frame. Cách sửa là khai báo Paint thành property khởi tạo một lần, chỉ đổi thuộc tính khi cần. Đây chỉ là cảnh báo Lint (DrawAllocation) chứ không phải lỗi compile, và không phải leak vì object ngắn hạn vẫn được thu hồi bình thường.
