freezed + json_serializable giúp gì so với viết tay model và fromJson/toJson?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Chúng sinh code cho phần lặp lại dễ sai: ==/hashCode theo giá trị, copyWith, toString, fromJson/toJson, và với freezed còn có union/sealed class cho state. Model bất biến, so sánh theo giá trị rất quan trọng với Bloc/Riverpod (tránh rebuild thừa, tránh vô tình mutate state). Trade-off: thêm bước dart run build_runner build, phải quản lý các file *.freezed.dart/*.g.dart và thời gian generate tăng ở project lớn; model vài field đơn giản thì record hoặc viết tay vẫn ổn. Lưu ý từ freezed 3, class dùng factory constructor phải khai báo abstract hoặc sealed.
import 'package:freezed_annotation/freezed_annotation.dart';

part 'user.freezed.dart';
part 'user.g.dart';

@freezed
abstract class User with _$User {
  const factory User({
    required String id,
    required String name,
    @Default(false) bool isAdmin,
  }) = _User;
  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
}
