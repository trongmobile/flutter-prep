Viết unit test cơ bản bằng XCTest thế nào? @testable import, setUp và các hàm XCTAssert... dùng ra sao, và vì sao test hàm thuần dễ hơn test cả ViewController?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Unit test nằm trong target Unit Testing Bundle: tạo class kế thừa XCTestCase, mỗi method bắt đầu bằng test (không tham số) được Xcode tự chạy bằng ⌘U hoặc nút kim cương cạnh method. @testable import TênApp cho test truy cập được cả những thứ internal của module app (chỉ hoạt động với build Debug). setUp() chạy trước mỗi test để dựng đối tượng mới và tearDown() chạy sau để dọn, nhờ đó các test độc lập, không phụ thuộc thứ tự chạy. Kiểm tra bằng XCTAssertEqual, XCTAssertTrue, XCTAssertNil, XCTAssertThrowsError; test có thể khai báo throws và dùng XCTUnwrap để unwrap Optional, fail gọn thay vì crash. Hàm thuần (cùng input luôn ra cùng output, không đụng mạng, đồng hồ, UserDefaults) rất dễ test: gọi và so kết quả. UIViewController thì phụ thuộc vòng đời view, mạng và state bên ngoài nên khó test, vì vậy hãy đưa logic (tính tiền, validate, format) ra struct hoặc ViewModel để test riêng, còn ViewController chỉ làm việc nối. Từ Xcode 16 có thêm framework Swift Testing (@Test, #expect), nhưng XCTest vẫn phải nắm vì UI test còn dùng nó. Bẫy: test phụ thuộc mạng hoặc giờ hệ thống thật sẽ lúc pass lúc fail (flaky).
// Trong target app
struct PriceCalculator {
    func total(prices: [Int], discountPercent: Int) -> Int {
        let sum = prices.reduce(0, +)
        return sum - sum * discountPercent / 100
    }
}

// Trong target test
import XCTest
@testable import ShopApp

final class PriceCalculatorTests: XCTestCase {
    private var sut: PriceCalculator!

    override func setUp() {
        super.setUp()
        sut = PriceCalculator()               // mỗi test có một instance mới
    }

    override func tearDown() {
        sut = nil
        super.tearDown()
    }

    func test_total_withoutDiscount_returnsSum() {
        XCTAssertEqual(sut.total(prices: [100, 200], discountPercent: 0), 300)
    }

    func test_total_with10PercentDiscount_returns90Percent() {
        XCTAssertEqual(sut.total(prices: [100, 200], discountPercent: 10), 270)
    }
}
