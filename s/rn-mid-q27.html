Component dùng useSelector((state) => state.orders.items.filter((o) => o.status === 'open')) và bị render lại mỗi lần bất kỳ action nào được dispatch, kèm cảnh báo selector trả về kết quả khác nhau ở các lần gọi. Vì sao, và bạn dùng createSelector và createEntityAdapter của Redux Toolkit thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
useSelector chạy selector sau mỗi action và so sánh kết quả với lần trước bằng ===; .filter() luôn trả về một mảng mới nên kết quả luôn 'khác', component render lại dù dữ liệu không đổi (react-redux ở dev mode còn cảnh báo điều này). Giải pháp là selector có memoization: createSelector([inputSelectors], resultFn) chỉ tính lại resultFn khi kết quả của các input selector (so sánh tham chiếu) đổi, nên cùng input thì trả về cùng mảng và useSelector không kích hoạt render. Input selector phải rẻ và không tạo object mới; phép biến đổi nặng đặt trong resultFn. Với selector nhận tham số (lọc theo id) cần tạo instance riêng cho mỗi component hoặc dùng Reselect 5 (mặc định weakMapMemoize nên cache được theo nhiều tham số). createEntityAdapter chuẩn hoá dữ liệu thành { ids: [], entities: {} } kèm sẵn các reducer (addOne, upsertMany, removeOne) và getSelectors() cho selectAll, selectById, selectIds: tra cứu theo id là O(1) và cập nhật một phần tử không đổi tham chiếu của các phần tử khác, nên item không đổi không bị render lại. Kết hợp với React.memo cho item và để mỗi item tự useSelector((s) => selectById(s, id)) thì chỉ item nào đổi mới render. Đừng lưu dữ liệu dẫn xuất vào store (tính bằng selector); và nếu dữ liệu đến từ API thì RTK Query đã cache theo endpoint, không cần tự chuẩn hoá thêm.
const ordersAdapter = createEntityAdapter<Order>(); // { ids, entities } kèm reducer và selector sẵn

const ordersSlice = createSlice({
  name: 'orders',
  initialState: ordersAdapter.getInitialState(),
  reducers: {
    received: ordersAdapter.upsertMany, // cập nhật một order không đổi tham chiếu của order khác
    removed: ordersAdapter.removeOne,
  },
});

export const { selectAll: selectAllOrders, selectById: selectOrderById } =
  ordersAdapter.getSelectors((state: RootState) => state.orders);

// Memo: cùng input thì trả cùng mảng, useSelector không kích hoạt render
export const selectOpenOrders = createSelector([selectAllOrders], (orders) =>
  orders.filter((o) => o.status === 'open'),
);

// Trong component
const openOrders = useSelector(selectOpenOrders);

// Mỗi item tự lấy dữ liệu theo id: chỉ item nào đổi mới render lại
const order = useSelector((s: RootState) => selectOrderById(s, id));
