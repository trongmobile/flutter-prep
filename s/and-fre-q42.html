Khai báo một API bằng Retrofit thế nào (@GET, @Path, @Query, @POST với @Body)? Converter dùng để làm gì, và JSON được parse thành data class ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Retrofit biến một interface thành HTTP client: mỗi hàm là một endpoint. @GET("users/{id}") cho biết method HTTP và đường dẫn tương đối so với baseUrl (nên kết thúc bằng dấu /); @Path điền vào {id}, @Query thành ?page=1, @Body gửi một object làm body cho @POST/@PUT, @Header thêm header. Retrofit chỉ lo phần gọi HTTP, việc đổi JSON thành object (và ngược lại) là của converter: GsonConverterFactory, Moshi hoặc kotlinx.serialization, và phải addConverterFactory khi build, thiếu thì báo lỗi không biết chuyển @Body/kiểu trả về. Tên field trong data class phải khớp key JSON, khác thì ánh xạ bằng @SerializedName, @Json(name = ...) hoặc @SerialName. Với hàm suspend, Retrofit trả thẳng body và ném HttpException khi server trả 4xx/5xx, IOException khi mất mạng. Lưu ý: Gson không biết null safety của Kotlin, field thiếu trong JSON có thể thành null dù khai báo non-null, trong khi Moshi và kotlinx.serialization chặt hơn.
data class UserDto(
  val id: Int,
  val name: String,
  @SerializedName("avatar_url") val avatarUrl: String?, // key JSON khác tên field
)

data class CreateUserRequest(val name: String)

interface UserApi {
  @GET("users/{id}")
  suspend fun getUser(@Path("id") id: Int): UserDto                        // GET users/42

  @GET("users")
  suspend fun searchUsers(@Query("q") keyword: String): List<UserDto>      // GET users?q=an

  @POST("users")
  suspend fun createUser(@Body request: CreateUserRequest): UserDto        // body được converter đổi sang JSON
}

val api: UserApi = Retrofit.Builder()
  .baseUrl("https://api.example.com/")                  // phải kết thúc bằng "/"
  .addConverterFactory(GsonConverterFactory.create())   // JSON <-> object
  .build()
  .create(UserApi::class.java)
