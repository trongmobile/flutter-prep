Với kotlinx.serialization và cấu hình Json mặc định, decode JSON có thêm key price mà class không khai báo thì sao?

@Serializable
data class Product(val id: Int, val name: String)

val json = """{"id":1,"name":"Phone","price":100}"""
val product = Json.decodeFromString<Product>(json)
  1. AParse thành công, key price bị bỏ qua
  2. BLỗi compile vì Product thiếu field price
  3. CNém SerializationException vì gặp key lạ
  4. DParse thành công nhưng name bằng null
Xem đáp án
Đáp án đúng: C
Mặc định Json ném lỗi khi gặp key không khai báo trong class, để phát hiện sớm sai lệch với API. Khi backend có thể thêm field mới, cấu hình Json { ignoreUnknownKeys = true } và dùng chung instance đó trong app.
