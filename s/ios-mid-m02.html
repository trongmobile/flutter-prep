Task group dưới đây thêm task theo thứ tự 3, 1, 2 với thời gian ngủ tỉ lệ theo n. Mảng result in ra là gì?

let result = await withTaskGroup(of: Int.self) { group in
  for n in [3, 1, 2] {
    group.addTask {
      try? await Task.sleep(for: .milliseconds(n * 100))
      return n
    }
  }
  var values: [Int] = []
  for await value in group { values.append(value) }
  return values
}
print(result)

Đáp án đúng: A
for await trên task group trả kết quả theo thứ tự child task hoàn thành, không theo thứ tự addTask. Task ngủ 100ms xong trước nên ra [1, 2, 3]; khoảng cách 100ms đủ lớn để thứ tự ổn định. Muốn giữ thứ tự ban đầu thì trả kèm index rồi sắp xếp lại.
