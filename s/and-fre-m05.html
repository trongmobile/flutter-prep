Đoạn code so sánh hai object data class sau in ra gì?

data class Point(val x: Int, val y: Int)

fun main() {
  val a = Point(1, 2)
  val b = Point(1, 2)
  println(a == b)
  println(a === b)
}
  1. Atrue rồi false
  2. Btrue rồi true
  3. Cfalse rồi false
  4. Dfalse rồi true
Xem đáp án
Đáp án đúng: A
Trong Kotlin, == gọi equals(), mà data class tự sinh equals() so sánh theo giá trị nên kết quả là true. === so sánh tham chiếu, hai object được tạo riêng nên ra false; người từ Java hay nhầm == của Kotlin là so sánh tham chiếu.
