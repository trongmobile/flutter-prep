Màn hình SwiftUI có ViewModel tải dữ liệu từ API. Mỗi khi view cha cập nhật (đổi tab rồi quay lại, hoặc cha có bộ đếm thời gian), ViewModel của màn con bị tạo lại, mất dữ liệu và gọi lại API. Nguyên nhân là gì, và quyền sở hữu state (@State, @StateObject, @ObservedObject, @Observable) được khai báo đúng thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
View của SwiftUI là struct nhẹ và bị dựng lại liên tục theo state của cha; state thật sống ở chỗ khác do SwiftUI quản lý, gắn với identity của view trong cây. @ObservedObject chỉ quan sát một object do bên ngoài giữ: viết @ObservedObject var vm = DetailViewModel() thì mỗi lần cha dựng lại struct sẽ tạo một ViewModel mới nên mất state. @StateObject (iOS 14 trở lên) khiến SwiftUI giữ object suốt vòng đời view và chỉ chạy autoclosure khởi tạo một lần; quy tắc là view sở hữu ViewModel thì dùng @StateObject, view chỉ được truyền vào thì dùng @ObservedObject. Với @Observable (iOS 17), view sở hữu thì dùng @State var model = Model(), view nhận từ ngoài thì chỉ cần let/var thường (hoặc @Bindable khi cần binding). Bẫy: @State không có autoclosure như @StateObject, nên Model() được khởi tạo lại mỗi lần struct view được dựng (bản mới bị bỏ đi nhưng init vẫn chạy), vì vậy init của model phải nhẹ và không gọi API; việc tải đặt ở .task { }, mà .task chạy lại mỗi lần view xuất hiện nên cần cờ loaded hoặc kiểm tra dữ liệu đã có. Nguyên nhân thứ hai là identity: đổi id, if/else trả hai view khác nhau, hay ForEach với id không ổn định đều khiến SwiftUI coi là view mới và reset state, nên cần giữ identity ổn định và dùng modifier điều kiện thay cho nhánh if khi muốn giữ state.
struct OrderListScreen: View {
  @State private var model = OrderListModel() // view sở hữu: giữ suốt vòng đời, init phải nhẹ

  var body: some View {
    List(model.orders) { OrderRow(order: $0) }
      .task { await model.loadIfNeeded() } // không gọi API trong init
  }
}

@Observable
final class OrderListModel {
  var orders: [Order] = []
  private var loaded = false

  func loadIfNeeded() async {
    guard !loaded else { return } // .task chạy lại mỗi lần view xuất hiện
    orders = (try? await OrderAPI.fetchOrders()) ?? []
    loaded = true
  }
}

// iOS 16 trở xuống dùng ObservableObject:
// view sở hữu dùng @StateObject, view được truyền vào dùng @ObservedObject
