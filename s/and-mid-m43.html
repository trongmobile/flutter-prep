Bản debug parse JSON đúng, nhưng bản release (isMinifyEnabled = true, chỉ dùng rule R8 mặc định của AGP, UserDto không có @SerializedName và không có keep rule) lại cho displayName là null dù JSON hợp lệ. Nguyên nhân gần nhất là gì?

data class UserDto(val id: Long, val displayName: String)

val user = Gson().fromJson(json, UserDto::class.java)
// json = {"id":1,"displayName":"Lan"}
  1. AR8 đổi tên field nên tên field không còn khớp với key trong JSON
  2. BBản release tắt reflection trên field private nên Gson không gán được giá trị
  3. CR8 xoá constructor của UserDto nên Gson tạo object rỗng và bỏ qua mọi field
  4. DGson cần thêm kotlin-reflect trong bản release mới parse được data class Kotlin
Xem đáp án
Đáp án đúng: A
Gson ánh xạ JSON vào field theo tên bằng reflection; R8 obfuscate displayName thành tên ngắn nên key JSON không còn khớp và field giữ giá trị mặc định. Sửa bằng @SerializedName("displayName"), keep rule cho package DTO, hoặc dùng thư viện sinh code lúc compile như Moshi codegen/kotlinx.serialization. Reflection vẫn chạy bình thường trên bản release.
