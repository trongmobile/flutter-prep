Push hiện bình thường khi app ở background, nhưng khi app đang mở thì không thấy banner, và bấm vào thông báo chỉ mở app ở màn cũ chứ không vào đúng đơn hàng. Bạn cài UNUserNotificationCenterDelegate thế nào, và truyền payload để điều hướng ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Khi app ở foreground, hệ thống mặc định không hiện thông báo. Phải gán UNUserNotificationCenter.current().delegate và trả về tuỳ chọn hiển thị trong userNotificationCenter(_:willPresent:): [.banner, .list, .sound] (.alert đã deprecated từ iOS 14); có thể trả [] khi người dùng đang ở đúng cuộc chat đó. Gán delegate sớm, trong application(_:didFinishLaunchingWithOptions:), không phải trong một view hay VC: nếu app được mở từ thông báo lúc đang bị kill, delegate phải có sẵn trước khi launch xong thì mới nhận được didReceive. Khi người dùng bấm thông báo, userNotificationCenter(_:didReceive:) được gọi: đọc response.notification.request.content.userInfo (dữ liệu tuỳ chỉnh như orderId nằm ngoài khối aps) và xét response.actionIdentifier (UNNotificationDefaultActionIdentifier là bấm vào thân thông báo). Đừng push màn hình trực tiếp từ AppDelegate: lúc cold start UI có thể chưa dựng xong, nên lưu route chờ xử lý rồi để router hoặc coordinator mở khi sẵn sàng. Payload giới hạn 4KB, chỉ gửi ID rồi để màn hình tự tải chi tiết. Nếu bật Swift 6 language mode mà compiler báo lỗi Sendable ở các hàm delegate này, hãy khai báo conformance là @preconcurrency UNUserNotificationCenterDelegate.
final class AppDelegate: NSObject, UIApplicationDelegate, UNUserNotificationCenterDelegate {
  func application(_ application: UIApplication,
                   didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]? = nil) -> Bool {
    UNUserNotificationCenter.current().delegate = self  // đặt sớm, trước khi launch xong
    return true
  }

  // App đang mở: thiếu hàm này thì thông báo không hiện
  func userNotificationCenter(_ center: UNUserNotificationCenter,
                              willPresent notification: UNNotification) async -> UNNotificationPresentationOptions {
    [.banner, .list, .sound]
  }

  // Người dùng bấm vào thông báo
  func userNotificationCenter(_ center: UNUserNotificationCenter,
                              didReceive response: UNNotificationResponse) async {
    guard response.actionIdentifier == UNNotificationDefaultActionIdentifier,
          let orderId = response.notification.request.content.userInfo["orderId"] as? String
    else { return }
    await MainActor.run {
      AppRouter.shared.pendingRoute = .orderDetail(id: orderId) // root view mở màn khi UI sẵn sàng
    }
  }
}
