OrderDetailViewModel cần orderId (chỉ biết lúc chạy) cùng repository do Hilt cung cấp; ngoài ra dự án có hai OkHttpClient (một có interceptor auth, một cho CDN không auth). Hilt xử lý từng trường hợp thế nào, và khi nào nên dùng cách nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đây là hai bài toán khác nhau. Tham số chỉ biết lúc chạy thì Hilt không tự inject được. Với ViewModel, nếu giá trị đến từ argument của Navigation hoặc Intent extras thì cách đơn giản nhất là SavedStateHandle: Hilt tự inject nó và argument đã nằm sẵn bên trong. Khi giá trị không đến từ argument (như một object truyền vào từ danh sách) thì dùng @AssistedInject: tham số runtime đánh @Assisted, thêm một @AssistedFactory có hàm create(...), và khai báo @HiltViewModel(assistedFactory = ...); trong Compose lấy bằng hiltViewModel kèm creationCallback. Bẫy: ViewModel được cache theo key, tham số đổi mà key không đổi thì vẫn nhận ViewModel cũ, nên truyền key theo tham số. Với nhiều binding cùng kiểu, Dagger coi OkHttpClient là một key duy nhất nên hai @Provides cùng kiểu sẽ báo duplicate binding. Dùng @Qualifier tự định nghĩa (type-safe, đổi tên bằng IDE an toàn) hoặc @Named("cdn") (nhanh, nhưng là chuỗi nên gõ sai chỉ lộ lúc build). Qualifier phải có ở cả nơi provide lẫn nơi inject. Pattern này cũng dùng cho CoroutineDispatcher (@IoDispatcher) để test thay bằng test dispatcher. Nên ưu tiên @Qualifier cho thứ dùng lặp lại; @Named chỉ hợp cho trường hợp đơn lẻ.
@HiltViewModel(assistedFactory = OrderDetailViewModel.Factory::class)
class OrderDetailViewModel @AssistedInject constructor(
  @Assisted private val orderId: String,
  private val repo: OrderRepository,
) : ViewModel() {
  @AssistedFactory
  interface Factory { fun create(orderId: String): OrderDetailViewModel }
}

@Composable
fun OrderDetailRoute(orderId: String) {
  val vm = hiltViewModel<OrderDetailViewModel, OrderDetailViewModel.Factory>(
    key = orderId, // key theo tham số: đổi orderId thì tạo ViewModel mới
    creationCallback = { factory -> factory.create(orderId) },
  )
}

@Qualifier @Retention(AnnotationRetention.BINARY) annotation class AuthClient
@Qualifier @Retention(AnnotationRetention.BINARY) annotation class CdnClient

@Module
@InstallIn(SingletonComponent::class)
object NetworkModule {
  @Provides @Singleton @AuthClient
  fun authClient(auth: AuthInterceptor): OkHttpClient =
    OkHttpClient.Builder().addInterceptor(auth).build()

  @Provides @Singleton @CdnClient
  fun cdnClient(): OkHttpClient = OkHttpClient()
}
