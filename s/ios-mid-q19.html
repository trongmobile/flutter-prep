Dự án mới target iOS 17 trở lên, team phân vân giữa SwiftData và Core Data. Bạn cân nhắc những gì trước khi chọn?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
SwiftData xây trên nền Core Data nhưng API thuần Swift: model khai báo bằng macro @Model, quản lý qua ModelContainer/ModelContext, SwiftUI đọc dữ liệu bằng @Query tự cập nhật, ít boilerplate hơn hẳn. Đổi lại nó còn mới: một số thứ của Core Data như NSFetchedResultsController cho UIKit, batch insert/update hay tuỳ biến sâu chưa có tương đương đầy đủ, và hành vi có thay đổi giữa các bản iOS nên cần test kỹ trên từng phiên bản hỗ trợ. Về concurrency, ModelContext và object @Model không Sendable; việc nặng ở background dùng actor @ModelActor với context riêng, giữa các context chỉ truyền PersistentIdentifier. App SwiftUI là chính, schema vừa phải thì SwiftData hợp lý; app UIKit lớn, cần kiểm soát hiệu năng chặt hoặc đã đầu tư Core Data thì nên giữ Core Data, và hai bên có thể dùng chung một store để chuyển dần.
