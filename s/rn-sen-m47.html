App chạy New Architecture với React 19. Profile của user 'a' đã hiển thị xong, dữ liệu của 'b' chưa có trong cache. Khi user bấm nút, điều gì xảy ra?

function ProfileScreen() {
  const [userId, setUserId] = useState('a');
  const [isPending, startTransition] = useTransition();

  return (
    <View>
      <Button title='Đổi user' onPress={() => startTransition(() => setUserId('b'))} />
      {isPending && <Text>Đang tải...</Text>}
      <Suspense fallback={<Spinner />}>
        {/* Profile đọc dữ liệu bằng use(promise), promise được cache theo userId */}
        <Profile userId={userId} />
      </Suspense>
    </View>
  );
}
  1. AProfile của 'a' vẫn hiện, isPending là true cho tới khi dữ liệu của 'b' sẵn sàng, Spinner không hiện
  2. BSpinner hiện ngay vì Profile bị suspend, Suspense luôn thay nội dung đang hiển thị bằng fallback ngay lập tức
  3. CComponent hiển thị 'b' ngay với dữ liệu rỗng rồi tự cập nhật lại khi promise hoàn tất sau đó
  4. DApp báo lỗi vì không được để một component bị suspend bên trong callback của startTransition

Đáp án đúng: A
Một cập nhật trong transition không được phép ẩn nội dung đã hiển thị để thay bằng fallback: React giữ UI cũ trên màn, đặt isPending thành true và chỉ commit khi 'b' sẵn sàng. Nếu gọi setUserId('b') mà không bọc trong transition thì Spinner mới hiện và nội dung cũ bị ẩn. Suspend bên trong transition là trường hợp được hỗ trợ chính thức, và Profile không bao giờ render với dữ liệu rỗng.
