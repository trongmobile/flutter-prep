Làm sao chặn thao tác back khi form chưa lưu và hỏi xác nhận người dùng?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Dùng PopScope (thay cho WillPopScope đã deprecated): đặt canPop: false khi còn thay đổi chưa lưu để chặn back, và xử lý trong onPopInvokedWithResult khi người dùng cố back. Trong callback, nếu didPop là true thì route đã đóng nên không làm gì; ngược lại hiện dialog xác nhận và tự gọi Navigator.pop nếu người dùng đồng ý. Việc phải quyết định trước bằng canPop (thay vì callback trả về bool như WillPopScope) là để hỗ trợ predictive back của Android.
PopScope(
  canPop: !_hasUnsavedChanges,
  onPopInvokedWithResult: (didPop, result) async {
    if (didPop) return;
    final leave = await showDialog<bool>(
      context: context,
      builder: (_) => const ConfirmLeaveDialog(),
    );
    if (leave == true && context.mounted) Navigator.pop(context);
  },
  child: const EditForm(),
)
