Bên trong component Card, biến subtitle có kiểu gì?

type CardProps = {
  title: string;
  subtitle?: string;
};

function Card({ title, subtitle }: CardProps) {
  return <Text>{title}</Text>;
}
  1. Astring
  2. Bstring | null
  3. Cstring | null | undefined
  4. Dstring | undefined
Xem đáp án
Đáp án đúng: D
Dấu ? cho phép bỏ qua prop khi dùng component, lúc đó giá trị là undefined, nên TypeScript tính kiểu là string | undefined và buộc kiểm tra trước khi gọi method của string. null không tự động nằm trong kiểu này; muốn bỏ undefined thì gán mặc định như subtitle = ''.
