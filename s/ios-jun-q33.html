Card sản phẩm có cornerRadius và bạn thêm bóng đổ. Đặt layer.masksToBounds = true thì bóng biến mất; tắt đi thì bóng hiện nhưng danh sách nhiều card cuộn bị giật. Vì sao, và làm sao để vừa bo góc, vừa có bóng, vừa mượt?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
masksToBounds (tương đương clipsToBounds) cắt mọi thứ vẽ ra ngoài bounds của layer, trong đó có cả bóng, nên bóng chỉ hiện khi layer không bị clip. Còn khi layer có bóng mà không khai báo shadowPath, Core Animation phải dựa vào hình dạng nội dung (kênh alpha) để tính ra bóng, thường cần thêm một lượt render ngoài màn hình (offscreen rendering) cho mỗi card, nên cuộn giật. Giải pháp: tách hai view, view ngoài chỉ giữ bóng, view trong giữ nội dung với bo góc và clipsToBounds; đồng thời gán shadowPath bằng UIBezierPath bo góc tương ứng trong layoutSubviews (vì cần bounds đúng) để hệ thống khỏi phải tự tính. Kiểm tra bằng Debug > Color Off-screen Rendered trên Simulator, vùng bị offscreen sẽ nhuốm màu vàng, rồi đo lại bằng Instruments.
final class CardView: UIView {
  private let content = UIView() // view con: bo góc và clip nội dung

  override init(frame: CGRect) {
    super.init(frame: frame)
    // View ngoài chỉ giữ bóng, không clip
    layer.shadowColor = UIColor.black.cgColor
    layer.shadowOpacity = 0.2
    layer.shadowRadius = 8
    layer.shadowOffset = CGSize(width: 0, height: 4)

    content.layer.cornerRadius = 12
    content.clipsToBounds = true
    content.frame = bounds
    content.autoresizingMask = [.flexibleWidth, .flexibleHeight]
    addSubview(content)
  }
  required init?(coder: NSCoder) { fatalError("init(coder:) chưa cài đặt") }

  override func layoutSubviews() {
    super.layoutSubviews()
    // Khai báo sẵn hình dạng bóng để không phải tính từ nội dung
    layer.shadowPath = UIBezierPath(roundedRect: bounds, cornerRadius: 12).cgPath
  }
}
