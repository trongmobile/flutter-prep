Đoạn code dùng string interpolation sau in ra gì?

void main() {
  int a = 2, b = 3;
  print('$a + $b = ${a + b}');
}
  1. A2 + 3 = 23
  2. B5 = 5
  3. C$a + $b = 5
  4. D2 + 3 = 5
Xem đáp án
Đáp án đúng: D
$a chèn giá trị của một biến, còn biểu thức như a + b phải đặt trong ${...} và được tính như phép cộng số bình thường. Phần $a + $b chỉ là hai giá trị biến xen giữa bởi chuỗi + , không phải phép cộng hay nối chuỗi.
