App có 15 feature, mỗi team sở hữu một feature package; toàn bộ route đang nằm trong một file router.dart khổng lồ, tham số truyền bằng chuỗi ('/orders/$id') nên sai là lỗi runtime, và feature A không được import trực tiếp feature B. Bạn thiết kế navigation ở quy mô này thế nào với go_router?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mỗi feature package export danh sách RouteBase của riêng mình (cùng các route con), app shell chỉ ghép chúng lại; nhờ vậy team sở hữu route của feature mình và router.dart không còn là điểm nghẽn merge. Tham số truyền bằng route có kiểu: go_router_builder sinh class từ @TypedGoRoute (OrderDetailRoute(id: '123').go(context)), nên sai tên route hay thiếu tham số là lỗi compile; tham số trong URL chỉ nên là id và bộ lọc nhỏ, dữ liệu lớn tải lại theo id (để deep link, khôi phục state và nút back hoạt động). Cross-feature: feature A không biết feature B mà phụ thuộc vào một package 'contracts' nhỏ chứa route đã định kiểu hoặc interface điều hướng (OrderNavigator.openOrder(id)), app shell nối contract tới implementation qua DI; hoặc nhận callback từ app shell. Guard và redirect tập trung ở router gốc (redirect kèm refreshListenable theo trạng thái auth) để không rải kiểm tra đăng nhập vào từng màn; deep link khi chưa đăng nhập thì giữ đích lại và tiếp tục sau khi login. Bottom navigation giữ stack từng tab bằng StatefulShellRoute. Cần có quy tắc: mỗi đường dẫn do một nơi sở hữu; test cấu hình route (mỗi route khớp URL mong đợi, redirect chạy đúng) bằng test thuần không dựng UI; NavigatorObserver để ghi analytics màn hình; và xử lý route lỗi (errorBuilder) cho link không hợp lệ. Cũng nên bọc điều hướng sau một lớp mỏng vì API của package đổi giữa các major, để thay thế được khi cần.
// Trong package feature_orders: route có kiểu, do team Orders sở hữu
@TypedGoRoute<OrdersRoute>(
  path: '/orders',
  routes: [TypedGoRoute<OrderDetailRoute>(path: ':id')],
)
class OrdersRoute extends GoRouteData {
  const OrdersRoute();

  @override
  Widget build(BuildContext context, GoRouterState state) => const OrderListPage();
}

class OrderDetailRoute extends GoRouteData {
  const OrderDetailRoute({required this.id});
  final String id;

  @override
  Widget build(BuildContext context, GoRouterState state) => OrderDetailPage(id: id);
}

// Dùng: sai tên route hoặc thiếu tham số là lỗi compile
const OrderDetailRoute(id: '123').go(context);

// App shell: ghép route của các feature (mỗi feature export List<RouteBase>), guard đặt tập trung một chỗ
final router = GoRouter(
  routes: [...ordersRoutes, ...profileRoutes, ...cartRoutes],
  refreshListenable: authNotifier,
  redirect: (context, state) {
    final loggedIn = authNotifier.isLoggedIn;
    if (!loggedIn && !state.matchedLocation.startsWith('/login')) {
      return '/login?from=${Uri.encodeComponent(state.uri.toString())}'; // nhớ đích để quay lại sau khi đăng nhập
    }
    return null;
  },
);
