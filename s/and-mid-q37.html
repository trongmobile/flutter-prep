Bạn thêm animation mở rộng thẻ và đổi màu trong Compose; dùng animateDpAsState thì cả composable recompose liên tục suốt animation và hơi giật. Các API animation chính của Compose (animate*AsState, AnimatedVisibility, updateTransition, Animatable) dùng khi nào, và đọc giá trị animation ở phase nào để tránh recompose thừa?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Chọn API theo nhu cầu. animate*AsState (animateDpAsState, animateColorAsState...) cho animation một giá trị đi theo state mục tiêu: state đổi thì giá trị chạy tới mục tiêu mới. AnimatedVisibility cho nội dung vào hoặc ra (kèm enter/exit), AnimatedContent khi nội dung thay đổi theo state, Crossfade cho trường hợp đơn giản. updateTransition khi nhiều giá trị phải đổi đồng bộ theo cùng một state (màu, kích thước, độ mờ của một thẻ), Transition quản lý chung nên không lệch nhịp. Animatable khi cần điều khiển bằng code trong coroutine (animateTo, snapTo, stop), ví dụ hiệu ứng rung hoặc bám theo cử chỉ. animationSpec quyết định cảm giác: tween (thời lượng, easing), spring (vật lý, bị ngắt giữa chừng vẫn mượt vì giữ vận tốc), keyframes. Về hiệu năng: giá trị animation đổi mỗi frame; nếu đọc nó ngay trong body composable (Modifier.width(animatedDp)) thì mỗi frame composable recompose (đi qua cả phase composition rồi layout). Hãy đọc giá trị ở phase muộn hơn bằng lambda của modifier: Modifier.graphicsLayer { alpha = animatedAlpha } (phase draw), Modifier.offset { IntOffset(x, 0) } (phase layout), drawBehind { }; khi đó chỉ phase đó chạy lại mà không recompose. Ưu tiên animate các thuộc tính chỉ cần vẽ lại (alpha, scale, translation, rotation) hơn là kích thước vốn buộc layout lại. Đặt label cho transition để xem trong Animation Preview của Android Studio.
@Composable
fun ExpandableCard(expanded: Boolean, title: String, content: @Composable () -> Unit) {
  val transition = updateTransition(targetState = expanded, label = "card")
  val arrow by transition.animateFloat(label = "arrow") { if (it) 180f else 0f }
  val containerColor by transition.animateColor(label = "color") {
    if (it) MaterialTheme.colorScheme.primaryContainer else MaterialTheme.colorScheme.surface
  }

  // containerColor đọc ở composition nên Card recompose mỗi frame: chấp nhận được vì Card nhỏ
  Card(colors = CardDefaults.cardColors(containerColor = containerColor)) {
    Row(verticalAlignment = Alignment.CenterVertically) {
      Text(title, modifier = Modifier.weight(1f))
      Icon(
        Icons.Default.ExpandMore,
        contentDescription = null,
        // Đọc giá trị animation trong lambda của graphicsLayer: chỉ phase draw chạy lại, không recompose mỗi frame
        modifier = Modifier.graphicsLayer { rotationZ = arrow },
      )
    }
    AnimatedVisibility(
      visible = expanded,
      enter = expandVertically() + fadeIn(),
      exit = shrinkVertically() + fadeOut(),
    ) {
      content()
    }
  }
}
