Gọi map trên một List rồi lấy .first: đoạn code sau in ra những dòng nào, theo thứ tự?

void main() {
  final nums = [1, 2, 3];
  final doubled = nums.map((n) {
    print('map $n');
    return n * 2;
  });
  print('start');
  print(doubled.first);
}
  1. Amap 1, map 2, map 3, start, 2
  2. Bstart, map 1, 2
  3. Cstart, map 1, map 2, map 3, 2
  4. Dmap 1, start, 2
Xem đáp án
Đáp án đúng: B
map trả về một Iterable lazy: callback chưa chạy cho tới khi có ai duyệt, và .first chỉ cần phần tử đầu nên callback chạy đúng một lần. Muốn tính ngay toàn bộ thì gọi .toList(); nếu duyệt lại Iterable lazy nhiều lần thì callback cũng chạy lại nhiều lần.
