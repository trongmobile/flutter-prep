Bản release được build với --obfuscate --split-debug-info=build/symbols. Stack trace Dart trên Crashlytics toàn tên vô nghĩa. Bước nào còn thiếu?

  1. AUpload mapping.txt của R8/ProGuard, vì Dart AOT dùng chung file mapping với code Java/Kotlin
  2. BBuild lại cùng commit nhưng bỏ --obfuscate để lấy bản stack trace dễ đọc tương ứng
  3. CUpload các file .symbols của đúng build đó lên crash reporter, hoặc dùng flutter symbolize
  4. DKhông có cách nào, vì stack trace của bản build đã obfuscate không thể giải mã ngược
Xem đáp án
Đáp án đúng: C
--split-debug-info tách thông tin symbol của Dart ra các file .symbols theo từng ABI; crash reporter hoặc flutter symbolize cần đúng file của build đó để dịch ngược. mapping.txt của R8 chỉ áp dụng cho code Java/Kotlin, còn build lại sẽ cho binary khác với bản đang chạy.
