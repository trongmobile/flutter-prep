Viết một component tái sử dụng như AppButton thế nào? Khai báo props, giá trị mặc định và cho phép tuỳ biến style ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Một component tái sử dụng tốt có API nhỏ và rõ: khai báo kiểu props bằng TypeScript, props tuỳ chọn có giá trị mặc định ngay ở bước destructuring (variant = 'primary'), và nhận prop style để nơi dùng chỉnh thêm. Muốn style từ ngoài ghi đè được thì đặt style gốc trước và style truyền vào sau trong mảng, vì phần tử đứng sau thắng: style={[styles.base, style]}. Thay vì copy component ra nhiều bản, dùng prop biến thể như variant: 'primary' | 'outline'. Bọc bằng Pressable để có phản hồi khi nhấn và có disabled. Component chung không nên tự gọi API hay tự điều hướng; hãy nhận onPress từ bên ngoài để dùng được ở mọi màn hình. Nếu cần chèn nội dung tuỳ ý bên trong (ví dụ icon kèm chữ) thì nhận children kiểu React.ReactNode thay vì thêm hàng loạt prop.
type AppButtonProps = {
  title: string;
  onPress: () => void;
  variant?: 'primary' | 'outline';     // tuỳ chọn, mặc định primary
  disabled?: boolean;
  style?: StyleProp<ViewStyle>;        // cho nơi dùng chỉnh thêm
};

export function AppButton({ title, onPress, variant = 'primary', disabled, style }: AppButtonProps) {
  return (
    <Pressable
      onPress={onPress}
      disabled={disabled}
      style={({ pressed }) => [
        styles.base,
        variant === 'outline' && styles.outline,
        pressed && { opacity: 0.7 },
        disabled && { opacity: 0.4 },
        style,                          // style truyền từ ngoài đặt cuối để ghi đè
      ]}
    >
      <Text style={[styles.text, variant === 'outline' && styles.textOutline]}>{title}</Text>
    </Pressable>
  );
}
