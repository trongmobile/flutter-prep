Công ty muốn biến app RN thành một 'super app': các nhóm khác nhau (ví, đặt xe, mua sắm) tự phát hành mini-app độc lập mà không phải chờ bản phát hành chung của app host. Bạn thiết kế kiến trúc thế nào (tải bundle động, cô lập, version) và rủi ro lớn nhất là gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Ý chính là tách app thành host (shell) và nhiều mini-app là các bundle JS tải lúc chạy. Với RN có hai hướng: dùng Re.Pack (bundler dựa trên webpack/Rspack của Callstack) cùng Module Federation để mỗi mini-app build ra bundle riêng và dùng chung react, react-native dưới dạng singleton, host nạp bundle từ xa qua ScriptManager; hoặc mỗi mini-app là một bundle Metro độc lập chạy trong runtime riêng (cô lập tốt hơn nhưng tốn memory và khó dùng chung dependency). Hợp đồng giữa host và mini-app phải rõ ràng: một API 'bridge' có version (xác thực, điều hướng, thanh toán, analytics, storage riêng cho từng mini-app) thay vì cho mini-app chạm thẳng vào native module của host; mỗi mini-app khai báo phiên bản host tối thiểu, host từ chối nạp nếu không tương thích. Rủi ro lớn nhất: binary của host là cố định nên phải đóng gói sẵn mọi native dependency mà mini-app dùng (camera, maps) vì mini-app chỉ đổi được JS; lệch version react hay react-native giữa host và mini-app gây lỗi hook hay crash khó hiểu; bundle remote là code thực thi nên phải ký và kiểm tra tính toàn vẹn, đồng thời phải quản lý quyền (permission, dữ liệu user) của mini-app bên thứ ba; và Apple, Google có điều khoản về việc tải code lúc chạy nên cần xem lại chính sách của từng store. Vận hành: registry mini-app có kênh staging và production, rollout theo phần trăm, kill switch từ xa, theo dõi crash gắn nhãn theo mini-app và version, cache bundle để chạy được offline; và đo thời gian khởi động mini-app (tải bundle, khởi tạo) vì đó là trải nghiệm user cảm nhận.
// Host: nạp mini-app từ xa lúc chạy
ScriptManager.shared.addResolver(async (scriptId) => {
  const entry = await miniAppRegistry.resolve(scriptId, { hostVersion: HOST_VERSION, channel });
  if (!entry) return undefined; // host quá cũ cho mini-app này: không nạp
  return { url: entry.url, verifyScriptSignature: 'strict' }; // bundle remote là code thực thi: phải ký
});

const WalletApp = React.lazy(() => Federated.importModule('wallet', './WalletApp'));

  </Suspense>
</ErrorBoundary>;
