Trong viewDidLoad (main thread), code trộn main.async và global().sync. Thứ tự in ra là gì?

print("1")
DispatchQueue.main.async { print("2") }
DispatchQueue.global().sync { print("3") }
print("4")
  1. A1 2 3 4
  2. B1 3 2 4
  3. C1 3 4 2
  4. DDeadlock ngay sau khi in 1
Xem đáp án
Đáp án đúng: C
main.async chỉ xếp block in 2 vào main queue, nó chạy khi main thread xong việc hiện tại. global().sync chặn main thread tới khi in 3 xong nhưng không deadlock vì đó là queue khác; sau đó in 4, rồi mới tới 2.
