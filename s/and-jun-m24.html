Tác vụ nào phù hợp với Dispatchers.Default hơn Dispatchers.IO?

  1. AĐọc một file JSON lớn từ bộ nhớ trong của máy
  2. BChạy query đồng bộ tới SQLite
  3. CSắp xếp và lọc 50.000 phần tử trong RAM
  4. DGọi SDK cũ có API mạng dạng blocking
Xem đáp án
Đáp án đúng: C
Default có số thread bằng số nhân CPU (tối thiểu 2), dành cho tính toán giữ CPU bận như sort, lọc, xử lý ảnh. IO có nhiều thread hơn để chịu được việc thread bị chặn khi chờ file, database, mạng; đặt việc chờ I/O lên Default sẽ chiếm hết thread dành cho tính toán.
