FlutterMiddleTesting & CI/CDCâu hỏi phỏng vấn

Team muốn kiểm thử luồng 'đăng nhập, thêm vào giỏ, thanh toán' chạy trên thiết bị hoặc emulator. Viết integration_test thế nào, nó khác widget test ở đâu, và xử lý hộp thoại quyền của hệ điều hành cùng tính flaky ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
integration_test chạy toàn bộ app (không phải một widget riêng) trên thiết bị hoặc emulator: khai báo trong dev_dependencies, đặt file ở integration_test/, bắt đầu bằng IntegrationTestWidgetsFlutterBinding.ensureInitialized(), gọi app.main() hoặc tester.pumpWidget(MyApp()), rồi dùng cùng API với widget test (find, tap, enterText, pumpAndSettle) và chạy bằng flutter test integration_test -d <device>. Khác widget test ở chỗ nó chạy trên engine và nền tảng thật (plugin thật, platform channel thật, hiệu năng thật) nên chậm và tốn kém hơn, chỉ nên phủ vài luồng sống còn. Để ổn định: tìm bằng Key hoặc find.bySemanticsLabel thay vì text dễ đổi; thay backend thật bằng server giả hoặc môi trường staging có dữ liệu cố định (qua dart-define hoặc DI override); pumpAndSettle có thể treo nếu có animation lặp vô hạn (spinner) nên dùng pump(duration) hoặc chờ theo điều kiện bằng vòng pump kèm timeout; reset state (đăng xuất, xoá DB) giữa các test. Hộp thoại quyền và UI native của hệ điều hành nằm ngoài Flutter nên integration_test không điều khiển được: dùng patrol (có native automation) hoặc cấp quyền trước bằng adb shell pm grant hay cấu hình simulator. Cũng có thể đo hiệu năng bằng binding.traceAction và chạy trên Firebase Test Lab hoặc device farm trong CI. Test flaky cần bị cách ly và có người sửa, không retry vô hạn.
// integration_test/checkout_flow_test.dart
void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  testWidgets('đăng nhập, thêm vào giỏ và thanh toán thành công', (tester) async {
    app.main(); // chạy toàn bộ app, backend giả chọn qua dart-define
    await tester.pumpAndSettle();

    await tester.enterText(find.byKey(const Key('email')), 'an@example.com');
    await tester.enterText(find.byKey(const Key('password')), '123456');
    await tester.tap(find.byKey(const Key('login-button')));
    await tester.pumpAndSettle();

    await tester.tap(find.byKey(const Key('add-to-cart-1')));
    await tester.pump(const Duration(milliseconds: 500)); // không pumpAndSettle nếu có spinner lặp vô hạn

    await tester.tap(find.byKey(const Key('checkout-button')));
    await tester.pumpAndSettle();
    expect(find.text('Đặt hàng thành công'), findsOneWidget);
  });
}
// Chạy: flutter test integration_test/checkout_flow_test.dart -d emulator-5554
