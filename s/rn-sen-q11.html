Sau một năm, JS bundle của app tăng từ 6MB lên 14MB và startup chậm dần. Bạn phân tích và kiểm soát kích thước bundle thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Tôi tạo bundle production kèm source map rồi phân tích bằng source-map-explorer hoặc react-native-bundle-visualizer để thấy module nào chiếm chỗ. Thủ phạm quen thuộc: thư viện lớn kéo cả gói như moment kèm toàn bộ locale, lodash import nguyên gói thay vì từng hàm, nhiều thư viện trùng chức năng (hai thư viện ngày tháng, ba bộ icon), JSON tĩnh hoặc ảnh base64 lớn nhúng trong code, và code mock/dev lọt vào production. Cần nhớ Metro mặc định không tree-shake mạnh như bundler web, nên import cả gói thường đồng nghĩa với kéo cả gói vào bundle. Để kiểm soát lâu dài: đặt ngân sách kích thước bundle và báo chênh lệch trên CI ở mỗi PR, review dependency mới theo kích thước, tình trạng bảo trì và có kèm native code hay không. Bundle nhỏ hơn còn giúp mỗi bản OTA tải nhanh hơn.
// Kéo toàn bộ lodash vào bundle
import _ from 'lodash';
const onSearch = _.debounce(search, 300);

// Chỉ kéo đúng module cần dùng
import debounce from 'lodash/debounce';
const onSearch2 = debounce(search, 300);
