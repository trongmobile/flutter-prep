App SwiftUI có luồng nhiều màn (danh sách → chi tiết → đánh giá) dùng NavigationStack(path:). Bạn cần nút "Về trang chủ" pop hết về root từ màn sâu và khôi phục đúng chồng màn khi app bị hệ thống kill. NavigationPath khác mảng [Route] ở điểm nào, và bẫy khi trộn nhiều kiểu destination là gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
NavigationPath là collection type-erased: append được các giá trị Hashable thuộc nhiều kiểu khác nhau (Product, Order, Route...), và mỗi kiểu cần đúng một .navigationDestination(for:) tương ứng. Mảng [Route] với Route là enum thì type-safe, đọc được nội dung (path.last, kiểm tra "đang ở màn nào", assert trong test) nên thường là lựa chọn mặc định; chỉ dùng NavigationPath khi thật sự cần trộn nhiều kiểu. Pop về root bằng code là gán lại path rỗng (path = [], hoặc path.removeLast(path.count) với NavigationPath); pop một màn là removeLast(). Để nút "Về trang chủ" hoạt động từ màn sâu, truyền binding hoặc một router @Observable xuống, đừng để mỗi màn tự giữ path. Khôi phục khi app bị kill: nếu Route là Codable thì encode cả mảng ra Data lưu vào @SceneStorage rồi decode lúc khởi tạo; với NavigationPath dùng path.codable (trả về nil nếu có kiểu nào không Codable). Chỉ lưu ID thay vì cả model để dữ liệu cũ không bị khôi phục sai. Bẫy hay gặp: thiếu navigationDestination cho một kiểu thì không push được màn đó (chỉ có cảnh báo trong console); đặt navigationDestination bên trong container lazy như List hay LazyVStack có thể không được nạp, nên gắn ở root view của stack; và NavigationPath không cho đọc phần tử bên trong nên khó debug hơn mảng.
enum Route: Hashable, Codable {
    case detail(productID: String)
    case review(productID: String)
}

struct RootView: View {
    @SceneStorage("nav.path") private var savedPath: Data?
    @State private var path: [Route] = []

    var body: some View {
        NavigationStack(path: $path) {
            ProductList(onGoHome: { path = [] }) // pop về root bằng cách gán mảng rỗng
                .navigationDestination(for: Route.self) { route in
                    switch route {
                    case .detail(let id): ProductDetail(id: id)
                    case .review(let id): ReviewForm(id: id)
                    }
                }
        }
        .task { // khôi phục chồng màn cũ khi view xuất hiện
            if let savedPath, let restored = try? JSONDecoder().decode([Route].self, from: savedPath) {
                path = restored
            }
        }
        .onChange(of: path) { _, newPath in
            savedPath = try? JSONEncoder().encode(newPath)
        }
    }
}
