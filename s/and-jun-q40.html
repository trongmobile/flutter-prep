Tính năng chụp ảnh đại diện: app tạo file trong thư mục ảnh rồi đưa Uri.fromFile(file) cho app Camera thì crash FileUriExposedException. Vì sao, và bạn dùng FileProvider cùng TakePicture contract thế nào? Chia sẻ file cho app khác cần cấp quyền ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Từ Android 7.0 (API 24), đưa URI dạng file:// cho app khác bị cấm vì lộ đường dẫn nội bộ, hệ thống ném FileUriExposedException ngay khi startActivity. Thay vào đó dùng content:// URI do FileProvider cấp: khai báo <provider> trong Manifest với android:authorities="${applicationId}.fileprovider", android:exported="false", android:grantUriPermissions="true", kèm file res/xml/file_paths.xml liệt kê thư mục được chia sẻ (<cache-path>, <files-path>, <external-files-path>). File tạo trong bộ nhớ riêng của app nên không cần quyền lưu trữ; lấy URI bằng FileProvider.getUriForFile(context, authority, file) với authority khớp Manifest. ActivityResultContracts.TakePicture() nhận URI đích và trả Boolean báo chụp thành công, ảnh full-size được ghi vào URI đó (còn TakePicturePreview() chỉ trả thumbnail Bitmap nhỏ). Bẫy: nếu Manifest khai báo quyền CAMERA thì phải xin quyền runtime trước khi mở camera, không thì SecurityException; nhớ lưu URI vào SavedStateHandle hoặc onSaveInstanceState vì process có thể bị kill khi camera đang mở. Chia sẻ file cho app khác (ACTION_SEND) thì thêm FLAG_GRANT_READ_URI_PERMISSION, quyền đọc chỉ cấp tạm cho app nhận.
// Manifest: <provider android:name="androidx.core.content.FileProvider"
//   android:authorities="${applicationId}.fileprovider" android:exported="false"
//   android:grantUriPermissions="true"> + <meta-data> trỏ tới @xml/file_paths
// res/xml/file_paths.xml: <paths><cache-path name="photos" path="photos/" /></paths>

class ProfileFragment : Fragment() {
    private var photoUri: Uri? = null

    private val takePicture =
        registerForActivityResult(ActivityResultContracts.TakePicture()) { success ->
            if (success) showAvatar(photoUri!!) else photoUri = null
        }

    private fun launchCamera() {
        val dir = File(requireContext().cacheDir, "photos").apply { mkdirs() }
        val file = File.createTempFile("avatar_", ".jpg", dir)
        val authority = "${requireContext().packageName}.fileprovider"
        photoUri = FileProvider.getUriForFile(requireContext(), authority, file)
        takePicture.launch(photoUri!!)
    }

    private fun shareAvatar(uri: Uri) {
        val send = Intent(Intent.ACTION_SEND).apply {
            type = "image/jpeg"
            putExtra(Intent.EXTRA_STREAM, uri)
            addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION) // cấp quyền đọc tạm cho app nhận
        }
        startActivity(Intent.createChooser(send, "Chia sẻ ảnh"))
    }
}
