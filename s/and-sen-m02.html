Perfetto cho thấy main thread thỉnh thoảng bị block vài trăm ms ngay trong current(). Nguyên nhân và cách sửa hợp lý nhất?

class SettingsStore(private val file: File) {
  private val lock = Any()
  private var cached = Settings()

  // gọi từ main thread mỗi lần render
  fun current(): Settings = synchronized(lock) { cached }

  // gọi từ thread IO
  fun save(new: Settings) {
    synchronized(lock) {
      file.writeText(new.toJson()) // vài trăm ms trên máy chậm
      cached = new
    }
  }
}
  1. Asynchronized của Kotlin chuyển khối lệnh sang main thread để chạy
  2. BChờ khoá mà thread IO giữ suốt lúc ghi file; nên ghi file ngoài khoá
  3. Ccurrent() chưa được JIT compile; thêm Baseline Profile là hết block
  4. DGC dừng app để thu hồi cached cũ; nên bọc nó trong SoftReference
Xem đáp án
Đáp án đúng: B
save giữ lock trong suốt thao tác ghi đĩa nên mỗi lần main thread gọi current() lúc đó đều phải chờ, trên trace hiện thành lock contention. Thu hẹp vùng khoá: ghi file ngoài khoá (các lần ghi chạy tuần tự trên một thread riêng) và chỉ khoá lúc gán cached, hoặc dùng @Volatile cho reference tới object bất biến; JIT hay GC không giải thích được một lần chờ dài như vậy.
