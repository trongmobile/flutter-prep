Khi viết CustomPainter, shouldRepaint và tham số repaint dùng để làm gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
shouldRepaint(old) được gọi khi CustomPaint nhận một instance painter mới: trả true nếu dữ liệu vẽ khác (so field với old), trả false để bỏ qua bước paint; luôn true thì lãng phí, luôn false thì chart không cập nhật khi data đổi. Với animation, truyền Listenable (ví dụ AnimationController) vào super(repaint: ...): painter vẽ lại mỗi khi listenable thông báo mà không cần rebuild widget. Giữ paint() nhẹ (không I/O, không tính toán nặng), và với hình animate liên tục có thể bọc RepaintBoundary để không kéo phần còn lại của màn hình repaint theo.
class ProgressPainter extends CustomPainter {
  ProgressPainter(this.progress, this.color) : super(repaint: progress);
  final Animation<double> progress;
  final Color color;
  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()..color = color..strokeWidth = 6;
    canvas.drawLine(Offset.zero, Offset(size.width * progress.value, 0), paint);
  }
  @override
  bool shouldRepaint(ProgressPainter old) =>
      old.progress != progress || old.color != color;
}
