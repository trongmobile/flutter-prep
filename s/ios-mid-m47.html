User rời màn hình khi request đang chạy, loadFeed() bị huỷ, nhưng app vẫn hiện alert "Không tải được feed". Vì sao catch is CancellationError không bắt được?

func loadFeed() async {
  do {
    let (data, _) = try await URLSession.shared.data(from: feedURL)
    feed = try JSONDecoder().decode([Post].self, from: data)
  } catch is CancellationError {
    // task bị huỷ: bỏ qua
  } catch {
    errorMessage = "Không tải được feed" // hiện alert
  }
}
  1. AURLSession không hỗ trợ huỷ nên request chạy xong rồi ném lỗi timeout
  2. BURLSession ném URLError(.cancelled) thay vì CancellationError
  3. CJSONDecoder nhận data rỗng sau khi bị huỷ nên ném DecodingError
  4. DHàm async không ném CancellationError, chỉ có hàm throws mới ném
Xem đáp án
Đáp án đúng: B
Khi task chứa nó bị huỷ, URLSession huỷ request và ném URLError với code == .cancelled (NSURLErrorCancelled, -999; đã chạy thử trên macOS), không phải CancellationError, nên lỗi rơi xuống catch chung. Cần thêm catch let error as URLError where error.code == .cancelled hoặc kiểm tra Task.isCancelled trước khi hiện alert.
