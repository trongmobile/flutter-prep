App Android gọi API REST cần chuẩn bị gì? Vì sao gọi http:// hoặc localhost của máy dev lại không được?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Trước hết khai báo quyền INTERNET trong manifest (thiếu thì lỗi SecurityException: Permission denied (missing INTERNET permission?)), thêm thư viện HTTP như Retrofit/OkHttp cùng thư viện parse JSON (Gson, Moshi hoặc kotlinx.serialization), và gọi mạng ngoài main thread. Từ Android 9 (API 28), HTTP không mã hoá bị chặn mặc định với lỗi Cleartext HTTP traffic to ... not permitted: server production phải dùng HTTPS; khi dev thì chỉ cho phép đúng domain cần thiết trong network_security_config.xml (nên đặt ở bản debug), tránh bật usesCleartextTraffic="true" cho cả app. Trên emulator, localhost hay 127.0.0.1 chính là emulator chứ không phải máy dev; địa chỉ máy dev là 10.0.2.2. Máy thật cùng Wi-Fi thì dùng IP LAN của máy dev, hoặc chạy adb reverse tcp:3000 tcp:3000 để dùng được localhost.
<!-- AndroidManifest.xml -->
<uses-permission android:name="android.permission.INTERNET" />

<application
  android:networkSecurityConfig="@xml/network_security_config">
  ...
</application>

<!-- res/xml/network_security_config.xml: chỉ cho phép HTTP tới máy dev khi chạy emulator -->
<network-security-config>
  <domain-config cleartextTrafficPermitted="true">
    <domain includeSubdomains="false">10.0.2.2</domain>
  </domain-config>
</network-security-config>

<!-- Retrofit.Builder().baseUrl("http://10.0.2.2:3000/") -->
