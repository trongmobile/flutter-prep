Tính năng chọn ảnh cần quyền Photos, tính năng cửa hàng gần đây cần quyền vị trí. User từ chối một lần là tính năng 'câm', và có người chỉ cấp quyền ảnh 'đã chọn' (limited) hoặc vị trí gần đúng. Bạn thiết kế luồng xin quyền và xử lý các trạng thái thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Nguyên tắc là xin quyền đúng lúc cần, kèm lời giải thích của app trước khi hệ thống hiện hộp thoại, vì hộp thoại hệ thống chỉ hiện một lần khi trạng thái là notDetermined; sau khi bị từ chối chỉ đưa user tới Settings được (UIApplication.openSettingsURLString). Luôn khai báo chuỗi NS...UsageDescription trong Info.plist, thiếu thì app crash khi xin quyền. Phải xử lý đủ trạng thái: notDetermined (xin), authorized, denied (hướng dẫn mở Settings), restricted (do Screen Time hoặc MDM, không xin được) và với Photos còn có limited. Nhiều tính năng không cần quyền: chọn ảnh bằng PHPickerViewController (hoặc PhotosPicker của SwiftUI) chạy ngoài process, không cần quyền thư viện ảnh và app chỉ nhận ảnh user đã chọn; chỉ xin quyền Photos khi cần duyệt cả thư viện hoặc lưu ảnh (addOnly). Với vị trí, từ iOS 14 theo dõi thay đổi qua locationManagerDidChangeAuthorization(_:), kiểm tra authorizationStatus và accuracyAuthorization (user có thể chỉ cho vị trí gần đúng .reducedAccuracy; cần chính xác thì xin requestTemporaryFullAccuracyAuthorization(withPurposeKey:)). Quyền whenInUse thường là đủ; chỉ xin always khi thật sự cần chạy nền. Thiết kế UI để tính năng vẫn dùng được khi bị từ chối (nhập địa chỉ tay thay GPS), đừng chặn cả app, và kiểm tra lại quyền khi app quay về foreground vì user có thể đổi trong Settings bất cứ lúc nào.
final class LocationPermission: NSObject, CLLocationManagerDelegate {
  enum Access { case undetermined, granted(precise: Bool), denied, restricted }

  private let manager = CLLocationManager()
  var onChange: ((Access) -> Void)?

  override init() {
    super.init()
    manager.delegate = self
  }

  func request() { manager.requestWhenInUseAuthorization() } // gọi sau khi đã giải thích lý do cho user

  // iOS 14+: gọi lúc khởi tạo delegate và mỗi khi user đổi quyền trong Settings
  func locationManagerDidChangeAuthorization(_ manager: CLLocationManager) {
    switch manager.authorizationStatus {
    case .notDetermined: onChange?(.undetermined)
    case .restricted: onChange?(.restricted)
    case .denied: onChange?(.denied) // chỉ đưa user tới Settings được
    case .authorizedWhenInUse, .authorizedAlways:
      onChange?(.granted(precise: manager.accuracyAuthorization == .fullAccuracy))
    @unknown default: onChange?(.denied)
    }
  }
}

// Chọn ảnh không cần quyền Photos: PHPicker chạy ngoài process
var config = PHPickerConfiguration()
config.selectionLimit = 1
config.filter = .images
present(PHPickerViewController(configuration: config), animated: true)
