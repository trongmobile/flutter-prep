Model Todo dưới đây khai báo id là computed property. Điều gì xảy ra với list khi body được tính lại?

struct Todo: Identifiable {
  var id: UUID { UUID() }
  var title: String
}

struct TodoList: View {
  @State private var todos = Todo.samples
  var body: some View {
    List(todos) { todo in
      TodoRow(todo: todo) // TodoRow có @State riêng (đang sửa, đang mở rộng…)
    }
  }
}
  1. AKhông sao, vì UUID() luôn duy nhất nên vẫn thoả Identifiable
  2. BLỗi compile vì id của Identifiable phải là stored property
  3. Cid đổi mỗi lần đọc nên row bị coi là view mới và mất @State
  4. DChỉ animation bị sai, còn @State của từng row vẫn giữ nguyên
Xem đáp án
Đáp án đúng: C
SwiftUI dùng id để nối view giữa các lần render; id computed trả UUID mới mỗi lần nên không row nào khớp với lần trước, state bị huỷ, animation sai và tốn chi phí dựng lại. Identifiable không bắt buộc stored property nên code vẫn compile, vì thế bug này rất khó thấy.
