Dự án cần gọi API thanh toán đòi secret key. Một bạn viết const SECRET_KEY = 'sk_live_abc' ngay trong code TypeScript của app rồi build bản release. Nhận định nào đúng?

  1. AKhông an toàn: bundle JS lấy ra đọc được, secret phải ở backend
  2. BAn toàn nếu đã bật Hermes, vì bytecode là mã nhị phân không đọc được
  3. CAn toàn nếu đưa key vào file .env và không commit file đó lên Git
  4. DAn toàn nếu cắt key thành nhiều đoạn rồi nối lại lúc app chạy
Xem đáp án
Đáp án đúng: A
Mọi thứ nằm trong app đều nằm trên máy người dùng: họ giải nén file cài đặt, lấy bundle JS (Hermes bytecode vẫn lộ chuỗi và có thể decompile) và tìm ra key. Biến .env thường được nhúng thẳng vào bundle lúc build, còn tách chuỗi chỉ là che mắt. Secret phải nằm ở server: app chỉ gọi backend của bạn (kèm xác thực người dùng), backend mới gọi bên thứ ba.
