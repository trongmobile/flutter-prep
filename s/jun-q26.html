Dùng package http, khi server trả 404 hoặc 500 thì http.get có ném exception không? Nên xử lý thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Không. http chỉ ném lỗi khi có sự cố ở tầng kết nối (mất mạng, không phân giải được tên miền…), còn mọi HTTP status đều trả về Response bình thường, nên phải tự kiểm tra response.statusCode trước khi jsonDecode body. Thường gom việc này vào một lớp API client: 2xx thì parse, còn lại ném một exception tự định nghĩa (ví dụ ApiException) chứa status và message để UI hiển thị phù hợp. Ngược lại, dio mặc định coi status ngoài 2xx là lỗi và ném DioException, có thể đổi qua validateStatus.
final res = await http.get(Uri.parse('$baseUrl/users/1'));
if (res.statusCode == 200) {
  return User.fromJson(jsonDecode(res.body) as Map<String, dynamic>);
}
throw ApiException(res.statusCode, res.body);
