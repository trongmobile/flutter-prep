SettingsRepository được khởi tạo mới trong mỗi ViewModel (không phải singleton), nên cùng lúc có hai instance tạo DataStore trỏ tới file settings. Khi cả hai đọc hoặc ghi dữ liệu thì sao?

class SettingsRepository(context: Context) {
  private val dataStore = PreferenceDataStoreFactory.create(
    produceFile = { context.preferencesDataStoreFile("settings") }
  )

  val darkMode: Flow<Boolean> = dataStore.data.map { it[DARK_MODE] ?: false }

  suspend fun setDarkMode(on: Boolean) {
    dataStore.edit { it[DARK_MODE] = on }
  }

  private companion object {
    val DARK_MODE = booleanPreferencesKey("dark_mode")
  }
}
  1. AHai DataStore tự đồng bộ với nhau qua file nên dữ liệu luôn nhất quán
  2. BNém IllegalStateException vì có nhiều DataStore cùng hoạt động trên một file
  3. CCả hai chạy bình thường, lần ghi sau cùng ghi đè lần trước như SharedPreferences
  4. DInstance tạo sau bị suspend cho tới khi instance trước bị đóng hoàn toàn

Đáp án đúng: B
Mỗi file chỉ được có một DataStore hoạt động trong cùng process; nếu có nhiều instance cùng file thì khi đọc hoặc cập nhật dữ liệu DataStore ném IllegalStateException (multiple DataStores active for the same file). Cần giữ DataStore là singleton, ví dụ qua property delegate preferencesDataStore ở top level hoặc provide @Singleton bằng Hilt; chúng không tự đồng bộ và cũng không chặn nhau.
