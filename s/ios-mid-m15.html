Property wrapper Trimmed cắt khoảng trắng và đếm số lần gán qua projectedValue. Sau hai lần gán, dòng print in ra gì?

@propertyWrapper
struct Trimmed {
  var value = ""
  var projectedValue = 0 // đếm số lần gán
  var wrappedValue: String {
    get { value }
    set { value = newValue.trimmingCharacters(in: .whitespaces); projectedValue += 1 }
  }
}
struct Form { @Trimmed var name: String }

var form = Form()
form.name = "  An  "
form.name = " Bình"
print("[\(form.name)]", form.$name)
  1. A[ Bình] 2
  2. B[Bình] 1
  3. C[Bình] 2
  4. DLỗi compile: $name chỉ dùng được trong SwiftUI
Xem đáp án
Đáp án đúng: C
Mỗi lần gán, setter của wrappedValue cắt khoảng trắng hai đầu và tăng projectedValue, nên sau hai lần gán có Bình và 2. $name truy cập projectedValue của bất kỳ property wrapper nào, không riêng gì SwiftUI.
