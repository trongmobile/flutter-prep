Banner mờ dần hiện ra trong 500ms khi mount. Nếu người dùng bấm Text (gây re-render) khi animation đang chạy giữa chừng, điều gì xảy ra?

function Banner() {
  const [count, setCount] = useState(0);
  const opacity = new Animated.Value(0);

  useEffect(() => {
    Animated.timing(opacity, {
      toValue: 1,
      duration: 500,
      useNativeDriver: true,
    }).start();
  }, []);

  return (
    <Animated.View style={{ opacity }}>
      <Text onPress={() => setCount(count + 1)}>Đã bấm {count} lần</Text>
    </Animated.View>
  );
}
  1. AAnimation chạy tiếp tới hết vì useNativeDriver: true chạy độc lập với React
  2. BAnimation khởi động lại từ đầu vì mỗi lần render effect chạy lại
  3. CBanner nhảy về trong suốt vì mỗi lần render tạo một Animated.Value mới
  4. DAnimation dừng ở giá trị hiện tại vì re-render huỷ animation đang chạy
Xem đáp án
Đáp án đúng: C
new Animated.Value(0) trong thân component tạo một giá trị mới (đang ở 0) sau mỗi lần render: animation đang chạy vẫn cập nhật Value cũ, nhưng Animated.View giờ gắn với Value mới, và effect với deps [] không chạy lại nên banner kẹt ở trạng thái trong suốt. Giữ cùng một đối tượng qua các lần render bằng useRef(new Animated.Value(0)).current, đúng như ví dụ trong tài liệu.
