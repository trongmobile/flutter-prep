API trả về {"name": "Cà phê", "price": 25000} và app chạy trên Android. Đoạn code sau cho kết quả gì?

import 'dart:convert';

class Product {
  Product(this.name, this.price);
  final String name;
  final double price;

  factory Product.fromJson(Map<String, dynamic> json) =>
      Product(json['name'] as String, json['price'] as double);
}

void main() {
  final json = jsonDecode('{"name": "Cà phê", "price": 25000}');
  print(Product.fromJson(json).price);
}
  1. AIn ra 25000.0, vì as double tự đổi số nguyên thành số thực
  2. BNém TypeError, vì 25000 được jsonDecode đọc thành int chứ không phải double
  3. CLỗi compile vì không thể ép giá trị dynamic sang double bằng as
  4. DIn ra 25000, vì Dart coi int là kiểu con của double nên phép ép luôn thành công
Xem đáp án
Đáp án đúng: B
jsonDecode trả int cho số không có phần thập phân hay số mũ (như 25000) và double cho số có (như 25000.5). int và double đều là kiểu con của num chứ không phải con của nhau, và as double chỉ kiểm tra kiểu chứ không chuyển đổi, nên ném lỗi type 'int' is not a subtype of type 'double' in type cast (trên Android/iOS). Lỗi này hay xuất hiện chập chờn khi server trả 25000 lúc này và 25000.5 lúc khác. Cách đúng là (json['price'] as num).toDouble().
