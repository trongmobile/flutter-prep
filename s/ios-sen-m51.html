Trong một Swift package có hai target Networking và FeatureOrders; FeatureOrders cần gọi một API nội bộ của Networking, nhưng bạn không muốn lộ API này cho app hay package khác import Networking. Mức truy cập nào phù hợp?

  1. Apackage: chỉ các module cùng package nhìn thấy, bên ngoài package thì không
  2. Bpublic kèm tiền tố _ trong tên để báo hiệu đây là API nội bộ, không nên dùng
  3. Cinternal rồi dùng @testable import Networking trong FeatureOrders
  4. Dopen, vì open là mức duy nhất cho phép module khác trong cùng package gọi tới

Đáp án đúng: A
package (Swift 5.9, SE-0386) cho mọi module build trong cùng package dùng API, còn client ngoài package không thấy; hợp với modularization bằng nhiều target. public với tiền tố _ chỉ là quy ước, ai cũng gọi được; internal kèm @testable chỉ chạy khi module build với testability (thường chỉ Debug), build Release báo module was not compiled for testing; open còn rộng hơn public vì cho phép cả subclass từ bên ngoài.
