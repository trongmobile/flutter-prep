Feed dùng UICollectionViewDiffableDataSource với identifier là id của post. Mỗi lần bấm thích, code dưới làm cell nháy và cuộn bị khựng. Cách sửa phù hợp nhất?

func toggleLike(_ postID: Post.ID) {
  store.toggleLike(postID) // cập nhật model
  var snapshot = dataSource.snapshot()
  snapshot.reloadItems([postID])
  dataSource.apply(snapshot)
}
  1. AGọi collectionView.reloadData() để cập nhật một lần cho gọn
  2. BTạo identifier mới cho post rồi apply snapshot mới
  3. CGọi invalidateLayout() của layout ngay sau khi apply
  4. DDùng reconfigureItems để cấu hình lại cell đang hiện
Xem đáp án
Đáp án đúng: D
reloadItems thay cell hiện tại bằng cell mới lấy qua cell provider nên dễ nháy và tốn chi phí; reconfigureItems (iOS 15+) chạy lại phần cấu hình trên chính cell đang hiển thị nên nhẹ và không nháy. Đổi identifier thì diffable coi như xoá item cũ và chèn item mới, còn reloadData() bỏ qua cả cơ chế diff lẫn animation.
