ViewModel có isLoading, items, error là ba property riêng nên UI thỉnh thoảng hiện cả spinner lẫn thông báo lỗi, hoặc danh sách cũ cùng màn lỗi. Bạn tái cấu trúc thế nào, và xử lý sự kiện một lần như alert hay điều hướng ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Gốc vấn đề là ba property độc lập cho phép tổ hợp vô nghĩa như isLoading == true cùng error != nil, và mọi chỗ trong code phải nhớ tự reset hai biến còn lại. Hãy mô hình hoá các trạng thái hợp lệ bằng một enum, ví dụ idle, loading, loaded(items), failed(message): compiler loại tổ hợp sai, view chỉ cần switch một lần, và mọi chuyển trạng thái nằm ở một chỗ trong ViewModel (view gửi action, ViewModel đổi state). Nếu cần giữ danh sách cũ khi đang refresh hay khi lỗi thì đừng nhét vào loading làm mất dữ liệu: dùng struct { items, phase } hoặc loaded(items, isRefreshing:). Sự kiện một lần như alert, toast, điều hướng không nên là state sống lâu vì xoay máy hay quay lại màn sẽ hiện lại. Có hai cách: biến chúng thành state có vòng đời rõ ràng (vd. alert: AlertInfo? gắn với .alert(item:), view gán nil khi user đóng; điều hướng thì ghi vào path/route), hoặc dùng AsyncStream cho sự kiện kiểu bắn-rồi-quên, chấp nhận mất sự kiện nếu lúc đó không ai lắng nghe. Đánh đổi: enum lồng nhiều tầng khó đọc nên giữ phẳng, và cho state conform Equatable để test dễ (#expect(states == [.loading, .loaded(items)])).
enum LoadState<Value> {
    case idle
    case loading
    case loaded(Value)
    case failed(String)
}

@MainActor @Observable
final class OrdersViewModel {
    private(set) var state: LoadState<[Order]> = .idle
    var alert: AlertInfo? // sự kiện một lần: view gán nil khi user đóng
    private let repository: OrderRepository

    init(repository: OrderRepository) { self.repository = repository }

    func load() async {
        if case .loading = state { return } // chặn load chồng nhau
        state = .loading
        do {
            state = .loaded(try await repository.fetchOrders())
        } catch {
            state = .failed(error.localizedDescription)
        }
    }
}

struct OrdersScreen: View {
    @State var viewModel: OrdersViewModel

    var body: some View {
        Group {
            switch viewModel.state {
            case .idle, .loading: ProgressView()
            case .loaded(let orders): OrderList(orders: orders)
            case .failed(let message): ErrorView(message: message, retry: { Task { await viewModel.load() } })
            }
        }
        .task { await viewModel.load() }
    }
}
