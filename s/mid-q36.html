Một widget chỉ hiển thị tên người dùng nhưng bị rebuild mỗi khi bất kỳ field nào của User đổi (như điểm thưởng cập nhật liên tục). Bạn dùng ref.watch(provider.select(...)) của Riverpod thế nào, và khi nào select không giúp được?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
ref.watch(userProvider) làm widget rebuild mỗi khi provider phát giá trị mới (khác theo ==), kể cả khi phần widget dùng không đổi. ref.watch(userProvider.select((u) => u.name)) chỉ rebuild khi giá trị mà select trả về đổi (so bằng ==), nên hợp để theo dõi một field của model lớn hay một thuộc tính dẫn xuất (select((s) => s.items.length)). Với AsyncValue, lấy field từ giá trị đã có bằng select((a) => a.asData?.value.name). select cũng dùng được với ref.listen để phản ứng với thay đổi một phần (hiện SnackBar khi riêng error đổi) mà không chạy callback cho các thay đổi khác. Lưu ý: hàm select phải trả về giá trị so sánh được; trả về list hay object mới mỗi lần (.where(...), .toList()) thì luôn khác nên vẫn rebuild liên tục, cần model có == đúng (freezed, Equatable) hoặc trả về kiểu nguyên thuỷ. select chỉ giảm rebuild của widget phía người dùng, còn provider vẫn tính lại bình thường, nên tính toán nặng cần tách thành provider riêng. Chia nhỏ provider theo mối quan tâm (một provider cho profile, một cho điểm thưởng) là cách tối ưu căn bản hơn; đừng rải select khắp nơi để chữa thiết kế state quá to.
class UserNameText extends ConsumerWidget {
  const UserNameText({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    // Chỉ rebuild khi name đổi, bỏ qua thay đổi của points, avatar...
    final name = ref.watch(userProvider.select((u) => u.name));
    return Text(name);
  }
}

// Lắng nghe một phần của state: hiện SnackBar khi chỉ riêng error đổi
ref.listen(
  checkoutProvider.select((s) => s.error),
  (previous, next) {
    if (next != null) {
      ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text(next)));
    }
  },
);

// AsyncValue: lấy field từ giá trị đã có
final city = ref.watch(profileProvider.select((a) => a.asData?.value.city));
