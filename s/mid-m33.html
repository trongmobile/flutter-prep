Hàm save nhận tham số kiểu Order (class tự định nghĩa). Test ném StateError ngay tại dòng when(...). Cách sửa là gì?

class MockRepo extends Mock implements OrderRepository {}

test('lưu đơn hàng', () async {
  final repo = MockRepo();
  when(() => repo.save(any())).thenAnswer((_) async {});
  // ...
});
  1. AĐổi thenAnswer thành thenReturn(Future.value())
  2. BGọi registerFallbackValue(FakeOrder()) trong setUpAll
  3. CĐổi any() thành any<Order>() để chỉ rõ kiểu
  4. DĐánh dấu MockRepo bằng annotation @GenerateMocks

Đáp án đúng: B
any() của mocktail cần một giá trị fallback cho kiểu tham số: kiểu primitive có sẵn, còn class tự định nghĩa phải đăng ký bằng registerFallbackValue (thường với class FakeOrder extends Fake implements Order {}). Ghi rõ any<Order>() vẫn cần fallback, còn @GenerateMocks là của mockito.
