App crash trên máy test. Bạn đọc Logcat và stack trace để tìm nguyên nhân thế nào? Các mức log khác nhau ra sao và lọc log thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mở Logcat trong Android Studio, chọn đúng thiết bị và lọc theo app (package:mine), để mức level:error cho gọn. Tìm dòng FATAL EXCEPTION: ngay dưới là loại exception cùng message (NullPointerException, IllegalStateException...) rồi stack trace. Cách đọc: đi từ trên xuống, bỏ qua các dòng của framework (android.*, androidx.*, kotlinx.*) và tìm dòng đầu tiên thuộc package của mình (ví dụ MainActivity.onCreate(MainActivity.kt:27)): đó là chỗ cần mở. Luôn kéo xuống xem Caused by: cuối cùng vì nguyên nhân gốc thường nằm ở đó, exception ngoài cùng chỉ là lớp bọc (ví dụ Unable to start activity). Các mức log tăng dần: Log.v (Verbose), d (Debug), i (Info), w (Warn), e (Error); lọc thêm theo tag: hoặc từ khoá. Khi chỉ đọc log chưa đủ, đặt breakpoint ở lề dòng code, chạy bằng Debug, rồi xem giá trị biến, Step Over/Step Into và Evaluate Expression thay vì đoán. Bẫy: log token, mật khẩu hay dữ liệu cá nhân (log có thể lộ qua adb hoặc bug report), và nuốt exception bằng catch rỗng khiến không còn gì để đọc.
// Stack trace trong Logcat (rút gọn):
// FATAL EXCEPTION: main
// java.lang.RuntimeException: Unable to start activity ComponentInfo{com.example.shop/com.example.shop.MainActivity}
//     at android.app.ActivityThread.performLaunchActivity(...)      <- framework, bỏ qua
// Caused by: java.lang.NullPointerException: Attempt to invoke virtual method 'void android.widget.TextView.setText(...)' on a null object reference
//     at com.example.shop.MainActivity.onCreate(MainActivity.kt:27) <- dòng đầu tiên của app: mở dòng này

private const val TAG = "MainActivity"

Log.d(TAG, "Đã tải ${items.size} sản phẩm")       // thông tin phục vụ debug
Log.e(TAG, "Tải đơn hàng thất bại", exception)    // truyền cả exception để in stack trace
// Lọc trong Logcat: package:mine level:error   hoặc   tag:MainActivity
