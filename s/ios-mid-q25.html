App SwiftUI cần mở thẳng màn chi tiết đơn hàng khi user bấm universal link https://shop.vn/orders/123, kể cả khi app đang ở tab khác hoặc đã push nhiều màn. Bạn tổ chức navigation thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Dùng NavigationStack(path:) với path là mảng route Hashable (enum Route) hoặc NavigationPath, đặt trong một router @Observable để điều khiển điều hướng bằng code: push là append, pop về root là gán mảng rỗng. Mỗi kiểu route đăng ký đích đến bằng .navigationDestination(for:) gắn bên trong stack. Khi nhận link qua .onOpenURL (nhận cả universal link lẫn custom scheme), parse URL thành route, chọn đúng tab rồi gán lại cả path. Universal link cần file apple-app-site-association trên domain và entitlement Associated Domains (applinks:shop.vn); nếu máy chưa cài app, link mở website. Nhớ xử lý trường hợp user chưa đăng nhập: lưu route lại và điều hướng sau khi login xong.
enum Route: Hashable {
  case orders
  case orderDetail(id: String)
}

@Observable final class Router {
  var path: [Route] = []
  func handle(_ url: URL) {
    guard url.pathComponents.count == 3, url.pathComponents[1] == "orders" else { return }
    path = [.orders, .orderDetail(id: url.pathComponents[2])]
  }
}
