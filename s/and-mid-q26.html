Màn Home cần ghép dữ liệu từ ba nguồn Flow độc lập (user, orders từ Room, settings từ DataStore) thành một UiState. Bạn dùng combine, zip hay merge, và những chi tiết nào (giá trị đầu tiên, lỗi, giá trị trùng) hay gây lỗi?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
combine(a, b, c) { ... } phát một giá trị mỗi khi bất kỳ flow nào phát giá trị mới, kết hợp với giá trị mới nhất của các flow còn lại; đây là lựa chọn đúng khi ghép state từ nhiều nguồn thành một UiState. Chi tiết quan trọng: combine chỉ phát lần đầu khi tất cả các flow đã phát ít nhất một giá trị, nên nếu một nguồn (như settings) chưa bao giờ phát thì màn hình mãi ở trạng thái ban đầu; nguồn có thể chưa có dữ liệu cần onStart { emit(default) }. zip ghép theo cặp một-một (phần tử thứ n của flow này với phần tử thứ n của flow kia) và kết thúc khi một flow kết thúc, hợp cho hai chuỗi có tương ứng thứ tự, hiếm khi đúng cho state UI. merge gộp nhiều flow cùng kiểu thành một dòng xen kẽ theo thời gian, hợp cho sự kiện từ nhiều nguồn (analytics, thông báo). Cần ghép nhiều hơn 5 flow thì dùng combine(listOf(...)). Lỗi: một flow ném exception thì cả combine kết thúc với lỗi, nên catch ngay trên nhánh đó nếu muốn nguồn ấy lỗi mà màn hình vẫn dùng được. Dùng distinctUntilChanged ở nguồn đổi nhiều, và đưa phép biến đổi nặng ra flowOn(Dispatchers.Default) thay vì làm trong lambda của combine trên main. Kết thúc bằng stateIn(viewModelScope, WhileSubscribed(5_000), Loading).
class HomeViewModel(
  userRepo: UserRepository,
  orderRepo: OrderRepository,
  settings: SettingsRepository,
) : ViewModel() {

  val state: StateFlow<HomeUiState> = combine(
    userRepo.observeUser(),
    orderRepo.observeOrders().catch { emit(emptyList()) }, // nguồn này lỗi thì dùng danh sách rỗng, màn hình vẫn dùng được
    settings.observeCurrency().onStart { emit(Currency.VND) }, // có giá trị mặc định: combine không bị kẹt chờ
  ) { user, orders, currency ->
    HomeUiState.Ready(
      greeting = user.name,
      orders = orders.map { it.toUi(currency) },
    )
  }
    .flowOn(Dispatchers.Default) // phép map nặng không chạy trên main
    .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), HomeUiState.Loading)
}
