FileManager dùng để làm gì? Documents, Caches và tmp khác nhau thế nào, bạn lưu file ở đâu, và khi nào nên dùng file thay vì UserDefaults?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
FileManager đọc, ghi, xoá và liệt kê file, thư mục trong sandbox của app. Ba nơi hay dùng: Documents cho dữ liệu của người dùng không tái tạo được (ảnh đã chụp, tài liệu), được sao lưu cùng thiết bị; Library/Caches cho dữ liệu tải lại được (ảnh cache, response), không được sao lưu và hệ thống có thể xoá khi thiếu dung lượng; tmp (FileManager.default.temporaryDirectory) cho file tạm, nên tự dọn và hệ thống cũng có thể xoá khi app không chạy. Dữ liệu lớn mà tái tạo được thì đừng để ở Documents vì làm phình bản backup; nếu buộc để ở nơi được backup thì đánh dấu isExcludedFromBackup. UserDefaults chỉ hợp cho vài thiết lập nhỏ (cờ onboarding, theme) vì được nạp vào bộ nhớ khi app khởi động; ảnh hay danh sách vài nghìn phần tử thì ghi ra file (ví dụ Codable thành JSON) hoặc dùng database như Core Data, SwiftData. Bẫy: đừng lưu đường dẫn tuyệt đối vì đường dẫn của container có thể đổi sau khi cập nhật hoặc cài lại app, hãy chỉ lưu tên file rồi ghép với thư mục lúc dùng; và xử lý lỗi vì ghi file có thể thất bại (hết dung lượng).
struct Draft: Codable {
    var title: String
    var body: String
}

func draftURL() throws -> URL {
    let documents = try FileManager.default.url(
        for: .documentDirectory, in: .userDomainMask, appropriateFor: nil, create: true)
    return documents.appendingPathComponent("draft.json")   // chỉ nhớ tên file, ghép với thư mục lúc dùng
}

func save(_ draft: Draft) throws {
    let data = try JSONEncoder().encode(draft)
    try data.write(to: draftURL(), options: .atomic)        // .atomic: ghi file tạm rồi mới thay thế
}

func loadDraft() -> Draft? {
    guard let data = try? Data(contentsOf: draftURL()) else { return nil }
    return try? JSONDecoder().decode(Draft.self, from: data)
}

// Dữ liệu tải lại được thì để ở Caches
let caches = FileManager.default.urls(for: .cachesDirectory, in: .userDomainMask)[0]
