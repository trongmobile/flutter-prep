Khi isAdmin đổi từ false sang true, state nội bộ của Profile (ví dụ tab đang chọn) ra sao?

function Screen({ isAdmin }: { isAdmin: boolean }) {
  return isAdmin ? (
    <View style={styles.adminFrame}>
      <Profile />
    </View>
  ) : (
    <Profile />
  );
}
  1. AGiữ nguyên, vì cả hai nhánh đều render cùng component Profile
  2. BGiữ nguyên state, chỉ có useEffect của Profile chạy lại
  3. CReact báo lỗi vì hai nhánh trả về cấu trúc cây khác nhau
  4. DMất state, vì Profile bị unmount rồi mount lại
Xem đáp án
Đáp án đúng: D
React so sánh theo vị trí và type: ở gốc, type đổi từ Profile sang View nên cả cây cũ bị huỷ và Profile mới được mount với state ban đầu. Muốn giữ state thì giữ cấu trúc cây ổn định, ví dụ luôn bọc View và chỉ đổi style.
