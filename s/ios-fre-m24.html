Đoạn code sau hiển thị hai dòng chữ với font như thế nào?

VStack {
    Text("Tiêu đề")
    Text("Mô tả").font(.caption)
}
.font(.title)
  1. ACả hai đều dùng .title vì modifier ngoài cùng ghi đè
  2. BTiêu đề dùng .title, Mô tả dùng .caption
  3. CCả hai dùng font mặc định vì VStack không nhận .font
  4. DTiêu đề dùng font mặc định, Mô tả dùng .caption
Xem đáp án
Đáp án đúng: B
.font đặt trên container được truyền xuống các view con qua environment, nên Tiêu đề nhận .title. Giá trị đặt gần view hơn được ưu tiên, nên Mô tả giữ .caption của riêng nó.
