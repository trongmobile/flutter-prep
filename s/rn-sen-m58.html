Hàm giới hạn 3 upload đồng thời dưới đây được gọi với 5 file, và upload('b') ném lỗi (các file khác đều thành công). Điều gì xảy ra?

async function uploadAll(files: string[], limit = 3) {
  let next = 0;

  const worker = async () => {
    while (next < files.length) {
      const file = files[next++];
      await upload(file);
    }
  };

  await Promise.all(Array.from({ length: limit }, worker));
}

uploadAll(['a', 'b', 'c', 'd', 'e']); // upload('b') ném lỗi
  1. AuploadAll chờ mọi file xử lý xong hết rồi mới reject với lỗi của file b
  2. BMọi worker dừng ngay lập tức nên các file chưa bắt đầu không bao giờ được upload
  3. CuploadAll reject ngay, còn các worker khác vẫn upload tiếp các file còn lại ở nền
  4. DChỉ file b bị bỏ qua, uploadAll vẫn resolve bình thường vì Promise.all nuốt lỗi
Xem đáp án
Đáp án đúng: C
Promise.all reject ngay khi có một promise reject nên uploadAll ném lỗi tại thời điểm đó, nhưng nó không huỷ các promise còn lại. Worker gặp lỗi thoát khỏi vòng while và dừng; hai worker kia vẫn tiếp tục lấy file từ files cho tới hết. Hậu quả là nơi gọi tưởng cả đợt đã thất bại (hiện lỗi, cho thử lại và có thể upload trùng) trong khi upload vẫn diễn ra ngầm. Cách xử lý: bắt lỗi trong worker rồi gom kết quả (giống allSettled), hoặc dùng AbortController để dừng các worker khác khi lỗi đầu tiên xuất hiện.
