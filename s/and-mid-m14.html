Màn hình dùng var filter by rememberSaveable { mutableStateOf(Filter(minPrice = 0, brand = null)) }, trong đó Filter là data class thường, không Parcelable và không có Saver. Điều gì xảy ra?

  1. AChạy bình thường, data class được tự động serialize vào Bundle
  2. BNém IllegalArgumentException vì giá trị không lưu được vào Bundle
  3. CKhông lỗi, nhưng filter âm thầm reset về mặc định khi xoay máy
  4. DLỗi compile vì rememberSaveable chỉ nhận kiểu primitive và String

Đáp án đúng: B
