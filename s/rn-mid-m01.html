ProfileForm giữ nội dung form trong useState. Khi userId đổi từ 'u1' sang 'u2', state của form ra sao?

function ProfileScreen({ userId }: { userId: string }) {
  return <ProfileForm key={userId} userId={userId} />;
}

function ProfileForm({ userId }: { userId: string }) {
  const [name, setName] = useState('');
  return <TextInput value={name} onChangeText={setName} />;
}
  1. AGiữ nguyên, vì ProfileForm vẫn ở cùng vị trí và cùng type
  2. BVề giá trị ban đầu, vì key đổi khiến form mount lại
  3. CReact báo lỗi vì key chỉ dùng cho phần tử trong list
  4. DGiữ nguyên state, chỉ các useEffect của form chạy lại
Xem đáp án
Đáp án đúng: B
key là một phần danh tính của component ở mọi vị trí, không riêng trong list: key đổi thì React unmount instance cũ và mount instance mới với state ban đầu. Nếu không có key, cùng vị trí và cùng type thì state mới được giữ nguyên.
