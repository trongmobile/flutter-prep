Danh sách bài viết dùng infinite scroll nhưng đôi khi tải trùng một trang, bài viết bị lặp sau khi pull-to-refresh, và khi lỗi mạng giữa chừng thì không tải tiếp được. Bạn thiết kế phân trang phía client thế nào (offset hay cursor, trạng thái, phát hiện cuối danh sách, loại trùng)?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Chia trạng thái rõ ràng: danh sách items, nextCursor (hoặc page), cờ isLoadingMore, hasMore và error riêng cho lần tải thêm. Phát hiện gần cuối bằng ScrollController (position.pixels >= position.maxScrollExtent - 300) hoặc NotificationListener<ScrollNotification>, hoặc kích hoạt khi itemBuilder dựng tới item gần cuối; trước khi gọi API luôn kiểm tra isLoadingMore và hasMore để không tải trùng. Dùng cursor (id hoặc thời điểm của item cuối) thay vì offset/page khi dữ liệu thay đổi liên tục: offset dễ làm lặp hoặc sót item khi có bài mới chèn vào đầu. Pull-to-refresh (RefreshIndicator) thì reset cursor và thay toàn bộ danh sách, đồng thời bỏ qua các request tải thêm đang bay (gắn một mã phiên bản) để kết quả cũ không bị nối vào danh sách mới. Loại trùng theo id khi nối trang (dùng Map hoặc Set) phòng khi server trả trùng. Khi lỗi lúc tải thêm: giữ nguyên danh sách và hiện một dòng 'Thử lại' ở cuối, đừng thay cả màn hình bằng lỗi; đặt itemCount: items.length + (hasMore ? 1 : 0) để dòng cuối là spinner hoặc nút thử lại. Có thể dùng package infinite_scroll_pagination, hoặc để Riverpod/Bloc giữ state phân trang và UI chỉ phát sự kiện loadMore.
class PostListController extends ChangeNotifier {
  final _items = <String, Post>{}; // theo id: tự loại bài trùng
  String? _cursor;
  bool hasMore = true;
  bool isLoadingMore = false;
  Object? error;
  int _generation = 0; // tăng khi refresh để bỏ kết quả của request cũ

  List<Post> get items => _items.values.toList();

  Future<void> loadMore() async {
    if (isLoadingMore || !hasMore) return;
    isLoadingMore = true;
    error = null;
    notifyListeners();
    final gen = _generation;
    try {
      final page = await api.fetchPosts(cursor: _cursor, limit: 20);
      if (gen != _generation) return; // đã refresh trong lúc chờ: bỏ kết quả cũ
      for (final p in page.items) {
        _items[p.id] = p;
      }
      _cursor = page.nextCursor;
      hasMore = page.nextCursor != null;
    } catch (e) {
      if (gen == _generation) error = e; // giữ danh sách cũ, chỉ hiện nút thử lại ở cuối
    } finally {
      if (gen == _generation) isLoadingMore = false;
      notifyListeners();
    }
  }

  Future<void> refresh() {
    _generation++;
    _items.clear();
    _cursor = null;
    hasMore = true;
    isLoadingMore = false;
    return loadMore();
  }
}
