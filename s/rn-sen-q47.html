Design yêu cầu một loạt hiệu ứng: nút nhún khi bấm, bottom sheet kéo theo tay, animation onboarding xuất từ After Effects, biểu đồ vẽ tuỳ biến cập nhật liên tục và hiệu ứng làm mờ/shader trên ảnh. Bạn chọn công cụ nào cho từng loại, và dùng ngân sách frame để quyết định ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Ngân sách là 16,6ms mỗi frame ở 60Hz và 8,3ms ở 120Hz; nếu mỗi frame phải đi qua JS thread (tính toán, setState, bridge) thì bất kỳ việc nặng nào cũng làm rớt frame, nên nguyên tắc là để mỗi frame chạy hoàn toàn trên UI thread. Theo từng loại: nút nhún và hiệu ứng tương tác dùng Reanimated (shared value + useAnimatedStyle) chạy trên UI thread; Animated của core với useNativeDriver: true đủ cho opacity/transform đơn giản nhưng không animate được thuộc tính bố cục. Cử chỉ kéo theo tay: Reanimated + Gesture Handler. Animation do designer làm sẵn (onboarding, loading, empty state): Lottie chạy native, không tốn JS mỗi frame; đổi lại là kích thước file và độ phức tạp (nhiều layer, mask, matte tốn CPU/GPU) nên phải kiểm trên máy yếu, và nó là hình vẽ nên không tương tác sâu được. Vẽ tuỳ biến, biểu đồ thời gian thực, blur, shader: Skia (@shopify/react-native-skia) vẽ bằng GPU và kết hợp được với shared value của Reanimated; đổi lại thêm dung lượng bundle, đường cong học tập, và nội dung vẽ trên canvas không tự có accessibility nên phải bổ sung. Tránh animate thuộc tính bố cục (width, height) vì buộc layout lại mỗi frame, ưu tiên transform và opacity, và tôn trọng "giảm chuyển động" của hệ thống. Đo bằng Perf Monitor (JS FPS so với UI FPS), Perfetto/System Trace để xem frame vượt ngân sách, Instruments Core Animation; thử trên máy yếu lẫn máy 120Hz, ở build release.
// Nút nhún: shared value được cập nhật và đọc hoàn toàn trên UI thread, không qua JS mỗi frame
const scale = useSharedValue(1);
const animatedStyle = useAnimatedStyle(() => ({ transform: [{ scale: scale.value }] }));

<Pressable
  onPressIn={() => { scale.value = withSpring(0.96); }}
  onPressOut={() => { scale.value = withSpring(1); }}
  onPress={onPress}
>
  <Animated.View style={animatedStyle}>{children}</Animated.View>
</Pressable>
