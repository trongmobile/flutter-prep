App cần chạy tốt trên điện thoại, máy tính bảng và máy gập: điện thoại dùng thanh điều hướng dưới, màn hình rộng dùng NavigationRail. Bạn thiết kế layout thích ứng (adaptive) thế nào, và .adaptive widget, LayoutBuilder, MediaQuery được dùng ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Dựa vào kích thước cửa sổ chứ không dựa vào loại thiết bị: Material 3 chia theo breakpoint chiều rộng (compact dưới 600dp, medium 600–839dp, expanded từ 840dp). Đọc kích thước cả cửa sổ bằng MediaQuery.sizeOf(context) để chọn kiểu điều hướng (thanh dưới, NavigationRail, thanh bên cố định), còn LayoutBuilder đo không gian cha cấp cho một vùng cụ thể nên hợp với từng component (card đổi từ dọc sang ngang). Dựng cấu trúc master–detail: hẹp thì sang màn chi tiết bằng push, rộng thì hiện danh sách và chi tiết cạnh nhau, và state chọn item nằm ngoài layout để xoay màn hình hay kéo giãn cửa sổ không làm mất. Dùng Flexible/Expanded thay vì kích thước cố định, giới hạn bề rộng nội dung (ConstrainedBox(maxWidth: 600)) trên màn lớn để chữ không bị kéo quá dài. Các widget thích ứng nền tảng như Switch.adaptive, Slider.adaptive, CircularProgressIndicator.adaptive, showAdaptiveDialog chọn kiểu Material hay Cupertino theo nền tảng; nhưng thích ứng kích thước và thích ứng nền tảng là hai việc khác nhau. Máy gập có MediaQuery.displayFeaturesOf (vùng bản lề) để tránh đặt nội dung ngay trên khe gập. Đừng khoá hướng màn hình vì có tablet, ChromeOS và chế độ đa cửa sổ; kiểm tra bằng nhiều cỡ cửa sổ trong DevTools hoặc emulator resizable, và trong flutter test bằng tester.view.physicalSize cho từng breakpoint.
class AdaptiveShell extends StatelessWidget {
  const AdaptiveShell({super.key, required this.index, required this.onSelect, required this.body});
  final int index;
  final ValueChanged<int> onSelect;
  final Widget body;

  static const _destinations = [
    (icon: Icons.home, label: 'Trang chủ'),
    (icon: Icons.receipt_long, label: 'Đơn hàng'),
    (icon: Icons.person, label: 'Tài khoản'),
  ];

  @override
  Widget build(BuildContext context) {
    final width = MediaQuery.sizeOf(context).width; // chiều rộng cửa sổ, không phải loại thiết bị
    if (width >= 600) {
      return Scaffold(
        body: Row(
          children: [
            NavigationRail(
              selectedIndex: index,
              onDestinationSelected: onSelect,
              labelType: NavigationRailLabelType.all,
              destinations: [
                for (final d in _destinations)
                  NavigationRailDestination(icon: Icon(d.icon), label: Text(d.label)),
              ],
            ),
            Expanded(child: body),
          ],
        ),
      );
    }
    return Scaffold(
      body: body,
      bottomNavigationBar: NavigationBar(
        selectedIndex: index,
        onDestinationSelected: onSelect,
        destinations: [
          for (final d in _destinations) NavigationDestination(icon: Icon(d.icon), label: d.label),
        ],
      ),
    );
  }
}
