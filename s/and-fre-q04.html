when trong Kotlin khác switch của Java ở những điểm nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
when không cần break và không có fall-through: nhánh đầu tiên khớp sẽ chạy rồi thoát. Điều kiện linh hoạt hơn nhiều: gộp nhiều giá trị bằng dấu phẩy, kiểm tra khoảng với in 5..7, kiểm tra kiểu với is (kèm smart cast), hoặc viết when không có đối số để thay chuỗi if-else if dài. when còn là expression nên trả về được giá trị; khi dùng như expression thì phải phủ hết mọi trường hợp, thường bằng nhánh else (với enum hay sealed class đã liệt kê đủ thì không cần else).
fun grade(score: Int): String = when (score) {
  10 -> "Xuất sắc"
  8, 9 -> "Giỏi"
  in 5..7 -> "Khá"
  else -> "Cần cố gắng"
}

fun describe(x: Any): String = when (x) {
  is String -> "Chuỗi dài ${x.length}" // smart cast sang String
  is Int -> "Số $x"
  else -> "Kiểu khác"
}
