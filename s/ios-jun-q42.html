Mất mạng thì màn Home trắng trơn và báo lỗi, dù hôm qua người dùng vừa xem xong. Product muốn mở app là thấy ngay dữ liệu cũ rồi cập nhật khi có mạng. Bạn làm cache-then-network thế nào, và có nên dùng NWPathMonitor để chặn gọi API khi 'không có mạng' không?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
ViewModel làm theo thứ tự: đọc cache và hiển thị ngay (đánh dấu là dữ liệu cũ), gọi API, thành công thì cập nhật UI và ghi đè cache, thất bại thì giữ nguyên dữ liệu đang có và chỉ báo nhẹ bằng banner hoặc toast; chỉ hiện lỗi toàn màn khi cache cũng trống. Với model Codable nhỏ, cache đơn giản là encode JSON rồi ghi file (write(to:options: .atomic)) vào thư mục Caches; hệ thống có thể xoá thư mục này khi thiếu dung lượng nên dữ liệu bắt buộc phải giữ thì để Application Support, còn dữ liệu lớn cần truy vấn thì dùng Core Data hoặc SwiftData. NWPathMonitor hợp để hiện banner 'Đang offline' và tự tải lại khi mạng trở lại (nhớ start(queue:) và về main thread khi đổi UI). Không nên dùng nó làm cổng chặn request: .satisfied chỉ nói có đường mạng, không đảm bảo tới được server (captive portal, Wi-Fi không ra internet), còn .unsatisfied có thể sai tạm thời lúc đổi mạng. Cách đúng là cứ gọi request rồi xử lý URLError (.notConnectedToInternet, .timedOut); nếu muốn request chờ có mạng thay vì lỗi ngay thì đặt waitsForConnectivity = true trong URLSessionConfiguration.
struct FeedCache {
  private let url = URL.cachesDirectory.appending(path: "feed.json")

  func load() -> [Post]? {
    guard let data = try? Data(contentsOf: url) else { return nil }
    return try? JSONDecoder().decode([Post].self, from: data)
  }

  func save(_ posts: [Post]) {
    guard let data = try? JSONEncoder().encode(posts) else { return }
    try? data.write(to: url, options: .atomic)
  }
}

// Trong ViewModel (@MainActor)
func refresh() async {
  if let cached = cache.load() { posts = cached; isStale = true } // hiện dữ liệu cũ ngay
  do {
    let fresh = try await api.fetchFeed()
    posts = fresh
    isStale = false
    cache.save(fresh)
  } catch where posts.isEmpty {
    errorMessage = "Không tải được dữ liệu"  // không có gì để hiện mới báo lỗi toàn màn
  } catch {
    showOfflineBanner = true                 // đã có dữ liệu cũ thì chỉ báo nhẹ
  }
}
