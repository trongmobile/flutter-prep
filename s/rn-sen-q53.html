Dự án có độ phủ unit test trên 80%, nhưng đội test bằng cách jest.mock hầu hết hook, sub-component và helper nội bộ. Kết quả là mỗi lần refactor code không đổi hành vi thì hàng chục test gãy, còn lỗi tích hợp giữa màn hình với API hay navigation vẫn lọt lên production. Bạn tái cấu trúc chiến lược test ở tầng Jest/RNTL thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Vấn đề cốt lõi là bộ test đang kiểm tra chi tiết triển khai thay vì hành vi thực tế, nên mock quá sâu làm test vừa giòn khi refactor vừa che mất lỗi nối dây giữa component, hook và tầng dữ liệu. Cách sửa là kéo đường biên mock ra đúng rìa ngoài của hệ thống: chỉ mock mạng ở tầng HTTP bằng MSW (Mock Service Worker), mock các native module (storage, camera, quyền hệ thống), timer và đồng hồ; còn toàn bộ phần bên trong như màn hình, custom hook, store, validation và React Query phải chạy thật cùng nhau. Với React Native Testing Library, mình chuyển trọng tâm sang test tích hợp ở mức màn hình hoặc luồng tính năng: bọc màn hình bằng TestProviders (tạo mới QueryClient với retry: false, store sạch và navigator giả lập), tương tác bằng userEvent và truy vấn phần tử theo vai trò hoặc nhãn hiển thị (getByRole, getByText, getByLabelText) thay vì phụ thuộc vào testID hay kiểm tra hàm nội bộ được gọi mấy lần. Unit test thuần chỉ giữ lại cho các hàm nghiệp vụ phức tạp như tính giá, state machine hay parser nhiều nhánh biên. Để triển khai mà không làm đình trệ team, không nên dừng sprint để viết lại toàn bộ test cũ; thay vào đó mình đặt quy ước cho mọi PR mới và bug fix đều viết integration test theo rìa hệ thống, xoá dần các test mock nội bộ mỗi khi chạm tới file cũ, và đo hiệu quả bằng số lỗi hồi quy lọt ra thay vì chạy theo phần trăm coverage.
// Đúng: chạy thật hook + React Query + UI, chỉ chặn HTTP ở rìa bằng MSW
server.use(
  http.post('/api/coupons/apply', () => HttpResponse.json({ discount: 50000 })),
);

render(<CheckoutScreen />, { wrapper: TestProviders });
const user = userEvent.setup();
await user.type(screen.getByLabelText('Mã giảm giá'), 'SALE50');
await user.press(screen.getByRole('button', { name: 'Áp dụng' }));

expect(await screen.findByText('Giảm 50.000đ')).toBeOnTheScreen();
