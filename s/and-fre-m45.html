Đoạn code Kotlin sau có vấn đề gì?

suspend fun fetchName(): String {
  delay(500)
  return "An"
}

fun onClickLoad() {
  val name = fetchName()
  println(name)
}
  1. ALỗi compile vì hàm thường không gọi trực tiếp được hàm suspend
  2. BChạy bình thường vì suspend tự chuyển sang thread nền
  3. CCompile được, nhưng crash lúc chạy với IllegalStateException
  4. DLỗi compile vì delay chỉ dùng được trong runBlocking
Xem đáp án
Đáp án đúng: A
Hàm suspend chỉ được gọi từ trong một coroutine hoặc từ một hàm suspend khác; onClickLoad là hàm thường nên compiler báo lỗi ngay. Muốn gọi phải mở coroutine, ví dụ lifecycleScope.launch { ... }. suspend chỉ cho phép hàm tạm dừng, không tự tạo thread nền, và delay gọi được trong bất kỳ hàm suspend nào.
