Cài React Navigation cần những gì? NavigationContainer, navigator và screen liên hệ thế nào, khi nào dùng Stack, Tab, Drawer?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Cài @react-navigation/native cùng hai package có native code là react-native-screens và react-native-safe-area-context (với Expo dùng npx expo install), rồi cài navigator cần dùng như @react-navigation/native-stack hoặc @react-navigation/bottom-tabs; trên iOS cần pod install và phải build lại app vì có native code. Cấu trúc: chỉ có một NavigationContainer ở gốc app để giữ state điều hướng; bên trong là navigator tạo bằng createNativeStackNavigator() hay createBottomTabNavigator(), mỗi navigator chứa nhiều Screen với name duy nhất và component. Gọi useNavigation() ở component nằm ngoài NavigationContainer sẽ báo Couldn't find a navigation object, còn render navigator mà thiếu container thì báo Couldn't register the navigator. Chọn loại: Stack cho luồng đi sâu có nút Back (danh sách rồi tới chi tiết); Tab cho 3–5 mục cấp một luôn cần truy cập (Trang chủ, Đơn hàng, Tài khoản); Drawer cho nhiều mục ít dùng (Drawer cần thêm react-native-gesture-handler và react-native-reanimated). Thường lồng nhau: Tab ở ngoài, mỗi tab chứa một Stack riêng. Khai báo kiểu ParamList cho navigator giúp TypeScript kiểm tra tên màn hình và params khi gọi navigate.
type RootStackParamList = {
  Home: undefined;            // không có params
  Detail: { id: number };
};

const Stack = createNativeStackNavigator<RootStackParamList>();

export default function App() {
  return (
    <NavigationContainer>     {/* chỉ một container ở gốc app */}
      <Stack.Navigator initialRouteName="Home">
        <Stack.Screen name="Home" component={HomeScreen} options={{ title: 'Trang chủ' }} />
        <Stack.Screen name="Detail" component={DetailScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}
