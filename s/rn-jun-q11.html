Danh sách sản phẩm phân trang bằng onEndReached, nhưng thỉnh thoảng cùng một trang bị tải hai lần, có lúc vừa mở màn hình đã gọi luôn trang 2. Vì sao và xử lý thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
onEndReached có thể bị gọi nhiều lần liên tiếp khi người dùng cuộn quanh vùng cuối, và gọi ngay sau lần render đầu nếu trang đầu chưa lấp đầy màn hình (khoảng cách tới cuối đã nhỏ hơn ngưỡng). Vì vậy cần cờ chặn: đang tải hoặc đã hết dữ liệu thì bỏ qua; cờ nên để trong useRef vì nó đổi ngay lập tức, không phải đợi re-render như state. onEndReachedThreshold tính theo đơn vị chiều dài vùng hiển thị của list, 0.5 nghĩa là gọi khi phần nội dung chưa cuộn tới chỉ còn khoảng nửa chiều dài vùng hiển thị. Ngoài ra keyExtractor phải trả về id ổn định và duy nhất; trang mới chứa item trùng với trang cũ sẽ gây trùng key và hiển thị sai.
const loadingRef = useRef(false);

const loadMore = async () => {
  if (loadingRef.current || !hasMore) return; // đang tải hoặc đã hết
  loadingRef.current = true;
  try {
    const res = await api.getProducts(page + 1);
    setItems((prev) => [...prev, ...res.items]);
    setPage(page + 1);
    setHasMore(res.hasMore);
  } finally {
    loadingRef.current = false;
  }
};
