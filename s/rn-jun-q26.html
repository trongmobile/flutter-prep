Màn hình giỏ hàng đang có bốn useState riêng (items, coupon, loading, error), mỗi thao tác phải gọi 2–3 hàm set liền nhau và thỉnh thoảng quên reset error. Khi nào nên chuyển sang useReducer, và nó khác useState thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
useReducer gom state vào một object và mọi thay đổi đều đi qua hàm reducer(state, action), nên luật cập nhật nằm ở một chỗ thay vì rải trong nhiều handler. Mỗi action trả về state mới trọn vẹn, ví dụ loadStarted vừa bật loading vừa xoá error, nên không còn trạng thái nửa vời. Nên dùng khi nhiều giá trị đổi cùng nhau hoặc có nhiều loại thao tác; state đơn giản, độc lập như bật/tắt modal thì useState gọn hơn. Reducer phải là hàm thuần: không gọi API, không sửa state tại chỗ mà trả về object mới (Strict Mode chạy reducer hai lần ở development để lộ lỗi này). Việc gọi API vẫn nằm ở handler hoặc effect, xong thì dispatch kết quả. dispatch có tham chiếu ổn định nên truyền cho component con không gây render thừa. Đây vẫn là state cục bộ; muốn chia sẻ thì kết hợp Context.
type CartState = { items: CartItem[]; coupon: string | null; loading: boolean; error: string | null };
type CartAction =
  | { type: 'loadStarted' }
  | { type: 'loaded'; items: CartItem[] }
  | { type: 'loadFailed'; message: string }
  | { type: 'couponApplied'; code: string }
  | { type: 'removed'; id: string };

function cartReducer(state: CartState, action: CartAction): CartState {
  switch (action.type) {
    case 'loadStarted':
      return { ...state, loading: true, error: null }; // bật loading và xoá lỗi cũ cùng lúc
    case 'loaded':
      return { ...state, loading: false, items: action.items };
    case 'loadFailed':
      return { ...state, loading: false, error: action.message };
    case 'couponApplied':
      return { ...state, coupon: action.code };
    case 'removed':
      return { ...state, items: state.items.filter((i) => i.id !== action.id) };
  }
}

const [state, dispatch] = useReducer(cartReducer, { items: [], coupon: null, loading: false, error: null });
dispatch({ type: 'removed', id: '42' });
