Union Action vừa được thêm nhánh { type: 'clear' } nhưng hàm apply chưa được sửa. Chuyện gì xảy ra?

type Action =
  | { type: 'add'; id: string }
  | { type: 'remove'; id: string }
  | { type: 'clear' };

function apply(ids: string[], a: Action): string[] {
  switch (a.type) {
    case 'add': return [...ids, a.id];
    case 'remove': return ids.filter((x) => x !== a.id);
    default: {
      const unhandled: never = a;
      return unhandled;
    }
  }
}
  1. ACompile được; gặp clear thì hàm trả về undefined
  2. BCompile được nhưng ném lỗi runtime khi nhận clear
  3. CLỗi compile ở case 'remove' vì a.id có thể không tồn tại
  4. DLỗi compile tại dòng gán never vì clear chưa xử lý
Xem đáp án
Đáp án đúng: D
Trong default, a bị thu hẹp còn { type: 'clear' }, không gán được cho never nên compiler báo lỗi; mẫu exhaustive check này buộc xử lý mọi nhánh mỗi khi union mở rộng. Trong case 'remove', a đã được narrow nên a.id hoàn toàn hợp lệ.
