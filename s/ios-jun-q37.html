Bạn merge main vào nhánh feature và Git báo conflict ở project.pbxproj, vì bạn và một đồng nghiệp cùng vừa thêm file mới. Bạn xử lý thế nào, và team làm gì để ít gặp lại?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mở file và đọc từng khối <<<<<<</=======/>>>>>>>: khi hai bên cùng thêm file thì thường là các dòng thêm độc lập, nên giữ cả hai phía rồi xoá các dấu conflict, đừng chọn đại một bên vì sẽ làm mất file của đồng nghiệp hoặc của mình. Sau đó mở project bằng Xcode, build và kiểm tra file của cả hai vẫn nằm đúng target; nếu Xcode không mở được project hoặc thiếu file thì làm lại merge cẩn thận. Chỗ nào không chắc thì nhắn đồng nghiệp ngồi xem cùng thay vì đoán. Để giảm conflict: chia code thành Swift Package local (thêm file vào package không đụng pbxproj), dùng XcodeGen hay Tuist sinh project từ file khai báo, hoặc dùng nhóm thư mục đồng bộ (synchronized folders) từ Xcode 16 để project không còn liệt kê từng file. Ngoài ra merge hoặc rebase main thường xuyên, giữ PR nhỏ, và không commit xcuserdata hay DerivedData.
