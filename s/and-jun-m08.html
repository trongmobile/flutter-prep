So sánh String literal, chuỗi nối từ hai literal và new String(...) bằng == trong Java, kết quả in ra là gì?

String a = "hello";
String b = "hel" + "lo";
String c = new String("hello");
System.out.println((a == b) + " " + (a == c) + " " + a.equals(c));
  1. Afalse false true
  2. Btrue true true
  3. Cfalse false false
  4. Dtrue false true
Xem đáp án
Đáp án đúng: D
"hel" + "lo" là hằng số lúc compile nên được gộp thành literal "hello", trỏ cùng object trong String pool với a. new String(...) luôn tạo object mới nên a == c là false dù nội dung giống nhau; so nội dung phải dùng equals().
