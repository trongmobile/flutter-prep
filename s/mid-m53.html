Với relational pattern và logical pattern, đoạn code Dart 3 sau in ra những dòng nào, theo thứ tự?

String grade(int score) => switch (score) {
  >= 90 => 'A',
  >= 80 && < 90 => 'B',
  < 0 || > 100 => 'invalid',
  _ => 'C',
};

void main() {
  print(grade(95));
  print(grade(85));
  print(grade(105));
  print(grade(-5));
}
  1. AA, B, invalid, invalid
  2. BA, B, A, invalid
  3. CA, B, A, C
  4. DLỗi compile vì < 0 || > 100 bị >= 90 che khuất
Xem đáp án
Đáp án đúng: B
switch thử các case từ trên xuống và dùng case đầu tiên khớp. 95 khớp >= 90 nên là A; 85 khớp >= 80 && < 90 nên là B; 105 cũng khớp >= 90 ngay từ case đầu nên ra A dù lẽ ra là giá trị không hợp lệ (muốn bắt giá trị sai thì phải đặt case < 0 || > 100 lên trước); -5 không khớp hai case đầu và khớp < 0, nên ra invalid. && và || là pattern logic ghép các pattern quan hệ. Case thứ ba không bị che khuất hoàn toàn (vì < 0 vẫn có thể tới được) nên không có lỗi compile, còn _ giữ cho switch luôn exhaustive.
