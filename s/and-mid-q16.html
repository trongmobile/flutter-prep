Marketing cần link https://shop.vn/orders/123 (trong email, SMS, notification) mở thẳng màn chi tiết đơn hàng của app dùng Navigation Compose với route type-safe. Bạn cấu hình deep link thế nào và cần lưu ý gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Gắn deep link vào destination bằng navDeepLink<OrderDetail>(basePath = "https://shop.vn/orders"): Navigation tự nối tham số bắt buộc thành path (/{orderId}), tham số có giá trị mặc định thành query. Deep link khai báo trong Navigation Compose không tự lộ ra ngoài app, nên phải tự thêm <intent-filter> (VIEW, DEFAULT, BROWSABLE, scheme và host) cho Activity chứa NavHost; muốn link https mở thẳng app một cách tin cậy thì làm App Links với android:autoVerify="true" và file assetlinks.json trên domain. NavController tự xử lý intent khi Activity được tạo, nhưng nếu Activity dùng singleTop thì intent mới đi vào onNewIntent và phải tự gọi navController.handleDeepLink(intent). Cuối cùng, coi tham số từ link là input không tin cậy: kiểm tra định dạng, để backend kiểm tra quyền xem đơn, và nếu chưa đăng nhập thì qua màn đăng nhập rồi quay lại đích.
@Serializable data class OrderDetail(val orderId: String)

// Trong NavHost: https://shop.vn/orders/123 -> OrderDetail("123")
composable<OrderDetail>(
  deepLinks = listOf(navDeepLink<OrderDetail>(basePath = "https://shop.vn/orders")),
) {
  OrderDetailScreen()
}
