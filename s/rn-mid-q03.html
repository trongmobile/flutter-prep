Màn hình dùng Zustand bị re-render mỗi khi bất kỳ field nào trong store đổi, dù nó chỉ cần user.name. Vì sao và sửa thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Gọi useStore() không có selector nghĩa là subscribe toàn bộ state, nên mọi lần set đều làm component render lại. Hãy chọn đúng phần cần dùng: useStore((s) => s.user.name); Zustand so sánh kết quả selector bằng Object.is và chỉ re-render khi nó đổi. Bẫy tiếp theo là selector trả về object/array mới mỗi lần như (s) => ({ a: s.a, b: s.b }): kết quả luôn 'khác' nên vẫn re-render, ở Zustand v5 còn có thể gây lỗi vòng lặp render. Khi cần nhiều field, bọc selector bằng useShallow hoặc gọi nhiều hook riêng; action trong store có reference ổn định nên lấy riêng chúng không gây re-render.
import { useShallow } from 'zustand/react/shallow';

// Chỉ re-render khi name đổi
const name = useStore((s) => s.user.name);

// Nhiều field: so sánh shallow thay vì so reference của object mới
const { count, inc } = useStore(
  useShallow((s) => ({ count: s.count, inc: s.inc })),
);
