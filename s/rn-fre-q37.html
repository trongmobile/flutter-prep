Giải thích cấu trúc một project React Native: android/, ios/, node_modules/, package.json, index.js, App.tsx. dependencies và devDependencies khác nhau thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
index.js là điểm vào của app, gọi AppRegistry.registerComponent để đăng ký component gốc App (viết trong App.tsx) với đúng tên project mà phía native sẽ tìm khi khởi động. android/ và ios/ là hai project native thật (Gradle và Xcode) mà bạn mở bằng Android Studio hoặc Xcode, nơi sửa quyền, icon, AndroidManifest.xml, Info.plist hay thêm code native; project Expo "managed" có thể không có hai thư mục này vì chúng được sinh ra khi chạy prebuild. node_modules/ chứa thư viện cài từ npm hoặc yarn, rất nặng, không commit lên git và luôn cài lại được từ lockfile. package.json liệt kê tên project, các script (start, android, ios, test) và phiên bản thư viện. dependencies là thư viện app cần khi chạy (react, react-native, react-navigation...), devDependencies chỉ phục vụ lúc phát triển (TypeScript, ESLint, Jest, các gói type). Với app React Native thì Metro chỉ đóng gói những gì bạn import, nên sự phân biệt này chủ yếu để mô tả ý nghĩa, và quan trọng hơn khi bạn xuất bản thư viện lên npm. Lockfile (package-lock.json hoặc yarn.lock) cần commit để cả team cài cùng một phiên bản.
// index.js: điểm vào của app
import { AppRegistry } from 'react-native';
import App from './App';
import { name as appName } from './app.json';

// Tên đăng ký phải khớp với tên mà phía native tìm khi khởi động
AppRegistry.registerComponent(appName, () => App);
