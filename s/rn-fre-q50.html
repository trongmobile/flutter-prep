Project React Native mới chỉ có App.tsx, sau vài tuần mọi thứ dồn vào một thư mục components/ hàng chục file và màn hình nào cũng tự gọi fetch. Bạn tổ chức thư mục thế nào, theo loại hay theo tính năng, và tách logic khỏi giao diện ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Có hai kiểu phổ biến. Theo loại (components/, screens/, hooks/, services/) dễ hiểu với app nhỏ nhưng khi app lớn thì một tính năng nằm rải rác ở nhiều thư mục. Theo tính năng (features/cart/, features/auth/, mỗi thư mục có màn hình, component, hook, API riêng) giúp sửa hay xoá một tính năng chỉ trong một chỗ; thực tế hay kết hợp cả hai: features/* cho phần riêng và components/ cho phần dùng chung như Button, Input. Nên đặt code trong src/ để android/ và ios/ gọn, cùng các thư mục api/, navigation/, hooks/, types/, constants/ (màu, kích thước, chuỗi hằng). Nguyên tắc tách: component chỉ lo hiển thị (nhận props, trả JSX); logic như gọi API, loading, error, validate đưa vào custom hook (useProducts) và tầng api/. Nhờ vậy màn hình ngắn dễ đọc, hook và hàm gọi API test được riêng, nhiều màn hình dùng lại được. Đừng gọi fetch thẳng trong component, và tránh để feature này import nội bộ của feature khác. Không có cấu trúc đúng duy nhất: chọn kiểu đơn giản, nhất quán trong team, và chỉ tách thêm khi thấy bắt đầu đau. Có thể dùng alias import như @/features/... thay cho ../../../ (Expo đọc paths trong tsconfig; bản bare cần thêm babel-plugin-module-resolver).
// src/
//   features/products/   api.ts, useProducts.ts, ProductListScreen.tsx
//   components/          Button, Input... dùng chung
//   navigation/, hooks/, types/, constants/

// features/products/api.ts
export async function fetchProducts(): Promise<Product[]> {
  const res = await fetch(`${API_URL}/products`);
  if (!res.ok) throw new Error(`HTTP ${res.status}`);
  return res.json();
}

// features/products/useProducts.ts: logic loading/error nằm ở đây
export function useProducts() {
  const [data, setData] = useState<Product[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    fetchProducts()
      .then(setData)
      .catch((e: Error) => setError(e.message))
      .finally(() => setLoading(false));
  }, []);

  return { data, loading, error };
}

// features/products/ProductListScreen.tsx: chỉ lo hiển thị
export function ProductListScreen() {
  const { data, loading, error } = useProducts();
  if (loading) return <ActivityIndicator />;
  if (error) return <Text>{error}</Text>;
  return <FlatList data={data} renderItem={renderProduct} keyExtractor={(p) => String(p.id)} />;
}
