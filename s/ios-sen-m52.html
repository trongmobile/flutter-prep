Navigation controller dùng animator tuỳ chỉnh để push. Màn mới hiện ra đúng animation nhưng sau đó giao diện kẹt, không điều hướng tiếp được. Nguyên nhân là gì?

final class FadePushAnimator: NSObject, UIViewControllerAnimatedTransitioning {
  func transitionDuration(using ctx: UIViewControllerContextTransitioning?) -> TimeInterval { 0.3 }

  func animateTransition(using ctx: UIViewControllerContextTransitioning) {
    guard let toView = ctx.view(forKey: .to) else { return }
    toView.alpha = 0
    ctx.containerView.addSubview(toView)
    UIView.animate(withDuration: 0.3) {
      toView.alpha = 1
    }
  }
}

// UINavigationControllerDelegate
func navigationController(_ nav: UINavigationController,
                          animationControllerFor operation: UINavigationController.Operation,
                          from fromVC: UIViewController,
                          to toVC: UIViewController) -> UIViewControllerAnimatedTransitioning? {
  operation == .push ? FadePushAnimator() : nil
}
  1. AtoView phải được thêm vào containerView sau khi animation xong chứ không phải trước đó
  2. BtransitionDuration phải bằng đúng thời lượng của UIView.animate thì UIKit mới nhả tương tác
  3. CChưa gọi ctx.completeTransition(...) khi animation xong nên UIKit coi transition vẫn đang chạy
  4. DUIKit tắt isUserInteractionEnabled của toView trong mọi transition tuỳ chỉnh, phải bật lại thủ công
Xem đáp án
Đáp án đúng: C
UIKit không tự biết animation tuỳ chỉnh khi nào xong: animator phải gọi transitionContext.completeTransition(!transitionContext.transitionWasCancelled), tốt nhất trong completion của animation. Thiếu lời gọi này, UIKit không nhận được thông báo transition đã kết thúc nên navigation controller coi như vẫn đang chuyển cảnh và không điều hướng tiếp được. Thứ tự thêm toView hay việc thời lượng có khớp hay không đều không phải nguyên nhân. Cách sửa: UIView.animate(withDuration: 0.3, animations: { ... }, completion: { _ in ctx.completeTransition(!ctx.transitionWasCancelled) }).
