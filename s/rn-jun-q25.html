Viết test cho màn hình Login bằng Jest và React Native Testing Library: nhập email, bấm Đăng nhập, chờ thông báo lỗi từ API hiện ra. getBy, queryBy và findBy khác nhau thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
React Native Testing Library render component trong môi trường Jest và cho tìm phần tử theo cách người dùng nhìn thấy (getByText, getByRole, getByPlaceholderText), rồi tương tác qua fireEvent hoặc userEvent. getBy* ném lỗi nếu không tìm thấy, dùng khi phần tử chắc chắn đang hiển thị; queryBy* trả về null, dùng để khẳng định phần tử không tồn tại; findBy* trả về Promise và chờ tới khi phần tử xuất hiện, dùng cho UI cập nhật sau thao tác async. API nên được mock bằng jest.mock để test nhanh và ổn định. Ưu tiên kiểm tra hành vi người dùng thấy thay vì state nội bộ hay snapshot cả màn hình.
jest.mock('../api'); // automock: mọi hàm của module api thành jest.fn()

test('hiện lỗi khi đăng nhập thất bại', async () => {
  jest.mocked(api.login).mockRejectedValue(new Error('Sai mật khẩu'));
  render(<LoginScreen />);

  fireEvent.changeText(screen.getByPlaceholderText('Email'), 'a@b.com');
  fireEvent.press(screen.getByText('Đăng nhập'));

  expect(await screen.findByText('Sai mật khẩu')).toBeTruthy();
  expect(screen.queryByText('Xin chào')).toBeNull();
});
