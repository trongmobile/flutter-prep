Khi counterProvider thay đổi giá trị, Text trong widget sau hiển thị gì?

class CounterText extends ConsumerWidget {
  const CounterText({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final count = ref.read(counterProvider);
    return Text('$count');
  }
}
  1. AGiá trị mới, vì trong build thì read hoạt động như watch
  2. BNém exception vì không được gọi ref.read trong build
  3. CGiá trị mới, nhưng trễ một frame so với ref.watch
  4. DVẫn giá trị cũ, vì ref.read không lắng nghe thay đổi
Xem đáp án
Đáp án đúng: D
ref.read chỉ đọc giá trị một lần, không đăng ký dependency, nên widget không rebuild khi provider đổi. Riverpod không ném lỗi trong trường hợp này, nhưng khuyến nghị luôn dùng ref.watch trong build, còn ref.read dành cho callback như onPressed.
