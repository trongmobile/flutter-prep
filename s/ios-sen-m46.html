Hai task con chạy trong group: A ném lỗi sau 0,1 giây, còn B đang chờ 2 giây và bắt lỗi huỷ để in log. Đoạn code sau in ra gì, và mất khoảng bao lâu?

enum UploadError: Error { case failed }

func uploadAll() async {
  do {
    try await withThrowingTaskGroup(of: Void.self) { group in
      group.addTask { // A
        try await Task.sleep(for: .milliseconds(100))
        throw UploadError.failed
      }
      group.addTask { // B
        do {
          try await Task.sleep(for: .seconds(2))
          print("B done")
        } catch {
          print("B cancelled")
        }
      }
      for try await _ in group {}
    }
    print("all uploaded")
  } catch {
    print("failed")
  }
}
  1. AB done sau khoảng 2 giây rồi failed, vì group không huỷ task con khi task khác ném lỗi
  2. Bfailed sau khoảng 0,1 giây, còn B bị bỏ lại chạy ngầm và vài giây sau mới in B done
  3. CB cancelled rồi failed, tổng khoảng 0,1 giây: lỗi huỷ task con, group chờ chúng xong
  4. Dfailed rồi B cancelled sau khoảng 0,1 giây, vì lỗi được ném trước khi B kịp bị huỷ
Xem đáp án
Đáp án đúng: C
Lỗi từ for try await thoát khỏi thân group nên group tự huỷ các task con còn lại; Task.sleep của B ném CancellationError ngay nên in B cancelled. Structured concurrency còn bảo đảm withThrowingTaskGroup chỉ trả về hoặc ném lỗi sau khi mọi task con đã kết thúc, nên failed luôn in sau B cancelled và không có task nào bị bỏ lại chạy ngầm.
