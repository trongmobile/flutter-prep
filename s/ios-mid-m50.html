Chỉ title của một Todo đổi (id giữ nguyên), rồi bạn apply snapshot mới. Diffable data source xử lý phần tử đó thế nào?

struct Todo: Hashable {
  let id: Int
  var title: String
}

// dataSource: UICollectionViewDiffableDataSource<Int, Todo>
var snapshot = NSDiffableDataSourceSnapshot<Int, Todo>()
snapshot.appendSections([0])
snapshot.appendItems(todos) // todos[1].title vừa đổi
dataSource.apply(snapshot)
  1. AXoá item cũ rồi chèn item mới, vì Hashable tự sinh tính cả title
  2. BTự reload đúng cell đó với nội dung mới vì nhận ra id không đổi
  3. CGiữ nguyên cell và nội dung cũ vì identity của item dựa trên vị trí
  4. DCrash runtime vì hai item khác nhau cùng mang một giá trị id

Đáp án đúng: A
Diffable data source so sánh item bằng Hashable/Equatable; Hashable tự sinh của struct dùng mọi stored property nên đổi title tạo identity mới và diff là xoá + chèn (animation delete/insert, mất selection). Muốn cập nhật tại chỗ thì dùng id làm item identifier, gọi snapshot.reconfigureItems([id]) rồi lấy dữ liệu theo id khi cấu hình cell.
