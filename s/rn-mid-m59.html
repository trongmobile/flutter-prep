Hàm kiểm tra phiên bản tối thiểu để bắt buộc cập nhật app dưới đây in ra gì, và kết quả có đúng ý không?

function needsUpdate(current: string, minimum: string) {
  return current < minimum;
}

console.log(needsUpdate('1.10.0', '1.9.0'));
console.log(needsUpdate('2.0.0', '10.0.0'));
  1. Afalse rồi true, đúng như mong đợi vì JavaScript tự hiểu các chuỗi này là số phiên bản gồm nhiều phần
  2. Btrue rồi false, sai cả hai vì chuỗi được so từng ký tự chứ không theo số phiên bản
  3. Cfalse rồi false, vì phép so sánh chuỗi chỉ xét ký tự đầu tiên của mỗi chuỗi
  4. DNém TypeError, vì toán tử < không dùng được để so sánh hai giá trị kiểu chuỗi
Xem đáp án
Đáp án đúng: B
Toán tử < trên hai chuỗi so sánh từng ký tự theo thứ tự mã Unicode chứ không hiểu số phiên bản. '1.10.0' và '1.9.0' khác nhau ở ký tự thứ ba, '1' nhỏ hơn '9' nên kết quả là true (người dùng 1.10.0 bị bắt cập nhật oan). '2.0.0' so với '10.0.0': '2' lớn hơn '1' nên ra false (bản 2.0.0 lẽ ra phải bị chặn lại nhưng lọt qua). Phải tách theo dấu chấm, đổi từng phần sang số rồi so lần lượt (hoặc dùng thư viện semver), hoặc để server trả về quyết định cuối cùng.
