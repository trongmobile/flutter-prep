Đoạn code upload ảnh dưới đây báo "Xong" ngay lập tức dù ảnh chưa upload, và lỗi upload không bị catch bắt. Vì sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
forEach không biết gì về Promise: nó gọi callback async cho từng phần tử, bỏ qua Promise trả về và kết thúc ngay, nên showToast('Xong') chạy khi các upload mới bắt đầu. Lỗi trong callback trở thành Promise bị reject mà không ai await, nên try/catch bên ngoài không bắt được, chỉ thấy cảnh báo unhandled promise rejection. Muốn chạy lần lượt thì dùng for (const p of photos) { await uploadPhoto(p); }; muốn song song thì await Promise.all(photos.map(uploadPhoto)). Quy tắc chung: try/catch chỉ bắt được lỗi async của Promise được await bên trong khối try.
async function uploadAll(photos: Photo[]) {
  try {
    photos.forEach(async (p) => {
      await uploadPhoto(p);
    });
    showToast('Xong');
  } catch (e) {
    showToast('Upload lỗi');
  }
}
