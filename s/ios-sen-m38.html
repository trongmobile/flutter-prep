Bạn phát hành một SDK analytics cho các app khác tích hợp; SDK có dùng UserDefaults và đọc thời gian tạo file. Yêu cầu nào của Apple phải đáp ứng?

  1. AHiện hộp thoại App Tracking Transparency ngay khi SDK khởi tạo
  2. BKèm PrivacyInfo.xcprivacy nêu dữ liệu thu thập và lý do dùng API
  3. CChỉ app chủ cần privacy manifest, SDK không phải khai báo gì
  4. DXin entitlement riêng từ Apple trước khi dùng UserDefaults
Xem đáp án
Đáp án đúng: B
Privacy manifest của SDK được gộp vào báo cáo quyền riêng tư của app tích hợp, và UserDefaults cùng các API đọc timestamp file nằm trong danh sách required reason API phải nêu lý do. ATT chỉ cần khi thực sự tracking user qua app, website của công ty khác, và SDK không nên tự ý hiện prompt.
