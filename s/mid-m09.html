Đoạn code dùng StreamController sau in ra gì?

import 'dart:async';

final controller = StreamController<int>();

Future<void> main() async {
  controller.add(1);
  controller.add(2);
  await for (final v in controller.stream) {
    print(v);
  }
  print('done');
}
  1. AIn 1, 2 rồi done
  2. BIn 1, 2; dòng done không bao giờ được in
  3. CKhông in gì vì event add trước khi listen đã bị mất
  4. DNém StateError vì add khi chưa có listener
Xem đáp án
Đáp án đúng: B
StreamController single-subscription buffer event cho tới khi có listener, nên 1 và 2 vẫn được nhận. Nhưng await for chỉ thoát khi stream phát sự kiện done, mà controller không bao giờ close(), nên code sau vòng lặp không chạy — một bug 'treo' rất hay gặp.
