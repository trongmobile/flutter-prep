Vì sao nên dùng ListAdapter + DiffUtil.ItemCallback thay vì gọi notifyDataSetChanged() mỗi khi danh sách đổi? areItemsTheSame và areContentsTheSame khác nhau thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
notifyDataSetChanged() báo rằng mọi thứ có thể đã đổi: RecyclerView phải bind lại toàn bộ item đang hiển thị, mất animation thêm/xoá và vị trí cuộn có thể nhảy. ListAdapter tính diff giữa list cũ và mới trên background thread rồi tự gọi đúng các notifyItemInserted/Removed/Changed. areItemsTheSame trả lời câu hỏi "có phải cùng một item không", thường so id; areContentsTheSame chỉ được gọi khi đã là cùng item, trả lời "nội dung hiển thị có đổi không", thường dùng == của data class. Bẫy hay gặp là sửa trực tiếp list hoặc object đã submit rồi submitList lại: ListAdapter không thấy khác biệt, nên luôn submit một list mới với item mới (tạo bằng copy).
private object ProductDiff : DiffUtil.ItemCallback<Product>() {
    override fun areItemsTheSame(oldItem: Product, newItem: Product) =
        oldItem.id == newItem.id
    override fun areContentsTheSame(oldItem: Product, newItem: Product) =
        oldItem == newItem
}

class ProductAdapter : ListAdapter<Product, ProductViewHolder>(ProductDiff) {
    // onCreateViewHolder, onBindViewHolder dùng getItem(position)
}

// Cập nhật bằng list mới, không sửa list cũ
adapter.submitList(products.map { if (it.id == id) it.copy(liked = true) else it })
