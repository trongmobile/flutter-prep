Mở app (đang ở HomePage, chưa bấm gì). Dòng CartModel created đã được in ra chưa?

class CartModel extends ChangeNotifier {
  CartModel() {
    debugPrint('CartModel created');
  }
}

void main() {
  runApp(
    ChangeNotifierProvider(
      create: (_) => CartModel(),
      child: const MyApp(),
    ),
  );
}

// HomePage không đọc CartModel; chỉ CartPage (mở từ nút giỏ hàng)
// gọi context.watch<CartModel>()
  1. AĐã in ngay khi runApp dựng ChangeNotifierProvider, vì create chạy lúc provider được tạo
  2. BĐã in ngay sau khung hình đầu tiên, vì provider khởi tạo notifier khi HomePage build xong
  3. CChưa in cho tới lần đầu notifyListeners() được gọi, vì lúc đó notifier mới thật sự cần tồn tại và có listener để báo
  4. DChưa in; create chạy lười (lazy) vào lần đầu có widget read/watch CartModel, trừ khi đặt lazy: false
Xem đáp án
Đáp án đúng: D
ChangeNotifierProvider(create: ...) mặc định có lazy: true: hàm create chỉ chạy lần đầu có widget đọc giá trị (context.read, context.watch, Consumer...), không chạy lúc provider được dựng. Vì HomePage không đọc CartModel, nó chỉ được tạo khi người dùng mở CartPage. Cần notifier khởi tạo sớm (ví dụ nạp dữ liệu ngay khi mở app) thì đặt lazy: false. notifyListeners() chỉ báo cho các listener, không quyết định lúc tạo notifier; provider cũng không chờ frame đầu tiên để khởi tạo.
