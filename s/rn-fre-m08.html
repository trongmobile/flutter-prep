Destructuring có giá trị mặc định dưới đây in ra gì khi age đang là null?

const user = { name: 'An', age: null };
const { name, age = 18 } = user;
console.log(name, age);
  1. AAn 18
  2. BAn null
  3. CAn undefined
  4. DLỗi vì age đã có giá trị
Xem đáp án
Đáp án đúng: B
Giá trị mặc định trong destructuring chỉ được dùng khi thuộc tính là undefined hoặc không tồn tại; null là một giá trị thật nên được giữ nguyên. Muốn coi null như thiếu dữ liệu thì viết user.age ?? 18.
