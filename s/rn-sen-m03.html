Trong một C++ TurboModule, việc tải file chạy trên thread nền và khi xong cần gọi callback JS mà module đã lưu lại. Cách làm đúng là gì?

  1. AGọi thẳng jsi::Function đã lưu từ thread nền, vì JSI an toàn đa luồng
  2. BTạo một jsi::Runtime mới trên thread nền rồi gọi callback trong runtime đó
  3. CSerialize kết quả thành JSON rồi gửi qua bridge như ở kiến trúc cũ
  4. DLên lịch việc gọi callback về JS thread qua CallInvoker của module
Xem đáp án
Đáp án đúng: D
jsi::Runtime không thread-safe: mọi thao tác với giá trị JS phải diễn ra trên thread của runtime. CallInvoker mà TurboModule nhận được dùng để đưa công việc về chạy trên JS thread; gọi jsi::Function thẳng từ thread nền có thể gây crash ngẫu nhiên rất khó tái hiện.
