Người dùng nhập ' OR '1'='1 vào ô tìm kiếm rồi gọi findUser. Kết quả và cách sửa đúng là gì?

Future<List<Map<String, Object?>>> findUser(Database db, String name) {
  return db.rawQuery("SELECT * FROM users WHERE name = '$name'");
}
  1. ATrả về mọi user vì điều kiện luôn đúng; dùng ? kèm tham số [name]
  2. BTrả về danh sách rỗng vì không user nào có tên đó; code này không cần sửa
  3. CNém DatabaseException vì thừa dấu '; sửa bằng name.replaceAll("'", '')
  4. DTrả về mọi user vì điều kiện luôn đúng; chỉ cần gọi name.trim() trước khi nối
Xem đáp án
Đáp án đúng: A
Nối chuỗi tạo ra ... WHERE name = '' OR '1'='1': đây là SQL hợp lệ và '1'='1' luôn đúng nên toàn bộ bảng bị trả về (SQL injection). Dùng placeholder như rawQuery('... WHERE name = ?', [name]) (hoặc query với where + whereArgs) để giá trị luôn được bind như dữ liệu chứ không bao giờ bị hiểu là SQL. trim() hay tự lọc ký tự không đảm bảo an toàn.
