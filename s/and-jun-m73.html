Khi chạy unit test dưới đây trong src/test (JVM cục bộ, không dùng Robolectric), test báo lỗi Method getMainLooper in android.os.Looper not mocked. Cách sửa đúng để LiveData chạy được trong JVM test là gì?

class CounterViewModelTest {
  @Test
  fun increment_updatesCount() {
    val vm = CounterViewModel()
    vm.increment() // gọi countLiveData.value = newCount
    assertEquals(1, vm.countLiveData.value)
  }
}
  1. AThêm @get:Rule val rule = InstantTaskExecutorRule() từ androidx.arch.core:core-testing vào class test
  2. BĐổi countLiveData.value trong CounterViewModel sang postValue để tránh gọi Looper.getMainLooper()
  3. CBọc thân hàm test bằng runTest của kotlinx-coroutines-test để giả lập sẵn main looper
  4. DDi chuyển test sang Dispatchers.IO bằng withContext(Dispatchers.IO) trước khi gọi vm.increment()
Xem đáp án
Đáp án đúng: A
LiveData sử dụng ArchTaskExecutor để kiểm tra main thread qua Looper.getMainLooper(), vốn là API Android bị stub trong unit test JVM nên ném lỗi not mocked. InstantTaskExecutorRule thay thế executor mặc định bằng một executor đồng bộ chạy ngay trên thread hiện tại, giúp setValue và postValue hoạt động bình thường. Cả postValue, runTest lẫn Dispatchers.IO đều không thay thế được ArchTaskExecutor, nên vẫn đụng vào Looper.getMainLooper().
