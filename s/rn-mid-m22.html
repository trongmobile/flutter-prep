HeavyList không bọc React.memo. Khi người dùng cuộn làm state y của ScrollTracker đổi (còn App không render lại), HeavyList có render lại không?

function ScrollTracker({ children }: { children: React.ReactNode }) {
  const [y, setY] = useState(0);
  return (
    <ScrollView onScroll={(e) => setY(e.nativeEvent.contentOffset.y)} scrollEventThrottle={16}>
      <Text>{Math.round(y)}</Text>
      {children}
    </ScrollView>
  );
}

// App: <ScrollTracker><HeavyList /></ScrollTracker>
  1. ACó, vì mọi component con đều render lại theo cha
  2. BCó, vì HeavyList không được bọc React.memo
  3. CKhông, vì ScrollView tự chặn render của các con
  4. DKhông, vì element children do App tạo vẫn giữ nguyên
Xem đáp án
Đáp án đúng: D
Element <HeavyList /> được tạo khi App render và truyền xuống qua children; ScrollTracker render lại nhưng trả về đúng element cũ nên React bỏ qua nó. Đây là cách giảm re-render bằng cấu trúc component mà không cần React.memo; ScrollView không có cơ chế chặn render nào.
