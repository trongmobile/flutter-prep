Team chuyển ViewModel từ ObservableObject + @Published sang macro @Observable. Cơ chế cập nhật view khác gì, và @StateObject, @ObservedObject, @EnvironmentObject được thay bằng gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Với ObservableObject, bất kỳ @Published nào đổi cũng bắn objectWillChange, nên mọi view đang observe object đó đều tính lại body, kể cả view không dùng property vừa đổi. @Observable (framework Observation, iOS 17+) theo dõi theo từng property: SwiftUI ghi lại property nào được đọc trong body và chỉ cập nhật view khi đúng property đó đổi, giảm re-render rõ rệt. Khi chuyển: @StateObject thành @State, @ObservedObject thành property thường (let/var), cần tạo binding thì dùng @Bindable, @EnvironmentObject thành @Environment(Model.self) đi cùng .environment(model). Bẫy: property không cần theo dõi thì đánh dấu @ObservationIgnored, và @State vẫn chạy biểu thức khởi tạo mỗi lần view init (chỉ giữ instance đầu tiên) nên tránh làm việc nặng trong init của model.
@Observable
final class CartModel {
  var items: [Item] = []
  var couponCode = ""
  @ObservationIgnored var lastSync: Date? // đổi không làm view cập nhật
}
struct CartScreen: View {
  @State private var model = CartModel() // thay cho @StateObject
  var body: some View { CouponField(model: model) }
}

struct CouponField: View {
  @Bindable var model: CartModel // để tạo binding $model.couponCode
  var body: some View { TextField("Mã giảm giá", text: $model.couponCode) }
}
