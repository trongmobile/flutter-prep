Backend (ID kiểu Snowflake, số nguyên 64-bit) trả JSON như dưới. Lệnh console.log in ra gì, và cần xử lý ra sao?

// Response body: {"id": 9007199254740993, "total": 120000}
const res = await fetch(url);
const order = await res.json();
console.log(order.id);
  1. A9007199254740993, vì res.json() tự dùng BigInt khi số nguyên vượt giới hạn an toàn
  2. B9007199254740992, vì số nguyên lớn bị làm tròn khi parse; nên để server trả id dạng chuỗi
  3. CNém RangeError, vì JSON.parse từ chối số nguyên lớn hơn Number.MAX_SAFE_INTEGER
  4. D9007199254741000, vì number chỉ giữ khoảng 15 chữ số có nghĩa nên các chữ số cuối thành 0
Xem đáp án
Đáp án đúng: B
JSON.parse (và res.json()) đọc mọi số thành number, tức double 64-bit, chỉ biểu diễn chính xác số nguyên tới Number.MAX_SAFE_INTEGER (2^53 − 1). 9007199254740993 không biểu diễn được nên bị làm tròn thành 9007199254740992, và hai id khác nhau có thể trở thành trùng nhau. Không có lỗi hay BigInt tự động nào; cách đúng là để server trả id dạng chuỗi.
