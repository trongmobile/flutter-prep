Promise.allSettled trả về gì khi một trong các promise đầu vào bị reject?

  1. AReject ngay với lỗi của promise bị reject
  2. BMảng chỉ gồm các giá trị thành công, phần tử lỗi bị bỏ qua
  3. CMảng object có status kèm value hoặc reason
  4. DGiá trị của promise hoàn thành sớm nhất
Xem đáp án
Đáp án đúng: C
allSettled không reject vì lỗi của phần tử con; nó chờ tất cả xong và trả mảng { status: 'fulfilled', value } hoặc { status: 'rejected', reason } theo đúng thứ tự đầu vào. Reject ngay là hành vi của Promise.all, còn lấy promise xong sớm nhất là Promise.race.
