Bạn dựng view vòng tròn tiến độ tự vẽ bằng draw(_:). Mỗi lần dữ liệu đổi là giật, và sau khi xoay máy hình bị kéo giãn hoặc sai kích thước. draw(_:) khác CAShapeLayer thế nào về hiệu năng, setNeedsDisplay và setNeedsLayout dùng khi nào, và intrinsicContentSize để làm gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
draw(_:) vẽ bằng Core Graphics trên CPU vào một bitmap làm backing store của layer, nên tốn bộ nhớ theo kích thước view nhân scale², và mỗi lần vẽ lại là rasterize lại cả vùng bị đánh dấu: nếu dữ liệu đổi liên tục hay có animation thì rất tốn. CAShapeLayer/CALayer để Core Animation render path trực tiếp: đổi path, strokeEnd, fillColor không phải vẽ lại bitmap và animate được. Chọn draw(_:) cho nội dung phức tạp, ít đổi; chọn layer cho hình học động. Trong draw chỉ vẽ phần giao với rect, không tạo gradient hay font mỗi lần, và không bao giờ tự gọi draw. setNeedsDisplay() báo cần vẽ lại nội dung ở chu kỳ vẽ kế tiếp (nhiều lần gọi chỉ gộp thành một); setNeedsLayout() báo cần chạy lại layoutSubviews(), nơi đặt frame cho view con và layer con. Đổi bounds không tự gọi draw trừ khi contentMode = .redraw, vì vậy xoay máy xong hình bị kéo giãn là lỗi quen thuộc. Layer tự thêm bằng code không theo Auto Layout: phải cập nhật frame và path trong layoutSubviews() chứ không phải trong init, và bọc bằng CATransaction.setDisableActions(true) để tránh animation ngầm khi layout. intrinsicContentSize cho Auto Layout biết kích thước tự nhiên của nội dung để view không cần constraint width/height; khi nội dung đổi thì gọi invalidateIntrinsicContentSize().
final class ProgressRingView: UIView {
    private let track = CAShapeLayer()
    private let ring = CAShapeLayer()

    var progress: CGFloat = 0 {
        didSet { ring.strokeEnd = progress } // đổi thuộc tính layer: không vẽ lại bitmap, tự animate ngầm
    }

    override init(frame: CGRect) {
        super.init(frame: frame)
        for layer in [track, ring] {
            layer.fillColor = UIColor.clear.cgColor
            layer.lineWidth = 8
            self.layer.addSublayer(layer)
        }
        track.strokeColor = UIColor.systemGray5.cgColor
        ring.strokeColor = UIColor.systemBlue.cgColor
        ring.lineCap = .round
        ring.strokeEnd = 0
    }

    required init?(coder: NSCoder) { fatalError("init(coder:) has not been implemented") }

    override func layoutSubviews() { // đặt lại frame và path mỗi khi bounds đổi (xoay máy, đổi size)
        super.layoutSubviews()
        CATransaction.begin()
        CATransaction.setDisableActions(true)
        let radius = min(bounds.width, bounds.height) / 2 - 4
        let path = UIBezierPath(arcCenter: CGPoint(x: bounds.midX, y: bounds.midY), radius: radius,
                                startAngle: -.pi / 2, endAngle: 1.5 * .pi, clockwise: true)
        for layer in [track, ring] {
            layer.frame = bounds
            layer.path = path.cgPath
        }
        CATransaction.commit()
    }

    override var intrinsicContentSize: CGSize { CGSize(width: 64, height: 64) }
}
