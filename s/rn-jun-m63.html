Màn quản trị có nút "Xoá người dùng", chỉ hiện khi user.role === 'admin' theo dữ liệu trong app. Backend xoá người dùng khi nhận DELETE /users/:id kèm bất kỳ token đăng nhập hợp lệ nào. Nhận định nào đúng?

  1. AĐủ an toàn, vì người dùng thường không thấy nút nên không thể gọi API xoá
  2. BKhông: client bị sửa hay gọi thẳng API được, server phải kiểm tra quyền
  3. CĐủ an toàn nếu bundle JS đã được Hermes biên dịch thành bytecode khó đọc
  4. DĐủ an toàn nếu API dùng HTTPS, vì khi đó không ai gửi được request giả mạo
Xem đáp án
Đáp án đúng: B
Ẩn nút chỉ là chuyện trải nghiệm: kẻ tấn công có thể sửa app, dùng máy root/jailbreak hoặc gọi API trực tiếp bằng Postman hay curl với token của chính họ. Phân quyền chỉ có hiệu lực khi server kiểm tra role hoặc permission của người gọi ở từng request. Hermes bytecode chỉ làm khó việc đọc code chứ không chặn được request tự tạo, còn HTTPS bảo vệ đường truyền khỏi bị nghe lén chứ không cho biết người gọi có quyền gì.
