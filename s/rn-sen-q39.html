Màn báo cáo tải một JSON vài MB (hàng chục nghìn bản ghi) rồi lọc, nhóm và sắp xếp ngay trên JS. Mỗi lần mở, UI đứng khoảng 2 giây, nút Huỷ cũng không bấm được. Bạn có những lựa chọn nào để không làm kẹt JS thread, và chọn theo tiêu chí gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Parse, lọc, sắp xếp và setState đều chạy trên cùng một JS thread, nên việc nặng liên tục sẽ chặn cả xử lý chạm lẫn render. Tôi cân nhắc theo thứ tự: một, có thật sự cần đưa cả đống dữ liệu xuống máy không; lọc, nhóm, phân trang hay tổng hợp ở server là rẻ nhất và giảm luôn mạng lẫn bộ nhớ. Hai, nếu dữ liệu phải nằm ở máy và truy vấn thường xuyên thì đưa vào SQLite (truy vấn không chạy trên JS thread, có index) thay vì giữ mảng khổng lồ trong JS. Ba, chia lô: xử lý vài trăm bản ghi rồi nhường thread bằng setTimeout(0), UI thở được và huỷ được giữa chừng; đổi lại tổng thời gian dài hơn và code phức tạp hơn. InteractionManager.runAfterInteractions chỉ hoãn việc cho tới sau animation; việc dài 2 giây vẫn chặn 2 giây. Bốn, đẩy sang runtime khác: worklet runtime của react-native-worklets (phần Reanimated tách ra) chạy được hàm JS trên thread riêng, nhưng dữ liệu phải sao chép/serialize qua ranh giới và không dùng được mọi thư viện. Năm, module native hoặc JSI/C++ cho hot path thật sự (parse hay mật mã nặng): nhanh nhất nhưng phải viết và bảo trì code cho hai nền tảng. Chọn theo tần suất, tốc độ tăng của dữ liệu, nhu cầu offline và năng lực native của đội: thường là server/SQLite trước, chia lô cho phần còn lại, native là phương án cuối. Đo bằng Perf Monitor và Hermes sampling profiler trước/sau thay vì đoán.
async function processInChunks<T, R>(
  items: T[],
  mapFn: (item: T) => R,
  signal: AbortSignal,
  chunkSize = 500,
): Promise<R[]> {
  const out: R[] = [];
  for (let i = 0; i < items.length; i += chunkSize) {
    if (signal.aborted) throw new Error('aborted');
    for (const item of items.slice(i, i + chunkSize)) out.push(mapFn(item));
    await new Promise<void>((resolve) => setTimeout(resolve, 0)); // nhường thread cho chạm và render
  }
  return out;
}

// Trong hàm async: huỷ được khi user bấm Huỷ hoặc rời màn hình
const controller = new AbortController();
const rows = await processInChunks(records, toRow, controller.signal);
