Ô search gọi API mỗi khi user gõ, và kết quả của từ khoá cũ đôi khi về sau, đè lên kết quả mới. Bạn huỷ request cũ thế nào? Gọi task.cancel() thì code trong task có dừng ngay không?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Cancellation trong Swift Concurrency là cooperative: cancel() chỉ đánh dấu task đã bị huỷ, code bên trong phải tự kiểm tra bằng Task.isCancelled, try Task.checkCancellation(), hoặc gọi các API có hỗ trợ huỷ như Task.sleep và các hàm async của URLSession (chúng throw khi task bị cancel). Cách làm: giữ tham chiếu Task hiện tại, cancel nó trước khi tạo task mới, dùng Task.sleep để debounce. Quan trọng là kiểm tra lại Task.isCancelled sau khi await xong và trước khi gán kết quả, nếu không response của từ khoá cũ vẫn có thể ghi đè. Trong SwiftUI có thể dùng .task(id: query), SwiftUI tự cancel task cũ mỗi khi query đổi.
// Trong ViewModel @MainActor
private var searchTask: Task<Void, Never>?

func queryChanged(_ text: String) {
  searchTask?.cancel()
  searchTask = Task {
    try? await Task.sleep(for: .milliseconds(300)) // debounce
    guard !Task.isCancelled else { return }
    let result = try? await api.search(text)
    guard !Task.isCancelled, let result else { return } // bỏ kết quả cũ
    items = result
  }
}
