Bạn cần bọc API vị trí dạng callback (FusedLocationProviderClient) thành Flow để nhiều màn hình dùng chung, không rò rỉ listener và không chạy khi app ở background. Bạn dùng callbackFlow, stateIn và thu thập ở UI thế nào, và SharingStarted.WhileSubscribed(5_000) giải quyết điều gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
callbackFlow chuyển callback thành Flow lạnh: đăng ký listener trong block và bắt buộc kết thúc bằng awaitClose { gỡ listener }, thiếu thì callbackFlow ném IllegalStateException. Phát giá trị bằng trySend (không suspend nên gọi được trong callback); channel bên trong có buffer, nên với dữ liệu kiểu 'giá trị mới nhất' như vị trí hãy chọn chính sách khi consumer chậm bằng conflate() hoặc buffer(onBufferOverflow = DROP_OLDEST). Flow lạnh sẽ đăng ký lại listener cho mỗi collector, nên chia sẻ bằng stateIn/shareIn ở scope của repository với SharingStarted.WhileSubscribed(5_000): có subscriber đầu tiên thì mới chạy upstream, khi subscriber cuối đi mất thì chờ 5 giây rồi mới dừng. Khoảng chờ đó đủ để xoay màn hình hay chuyển tab nhanh không phải kết nối lại, còn khi app thật sự xuống nền thì GPS được tắt. Ở UI thu thập bằng collectAsStateWithLifecycle() trong Compose hoặc repeatOnLifecycle(STARTED) trong View; collectAsState() hay lifecycleScope.launch { collect } không gắn với lifecycle của app nên vẫn thu thập khi ở nền và giữ upstream chạy mãi.
fun FusedLocationProviderClient.locationUpdates(request: LocationRequest): Flow<Location> = callbackFlow {
  val callback = object : LocationCallback() {
    override fun onLocationResult(result: LocationResult) {
      result.lastLocation?.let { trySend(it) } // không suspend, gọi được trong callback
    }
  }
  requestLocationUpdates(request, callback, Looper.getMainLooper())
  awaitClose { removeLocationUpdates(callback) } // collector bị huỷ thì gỡ listener
}.conflate() // chỉ cần vị trí mới nhất

class LocationRepository(client: FusedLocationProviderClient, request: LocationRequest, scope: CoroutineScope) {
  val location: StateFlow<Location?> = client.locationUpdates(request)
    .stateIn(scope, SharingStarted.WhileSubscribed(5_000), null)
}

// UI (Compose): dừng thu thập khi app xuống dưới STARTED
val location by repo.location.collectAsStateWithLifecycle()
