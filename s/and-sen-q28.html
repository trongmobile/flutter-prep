Design system cần một TagFlow xếp các chip theo hàng và xuống dòng khi hết chỗ, cùng một bố cục đặt vạch ngăn cao bằng item cao nhất trong hàng. Compose đo layout theo quy tắc nào, bạn viết Layout tuỳ biến thế nào, và intrinsic measurements dùng khi nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Compose có ba phase: composition, layout (đo rồi đặt vị trí) và drawing. Ở phase layout, mỗi child chỉ được đo tối đa một lần (single-pass measurement): parent đưa Constraints xuống, child trả về Placeable đã đo, rồi parent đặt vị trí; đo một child hai lần ném exception. Quy tắc này giữ độ phức tạp layout tuyến tính ngay cả khi lồng sâu, khác hệ thống View vốn có thể đo nhiều lần. Viết Layout(content) { measurables, constraints -> ... layout(width, height) { placeable.placeRelative(x, y) } }: đo từng measurable bằng measure(constraints.copy(minWidth = 0)), cộng dồn vị trí x, vượt maxWidth thì xuống hàng, rồi khai báo kích thước tổng. Khi parent cần biết kích thước 'tự nhiên' của con trước khi đo thật (vạch ngăn cao bằng item cao nhất trong Row) thì dùng intrinsic measurements: Modifier.height(IntrinsicSize.Min) hỏi trước minIntrinsicHeight của các con rồi mới đo thật với constraints cố định; nó tốn thêm một lượt đo nên chỉ dùng khi cần. SubcomposeLayout (nền của LazyColumn, BoxWithConstraints) cho compose con ngay lúc layout nên đắt, tránh đặt trong từng item. Tận dụng phase: đọc state ở layout hay draw (Modifier.layout, offset { }, drawBehind) thì chỉ phase đó chạy lại, không recompose. Thư viện foundation đã có FlowRow, nên chỉ tự viết khi cần hành vi đặc biệt.
@Composable
fun TagFlow(modifier: Modifier = Modifier, spacing: Dp = 8.dp, content: @Composable () -> Unit) {
  Layout(content = content, modifier = modifier) { measurables, constraints ->
    val gap = spacing.roundToPx()
    // Mỗi con chỉ được đo một lần
    val placeables = measurables.map { it.measure(constraints.copy(minWidth = 0, minHeight = 0)) }

    val positions = ArrayList<IntOffset>(placeables.size)
    var x = 0
    var y = 0
    var rowHeight = 0
    for (p in placeables) {
      if (x > 0 && x + p.width > constraints.maxWidth) { // hết chỗ: xuống hàng
        x = 0
        y += rowHeight + gap
        rowHeight = 0
      }
      positions += IntOffset(x, y)
      x += p.width + gap
      rowHeight = maxOf(rowHeight, p.height)
    }
    layout(constraints.maxWidth, y + rowHeight) {
      placeables.forEachIndexed { i, p -> p.placeRelative(positions[i]) }
    }
  }
}

// Intrinsic: vạch ngăn cao bằng item cao nhất trong Row
Row(Modifier.height(IntrinsicSize.Min)) {
  Text("Trái")
  VerticalDivider()
  Text("Phải\nnhiều dòng")
}
