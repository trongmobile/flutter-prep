async/await trong Swift giải quyết vấn đề gì so với completion handler? Hãy viết lại một hàm tải dữ liệu từ dạng callback sang async throws.

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Completion handler buộc code lồng nhau nhiều tầng (callback hell), phải nhớ gọi completion ở mọi nhánh (sót một nhánh là request treo mãi), xử lý lỗi rải rác và dễ tạo retain cycle. Hàm async thì trả giá trị bình thường: tại chỗ gọi bạn viết await, hàm tạm dừng (suspend) mà không chặn thread, có kết quả thì chạy tiếp dòng kế tiếp, nên code đọc từ trên xuống như code đồng bộ và lỗi dùng throws, try, do/catch quen thuộc. Mỗi await là một điểm có thể tạm dừng: sau đó trạng thái đã có thể đổi và code có thể chạy trên thread khác (trừ khi hàm thuộc @MainActor), nên ViewModel chạm vào UI thường đánh dấu @MainActor. async không có nghĩa là tự chạy ở thread nền, nó chỉ cho phép chờ mà không chặn. Chỉ gọi được await từ ngữ cảnh async; từ chỗ đồng bộ như action của Button thì tạo tác vụ bằng Task { }, và trong SwiftUI có thêm .task { } gắn vào view để chạy khi view hiện ra và tự huỷ khi view biến mất.
struct User: Decodable {
    let id: Int
    let name: String
}

// Cũ: completion handler, phải nhớ gọi completion ở mọi nhánh
func fetchUser(id: Int, completion: @escaping (Result<User, Error>) -> Void) {
    // dataTask ... completion(.success(user)) / completion(.failure(error))
}

// Mới: async throws, đọc từ trên xuống
func fetchUser(id: Int) async throws -> User {
    let url = URL(string: "https://api.example.com/users/\(id)")!
    let (data, _) = try await URLSession.shared.data(from: url) // thực tế nên kiểm tra thêm statusCode
    return try JSONDecoder().decode(User.self, from: data)
}

struct ProfileView: View {
    @State private var name = "..."

    var body: some View {
        VStack {
            Text(name)
            Button("Tải") {
                Task {                                   // từ ngữ cảnh đồng bộ sang async
                    do {
                        name = try await fetchUser(id: 1).name
                    } catch {
                        name = "Lỗi: \(error.localizedDescription)"
                    }
                }
            }
        }
    }
}
