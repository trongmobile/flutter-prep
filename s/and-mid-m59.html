Retrofit interface DownloadApi khai báo @GET suspend fun download(@Url url: String): ResponseBody được dùng để tải file video khoảng 500MB. Trên máy cấu hình thấp app crash OutOfMemoryError ngay khi gọi. Thiếu gì trong khai báo?

  1. AAnnotation @Streaming, để Retrofit trả body dạng luồng thay vì nạp cả file vào RAM
  2. BAnnotation @Multipart, để Retrofit chia file thành nhiều phần nhỏ khi tải về
  3. CHeader Accept-Encoding: gzip, để server nén bớt dữ liệu trước khi gửi xuống
  4. DĐổi kiểu trả về thành ByteArray, để Retrofit đọc file bằng bộ đệm nhỏ hơn
Xem đáp án
Đáp án đúng: A
Mặc định Retrofit đọc toàn bộ body response vào bộ nhớ (chuyển thành mảng byte) trước khi trả cho code, nên file lớn dễ gây OutOfMemoryError. @Streaming giữ ResponseBody dạng luồng: bạn đọc body.byteStream() và ghi dần ra file ở Dispatchers.IO (nhớ use { } để đóng). @Multipart dành cho request upload, header gzip chỉ giảm dung lượng truyền chứ không đổi cách đệm phía client, còn ByteArray buộc nạp cả file vào RAM.
