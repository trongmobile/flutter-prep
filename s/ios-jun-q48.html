QA viết UI test đăng nhập bằng XCUITest với app.buttons["Đăng nhập"].tap(): chạy trên máy dev thì pass, trên CI thì fail ngẫu nhiên, và đổi app sang tiếng Anh thì vỡ hết. Bạn viết UI test ổn định thế nào, và khi nào nên chọn UI test thay vì unit test?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
XCUITest chạy app thành một process riêng và tìm phần tử qua accessibility. Truy vấn theo chữ hiển thị (đã localize) rất dễ vỡ khi đổi ngôn ngữ hay sửa copy; hãy đặt accessibilityIdentifier (UIKit: button.accessibilityIdentifier = "login_button", SwiftUI: .accessibilityIdentifier("login_button")) rồi query app.buttons["login_button"]; identifier không được đọc ra cho người dùng, khác với accessibilityLabel. Nguyên nhân chập chờn chủ yếu là không chờ UI: bước tiếp theo chạy khi màn hình chưa kịp xuất hiện, nhất là trên CI chậm. Dùng element.waitForExistence(timeout:) hay expectation thay vì sleep. Các thực hành khác: continueAfterFailure = false để dừng ngay khi có lỗi đầu tiên; dùng launch arguments hay environment để app chạy với API giả và xoá phiên cũ, tránh phụ thuộc server thật; mỗi test độc lập, không dựa vào thứ tự chạy; tách locator ra Page Object. Chọn loại test: logic, ViewModel, parse JSON, tính toán thì unit test (nhanh, ổn định, viết nhiều); UI test chỉ dành cho vài luồng quan trọng chạy từ đầu đến cuối như đăng nhập, thanh toán, vì chậm, tốn CI và dễ flaky hơn.
final class LoginUITests: XCTestCase {
  let app = XCUIApplication()

  override func setUpWithError() throws {
    continueAfterFailure = false
    app.launchArguments = ["-uiTesting"]   // app đọc cờ này để dùng API giả, xoá phiên cũ
    app.launch()
  }

  func testLoginSuccess() {
    let email = app.textFields["login_email"]
    XCTAssertTrue(email.waitForExistence(timeout: 5))   // chờ màn hình, không dùng sleep
    email.tap()
    email.typeText("an@example.com")

    let password = app.secureTextFields["login_password"]
    password.tap()
    password.typeText("123456")

    app.buttons["login_button"].tap()
    XCTAssertTrue(app.staticTexts["home_title"].waitForExistence(timeout: 10))
  }
}
