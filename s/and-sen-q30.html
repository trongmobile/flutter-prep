Trong MVVM, ViewModel cần báo cho UI các sự kiện một lần như hiện snackbar hay điều hướng. Team dùng SharedFlow/Channel và gặp lỗi: xoay màn hình thì snackbar hiện lại, hoặc sự kiện bị mất khi app đang ở background. Bạn thiết kế việc xử lý sự kiện UI thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Hướng được Google khuyến nghị là coi sự kiện như một phần của state: ViewModel đặt 'thông báo đang chờ hiển thị' vào UI state, UI hiển thị xong thì gọi onMessageShown() để ViewModel xoá nó đi. Vì state luôn được giữ, sự kiện không mất khi UI chưa ở trạng thái STARTED, và sau khi đã tiêu thụ (xoá khỏi state) thì xoay màn hình không làm nó hiện lại; mỗi message nên có id riêng để hai thông báo giống nhau liên tiếp không bị gộp thành một. Các cách còn lại đều có điểm yếu: kiểu SingleLiveEvent phát lại khi có observer mới hoặc chỉ giao cho một observer; SharedFlow không replay thì mất sự kiện lúc không có subscriber; Channel kèm receiveAsFlow() giữ sự kiện tới khi có người nhận và chỉ giao một lần, nhưng nếu collector bị huỷ đúng lúc vừa nhận (ví dụ UI rời STARTED) thì sự kiện vẫn có thể mất, nên không phải bảo đảm tuyệt đối. Điều hướng cũng nên là kết quả của state (ví dụ navigateTo: Route?) hoặc được UI quyết định qua callback. Tôi dùng state cho mọi thứ phải tới tay user (lỗi thanh toán, điều hướng sau khi tạo đơn) và chỉ dùng Channel cho hiệu ứng 'bắn rồi quên' như rung hay âm thanh.
data class UiMessage(val text: String, val id: String = UUID.randomUUID().toString())

data class CheckoutUiState(
  val items: List<ItemUi> = emptyList(),
  val message: UiMessage? = null, // sự kiện đang chờ UI hiển thị
)

class CheckoutViewModel(private val repo: OrderRepository) : ViewModel() {
  private val _state = MutableStateFlow(CheckoutUiState())
  val state: StateFlow<CheckoutUiState> = _state.asStateFlow()

  fun onPay() = viewModelScope.launch {
    repo.pay().onFailure {
      _state.update { s -> s.copy(message = UiMessage("Thanh toán thất bại")) }
    }
  }

  fun onMessageShown() = _state.update { it.copy(message = null) } // đã hiển thị thì xoá khỏi state
}

// Compose
state.message?.let { msg ->
  LaunchedEffect(msg.id) {
    snackbarHostState.showSnackbar(msg.text)
    viewModel.onMessageShown()
  }
}
