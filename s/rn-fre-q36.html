Server chạy ở localhost:3000 trên máy dev nhưng app báo Network request failed. Nguyên nhân thường gặp và cách xử lý trên iOS Simulator, Android Emulator và máy thật?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
localhost luôn là chính thiết bị đang chạy app. iOS Simulator dùng chung mạng với máy Mac nên http://localhost:3000 thường chạy được. Android Emulator là máy ảo riêng, localhost trỏ vào chính emulator; địa chỉ của máy dev là 10.0.2.2 (hoặc chạy adb reverse tcp:3000 tcp:3000 để dùng localhost). Máy thật phải cùng mạng Wi-Fi và dùng IP LAN của máy dev (như 192.168.1.10), đồng thời server phải lắng nghe trên 0.0.0.0 chứ không chỉ 127.0.0.1, và firewall phải cho phép cổng đó. Còn có hai rào cản về HTTP không mã hoá: iOS có App Transport Security, template React Native đã mở cho mạng cục bộ nhưng nếu gọi IP LAN thì vẫn phải khai báo ngoại lệ trong Info.plist; Android 9 trở lên chặn cleartext, template chỉ bật usesCleartextTraffic ở bản debug. Nên đặt base URL theo môi trường thay vì ghi cứng khắp nơi, và dùng HTTPS cho production.
import { Platform } from 'react-native';

// Chọn địa chỉ máy dev theo nền tảng khi chạy trên simulator/emulator
const DEV_HOST = Platform.OS === 'android' ? '10.0.2.2' : 'localhost';

export const API_URL = __DEV__
  ? `http://${DEV_HOST}:3000`
  : 'https://api.myshop.com';

// Máy thật: dùng IP LAN của máy dev, ví dụ http://192.168.1.10:3000
// Android + adb reverse tcp:3000 tcp:3000: dùng được http://localhost:3000
