Form nhập liệu bị mất hết text đã gõ mỗi khi bật/tắt trạng thái loading, dù text nằm trong @State của view con. Nguyên nhân liên quan tới identity của view là gì, và sửa thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
SwiftUI gắn @State với identity của view chứ không gắn với struct view. Identity gồm structural identity (vị trí trong cây, mỗi nhánh if/else là một vị trí khác nhau) và explicit identity (id trong ForEach, modifier .id(...)). Nếu viết if isLoading { FormView().disabled(true) } else { FormView() } thì khi đổi nhánh, SwiftUI coi đó là hai view khác nhau, huỷ view cũ cùng state của nó rồi tạo view mới. Cách sửa là giữ một view duy nhất và thay đổi bằng modifier (.disabled(isLoading), .opacity, .overlay) thay vì rẽ nhánh. Ngược lại, khi muốn chủ động reset state (đổi user, đổi sản phẩm), gắn .id(product.id) để SwiftUI tạo view mới; đừng dùng .id(UUID()) vì view sẽ bị tạo lại ở mỗi lần render.
// Sai: hai nhánh là hai identity khác nhau, state của FormView bị reset
if isLoading {
  FormView().disabled(true)
} else {
  FormView()
}

// Đúng: một identity, chỉ đổi modifier
FormView()
  .disabled(isLoading)
  .overlay { if isLoading { ProgressView() } }
