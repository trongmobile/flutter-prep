Review code thấy val formatter by lazy { ... } được đọc từ nhiều thread, chỗ khác dùng Delegates.observable, và đồng nghiệp thắc mắc by viewModels() thực chất là gì. Hãy giải thích cơ chế property delegation by, các LazyThreadSafetyMode và cách tự viết một delegate.

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
by chuyển get/set của property sang một object delegate: compiler sinh accessor gọi getValue(thisRef, property) và setValue(...), bạn cung cấp hai hàm operator này hoặc implement ReadOnlyProperty/ReadWriteProperty. lazy có ba chế độ: mặc định SYNCHRONIZED (có khoá, initializer chạy tối đa một lần dù nhiều thread, an toàn nhưng tốn chi phí khoá); PUBLICATION (nhiều thread có thể cùng chạy initializer, chỉ giá trị đầu tiên được giữ, nên initializer phải idempotent); NONE (không đồng bộ, nhanh nhất, chỉ dùng khi chắc chắn một thread, như trong Activity/Fragment trên main thread). Nếu initializer ném lỗi, lần truy cập sau chạy lại chứ không cache lỗi. Delegates.observable gọi callback sau khi đã gán giá trị mới; Delegates.vetoable gọi trước và trả false thì từ chối gán. by viewModels() là một hàm trả về Lazy<VM>, và Lazy có sẵn extension getValue nên dùng được với by; ViewModel chỉ được tạo ở lần truy cập đầu tiên, nên truy cập quá sớm (Fragment chưa attach) sẽ lỗi. Tự viết delegate rất hợp để gói việc đọc/ghi SharedPreferences hay lấy argument của Intent. Bẫy: delegate không tự thread-safe, và mỗi property dùng delegate là thêm một object giữ state.
private val formatter by lazy(LazyThreadSafetyMode.NONE) {
  NumberFormat.getCurrencyInstance(Locale("vi", "VN")) // chỉ dùng trên main thread
}

var retryCount by Delegates.vetoable(0) { _, _, new -> new in 0..3 } // gán 4 bị từ chối

// Delegate tự viết: property đọc/ghi thẳng vào SharedPreferences
fun SharedPreferences.boolean(key: String, default: Boolean) =
  object : ReadWriteProperty<Any?, Boolean> {
    override fun getValue(thisRef: Any?, property: KProperty<*>) = getBoolean(key, default)
    override fun setValue(thisRef: Any?, property: KProperty<*>, value: Boolean) =
      edit { putBoolean(key, value) }
  }

class Settings(prefs: SharedPreferences) {
  var darkMode by prefs.boolean("dark_mode", false)
}
