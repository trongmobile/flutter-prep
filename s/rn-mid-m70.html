Danh sách phân trang dùng TanStack Query v5: mỗi lần chuyển trang, data thành undefined trong lúc chờ nên danh sách nháy thành trống. Cách giữ dữ liệu trang trước cho tới khi trang mới tải xong là gì?

const [page, setPage] = useState(1);

const { data, isFetching } = useQuery({
  queryKey: ['orders', page],
  queryFn: () => fetchOrders(page),
});
  1. AThêm placeholderData: keepPreviousData vào options của useQuery
  2. BĐặt staleTime: Infinity để mọi trang luôn được coi là còn tươi
  3. CBỏ page khỏi queryKey để các trang dùng chung một bản cache
  4. DBật refetchOnMount: false để query không xoá dữ liệu khi đổi trang
Xem đáp án
Đáp án đúng: A
Mỗi page có một queryKey riêng, query mới chưa có dữ liệu nên data là undefined cho tới khi tải xong. placeholderData: keepPreviousData (v5; trước đây là keepPreviousData: true) giữ dữ liệu của query trước làm dữ liệu tạm, kèm cờ isPlaceholderData để biết đang xem dữ liệu cũ. staleTime chỉ ảnh hưởng tới việc refetch trang đã có cache, bỏ page khỏi key khiến mọi trang dùng chung một cache (hiển thị sai trang), còn refetchOnMount không liên quan tới việc đổi key.
