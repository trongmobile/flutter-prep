Ô tìm kiếm gọi API mỗi khi gõ một ký tự, và kết quả của từ khoá cũ đôi khi về sau, đè lên kết quả mới. Bạn debounce và loại bỏ kết quả cũ thế nào trong Flutter (Timer thuần, rxdart hay Bloc/Riverpod)?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Có hai vấn đề cần giải riêng: gọi quá nhiều request (cần debounce) và kết quả về sai thứ tự (race condition). Debounce thuần Dart: giữ một Timer?, mỗi lần onChanged thì cancel() timer cũ rồi tạo timer mới 300ms trước khi gọi API, và nhớ cancel() trong dispose(). Race condition: gắn cho mỗi lần tìm một mã (bộ đếm hoặc chính chuỗi query) và bỏ kết quả nếu nó không còn là lần tìm mới nhất; hoặc dùng CancelToken của Dio để huỷ request cũ (server vẫn có thể xử lý nhưng app không nhận kết quả). Với Stream, rxdart có debounceTime và switchMap (tự huỷ subscription của request cũ khi có query mới), gọn nhất khi đã dùng Stream hay Bloc. Với Bloc có EventTransformer kèm restartable() của bloc_concurrency; với Riverpod, AsyncNotifier có thể kiểm tra mã tìm kiếm sau mỗi await, hoặc dùng ref.onDispose để huỷ request khi provider bị invalidate. Cũng nên bỏ qua query rỗng hoặc quá ngắn, và hiển thị trạng thái loading riêng cho lần tìm đang chạy.
class _SearchBoxState extends State<SearchBox> {
  Timer? _debounce;
  int _searchId = 0; // đánh dấu lần tìm mới nhất

  void _onChanged(String text) {
    _debounce?.cancel();
    _debounce = Timer(const Duration(milliseconds: 300), () => _search(text.trim()));
  }

  Future<void> _search(String query) async {
    if (query.length < 2) return;
    final id = ++_searchId;
    final results = await api.search(query);
    if (!mounted || id != _searchId) return; // kết quả của lần tìm cũ: bỏ
    setState(() => _results = results);
  }

  @override
  void dispose() {
    _debounce?.cancel();
    super.dispose();
  }
}

// Với rxdart: switchMap tự huỷ lần tìm cũ khi có query mới
queryController.stream
    .debounceTime(const Duration(milliseconds: 300))
    .distinct()
    .switchMap((q) => Stream.fromFuture(api.search(q)))
    .listen(_onResults);
