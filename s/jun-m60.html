Null-aware spread với một list có thể null: đoạn code sau in ra gì?

void main() {
  List<int>? extra;
  final items = [1, ...?extra, 2];
  print(items);
}
  1. A[1, null, 2], vì extra là null nên được thêm vào list như một phần tử
  2. BNém lỗi lúc chạy vì không thể trải (spread) một giá trị null vào list
  3. CLỗi compile vì ...? không phải toán tử hợp lệ trong collection literal
  4. D[1, 2], vì ...? bỏ qua cả phần spread khi extra là null
Xem đáp án
Đáp án đúng: D
...? là null-aware spread: khi vế phải là null thì không thêm gì, còn khác null thì trải từng phần tử như ... thường. Viết ...extra với kiểu List<int>? mới là lỗi compile vì null safety, và một giá trị null cũng không bao giờ được thêm vào list dưới dạng phần tử. Có thể đạt kết quả tương đương bằng collection-if: if (extra != null) ...extra.
