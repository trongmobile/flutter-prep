Bạn dùng package http gửi dữ liệu đăng nhập lên API bằng đoạn code sau, nhưng server báo lỗi không nhận được dữ liệu dạng JSON trong request body. Nguyên nhân là gì?

final response = await http.post(
  Uri.parse('https://api.example.com/login'),
  body: {'email': email, 'password': password},
);
  1. Ahttp.post gửi Map theo kiểu form URL-encoded, cần jsonEncode(body) và header Content-Type: application/json
  2. Bhttp.post không hỗ trợ gửi dữ liệu JSON trực tiếp, phải đổi sang dùng http.put hoặc Dio mới gửi được JSON
  3. CCần bọc Map bằng jsonDecode(...) trước khi truyền vào body và đặt encoding: utf8 cho request
  4. DUri.parse chỉ phân tích URL cho http.get, còn http.post bắt buộc phải truyền Uri.https và headers
Xem đáp án
Đáp án đúng: A
Trong package http, khi truyền một Map vào body, thư viện tự động mã hoá dữ liệu theo kiểu application/x-www-form-urlencoded giống form HTML thay vì JSON. Để gửi JSON đúng chuẩn, bạn phải chuyển Map thành chuỗi bằng jsonEncode(...) (từ dart:convert) và khai báo headers: {'Content-Type': 'application/json'}. http.post và Uri.parse đều dùng bình thường cho API JSON, còn jsonDecode là để đọc dữ liệu trả về từ server chứ không phải để gửi đi.
