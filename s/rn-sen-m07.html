App native nhúng 5 màn React Native (brownfield); code hiện tại tạo mới một React host/instance mỗi lần mở một màn RN. Hậu quả chính là gì?

  1. AMỗi lần mở phải khởi tạo lại runtime và load bundle: chậm, tốn memory, mất state chung
  2. BKhông ảnh hưởng gì, vì JS runtime luôn được dùng chung ngầm giữa các instance
  3. CChỉ ảnh hưởng ở bản debug, vì bản release đã cache sẵn bundle vào bộ nhớ đệm
  4. DApp crash ngay khi mở màn thứ hai vì mỗi process chỉ được phép có đúng một JS runtime
Xem đáp án
Đáp án đúng: A
Mỗi instance có JS runtime và module registry riêng, nên tạo mới mỗi lần là trả lại toàn bộ chi phí khởi tạo và không chia sẻ được state hay cache giữa các màn. Cách đúng là tạo một instance dùng chung ở mức Application/AppDelegate, có thể pre-warm; nhiều runtime trong một process vẫn chạy được, chỉ là lãng phí.
