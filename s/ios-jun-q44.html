QA báo app bật Dark Mode thì chữ đen trên nền đen ở vài màn, viền vẽ bằng layer.borderColor không đổi màu theo chế độ, và khi chỉnh cỡ chữ lớn nhất trong Settings thì label bị cắt, các nút chồng lên nhau. Bạn sửa thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Dark Mode: đừng hard-code .white/.black; dùng màu semantic của hệ thống (.systemBackground, .label, .secondaryLabel, .separator) hoặc Color Set trong asset catalog có biến thể Any/Dark rồi gọi UIColor(named:). UIColor dynamic tự đổi theo traitCollection, nhưng CGColor là giá trị đã resolve: layer.borderColor = color.cgColor chỉ đúng với chế độ lúc gán, nên phải gán lại khi chế độ đổi, bằng registerForTraitChanges (iOS 17+) hoặc traitCollectionDidChange (đã deprecated từ iOS 17), và resolve rõ ràng bằng color.resolvedColor(with: traitCollection).cgColor. Dynamic Type: dùng font theo text style (.preferredFont(forTextStyle: .body)) kèm adjustsFontForContentSizeCategory = true; font cố định systemFont(ofSize:) thì không co giãn, còn font tuỳ chỉnh phải bọc bằng UIFontMetrics(forTextStyle:).scaledFont(for:). Đặt numberOfLines = 0, không cố định chiều cao label hay cell (self-sizing), và khi chữ vào nhóm accessibility size (preferredContentSizeCategory.isAccessibilityCategory) thì đổi UIStackView ngang thành dọc. Kiểm tra bằng Environment Overrides trong Xcode hoặc Accessibility Inspector, thử ở cỡ chữ lớn nhất.
final class BadgeView: UIView {
  private let stack = UIStackView()
  private let titleLabel = UILabel()

  override init(frame: CGRect) {
    super.init(frame: frame)
    backgroundColor = .secondarySystemBackground          // màu semantic, tự đổi theo Dark Mode
    titleLabel.font = .preferredFont(forTextStyle: .headline)
    titleLabel.adjustsFontForContentSizeCategory = true   // co giãn theo cỡ chữ người dùng chọn
    titleLabel.numberOfLines = 0
    stack.addArrangedSubview(titleLabel)
    addSubview(stack)                                     // ... thêm constraint cho stack
    applyAppearance()

    // iOS 17+: chạy lại khi đổi Dark Mode hoặc cỡ chữ
    registerForTraitChanges([UITraitUserInterfaceStyle.self,
                             UITraitPreferredContentSizeCategory.self]) { (view: BadgeView, _) in
      view.applyAppearance()
    }
  }

  private func applyAppearance() {
    layer.borderWidth = 1
    // CGColor đã resolve nên phải resolve theo trait hiện tại và gán lại mỗi khi đổi
    layer.borderColor = UIColor.separator.resolvedColor(with: traitCollection).cgColor
    stack.axis = traitCollection.preferredContentSizeCategory.isAccessibilityCategory ? .vertical : .horizontal
  }

  required init?(coder: NSCoder) { fatalError("init(coder:) has not been implemented") }
}
