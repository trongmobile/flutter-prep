Class có một lazy var chứa closure dùng self.name. Sau khi gọi closure rồi gán biến về nil, chương trình in ra gì?

final class ProfileVC {
  let name = "Profile"
  lazy var logTitle: () -> Void = { print(self.name) }
  deinit { print("deinit") }
}

var vc: ProfileVC? = ProfileVC()
vc?.logTitle()
vc = nil
  1. AProfile rồi deinit
  2. BChỉ in Profile
  3. CLỗi compile vì dùng self khi khởi tạo property
  4. DChỉ in deinit
Xem đáp án
Đáp án đúng: B
Nhờ lazy, closure được phép dùng self, nhưng nó được lưu vào property của chính object và capture self mạnh: object giữ closure, closure giữ object. Vì vậy vc = nil không giải phóng được object và deinit không chạy; sửa bằng { [weak self] in ... }.
