Mỗi lần người dùng gõ một ký tự vào ô tìm kiếm, TextInput mất focus và bàn phím đóng lại. Nguyên nhân là gì?

function SearchScreen() {
  const [query, setQuery] = useState('');

  return (
    <FlatList
      data={results}
      renderItem={renderResult}
      ListHeaderComponent={() => (
        <TextInput value={query} onChangeText={setQuery} placeholder='Tìm kiếm' />
      )}
    />
  );
}
  1. AMỗi lần render tạo một hàm component mới, React coi là component khác nên mount lại cả header
  2. BFlatList luôn unmount rồi mount lại phần header mỗi khi data hoặc state của màn hình thay đổi
  3. CTextInput có value được điều khiển sẽ bị Android bỏ focus mỗi khi giá trị của nó thay đổi trong state
  4. DThiếu keyboardShouldPersistTaps='handled', nên chạm vào header làm bàn phím tự đóng lại
Xem đáp án
Đáp án đúng: A
ListHeaderComponent nhận một component hoặc một element. Hàm mũi tên viết inline có tham chiếu mới ở mỗi lần render nên với React đó là một type component khác: cây cũ bị unmount (mất focus, bàn phím đóng) rồi cây mới được mount. Cách sửa: truyền element, ListHeaderComponent={<TextInput ... />}, hoặc dùng một component được định nghĩa ngoài SearchScreen (có tham chiếu ổn định). FlatList không tự unmount header, và keyboardShouldPersistTaps chỉ quyết định việc chạm có đóng bàn phím hay không, không liên quan tới lúc gõ.
