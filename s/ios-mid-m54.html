Màn danh sách hiển thị 50.000 bản ghi Core Data bằng NSFetchRequest; mở màn thì memory tăng vọt vì mọi object được nạp ngay. Thay đổi nào phù hợp nhất mà vẫn cuộn xem đủ danh sách?

  1. AĐặt returnsObjectsAsFaults = false để Core Data nạp sẵn mọi thuộc tính trong một lần
  2. BĐặt fetchLimit = 20 rồi bỏ phần còn lại, vì người dùng hiếm khi cuộn xa tới thế
  3. CĐặt fetchBatchSize (ví dụ 20) để dữ liệu object chỉ được nạp từng lô khi cuộn tới
  4. DChuyển fetch sang viewContext thay vì background context để Core Data tự tối ưu bộ nhớ
Xem đáp án
Đáp án đúng: C
Với fetchBatchSize khác 0, Core Data vẫn ghi nhận identity của mọi kết quả nhưng chỉ nạp dữ liệu theo từng lô; mảng trả về là một proxy nạp thêm lô khi được truy cập, nên memory tăng dần theo phần danh sách đã cuộn qua thay vì 50.000 object ngay từ đầu (NSFetchedResultsController cũng dùng được). returnsObjectsAsFaults = false làm ngược lại, fetchLimit cắt mất dữ liệu, còn chuyển sang viewContext chỉ đưa việc fetch lên main thread.
