Vì sao gọi setCount(count + 1) ba lần liên tiếp trong một handler mà count chỉ tăng 1? Sửa thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Setter của useState không đổi biến count ngay mà xếp yêu cầu cập nhật vào hàng đợi và lên lịch render lại. Trong cùng một lần render, count là hằng số của lần render đó, nên cả ba lời gọi đều tương đương setCount(0 + 1). Khi giá trị mới phụ thuộc giá trị cũ, hãy dùng updater function setCount((c) => c + 1): React chạy lần lượt từng updater với giá trị mới nhất trong hàng đợi, nên tăng đủ 3. Cũng vì cơ chế này, console.log(count) ngay sau khi gọi setter vẫn in ra giá trị cũ.
const [count, setCount] = useState(0);

const addThreeWrong = () => {
  setCount(count + 1);
  setCount(count + 1);
  setCount(count + 1); // count chỉ thành 1
};

const addThree = () => {
  setCount((c) => c + 1);
  setCount((c) => c + 1);
  setCount((c) => c + 1); // count thành 3
};
