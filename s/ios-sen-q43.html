Màn hình lưới ảnh tải 500 thumbnail bằng for id in ids { Task { await load(id) } }: app bắn hàng trăm request cùng lúc, rời màn hình vẫn tải tiếp, và lỗi của từng ảnh biến mất không dấu vết. Bạn thiết kế lại bằng structured concurrency thế nào và giới hạn số tác vụ chạy đồng thời ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mỗi Task { } rời rạc là unstructured: không có task cha nên không tự huỷ khi view biến mất, không gom được lỗi, và không ai biết khi nào xong. Structured concurrency gắn vòng đời con vào cha: withThrowingTaskGroup chỉ trả về khi mọi child task đã xong, huỷ task cha lan xuống mọi child, và lỗi của child được ném ra ở group.next(); khi lỗi thoát khỏi thân group thì các child còn lại bị huỷ. Huỷ là hợp tác: child phải gọi try Task.checkCancellation() hoặc dùng API có hỗ trợ huỷ như URLSession.data(for:). TaskGroup không tự giới hạn số tác vụ đồng thời, nên làm cửa sổ trượt: thêm N task đầu, mỗi lần next() trả về thì thêm một task mới. Muốn dọn tài nguyên khi bị huỷ (ví dụ huỷ request của một SDK dạng callback) dùng withTaskCancellationHandler(operation:onCancel:); onCancel chạy ngay lập tức trên thread bất kỳ nên phải thread-safe. Với dòng dữ liệu: AsyncStream mặc định buffer không giới hạn, producer nhanh hơn consumer sẽ làm phình bộ nhớ, nên đặt bufferingPolicy: .bufferingNewest(n) khi chỉ cần dữ liệu mới nhất. Back-pressure thật chỉ có với nguồn kiểu pull như URLSession.bytes, còn AsyncStream bọc callback thì không có. Trong SwiftUI dùng .task (tự huỷ khi view biến mất) và .task(id:); Task { } hay Task.detached chỉ để vượt ranh giới sync sang async hoặc cho việc cố ý sống lâu hơn scope, và hãy giữ handle để huỷ được.
func loadThumbnails(ids: [Int], maxConcurrent: Int = 6) async throws -> [Int: UIImage] {
  var result: [Int: UIImage] = [:]

  try await withThrowingTaskGroup(of: (Int, UIImage).self) { group in
    var iterator = ids.makeIterator()

    // Khởi động tối đa maxConcurrent tác vụ
    for _ in 0..<maxConcurrent {
      guard let id = iterator.next() else { break }
      group.addTask { (id, try await fetchThumbnail(id)) }
    }

    // Mỗi tác vụ xong thì nạp thêm một tác vụ mới (cửa sổ trượt)
    while let (id, image) = try await group.next() {
      result[id] = image
      if let nextID = iterator.next() {
        group.addTask { (nextID, try await fetchThumbnail(nextID)) }
      }
    }
  } // lỗi thoát khỏi đây thì các child còn lại tự bị huỷ

  return result
}
