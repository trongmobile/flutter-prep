copy() của data class được dùng như sau. Dòng println in ra gì?

data class Cart(val owner: String, val items: MutableList<String>)

fun main() {
  val a = Cart("An", mutableListOf("Áo"))
  val b = a.copy(owner = "Bình")
  b.items.add("Quần")
  println("${a.items} ${b.items}")
}
  1. A[Áo] [Áo, Quần]
  2. B[Áo] [Quần]
  3. C[Áo, Quần] [Áo, Quần]
  4. D[Áo, Quần] [Áo]
Xem đáp án
Đáp án đúng: C
copy() chỉ sao chép nông (shallow copy): các property được gán sang object mới, nên owner độc lập nhưng items của a và b vẫn trỏ cùng một MutableList. Thêm phần tử qua b thì a cũng thấy Quần. Để tránh, dùng List bất biến và tạo list mới khi đổi (a.copy(items = a.items + "Quần")), hoặc sao chép tường minh bằng a.items.toMutableList().
