Màn hình dùng ref.current.measureInWindow(...) để đặt tooltip ngay dưới một icon bọc trong <View ref={anchorRef}> (không có style màu nền, viền hay bóng). Trên Android (và trên iOS khi bật Fabric), hàm measureInWindow không trả về toạ độ hoặc trả về giá trị rỗng. Nguyên nhân và cách sửa đúng là gì?

const anchorRef = useRef<View>(null);

const showTooltip = () => {
  anchorRef.current?.measureInWindow((x, y, width, height) => {
    setAnchor({ x, y, width, height });
  });
};

return (
  <View ref={anchorRef} style={{ padding: 8 }}>
    <Icon name="info" />
  </View>
);
  1. AView chỉ dùng để căn bố cục bị tối ưu làm phẳng khỏi cây native (view flattening); cần thêm collapsable={false} cho View đó
  2. BmeasureInWindow chỉ hoạt động với component Animated.View; cần đổi <View> sang <Animated.View> để giữ native node
  3. CThư viện Yoga không tính toạ độ khi chỉ đặt padding; cần thêm position: 'relative' và flex: 1 vào style của View
  4. DKhông được gọi measureInWindow trong event handler; phải chuyển lời gọi này vào useLayoutEffect để đọc được toạ độ thật
Xem đáp án
Đáp án đúng: A
Để tối ưu hiệu năng cây hiển thị, React Native (trên Android và trên cả iOS với kiến trúc Fabric) tự động loại bỏ các View chỉ làm nhiệm vụ layout mà không vẽ gì (view flattening), khiến native node không tồn tại để measureInWindow đo. Đặt collapsable={false} sẽ tắt tối ưu này cho View cần đo. Đổi sang Animated.View hay thêm position: 'relative' không tắt view flattening nếu view vẫn thuần layout, còn gọi measureInWindow trong handler là bình thường sau khi view đã layout.
