Với go_router, làm sao xây bottom navigation mà mỗi tab giữ nguyên stack điều hướng và state khi chuyển tab?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Dùng StatefulShellRoute.indexedStack: mỗi tab là một StatefulShellBranch có Navigator riêng, các branch được giữ trong IndexedStack nên state và stack con không mất khi đổi tab. builder nhận StatefulNavigationShell để dựng Scaffold + NavigationBar; đổi tab bằng goBranch(index), truyền initialLocation: true khi bấm lại tab đang mở để quay về gốc tab. Khác với ShellRoute thường (chỉ một Navigator con dùng chung), cách này hợp với app nhiều tab kiểu mạng xã hội; đổi lại tốn bộ nhớ hơn vì các tab đã mở đều được giữ sống.
StatefulShellRoute.indexedStack(
  builder: (context, state, shell) => ScaffoldWithNavBar(shell: shell),
  branches: [
    StatefulShellBranch(routes: [
      GoRoute(path: '/feed', builder: (c, s) => const FeedPage()),
    ]),
    StatefulShellBranch(routes: [
      GoRoute(path: '/profile', builder: (c, s) => const ProfilePage()),
    ]),
  ],
)
