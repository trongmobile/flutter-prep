JSON trả createdAt dạng chuỗi ISO 8601, model khai báo let createdAt: Date, decode bằng JSONDecoder() không cấu hình gì. Kết quả là gì?

struct Order: Decodable {
  let id: Int
  let createdAt: Date
}

let json = Data(#"{"id": 1, "createdAt": "2024-05-01T10:00:00Z"}"#.utf8)
let order = try JSONDecoder().decode(Order.self, from: json)
  1. ANém typeMismatch vì mặc định Date đọc từ số
  2. BDecode thành công vì chuỗi đúng chuẩn ISO 8601
  3. CcreatedAt nhận thời điểm hiện tại do parse lỗi
  4. DNém keyNotFound cho key createdAt

Đáp án đúng: A
Chiến lược mặc định .deferredToDate decode Date từ một số Double (số giây tính từ 1/1/2001), nên gặp chuỗi sẽ ném typeMismatch. Cần đặt decoder.dateDecodingStrategy = .iso8601, hoặc .formatted(...) với DateFormatter khi server dùng format khác.
