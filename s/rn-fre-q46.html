Đồng nghiệp mới viết màn Home: ScrollView với .map() 500 sản phẩm, ảnh gốc rộng 4000px, console.log trong renderItem và toàn bộ state đặt ở App. App giật và nóng máy. Những lỗi hiệu năng cơ bản nào cần sửa trước?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Đây là các lỗi hay gặp ở người mới, đều sửa được mà chưa cần công cụ phức tạp. (1) ScrollView kèm .map() tạo cả 500 view ngay từ đầu, nên dùng FlatList để chỉ render phần đang thấy. (2) Ảnh quá lớn: tải ảnh 4000px chỉ để hiện ô 100px làm tốn RAM giải mã, cuộn giật và có thể bị hệ điều hành kill vì hết bộ nhớ; hãy dùng thumbnail đúng kích thước từ server và đặt width/height rõ ràng cho ảnh mạng. (3) Trong danh sách, tránh để renderItem là hàm vô danh viết thẳng trong JSX: định nghĩa nó ngoài component hoặc bọc useCallback, và bọc dòng bằng React.memo để dòng không đổi thì không render lại. (4) console.log dày đặc ở chỗ chạy nhiều (như renderItem hay sự kiện cuộn) làm nghẽn luồng JS; xoá chúng, hoặc loại bỏ khi build production bằng babel-plugin-transform-remove-console. (5) State đặt quá cao (ở App hay ở cha của cả màn hình) khiến mỗi lần gõ phím cả cây render lại; hãy đưa state xuống component dùng nó. Nguyên tắc chung: đo trước khi tối ưu, đo trên bản release, và đừng rải useMemo khắp nơi khi chưa biết chỗ chậm.
const ProductRow = React.memo(function ProductRow({ item }: { item: Product }) {
  return (
    <View style={styles.row}>
      {/* ảnh thumbnail đúng kích thước hiển thị, không phải ảnh gốc 4000px */}
      <Image source={{ uri: item.thumbUrl }} style={styles.thumb} />
      <Text>{item.name}</Text>
    </View>
  );
});

// Định nghĩa ngoài component để không tạo hàm mới mỗi lần render
function renderProduct({ item }: ListRenderItemInfo<Product>) {
  return <ProductRow item={item} />;
}

function HomeScreen({ products }: { products: Product[] }) {
  return <FlatList data={products} renderItem={renderProduct} keyExtractor={(p) => String(p.id)} />;
}

const styles = StyleSheet.create({
  row: { flexDirection: 'row', alignItems: 'center', padding: 8 },
  thumb: { width: 100, height: 100, marginRight: 12 },
});
