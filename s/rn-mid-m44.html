Màn gallery dùng FlatList với numColumns phụ thuộc chiều rộng cửa sổ. Khi người dùng xoay máy làm columns đổi từ 2 sang 3, chuyện gì xảy ra và cách sửa là gì?

function Gallery({ photos }: { photos: Photo[] }) {
  const { width } = useWindowDimensions();
  const columns = width > 600 ? 3 : 2;

  return (
    <FlatList
      data={photos}
      numColumns={columns}
      renderItem={({ item }) => <PhotoCell photo={item} />}
    />
  );
}
  1. AChạy bình thường vì FlatList tự chia lại hàng khi numColumns đổi, chỉ cần thêm extraData={columns}
  2. BReact Native ném lỗi 'Changing numColumns on the fly'; đặt key theo columns để list mount lại
  3. CList vẫn giữ số cột cũ vì numColumns chỉ được đọc lúc mount; gọi scrollToOffset để làm mới
  4. DBáo lỗi vì numColumns phải là hằng số, nên cần khai báo giá trị đó ngoài component
Xem đáp án
Đáp án đúng: B
FlatList kiểm tra trong componentDidUpdate rằng numColumns không đổi giữa hai lần render và ném lỗi invariant nếu khác, vì cách chia hàng phụ thuộc vào số cột. Cách xử lý chính thức là đổi key (ví dụ key={'cols-' + columns}) để list mount lại với số cột mới; extraData chỉ báo list vẽ lại item khi dữ liệu ngoài data đổi, không né được kiểm tra này.
