Bạn chuẩn bị build bản release đầu tiên đưa lên Google Play. Đồng nghiệp đã commit file release.jks cùng mật khẩu keystore ghi thẳng trong build.gradle.kts lên Git. Vì sao đó là vấn đề, cấu hình signing đúng thế nào, và isMinifyEnabled, isShrinkResources, Play App Signing có vai trò gì?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Keystore là danh tính của app: ai có file cùng mật khẩu thì ký được bản cập nhật giả mạo. Vì vậy .jks và mật khẩu không bao giờ vào Git (thêm vào .gitignore); lỡ commit rồi thì coi như đã lộ, phải đổi khoá chứ không chỉ xoá file vì lịch sử Git vẫn còn. Đọc thông tin ký từ keystore.properties nằm ngoài repo (hoặc biến môi trường và secret trên CI) trong signingConfigs. Với Play App Signing, bạn ký bằng upload key còn Google giữ khoá ký thật và ký lại bản phân phối: mất upload key vẫn xin Google đặt lại được, còn tự giữ khoá mà mất thì không cập nhật được app đã phát hành nữa. Trong build type release, isMinifyEnabled = true bật R8 (rút gọn, tối ưu, làm rối code) cùng proguardFiles(...), còn isShrinkResources = true loại resource không dùng và chỉ hoạt động khi đã minify. Bẫy: sau khi bật R8 phải chạy thử bản release vì lỗi chỉ lộ ở đó (thường do thiếu keep rule với reflection/serialization); giữ mapping.txt của từng bản (Play Console tự nhận khi upload AAB) để giải mã stack trace; versionCode phải tăng ở mỗi lần phát hành.
// app/build.gradle.kts
val keystoreProps = Properties().apply {
    val file = rootProject.file("keystore.properties") // nằm trong .gitignore
    if (file.exists()) file.inputStream().use { load(it) }
}

android {
    signingConfigs {
        create("release") {
            storeFile = (keystoreProps["storeFile"] as String?)?.let { file(it) }
            storePassword = keystoreProps["storePassword"] as String?
            keyAlias = keystoreProps["keyAlias"] as String?
            keyPassword = keystoreProps["keyPassword"] as String?
        }
    }
    buildTypes {
        release {
            isMinifyEnabled = true    // R8: rút gọn, tối ưu, làm rối code
            isShrinkResources = true  // bỏ resource không dùng (cần isMinifyEnabled)
            proguardFiles(getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro")
            signingConfig = signingConfigs.getByName("release")
        }
    }
}
