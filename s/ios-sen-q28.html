Team phát hành SDK nội bộ dưới dạng XCFramework cho các app khác build bằng phiên bản Xcode khác nhau. Sau khi nâng Xcode, app tích hợp báo module được biên dịch bằng phiên bản Swift khác, và việc thêm một case vào enum public của SDK làm vỡ các app tích hợp. Bạn xử lý thế nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Mặc định module Swift không ổn định giữa các phiên bản compiler: file .swiftmodule mô tả API phụ thuộc vào compiler đã build ra nó nên bản compiler khác không import được. Khi phân phối binary phải bật library evolution (BUILD_LIBRARY_FOR_DISTRIBUTION = YES, tức -enable-library-evolution): compiler sinh thêm .swiftinterface, một dạng text ổn định được build lại phía người dùng, nên binary dùng được với compiler mới hơn. Đổi lại compiler phải chừa chỗ cho việc API tiến hoá, nên một số truy cập đi gián tiếp và chậm hơn một chút. Nó cũng quyết định quy tắc nâng cấp API tương thích: enum public không @frozen được coi là 'có thể thêm case', người dùng bắt buộc viết @unknown default khi switch nên thêm case không làm vỡ nguồn; @frozen là lời hứa layout không đổi (nhanh hơn nhưng sau này không thêm case hay field được). @inlinable và @usableFromInline đưa thân hàm vào interface để người dùng inline, nhưng sau đó implementation bị đóng đinh vì đã nằm trong binary của client, nên chỉ dùng cho hot path. open cho phép subclass và override ở ngoài module nên khoá hợp đồng chặt hơn nhiều so với public; mặc định chọn public và final. Ngoài việc nhớ cờ, cần chạy swift-api-digester trên CI để phát hiện thay đổi API làm vỡ tương thích, đóng gói XCFramework đủ slice thiết bị và simulator, kèm dSYM và Privacy Manifest nếu SDK dùng API thuộc diện phải khai báo.
// Build: xcodebuild archive ... BUILD_LIBRARY_FOR_DISTRIBUTION=YES SKIP_INSTALL=NO

public enum PaymentError: Error { // không @frozen: sau này được phép thêm case
  case declined
  case network
}

// Phía app dùng SDK: bắt buộc @unknown default với enum không @frozen
switch error {
case .declined: showDeclined()
case .network: showRetry()
@unknown default: showGenericError() // case mới ở bản SDK sau không làm vỡ nguồn
}

@frozen public struct Money { // hứa layout không đổi: nhanh hơn nhưng không thể thêm field
  public var amount: Int
  public var currency: String
}
