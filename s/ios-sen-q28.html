Code review thấy let repositories: [any Repository] rải khắp nơi và một người đề xuất đổi hết sang generic some Repository hoặc <R: Repository>. some và any khác nhau thế nào, chi phí của existential ra sao, và khi nào bạn chọn loại nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
some P (opaque type) là một kiểu cụ thể duy nhất mà compiler biết nhưng ẩn với bên gọi, nên compiler có thể chuyên biệt hoá (specialize), gọi trực tiếp và inline. Generic <R: P> tương tự nhưng do bên gọi chọn kiểu. any P (existential) là một cái hộp chứa giá trị của bất kỳ kiểu nào conform P, quyết định lúc chạy: giá trị lưu trong existential container (vùng đệm inline cỡ ba word, lớn hơn thì cấp phát heap) cùng con trỏ metadata và witness table, mọi lời gọi method đi qua witness table (dynamic dispatch) nên khó inline và tốn chi phí cấp phát, copy khi giá trị lớn. Vì vậy với code nóng (vòng lặp, parse, render) ưu tiên generic hoặc some; any đúng chỗ khi thật sự cần tính dị thể: mảng chứa nhiều kiểu khác nhau, dependency chọn lúc chạy (mock khi test, đổi implementation theo feature flag), hay protocol có associated type nhưng chấp nhận dùng qua primary associated type (any Collection<Int>). Từ Swift 5.7, protocol có associated type dùng được như any; có thể bật upcoming feature ExistentialAny để compiler bắt buộc viết any cho rõ. Đừng vì sợ any mà biến cả codebase thành generic: tham số kiểu lan khắp nơi, build chậm, code khó đọc, trong khi chi phí dynamic dispatch hiếm khi là nút thắt so với I/O hay layout, nên hãy đo trước. Lưu ý some làm kiểu trả về thì không thể trả về hai kiểu khác nhau theo if.
protocol Repository { func load() async throws -> [Item] }

// Generic: compiler chuyên biệt hoá cho từng kiểu cụ thể, gọi trực tiếp, inline được
func syncAll<R: Repository>(_ repo: R) async throws -> Int {
  try await repo.load().count
}

// any: chọn implementation lúc chạy, đổi lại là dispatch qua witness table
struct AppEnvironment {
  var repository: any Repository // bản thật khi chạy, mock khi test
}

// some: ẩn kiểu cụ thể nhưng chỉ được có một kiểu duy nhất
func makeRepository() -> some Repository { RemoteRepository() }
