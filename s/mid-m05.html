Đoạn code sau chạy thế nào?

void main() {
  List<num> nums = <int>[1, 2];
  nums.add(1.5);
  print(nums);
}
  1. AIn ra [1, 2, 1.5]
  2. BLỗi compile ở dòng gán <int>[1, 2] cho List<num>
  3. CIn ra [1, 2, 1] vì 1.5 bị ép về int
  4. DCompile được nhưng ném TypeError khi add(1.5)
Xem đáp án
Đáp án đúng: D
Generic của Dart là covariant nên gán List<int> cho List<num> hợp lệ lúc compile, nhưng object thật vẫn là List<int> (generic được reify) nên thêm double bị kiểm tra và ném TypeError lúc runtime. Cách tránh là tạo đúng kiểu <num>[] ngay từ đầu.
