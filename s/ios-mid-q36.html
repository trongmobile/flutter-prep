Team lưu mọi thứ vào UserDefaults: cờ onboarding, danh sách sản phẩm yêu thích vài nghìn phần tử và cả ảnh nhỏ dạng Data; app khởi động chậm dần. Nên lưu gì ở UserDefaults/@AppStorage, gì ở file, Keychain hay database, và những bẫy nào cần biết?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
UserDefaults dành cho cấu hình nhỏ dạng key-value (cờ, lựa chọn của user, phiên bản schema): nó được nạp vào bộ nhớ khi truy cập đầu tiên, nên nhét dữ liệu lớn vào đó làm chậm khởi động và tốn memory. Dữ liệu có cấu trúc hoặc lớn (danh sách yêu thích, cache) nên vào file trong Application Support hoặc Caches (mã hoá Codable ra JSON, đặt completeFileProtection nếu nhạy cảm), hoặc vào database (SwiftData, Core Data, SQLite) khi cần truy vấn. Bí mật (token, mật khẩu) vào Keychain, không bao giờ vào UserDefaults vì đó là plist không mã hoá và nằm trong bản backup. @AppStorage trong SwiftUI là wrapper của UserDefaults tự cập nhật view khi giá trị đổi, chỉ hỗ trợ kiểu đơn giản (Bool, Int, Double, String, URL, Data, và RawRepresentable với raw value đơn giản), không dùng cho object phức tạp. Các bẫy: key là chuỗi nên dễ gõ sai, hãy gom key vào một chỗ; giá trị chưa có trả về nil, 0 hoặc false nên cần giá trị mặc định rõ ràng (register(defaults:)); app và extension (widget) muốn chia sẻ phải dùng UserDefaults(suiteName:) với App Group chứ không phải .standard; và khi đổi cấu trúc dữ liệu đã lưu nên có schemaVersion để migrate. Muốn đồng bộ giá trị nhỏ qua iCloud thì dùng NSUbiquitousKeyValueStore. Cuối cùng nhớ rằng UserDefaults bị xoá khi gỡ app, còn item Keychain thì có thể còn lại.
// Cờ và lựa chọn nhỏ: @AppStorage, gom key về một chỗ để khỏi gõ sai
enum Keys {
  static let hasSeenOnboarding = "hasSeenOnboarding"
  static let sortOrder = "favorites.sortOrder"
}

struct SettingsView: View {
  @AppStorage(Keys.hasSeenOnboarding) private var hasSeenOnboarding = false
  @AppStorage(Keys.sortOrder) private var sortOrder: SortOrder = .recent // enum có raw value String hoặc Int

  var body: some View {
    Toggle("Đã xem hướng dẫn", isOn: $hasSeenOnboarding)
  }
}

// Dữ liệu lớn: ghi file thay vì nhét vào UserDefaults
func saveFavorites(_ favorites: [Product]) throws {
  let url = try FileManager.default
    .url(for: .applicationSupportDirectory, in: .userDomainMask, appropriateFor: nil, create: true)
    .appendingPathComponent("favorites.json")
  try JSONEncoder().encode(favorites).write(to: url, options: [.atomic, .completeFileProtection])
}

// Chia sẻ với widget: UserDefaults trong App Group, không phải .standard
let shared = UserDefaults(suiteName: "group.vn.shop.app")
