Người dùng chưa đăng nhập mở app (giả sử bỏ qua cảnh báo kiểu của TypeScript và build vẫn chạy). Console in ra gì?

async function isLoggedIn(): Promise<boolean> {
  return false;
}

if (isLoggedIn()) {
  console.log('vào Home');
} else {
  console.log('vào Login');
}
  1. Avào Home, vì Promise là object nên luôn truthy
  2. Bvào Login, vì hàm isLoggedIn trả về false
  3. CKhông in gì, vì if tự chờ Promise có kết quả
  4. DNém lỗi, vì điều kiện của if bắt buộc là boolean
Xem đáp án
Đáp án đúng: A
Hàm async luôn trả về một Promise, kể cả khi bên trong return false. Promise là object nên truthy, và if không chờ nó settle, vì vậy nhánh vào Home chạy. JavaScript cũng không bắt điều kiện phải là boolean nên không có lỗi runtime. Phải dùng if (await isLoggedIn()) bên trong một hàm async. TypeScript bật strict có thể báo lỗi kiểu kinh điển này, nhưng Metro chỉ xoá kiểu chứ không kiểm tra nên bản build vẫn chạy và rẽ sai nhánh.
