Khi người dùng đăng xuất rồi đăng nhập tài khoản khác ngay trên cùng thiết bị (không tắt app), QA phát hiện người dùng mới thỉnh thoảng thấy thoáng dữ liệu, thông báo hoặc giỏ hàng của tài khoản trước. Bạn thiết kế cơ chế cô lập và dọn dẹp state khi đổi phiên thế nào cho triệt để?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Lỗi này xảy ra vì dữ liệu phiên nằm rải rác ở nhiều tầng ngoài một store duy nhất: cache của TanStack Query hoặc RTK Query, các store bộ nhớ như Zustand/Redux, dữ liệu lưu đĩa ở MMKV/AsyncStorage, các request đang bay dở rồi trả về sau khi đã đăng xuất, socket và listener native. Giải pháp cần xử lý đồng bộ theo ba lớp. Lớp thứ nhất là bộ điều phối phiên khi đăng xuất: huỷ toàn bộ request đang bay bằng AbortController gắn theo phiên hiện tại (hoặc kiểm tra sessionId trước khi ghi response vào cache để tránh request chậm của user cũ ghi đè), ngắt kết nối WebSocket, gỡ user context trên Sentry/Analytics và huỷ đăng ký push token theo tài khoản cũ. Lớp thứ hai là cô lập dữ liệu lưu trữ: gọi queryClient.clear() để xoá sạch cache thay vì invalidateQueries (vốn có thể kích hoạt refetch ngầm), chạy danh sách resetAllStores() đã đăng ký ở các Zustand/Redux store, và tách namespace key lưu đĩa theo userId (hoặc tạo instance MMKV riêng theo user) để không bao giờ trộn lẫn với cài đặt chung của thiết bị như ngôn ngữ hay onboarding. Lớp thứ ba rất hiệu quả ở tầng UI là gắn key={sessionId} cho cây component sau đăng nhập; khi sessionId đổi, React tự động huỷ toàn bộ cây màn hình cũ, dọn sạch mọi useState, useRef và chạy cleanup của useEffect trước khi dựng phiên mới. Cuối cùng mình viết một integration test mô phỏng user A có request chậm đang chạy rồi chuyển sang user B để xác nhận dữ liệu cũ không bao giờ lọt sang.
let sessionAbort = new AbortController();
const storeResetters = new Set<() => void>();

export const registerStoreReset = (fn: () => void) => storeResetters.add(fn);

export async function switchSessionTeardown(queryClient: QueryClient) {
  sessionAbort.abort();
  sessionAbort = new AbortController();
  socketClient.disconnect();
  queryClient.clear();
  storeResetters.forEach((reset) => reset());
  await storage.clearUserScopedKeys();
}
