Task gửi vào ExecutorService bằng submit() ném NullPointerException. Exception đó đi đâu?

ExecutorService pool = Executors.newSingleThreadExecutor();
pool.submit(() -> {
  List<String> items = null;
  System.out.println(items.size()); // NullPointerException
});
  1. APool in stack trace qua uncaught exception handler rồi chạy tiếp
  2. BBị giữ trong Future; không gọi get() thì lỗi im lặng
  3. CLàm crash app vì exception không được bắt trên worker thread
  4. DLàm pool tự shutdown() và từ chối mọi task gửi sau đó
Xem đáp án
Đáp án đúng: B
submit() bọc task trong FutureTask, exception bị bắt và lưu lại, chỉ ném ra (bọc trong ExecutionException) khi gọi future.get(). Với execute() thì khác: exception đi tới uncaught exception handler, trên Android mặc định là crash app.
