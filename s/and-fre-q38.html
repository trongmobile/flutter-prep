Coroutine là gì và khác Thread ở điểm nào? Từ khoá suspend nghĩa là gì, và viewModelScope.launch { ... } bắt đầu chạy ở thread nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Coroutine là một tác vụ bất đồng bộ nhẹ: bạn viết code tuần tự nhưng nó có thể tạm dừng (suspend) ở chỗ phải chờ rồi chạy tiếp, mà không chặn thread đang chạy nó. Thread là đơn vị do hệ điều hành quản lý, mỗi cái tốn bộ nhớ stack và chi phí chuyển ngữ cảnh nên không tạo được quá nhiều; coroutine rẻ hơn hẳn, hàng nghìn coroutine có thể chia nhau vài thread vì coroutine đang chờ sẽ nhả thread cho việc khác. suspend đánh dấu một hàm có thể tạm dừng và chỉ được gọi từ coroutine hoặc từ hàm suspend khác; từ khoá này không tự chuyển thread, hàm vẫn chạy trên thread của nơi gọi cho tới khi bạn dùng withContext. launch khởi động coroutine kiểu bắn-và-quên và trả về Job. viewModelScope mặc định chạy trên Dispatchers.Main.immediate nên block bên trong bắt đầu ở main thread và tự bị huỷ khi ViewModel bị xoá. Bẫy hay gặp: tưởng launch là chạy nền, trong khi gọi một hàm chặn (blocking) ngay trong đó vẫn làm đứng UI.
class UserViewModel(private val repo: UserRepository) : ViewModel() {
  private val _name = MutableStateFlow("")
  val name: StateFlow<String> = _name

  fun load() {
    viewModelScope.launch {          // bắt đầu trên main thread
      val user = repo.fetchUser()    // hàm suspend: tạm dừng ở đây, main thread vẫn rảnh
      _name.value = user.name        // quay lại main để cập nhật state
    }
  }
}

class UserRepository(private val api: LegacyUserApi) {
  suspend fun fetchUser(): User = withContext(Dispatchers.IO) {
    api.getUserBlocking()            // lời gọi chặn: chuyển sang thread IO
  }
}
