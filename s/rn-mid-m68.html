Với Expo Router, màn app/product/[id].tsx đang mở sản phẩm 1, rồi người dùng router.push('/product/2') nên có thêm một màn sản phẩm 2 nằm phía trên. Màn sản phẩm 1 (nằm dưới, vẫn còn mounted) đọc id như dưới đây. Nó hiển thị id nào?

export default function ProductScreen() {
  const { id } = useGlobalSearchParams<{ id: string }>();

  return <Text>Sản phẩm {id}</Text>;
}
  1. A1, vì mỗi màn luôn giữ params của chính nó dù dùng hook nào để đọc
  2. BVẫn là 1 cho tới khi màn sản phẩm 1 được focus lại rồi render lại
  3. Cundefined, vì màn bị che nên Expo Router xoá params của màn đó
  4. D2, vì hook này lấy params của route đang được focus trên toàn app
Xem đáp án
Đáp án đúng: D
useGlobalSearchParams trả về params của URL hiện tại trên toàn app, nên khi màn khác được push lên, màn dưới (vẫn mounted) cũng cập nhật theo và đọc id mới. useLocalSearchParams trả về params gắn với route của chính màn hình đó nên vẫn giữ 1. Màn có fetch hay hiển thị dữ liệu theo id nên dùng useLocalSearchParams; hook global dành cho trường hợp thật sự cần theo dõi URL toàn cục (như analytics). Expo Router không xoá params của màn bị che.
