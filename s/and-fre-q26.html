Class trong Kotlin khác Java ở những điểm nào? Vì sao muốn kế thừa phải thêm open, và primary constructor cùng khối init hoạt động ra sao?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Class và method trong Kotlin mặc định là final: muốn cho kế thừa phải khai báo open class, muốn cho override phải đánh dấu open fun, và lớp con viết override. Primary constructor nằm ngay sau tên class; tham số có val/var tự thành property, không có thì chỉ là tham số dùng được trong init và khi khởi tạo property. Khối init chạy lúc tạo object, theo đúng thứ tự khai báo và xen kẽ với các property initializer. Giá trị mặc định cho tham số thay được phần lớn constructor overload kiểu Java; constructor phụ (constructor(...)) bắt buộc gọi về primary bằng this(...). Chỉ khi kế thừa class Android có nhiều constructor như View thì mới cần constructor phụ hoặc @JvmOverloads constructor. Kotlin cũng không có từ khoá new: gọi thẳng Dog("Mực").
open class Animal(val name: String) {
  open fun sound() = "..."
}

class Dog(name: String, val age: Int = 1) : Animal(name) {
  init {
    println("Tạo Dog $name") // chạy khi khởi tạo object
  }

  override fun sound() = "Gâu"
}

fun main() {
  val d = Dog("Mực")           // age dùng giá trị mặc định 1
  println("${d.name} ${d.age} ${d.sound()}") // Mực 1 Gâu
}
