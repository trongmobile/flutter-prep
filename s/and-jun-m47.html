App có targetSdk 34 và không cấu hình Network Security Config. Request OkHttp gọi tới http://api.example.com/users (HTTP, không phải HTTPS) trên Android 14 sẽ thế nào?

  1. AChạy bình thường, Android chỉ in cảnh báo bảo mật vào Logcat
  2. BBị chặn với UnknownServiceException vì cleartext HTTP bị tắt mặc định
  3. CTự động nâng cấp lên HTTPS rồi mới gửi request tới server
  4. DChạy bình thường nếu app đã khai báo quyền INTERNET trong manifest
Xem đáp án
Đáp án đúng: B
Từ Android 9, app có targetSdk từ 28 trở lên bị chặn cleartext traffic theo mặc định: OkHttp ném UnknownServiceException ("CLEARTEXT communication ... not permitted by network security policy"), quyền INTERNET không đổi được điều đó. Cách đúng là chuyển server sang HTTPS; nếu chỉ cần cho domain dev thì khai báo <domain-config cleartextTrafficPermitted="true"> giới hạn trong Network Security Config, thay vì bật usesCleartextTraffic cho cả app.
