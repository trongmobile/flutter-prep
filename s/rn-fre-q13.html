Controlled TextInput là gì? Vì sao form đăng nhập thường được làm theo kiểu controlled?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Controlled nghĩa là nội dung ô nhập lấy từ state qua prop value, và mỗi lần người dùng gõ thì onChangeText cập nhật lại state; state trở thành nguồn dữ liệu duy nhất. Nhờ vậy dễ validate ngay khi gõ, format dữ liệu, reset form hoặc disable nút submit khi dữ liệu chưa hợp lệ. onChangeText nhận thẳng chuỗi mới, còn onChange nhận event và text nằm ở e.nativeEvent.text. Bẫy: truyền value mà không cập nhật state trong onChangeText thì ô nhập luôn bị ép về giá trị cũ, gõ không đổi được; nếu chỉ cần giá trị ban đầu thì dùng defaultValue (uncontrolled).
function LoginForm({ onLogin }: { onLogin: (email: string) => void }) {
  const [email, setEmail] = useState('');
  const isValid = email.includes('@');
  return (
    <View>
      <TextInput
        value={email}
        onChangeText={setEmail} // nhận thẳng chuỗi mới
        placeholder="Email"
        autoCapitalize="none"
      />
      <Button title="Đăng nhập" disabled={!isValid} onPress={() => onLogin(email)} />
    </View>
  );
}
