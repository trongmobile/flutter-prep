Nhận định nào đúng về extension function trong Kotlin?

  1. ANó thêm method thật vào bytecode của class gốc
  2. BTrùng signature với member thì extension được ưu tiên
  3. CNó không truy cập được member private của class
  4. DChỉ viết được cho class do chính mình khai báo
Xem đáp án
Đáp án đúng: C
Extension được compile thành hàm static nhận object làm tham số đầu tiên, nên chỉ thấy những member mà code bên ngoài class thấy được và không hề sửa class gốc. Khi trùng signature thì member function luôn thắng; còn chính vì không cần sửa source nên ta viết được extension cho String, View hay class của thư viện.
