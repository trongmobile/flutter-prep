App hiện màn hình đỏ TypeError: undefined is not an object (evaluating 'user.name'), còn thỉnh thoảng có hộp vàng ở cuối màn hình. Bạn đọc màn hình đỏ thế nào, LogBox đỏ và vàng khác nhau ra sao, và dùng những công cụ debug cơ bản nào?

Tự trả lời thành tiếng trước, rồi mới xem đáp án mẫu nhé.

Xem đáp án mẫu
Màn hình đỏ (LogBox) hiện khi có lỗi chưa được bắt hoặc console.error, và chỉ có ở bản dev. Đọc từ trên xuống: dòng đầu là loại lỗi cùng thông điệp (ở đây nghĩa là user đang undefined khi truy cập .name), phần Call Stack liệt kê chuỗi hàm; hãy tìm dòng đầu tiên thuộc file của bạn (bỏ qua node_modules) để biết file và số dòng, rồi tự hỏi vì sao biến đó chưa có dữ liệu, thường là do API chưa trả về lúc render lần đầu. Hộp vàng là cảnh báo (console.warn hoặc cảnh báo của React như thiếu key): app vẫn chạy nhưng nên sửa; LogBox.ignoreLogs chỉ ẩn thông báo chứ không sửa lỗi. Dev Menu mở bằng Cmd+D (iOS Simulator), Cmd+M hoặc Ctrl+M (Android Emulator), lắc máy thật hoặc nhấn d trong terminal Metro; từ đó có Reload, bật tắt Fast Refresh và mở DevTools. console.log xem ở tab Console của React Native DevTools (các bản RN cũ hơn còn in ra terminal Metro); trong DevTools còn đặt được breakpoint và có tab Components để xem cây component cùng props, state, hooks hiện tại. Mẹo: đặt log hoặc breakpoint ngay trước dòng lỗi để nhìn giá trị thật thay vì đoán.
function Profile({ userId }: { userId: string }) {
  const [user, setUser] = useState<User | null>(null);

  useEffect(() => {
    fetchUser(userId).then(setUser);
  }, [userId]);

  console.log('Profile render, user =', user); // lần render đầu in ra null

  // return <Text>{user.name}</Text>; // lỗi: lúc render đầu user còn null
  if (!user) return <ActivityIndicator />;
  return <Text>{user.name}</Text>;
}
