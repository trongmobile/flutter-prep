Dùng Gesture Handler cùng Reanimated, callback onEnd của gesture (chạy dưới dạng worklet trên UI thread) gọi thẳng setScore của React. Điều gì xảy ra?

const [score, setScore] = useState(0);
const offset = useSharedValue(0);

const pan = Gesture.Pan()
  .onUpdate((e) => {
    offset.value = e.translationX;
  })
  .onEnd(() => {
    setScore((s) => s + 1); // gọi từ UI thread
  });
  1. AChạy bình thường vì Reanimated tự chuyển mọi hàm về JS thread
  2. BsetScore chạy trên UI thread nên state được cập nhật nhanh hơn
  3. CBáo lỗi vì hàm JS thường không gọi đồng bộ được từ UI runtime
  4. DKhông lỗi, nhưng setScore bị bỏ qua và score giữ nguyên
Xem đáp án
Đáp án đúng: C
Worklet chạy trong một JS runtime riêng trên UI thread; hàm không phải worklet như setScore không thể gọi thẳng từ đó và sẽ báo lỗi kiểu 'Tried to synchronously call a non-worklet function on the UI thread'. Cần lên lịch về JS thread bằng runOnJS(setScore)(...) (các bản mới chuyển sang API tương đương của react-native-worklets) hoặc cho gesture chạy trên JS bằng .runOnJS(true).
